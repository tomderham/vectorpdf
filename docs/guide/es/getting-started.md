# Primeros pasos con VectorPDF

VectorPDF requiere macOS 15 o posterior y un chip de Apple. Para instalarlo, arrástralo a la carpeta Aplicaciones.

¿Es tu primera vez con VectorPDF? Elige Help > Take the Tour, o haz clic en New here? Take the Tour en una pantalla Start vacía. Se abre un breve documento de muestra en el que puedes probar estas funciones y hacer anotaciones.

## Abrir tu primer PDF

Cuando VectorPDF se abre sin ningún documento, muestra la pantalla de inicio. Haz cualquiera de estas cosas:

- Arrastra un PDF a la zona para soltar archivos.
- Haz clic en la zona para soltar archivos y elige un archivo.
- Pulsa ⌘O.

También puedes abrir un PDF desde el Finder con [Open With](open-documents.md), o elegir uno en Tab Groups, Favorites o Recent Documents en la pantalla de inicio.

## Cinco cosas para probar

1. **Mantén pulsada la tecla Comando sobre un enlace.** Mueve el puntero sobre una referencia a una ecuación, figura, tabla o cita y mantén pulsada la tecla ⌘ para [previsualizar su destino](link-peek.md). Al soltarla, la previsualización se cierra.
2. **Busca.** Pulsa ⌘F. Los [resultados](search.md) aparecen en la barra lateral a medida que se encuentran, y ⌘G te lleva de uno a otro.
3. **Guarda el lugar donde estás.** Selecciona texto y pulsa ⌘B para crear un [ancla](anchors.md) a la que puedas volver.
4. **Anota.** Selecciona texto y pulsa ⇧⌘H para [resaltarlo](text-markup.md), o pulsa ⇧⌘A para mostrar la barra de herramientas Markup.
5. **Abre dos documentos relacionados como pestañas.** Pulsa ⌥⌘O para abrir el segundo y luego haz clic con el botón derecho en una referencia de texto simple como “Section 4.2 of the Master Agreement” para [encontrarla en la otra pestaña](cross-document-references.md).

## Orientarte en la app

La barra de menús, la barra lateral y las barras de herramientas cubren la mayoría de las funciones, y al hacer clic con el botón derecho aparecen los comandos adecuados para lo que hay bajo el puntero. Consulta [La ventana de VectorPDF](the-window.md) para hacer un recorrido, [Menús de clic derecho](right-click-menus.md) para ver qué hay en cada menú y [Atajos de teclado](keyboard-shortcuts.md) para ver la lista completa.

Para buscar en esta guía, usa el campo Buscar en esta guía de la parte superior de la barra lateral. El campo de búsqueda de la parte superior de esta ventana busca en la ayuda de todas tus apps.
