# Atajos de teclado

Muchos de estos comandos también están en un menú de clic derecho, como se indica a continuación. Consulta [Menús de clic derecho](right-click-menus.md).

## Documentos

| Acción | Atajo |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Compare Documents | Menú File, o haz clic con el botón derecho en el título del documento y elige Compare With |
| Insert Pages from PDF | ⌥⌘I, o clic con el botón derecho en una miniatura |
| Duplicate Pages | ⇧⌘D, o clic con el botón derecho en una miniatura |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Añadir a favoritos o quitar de favoritos | ⌘D, o clic con el botón derecho en el título del documento |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## Navegación

| Acción | Atajo |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow o Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow o Right Arrow |
| First Page | ⌘Up Arrow o ⌘Home |
| Last Page | ⌘Down Arrow o ⌘End |
| Cambio anterior o siguiente, al comparar documentos | ⌥⌘Up Arrow o ⌥⌘Down Arrow, o las flechas de la pestaña Changes |
| Avanzar o retroceder por la página | Space o ⇧Space |
| Next Tab | ⇧⌘] o ⌃Tab |
| Previous Tab | ⇧⌘[ o ⇧⌃Tab |

| Zoom Out | ⌘− |

## Búsqueda y texto

| Acción | Atajo | Clic derecho |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G, o Return en el campo de búsqueda | |
| Find Previous | ⇧⌘G, o ⇧Return en el campo de búsqueda | |
| Copy | ⌘C | Texto seleccionado |
| Highlight | ⇧⌘H | Texto seleccionado |
| Underline | ⇧⌘U | Texto seleccionado |
| Strikethrough | ⇧⌘X | Texto seleccionado |
| Stop Speaking | ⌥⌘. | Texto seleccionado |
| Add Anchor | ⌘B | Selección, enlace o página, como Create Anchor |

## Ratón y trackpad

| Acción | Gesto |
| --- | --- |
| Previsualizar un enlace | Mantener pulsada la tecla ⌘ sobre él, o hacer clic fuerte |
| Abrir un enlace en una ventana nueva | ⌘-clic |
| Seleccionar una palabra | Doble clic |
| Seleccionar una línea | Triple clic |
| Seleccionar un área | Arrastrar con ⌥ pulsada |
| Abrir los comentarios de una anotación | Hacer doble clic en ella, salvo en un cuadro de texto o una llamada |
| Zoom | Pellizcar |

## Anotaciones y mediciones

| Acción | Atajo | Clic derecho |
| --- | --- | --- |
| Deshacer o rehacer un cambio en una anotación | ⌘Z o ⇧⌘Z | |
| Editar el cuadro de texto o la llamada seleccionados | Return | La anotación |
| Eliminar la anotación seleccionada | Delete | La anotación |
| Mover la anotación seleccionada | Teclas de flecha, o ⇧Arrow keys para moverla 10 puntos | |
| Terminar un perímetro o un área | Return | |
| Invertir Ortho Lock (0°, 45° o 90°) en una línea | Mantener pulsada la tecla ⇧ | |
| Dibujar un cuadrado o círculo, o una línea en un múltiplo de 45° | Mantener pulsada ⇧ al arrastrar con la herramienta Shapes | |
| Cancelar o salir de la herramienta actual | Escape | |
