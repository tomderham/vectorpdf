# Guía del usuario de VectorPDF

para macOS

VectorPDF es un lector de PDF rápido para artículos técnicos, especificaciones, contratos y planos. Mantén pulsada la tecla Comando sobre una referencia para ver a qué apunta, sin perder la página en la que estás. También puedes anotar, medir, censurar y reorganizar archivos PDF, todo en tu Mac.

> **Nota:** Esta guía se ha traducido automáticamente del inglés. La interfaz de VectorPDF solo está disponible en inglés, por lo que los nombres de menús y botones aparecen en inglés, tal como se ven en pantalla.
