# Desplazarse por un documento

## Desplazarse y pasar páginas

Desplázate con el trackpad o el ratón. VectorPDF solo prepara las páginas cercanas a donde estás leyendo, por lo que incluso los documentos muy largos siguen siendo rápidos.

Con el teclado:

| Teclas | Acción |
| --- | --- |
| Left Arrow, Right Arrow | Página anterior o siguiente |
| Up Arrow, Down Arrow | Desplazarse dentro de una página más alta que la ventana y luego pasar a la página siguiente. Si la página cabe en la ventana, avanzar de página en página. |
| Page Up, Page Down | Desplazarse un tramo mayor y luego pasar a la página siguiente |
| Space, ⇧Space | Avanzar o retroceder, igual que Page Down y Page Up |
| ⌥Up Arrow, ⌥Down Arrow, ⌥Left Arrow, ⌥Right Arrow | Página anterior o siguiente |
| ⌘Up Arrow, ⌘Down Arrow | Primera o última página |

En Two-Page Mode, estas teclas pasan una doble página completa.

## Ir a una página

Haz clic en el número de página de la barra de herramientas, escribe la página que quieres y pulsa Return. Pulsa Escape para cancelar.

## Volver al lugar donde estabas

Después de seguir un enlace o saltar a un resultado, elige Go > Back (⌘[) para volver. Go > Forward (⌘]) te lleva en sentido contrario.

## Usar la estructura del documento

- [El esquema](outline-and-thumbnails.md) te lleva a cualquier sección.
- [Las miniaturas](outline-and-thumbnails.md) muestran todas las páginas.
- [Las anclas](anchors.md) marcan los lugares a los que quieres volver.
- [Link Peek](link-peek.md) te muestra el destino de un enlace sin salir de tu página.
