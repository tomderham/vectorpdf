# Imprimir

Elige File > Print o pulsa ⌘P.

En el cuadro de diálogo de impresión, elige PDF Options para ver:

- **Auto Rotate:** gira las páginas para que se ajusten al papel.
- **Scale to Fit:** ajusta cada página al papel.
- **Scale:** imprime al porcentaje que escribas.

VectorPDF imprime con el mismo motor que usa en pantalla, por lo que el resultado coincide con lo que ves.
