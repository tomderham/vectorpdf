# Propiedades del documento

Elige File > Document Properties o pulsa ⌘I. Elige una pestaña en la parte superior:

- **General:** el título, el autor, el asunto, las palabras clave, las fechas, la aplicación con la que se creó, la ubicación del archivo y su almacenamiento.
- **Security:** el cifrado del documento y si permite imprimir, copiar, hacer cambios, añadir comentarios, completar formularios, extraer contenido para accesibilidad y ensamblar páginas.
- **Page Geometry:** los cuadros MediaBox, CropBox, BleedBox, TrimBox y ArtBox de cualquier página, en puntos, pulgadas o milímetros.
- **Fonts:** las fuentes del documento, su tipo y codificación, y si cada una está incrustada. Usa el campo de filtro para encontrar una.
