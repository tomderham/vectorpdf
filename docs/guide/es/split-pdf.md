# Dividir un PDF

1. Elige File > Split PDF.
2. En Split Method, elige una opción:
   - **Every N Pages:** un archivo nuevo cada cierto número de páginas.
   - **Single Pages:** un archivo por cada página.
   - **Page Ranges:** escribe números o intervalos de página separados por comas, como `1-5, 6-12, 13-20`.
3. En Save Location, haz clic en Choose para elegir una carpeta.
4. En File Naming, escribe un prefijo y elige un estilo: Part Number o Page Range. Output Preview muestra los archivos que se crearán.
5. Haz clic en Split PDF.

El documento original no cambia. Cuando termine la división, haz clic en Reveal in Finder para ver los archivos.
