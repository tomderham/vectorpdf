# Cambiar los colores del PDF

VectorPDF puede cambiar el aspecto de las páginas de un documento, sea cual sea el aspecto de macOS. Esto resulta útil para leer en una habitación a oscuras. No modifica el PDF.

Elige View > PDF Color, o usa el ajuste PDF Color en [Settings](settings.md), y elige una opción:

- **Follow System:** las páginas siguen el aspecto de macOS.
- **Light:** las páginas se muestran tal como las define el documento.
- **Dark:** los colores de las páginas se invierten conservando los tonos, de modo que los diagramas y los resaltados se siguen reconociendo.
- **Sepia:** las páginas adquieren un tono cálido de papel.

Al imprimir y exportar se usan los colores originales del documento.
