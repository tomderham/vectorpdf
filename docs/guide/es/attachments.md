# Archivos adjuntos a un PDF

Un PDF puede llevar otros archivos dentro: una hoja de cálculo con un informe, un modelo CAD con un juego de planos o los datos de una factura electrónica. Cuando un documento tiene archivos adjuntos, la pestaña Attachments (un clip) aparece en la parte superior de la barra lateral. Un documento de una o dos páginas con archivos adjuntos se abre en la pestaña Attachments.

Cada adjunto muestra su nombre y, cuando el PDF los incluye, su descripción, su tamaño y la página a la que está adjunto. Mantén el puntero sobre uno para ver qué tipo de archivo es y su fecha.

| Para | Haz lo siguiente |
| --- | --- |
| Previsualizar un adjunto | Haz doble clic en él, o selecciónalo y pulsa la barra espaciadora |
| Previsualizar el siguiente o el anterior | Con Quick Look abierto, pulsa la tecla de flecha abajo o arriba |
| Abrirlo en su app | Haz clic con el botón derecho en él y elige Open |
| Guardar una copia | Haz clic con el botón derecho en él y elige Save As…, o arrástralo al Finder |
| Guardarlos todos | Haz clic en Save All… en la parte superior de la pestaña y elige una carpeta |
| Ir a su página | Haz clic con el botón derecho en él y elige Show on Page |

> **Advertencia:** Un adjunto puede ser cualquier tipo de archivo, incluida una app o un script. Abre solo archivos de confianza. VectorPDF marca como descargados los archivos que extrae de un PDF, para que macOS compruebe las apps y los scripts antes de que se ejecuten, como hace con los archivos de internet.

## Facturas electrónicas

Las facturas ZUGFeRD y Factur-X llevan sus datos en un archivo XML, normalmente llamado `factur-x.xml` o `zugferd-invoice.xml`. Aparece con los demás adjuntos, así que puedes guardarlo para tu software de contabilidad. VectorPDF no muestra por sí mismo los detalles de la factura.
