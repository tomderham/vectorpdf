# Seleccionar, copiar y consultar texto

## Seleccionar texto

- **Arrastra** sobre el texto. Las selecciones siguen el orden de lectura, por lo que se mantienen en una sola columna en los diseños de varias columnas y omiten los números de línea del margen. Pueden abarcar varias páginas.
- Haz **doble clic** para seleccionar una palabra o **triple clic** para seleccionar una línea.
- **Mantén pulsada la tecla ⌥ y arrastra** para seleccionar un área rectangular, como una figura o una tabla.

Pulsa Escape para borrar la selección.

En una página escaneada, puedes seleccionar el texto una vez que se haya [reconocido](scanned-pages.md).

## Copiar

Pulsa ⌘C, o haz clic con el botón derecho en el texto seleccionado y elige Copy Text.

Haz clic con el botón derecho en una selección rectangular para ver más opciones:

- **Copy Extracted Text** copia el texto que haya en el área.
- **Copy Screenshot** copia el área como imagen.
- **Save Screenshot As** guarda el área como archivo de imagen.

## Consultar y traducir

Haz clic con el botón derecho en el texto seleccionado y elige:

- **Look Up** para ver una definición del diccionario.
- **Translate Selection** para traducirlo.

## Escuchar el texto en voz alta

Selecciona texto y elige Edit > Speech > Start Speaking, o haz clic con el botón derecho y elige Start Speaking. Para detenerlo, elige Stop Speaking o pulsa ⌥⌘. (Opción-Comando-punto).

## Otras acciones

El menú que aparece al hacer clic con el botón derecho en el texto seleccionado también incluye comandos para [resaltar, subrayar o tachar](text-markup.md) el texto, [crear un ancla](anchors.md) y abrir la selección en una ventana nueva.
