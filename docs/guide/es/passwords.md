# Contraseñas y cifrado

## Abrir un PDF protegido

VectorPDF te pide la contraseña cuando abres un PDF protegido. Si haces clic en Cancel, el documento permanece cerrado.

## Cifrar una copia

1. Elige File > Save Encrypted with Password (⌥⌘S).
2. Elige un nombre y una ubicación.
3. Escribe la contraseña dos veces y haz clic en Encrypt & Save.

La copia se cifra con AES-256 y necesita la contraseña para abrirse.

> **Advertencia:** Guarda la contraseña en un lugar seguro. Si la pierdes, no hay forma de recuperar un PDF cifrado.

## Ver los permisos de un documento

Para ver qué permite el autor de un documento, como imprimir o copiar, elige File > Document Properties (⌘I) y haz clic en Security. Consulta [Propiedades del documento](document-properties.md).
