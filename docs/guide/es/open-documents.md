# Abrir documentos

## Abrir un PDF

- **En una ventana nueva:** elige File > Open PDF o pulsa ⌘O.
- **En una pestaña nueva:** elige File > Open PDF in New Tab o pulsa ⌥⌘O.
- **Desde el Finder:** haz clic con el botón derecho en un PDF y elige Open With > VectorPDF. Para abrir todos los PDF en VectorPDF, selecciona un PDF, elige File > Get Info en el Finder, cambia “Open with” y haz clic en Change All.
- **Arrastrando:** arrastra un PDF a la pantalla de inicio para abrirlo ahí, o sobre un documento abierto para abrirlo en una pestaña nueva.
- **Desde una lista:** elige File > Open Recent o usa el menú [Favorites](favorites-and-tab-groups.md). En la pantalla de inicio, haz clic con el botón derecho en un documento para abrirlo en una pestaña o ventana nueva.

## Libros electrónicos, cómics y documentos XPS

VectorPDF también abre libros electrónicos EPUB y FictionBook (FB2), archivos de cómic CBZ y documentos XPS, de las mismas formas que un PDF. Un libro electrónico se compone en páginas para leerlo.

Puedes leer estos documentos, seguir su índice, buscar en ellos, seleccionar y copiar su texto, y añadir [anclas](anchors.md). Se abren solo para lectura: VectorPDF no puede guardarlos, así que el marcado, la medición, la censura y la edición de páginas no están disponibles, y Save aparece atenuado.

## PDF protegidos con contraseña

VectorPDF te pide la contraseña cuando abres un PDF protegido. Consulta [Contraseñas y cifrado](passwords.md).

## PDF en el almacenamiento en la nube

VectorPDF reconoce los archivos de iCloud Drive, Google Drive, Dropbox, OneDrive y Box. Si un archivo aún no está en tu Mac, VectorPDF lo descarga antes de abrirlo y te muestra el progreso. Si la descarga no termina, verás un mensaje y podrás volver a intentarlo cuando tengas conexión.

## Cuando un archivo cambia

VectorPDF vigila cada archivo abierto. Si otra app cambia el archivo, el documento se vuelve a cargar por sí solo. Esto resulta útil si generas un PDF desde LaTeX u otra herramienta y quieres mantenerlo abierto.

Si tienes cambios sin guardar, VectorPDF te pregunta si quieres usar **Reload from Disk**, con lo que pierdes tus cambios, o **Keep My Changes**.

Si mueves o cambias el nombre de un archivo en el Finder, el documento abierto lo sigue.

## Cerrar un documento

Cierra una pestaña o ventana como de costumbre. Si hay cambios sin guardar, VectorPDF te pregunta si quieres guardarlos. VectorPDF recuerda [dónde estabas](reading-positions.md) para la próxima vez.
