# Pestañas y ventanas

## Pestañas

VectorPDF usa las pestañas de ventana estándar de macOS.

- **Pestaña nueva:** pulsa ⌘T o haz clic en el botón + de la barra de pestañas.
- **Abrir un PDF en una pestaña nueva:** pulsa ⌥⌘O o arrástralo sobre un documento abierto.
- **Ventana nueva:** pulsa ⌘N para abrir una ventana vacía, o ⌘O para abrir un PDF en una ventana nueva.
- **Cambiar de pestaña:** pulsa ⇧⌘] para la pestaña siguiente y ⇧⌘[ para la anterior (Go > Next Tab y Go > Previous Tab). ⌃Tab y ⇧⌃Tab también funcionan.

Para guardar las pestañas abiertas como grupo, haz clic con el botón derecho en el título del documento y elige Save All Open Tabs as a Group. Consulta [Favoritos y grupos de pestañas](favorites-and-tab-groups.md).

Mantener los documentos relacionados como pestañas de una misma ventana también permite a VectorPDF [seguir las referencias entre ellos](cross-document-references.md).

## Encontrar una ventana abierta

El menú Window y el icono de VectorPDF en el Dock muestran tus ventanas abiertas, con las pestañas de cada una.

## Ventanas de ancla {#anchor-windows}

Puedes abrir cualquier lugar de un documento en una pequeña ventana propia, para tener a la vista una figura o una definición mientras lees:

- Haz ⌘-clic en un enlace.
- Haz clic con el botón derecho en un enlace, una selección, un lugar de la página, un resultado de búsqueda o una entrada del esquema, y elige **Open in New Window**.

Estas ventanas tienen un banner en la parte superior. Haz clic en él para volver al lugar que muestra. Haz clic en **Close all Child Windows** en el banner para cerrar todas las ventanas abiertas desde el mismo documento. También se cierran cuando cierras el documento del que proceden.

VectorPDF no abre duplicados: si el lugar ya está abierto en una ventana, trae esa ventana al frente.
