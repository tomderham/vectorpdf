# Menús de clic derecho

Haz clic con el botón derecho, o haz clic con la tecla Control pulsada, para ver los comandos correspondientes a lo que hay bajo el puntero. El menú que aparece depende de dónde hagas clic.

## En el documento

| Clic derecho en | Comandos |
| --- | --- |
| Texto seleccionado | Copy Text, Look Up, Translate Selection, Start Speaking o Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un área seleccionada | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un enlace | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un resaltado, subrayado o tachado | Comments… y el comando Remove correspondiente |
| Un cuadro de texto | Comments…, Edit Text Box y el comando de eliminación |
| Una llamada | Comments…, Edit Callout Note, Line Ending y el comando de eliminación |
| Una nota, o el contorno de un rectángulo, óvalo o nube de revisión | Comments… y el comando para eliminar |
| Una línea o flecha | Comments…, Line Ending y el comando para eliminar |
| Un dibujo, sello o medición | Comments… y el comando de eliminación |
| Una forma, nube, línea, nota, sello o cuadro de texto guardado antes en el documento, o creado en otra app | Comments…, Line Ending para una línea, y el comando para eliminar |
| Un resaltado, dibujo o medición guardado antes en el documento, o creado en otra app | Comments… y los comandos de cualquier otro lugar de la página |
| Cualquier otro lugar de la página | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

Si haces clic con el botón derecho en una referencia de texto simple y hay documentos relacionados abiertos en otras pestañas, el menú también incluye comandos para [ir a ella o encontrarla](cross-document-references.md).

En un PDF creado con LaTeX y SyncTeX activado, todos los menús del documento empiezan por **Show in Editor**, que abre la [línea de código](latex.md) del lugar en el que hiciste clic.

En un documento con [capas](layers.md), el menú de una anotación también tiene **Layer**, para moverla a otra capa o a ninguna.

## En la barra lateral

| Clic derecho en | Comandos |
| --- | --- |
| Una entrada del esquema | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Una miniatura | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up, Move Page Down, Delete Page. Con varias páginas seleccionadas, los comandos indican cuántas, como Delete 3 Pages. Consulta [Reorganizar páginas](pages.md). |
| Un resultado de búsqueda | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un ancla | Open in New Window o Close Window, Copy Text, Copy Screenshot, Delete Anchor |
| Una anotación en la pestaña Comments | Show on Page, Comments…, Delete |
| Una capa en la pestaña Layers | Put New Annotations Here o Stop Putting New Annotations Here. Consulta [Mostrar y ocultar capas](layers.md). |
| Un adjunto en la pestaña Attachments | Quick Look, Open, Save As… y, para un archivo adjunto a una página, Show on Page. Consulta [Archivos adjuntos a un PDF](attachments.md). |

## En la ventana

| Clic derecho en | Comandos |
| --- | --- |
| El título del documento, o una parte vacía de la barra de herramientas | Añadir a favoritos o quitar de favoritos, Save All Open Tabs as a Group, Update Group “nombre” with Open Tabs, Compare With (consulta [Comparar dos documentos](compare-documents.md)), y tus grupos de pestañas y favoritos |
| Una fila de la pantalla de inicio | Open, Open in New Tab, Open in New Window, Show in Finder, y Remove o Delete |

Algunos comandos solo aparecen cuando corresponden. Por ejemplo, Save All Open Tabs as a Group requiere más de una pestaña, y los comandos de anclas no están disponibles en una ventana abierta desde un ancla.
