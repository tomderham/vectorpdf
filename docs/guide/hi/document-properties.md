# दस्तावेज़ की प्रॉपर्टी

File > Document Properties चुनें, या ⌘I दबाएँ। ऊपर से कोई टैब चुनें:

- **General:** शीर्षक, लेखक, विषय, कीवर्ड, तारीखें, इसे बनाने वाला ऐप्लिकेशन, फ़ाइल का स्थान और उसका स्टोरेज।
- **Security:** दस्तावेज़ का एन्क्रिप्शन, और यह कि वह प्रिंट करने, कॉपी करने, बदलाव करने, टिप्पणी करने, फ़ॉर्म भरने, ऐक्सेसिबिलिटी के लिए सामग्री निकालने और पेज असेंबली की अनुमति देता है या नहीं।
- **Page Geometry:** किसी भी पेज के MediaBox, CropBox, BleedBox, TrimBox और ArtBox, पॉइंट, इंच या मिलीमीटर में।
- **Fonts:** दस्तावेज़ के फ़ॉन्ट, उनका प्रकार और एन्कोडिंग, और यह कि हर फ़ॉन्ट एम्बेड किया गया है या नहीं। किसी फ़ॉन्ट को ढूँढने के लिए फ़िल्टर फ़ील्ड का उपयोग करें।
