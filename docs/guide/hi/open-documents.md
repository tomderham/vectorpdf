# दस्तावेज़ खोलें

## PDF खोलें

- **नई विंडो में:** File > Open PDF चुनें, या ⌘O दबाएँ।
- **नए टैब में:** File > Open PDF in New Tab चुनें, या ⌥⌘O दबाएँ।
- **Finder से:** किसी PDF पर राइट-क्लिक करें, फिर Open With > VectorPDF चुनें। सभी PDF को VectorPDF में खोलने के लिए, कोई PDF चुनें, Finder में File > Get Info चुनें, और “Open with” को बदलें।
- **ड्रैग करके:** किसी PDF को वहीं खोलने के लिए उसे Start स्क्रीन पर ड्रैग करें, या नए टैब में खोलने के लिए किसी खुले दस्तावेज़ पर ड्रैग करें।
- **सूची से:** File > Open Recent चुनें, या [Favorites](favorites-and-tab-groups.md) मेनू का उपयोग करें। Start स्क्रीन पर किसी दस्तावेज़ को नए टैब या विंडो में खोलने के लिए उस पर राइट-क्लिक करें।

## पासवर्ड से सुरक्षित PDF

जब आप कोई सुरक्षित PDF खोलते हैं, तो VectorPDF पासवर्ड माँगता है। [पासवर्ड और एन्क्रिप्शन](passwords.md) देखें।

## क्लाउड स्टोरेज में PDF

VectorPDF iCloud Drive, Google Drive, Dropbox, OneDrive और Box में मौजूद फ़ाइलों को पहचानता है। अगर कोई फ़ाइल अभी आपके Mac पर नहीं है, तो VectorPDF उसे खोलने से पहले डाउनलोड करता है और आपको प्रगति दिखाता है। अगर डाउनलोड पूरा नहीं होता, तो आपको एक संदेश दिखेगा, और कनेक्ट होने पर आप फिर से कोशिश कर सकते हैं।

## जब कोई फ़ाइल बदलती है

VectorPDF हर खुली फ़ाइल पर नज़र रखता है। अगर कोई दूसरा ऐप फ़ाइल बदलता है, तो दस्तावेज़ अपने आप रीलोड हो जाता है। यह तब उपयोगी है जब आप LaTeX या किसी अन्य टूल से PDF बना रहे हों और उसे खुला रखना चाहते हों।

अगर आपके बदलाव सहेजे नहीं गए हैं, तो VectorPDF पूछता है कि **Reload from Disk** करना है, जिससे आपके बदलाव खो जाएँगे, या **Keep My Changes** करना है।

अगर आप Finder में किसी फ़ाइल को ले जाते हैं या उसका नाम बदलते हैं, तो खुला दस्तावेज़ भी उसके साथ जुड़ा रहता है।

## दस्तावेज़ बंद करें

टैब या विंडो को सामान्य तरीके से बंद करें। अगर बदलाव सहेजे नहीं गए हैं, तो VectorPDF पूछता है कि उन्हें सहेजना है या नहीं। VectorPDF अगली बार के लिए याद रखता है कि [आप कहाँ थे](reading-positions.md)।
