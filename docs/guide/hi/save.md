# अपने बदलाव सहेजें

मार्कअप, फ़ॉर्म की प्रविष्टियाँ, पेज के बदलाव और रिडैक्शन तब तक आपकी फ़ाइल में नहीं लिखे जाते जब तक आप सहेजते नहीं। जिस विंडो में बदलाव सहेजे नहीं गए हैं, उसके बंद करने वाले बटन में एक बिंदु दिखता है।

| यह करने के लिए | यह करें |
| --- | --- |
| सहेजें | File > Save चुनें, या ⌘S दबाएँ |
| नए नाम से कॉपी सहेजें | File > Save As चुनें, या ⇧⌘S दबाएँ |
| पासवर्ड से सुरक्षित कॉपी सहेजें | File > [Save Encrypted with Password](passwords.md) चुनें, या ⌥⌘S दबाएँ |

अगर आप बिना सहेजे बदलावों वाला दस्तावेज़ बंद करते हैं, तो VectorPDF पूछता है कि उन्हें सहेजना है या नहीं।

[डिजिटल रूप से हस्ताक्षरित](digital-signatures.md) दस्तावेज़ को सहेजते समय आपके बदलाव हस्ताक्षरित हिस्से के बाद जोड़े जाते हैं, ताकि जहाँ तक बदलावों की अनुमति है, उसके हस्ताक्षर मान्य रहें।

## अपने बदलाव रद्द करें

पिछली बार सहेजने के बाद किए गए सभी बदलाव हटाने के लिए, File > Revert to Saved चुनें। VectorPDF पहले पूछता है, फिर फ़ाइल को वैसे ही खोलता है जैसी वह पिछली बार सहेजी गई थी, उसी पेज पर जिसे आप पढ़ रहे थे। इसे पूर्ववत नहीं किया जा सकता।

किसी दस्तावेज़ की छोटी कॉपी बनाने के लिए, [Optimized PDF](export.md#optimized-pdf) देखें।

## अगर VectorPDF अचानक बंद हो जाए {#if-vectorpdf-quits-unexpectedly}

जब किसी दस्तावेज़ में बिना सहेजे बदलाव हों, तो VectorPDF आपके Mac पर उसकी एक प्रति रखता है, जो लगभग हर 30 सेकंड में अपडेट होती है। अगर VectorPDF अचानक बंद हो जाए, तो अगली बार खुलने पर यह प्रतियाँ पेश करता है:

- **Open Recovered Copy** हर प्रति को उसके मूल के बगल में "(Recovered)" नाम से सहेजता है और खोलता है। मूल नहीं बदलता। दोनों की तुलना करें, फिर जो चाहिए वह रखें।
- **Decide Later** प्रतियाँ रखता है और अगली बार फिर पूछता है।
- **Discard Changes** प्रतियाँ हटा देता है।

जब आप दस्तावेज़ सहेजते हैं, उसे पिछली सहेजी स्थिति पर लौटाते हैं या बिना सहेजे बंद करते हैं, और जब आप VectorPDF बंद करते हैं, तो प्रति हटा दी जाती है। पासवर्ड से सुरक्षित दस्तावेज़ों की प्रति नहीं बनती, क्योंकि प्रति एन्क्रिप्ट नहीं होगी।

## दस्तावेज़ साझा करें

macOS की साझा करने की सेवा का उपयोग करने के लिए File > Share चुनें, या फ़ाइल ढूँढने के लिए File > Show in Finder (⇧⌘R) चुनें। Start स्क्रीन पर किसी दस्तावेज़ को Finder में दिखाने के लिए उस पर राइट-क्लिक करें।

## PDF में क्या सहेजा नहीं जाता

कुछ चीज़ें VectorPDF के पास ही रहती हैं और फ़ाइल के साथ नहीं जातीं: [ऐंकर](anchors.md), आपकी [पढ़ने की स्थिति](reading-positions.md), दृश्य का घुमाव, और [OCR](scanned-pages.md) से मिला टेक्स्ट, जब तक आप उसे [PDF में सहेज](scanned-pages.md#save-the-recognized-text-in-the-pdf) नहीं लेते।
