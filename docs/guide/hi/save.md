# अपने बदलाव सहेजें

मार्कअप, फ़ॉर्म की प्रविष्टियाँ, पेज के बदलाव और रिडैक्शन तब तक आपकी फ़ाइल में नहीं लिखे जाते जब तक आप सहेजते नहीं। जिस विंडो में बदलाव सहेजे नहीं गए हैं, उसके बंद करने वाले बटन में एक बिंदु दिखता है।

| यह करने के लिए | यह करें |
| --- | --- |
| सहेजें | File > Save चुनें, या ⌘S दबाएँ |
| नए नाम से कॉपी सहेजें | File > Save As चुनें, या ⇧⌘S दबाएँ |
| पासवर्ड से सुरक्षित कॉपी सहेजें | File > [Save Encrypted with Password](passwords.md) चुनें, या ⌥⌘S दबाएँ |

अगर आप बिना सहेजे बदलावों वाला दस्तावेज़ बंद करते हैं, तो VectorPDF पूछता है कि उन्हें सहेजना है या नहीं।

## दस्तावेज़ साझा करें

macOS की साझा करने की सेवा का उपयोग करने के लिए File > Share चुनें, या फ़ाइल ढूँढने के लिए File > Show in Finder (⇧⌘R) चुनें। Start स्क्रीन पर किसी दस्तावेज़ को Finder में दिखाने के लिए उस पर राइट-क्लिक करें।

## PDF में क्या सहेजा नहीं जाता

कुछ चीज़ें VectorPDF के पास ही रहती हैं और फ़ाइल के साथ नहीं जातीं: [ऐंकर](anchors.md), आपकी [पढ़ने की स्थिति](reading-positions.md), दृश्य का घुमाव, और [OCR](scanned-pages.md) से मिला टेक्स्ट।
