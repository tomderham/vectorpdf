# चुनें कि Agent कैसे जवाब दे

संबंधित अंशों की खोज हमेशा आपके Mac पर होती है। जवाब कौन लिखेगा, यह आप VectorPDF > Settings > AI Synthesis Engine में चुन सकते हैं। इस सेटिंग के लिए macOS 27 ज़रूरी है।

| इंजन | यह कैसे काम करता है | आपके Mac से बाहर क्या जाता है |
| --- | --- | --- |
| On-Device | आपके Mac पर Apple Intelligence | कुछ नहीं |
| Private Cloud Compute | Apple के सर्वर, लंबे और ज़्यादा विस्तृत जवाबों के लिए | आपका प्रश्न और उपयोग किए गए अंश, जो Apple के Private Cloud Compute पर जाते हैं |
| Online Model (your API key) | आपकी चुनी हुई सेवा, जिसका बिल उस सेवा में आपके खाते से लिया जाता है | आपका प्रश्न, अंश (या छोटे दस्तावेज़ का पूरा टेक्स्ट) और पिछली बातचीत |

macOS 26 पर Agent डिवाइस पर ही जवाब देता है।

Private Cloud Compute केवल VectorPDF की उन प्रतियों में दिखता है जो इसके लिए साइन की गई हैं। GitHub से डाउनलोड किया गया संस्करण डिवाइस पर ही जवाब देता है।

## ऑनलाइन मॉडल का उपयोग करें

1. Settings में AI Synthesis Engine को Online Model पर सेट करें।
2. कोई सेवा चुनें: OpenAI, Google Gemini या OpenRouter।
3. अपनी API की दर्ज करें। हर सेवा से की पाने का लिंक दिया गया है। की आपके लॉगिन कीचेन में संग्रहित होती है।
4. कोई मॉडल चुनें।

अगर सेवा जवाब नहीं दे पाती, तो VectorPDF डिवाइस पर ही जवाब देता है।

> **चेतावनी:** आप जो भेजते हैं उस पर सेवा की गोपनीयता नीति और शर्तें लागू होती हैं। मुफ़्त Gemini की पर Google आपकी भेजी गई सामग्री का उपयोग अपने उत्पादों को बेहतर बनाने के लिए कर सकता है, और लोग उसकी समीक्षा कर सकते हैं, इसलिए गोपनीय दस्तावेज़ न भेजें। [गोपनीयता](privacy.md) देखें।
