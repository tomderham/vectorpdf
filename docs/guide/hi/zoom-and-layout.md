# ज़ूम, रोटेट और पेज लेआउट

## ज़ूम

| यह करने के लिए | यह करें |
| --- | --- |
| ज़ूम इन या ज़ूम आउट करें | ⌘+ या ⌘− दबाएँ, टूलबार में + या − पर क्लिक करें, या ट्रैकपैड पर पिंच करें |
| सटीक ज़ूम सेट करें | टूलबार में प्रतिशत पर क्लिक करें, 10 से 1000 के बीच कोई मान टाइप करें, फिर Return दबाएँ |
| पेज को वास्तविक आकार में देखें | View > Actual Size (100%) चुनें, या ⌘1 दबाएँ |
| पेज की चौड़ाई फ़िट करें | View > Zoom to Fit Width चुनें, या ⌘9 दबाएँ |
| पूरा पेज फ़िट करें | View > Zoom to Fit Window चुनें, या ⌥⌘0 दबाएँ |

Zoom In और Zoom Out कमांड 25% से 400% के बीच काम करते हैं। इन सीमाओं से आगे जाने के लिए प्रतिशत टाइप करें।

VectorPDF हर ज़ूम स्तर पर पेजों को स्पष्ट रखता है, क्योंकि वह किसी इमेज को बड़ा करने के बजाय उन्हें फिर से बनाता है।

## 100% का अर्थ

View > Define 100% Scale As चुनें, फिर इनमें से एक चुनें:

- **Size on Screen Equals Size on Printout:** 100% पर पेज लगभग अपने प्रिंट किए गए आकार में दिखता है।
- **1 Point Equals 1 Screen Point:** एक PDF पॉइंट आपके डिस्प्ले पर एक पॉइंट जगह लेता है।

## दृश्य घुमाएँ {#rotate-the-view}

टूलबार में Rotate Left या Rotate Right पर क्लिक करें। इससे केवल यह बदलता है कि दस्तावेज़ स्क्रीन पर कैसा दिखता है, और यह सहेजा नहीं जाता। PDF में ही पेजों को घुमाने के लिए [पेजों को फिर से व्यवस्थित करें](pages.md) देखें।

## Two-Page Mode

टूलबार में Two-Page Mode पर क्लिक करें, या View > Two Pages (⌥⌘2) चुनें। पेज खुली किताब की तरह जोड़ियों में दिखते हैं, कवर पेज अकेला रहता है, और स्प्रेड को विंडो में फ़िट करने के लिए ज़ूम किया जाता है। वापस जाने के लिए बटन पर फिर से क्लिक करें या View > Single Page चुनें।

> **नोट:** जब दृश्य घुमाया गया हो या Two-Page Mode में हो, तब आप टेक्स्ट नहीं चुन सकते, लिंक पर नहीं जा सकते, मार्कअप और माप टूल का उपयोग नहीं कर सकते, और फ़ॉर्म नहीं भर सकते। इनका उपयोग करने के लिए बिना घुमाव वाले Single Page पर लौटें।
