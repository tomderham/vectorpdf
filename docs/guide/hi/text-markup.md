# हाइलाइट, अंडरलाइन और स्ट्राइकथ्रू करें

## चयनित टेक्स्ट पर मार्कअप करें

टेक्स्ट चुनें, फिर इनमें से कोई एक काम करें:

| मार्कअप | मेनू | शॉर्टकट |
| --- | --- | --- |
| Highlight | Edit > Highlight Selection | ⇧⌘H |
| Underline | Edit > Underline Selection | ⇧⌘U |
| Strikethrough | Edit > Strikethrough Selection | ⇧⌘X |

आप Markup टूलबार के बटन का भी उपयोग कर सकते हैं, या चयन पर राइट-क्लिक करके Highlight, Underline या Strikethrough चुन सकते हैं। हर एक में रंगों की सूची होती है।

## रंग चुनें

Markup टूलबार (⇧⌘A) में एक रंग बटन होता है। उस पर क्लिक करें, फिर किसी रंग पर क्लिक करें। शॉर्टकट और टूलबार बटन वहाँ चुने गए रंग का उपयोग करते हैं। किसी एक मार्कअप के लिए रंग चुनने के लिए राइट-क्लिक मेनू की रंग सूची का उपयोग करें, या Edit मेनू में उस आइटम के नीचे की सूची का।

## मार्कअप हटाएँ

अभी बनाया गया मार्कअप पहले जैसा करने के लिए Edit > Undo चुनें या ⌘Z दबाएँ।

चिह्नित टेक्स्ट पर राइट-क्लिक करें, फिर Remove Highlight, Remove Underline या Remove Strikethrough चुनें। या Markup टूलबार में इरेज़र चुनें, फिर जिन मार्कअप को हटाना है उन पर क्लिक करें या उनके ऊपर से खींचें। गलती से हटाया गया मार्कअप ⌘Z से वापस आ जाता है।

## अपने मार्कअप का सारांश बनाएँ

अपने ऐनोटेशन की सूची पाने के लिए File > Export Annotations Summary (⇧⌘E) चुनें। आप इसे Markdown या CSV के रूप में सहेज सकते हैं। [अन्य फ़ॉर्मैट में एक्सपोर्ट करें](export.md) देखें।
