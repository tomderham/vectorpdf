# दस्तावेज़ में इधर-उधर जाएँ

## स्क्रोल करें और पेज पलटें

अपने ट्रैकपैड या माउस से स्क्रोल करें। VectorPDF केवल उन्हीं पेजों का लेआउट बनाता है जो आपके पढ़ने की जगह के पास हैं, इसलिए बहुत लंबे दस्तावेज़ भी तेज़ चलते हैं।

कीबोर्ड से:

| कुंजियाँ | क्रिया |
| --- | --- |
| Left Arrow, Right Arrow | पिछला या अगला पेज |
| Up Arrow, Down Arrow | विंडो से लंबे पेज के अंदर स्क्रोल करें, फिर अगले पेज पर जाएँ। अगर पेज विंडो में समा जाता है, तो एक बार में एक पेज आगे या पीछे जाएँ। |
| Page Up, Page Down | बड़े चरण में स्क्रोल करें, फिर अगले पेज पर जाएँ |
| Space, ⇧Space | आगे या पीछे, Page Down और Page Up की तरह |
| ⌥Up Arrow, ⌥Down Arrow, ⌥Left Arrow, ⌥Right Arrow | पिछला या अगला पेज |
| ⌘Up Arrow, ⌘Down Arrow | पहला या अंतिम पेज |

Two-Page Mode में ये कुंजियाँ पूरा स्प्रेड पलटती हैं।

## किसी पेज पर जाएँ

टूलबार में पेज नंबर पर क्लिक करें, मनचाहा पेज टाइप करें, फिर Return दबाएँ। रद्द करने के लिए Escape दबाएँ।

कुछ दस्तावेज़ अपने पेजों को खुद नाम देते हैं, जैसे प्रारंभिक पेजों के लिए `iv` या ड्रॉइंग शीट के लिए `A-101`। तब VectorPDF यह लेबल टूलबार, पेज इंडिकेटर और थंबनेल में दिखाता है, और उसके साथ पेज की स्थिति भी, जैसे `iv (4 of 300)`। किसी पेज पर जाने के लिए उसका लेबल टाइप करें। अगर कोई लेबल एक से ज़्यादा बार इस्तेमाल हुआ है, तो आप उस लेबल वाले अगले पेज पर पहुँचते हैं। किसी पेज पर उसकी स्थिति से जाने के लिए `#` और संख्या टाइप करें, जैसे `#13`।

Print और Split PDF पेजों को हमेशा उनकी स्थिति से गिनते हैं, फ़ाइल के पहले पेज से शुरू करके।

## जहाँ थे वहाँ वापस जाएँ

किसी लिंक पर जाने या किसी परिणाम पर पहुँचने के बाद, वापस आने के लिए Go > Back (⌘[) चुनें। Go > Forward (⌘]) आपको दूसरी दिशा में ले जाता है।
