# पासवर्ड और एन्क्रिप्शन

## सुरक्षित PDF खोलें

जब आप कोई सुरक्षित PDF खोलते हैं, तो VectorPDF पासवर्ड माँगता है। अगर आप Cancel पर क्लिक करते हैं, तो दस्तावेज़ बंद ही रहता है।

## एन्क्रिप्ट की गई कॉपी बनाएँ

1. File > Save Encrypted with Password (⌥⌘S) चुनें।
2. कोई नाम और स्थान चुनें।
3. पासवर्ड दो बार दर्ज करें, फिर Encrypt & Save पर क्लिक करें।

कॉपी AES-256 से एन्क्रिप्ट की जाती है, और उसे खोलने के लिए पासवर्ड ज़रूरी होता है।

> **चेतावनी:** पासवर्ड सुरक्षित रखें। अगर पासवर्ड खो जाता है, तो एन्क्रिप्ट किए गए PDF को वापस पाने का कोई तरीका नहीं है।

## दस्तावेज़ की अनुमतियाँ देखें

यह देखने के लिए कि दस्तावेज़ का लेखक किन चीज़ों की अनुमति देता है, जैसे प्रिंट करना या कॉपी करना, File > Document Properties (⌘I) चुनें, फिर Security पर क्लिक करें। [दस्तावेज़ की प्रॉपर्टी](document-properties.md) देखें।
