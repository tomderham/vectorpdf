# दस्तावेज़ के बारे में पूछें

Agent खुले दस्तावेज़ के बारे में प्रश्नों के जवाब देता है, और वे अंश दिखाता है जिनसे उसका जवाब लिया गया है। इसके लिए macOS 26 या उसके बाद का संस्करण ज़रूरी है।

## प्रश्न पूछें

1. साइडबार में Ask About This Document टैब पर क्लिक करें। पहली बार VectorPDF आपके Mac पर दस्तावेज़ को इंडेक्स करता है और उसकी प्रगति दिखाता है।
2. कोई प्रश्न टाइप करें, फिर Return दबाएँ, या Ask पर क्लिक करें। नई लाइन के लिए ⇧Return दबाएँ।

[लेयर](layers.md) वाले दस्तावेज़ में केवल दिखाई गई लेयर इंडेक्स की जाती हैं। अगर आप लेयर दिखाते या छिपाते हैं, तो दस्तावेज़ फिर से इंडेक्स किया जाता है।

जवाब के नीचे, उपयोग किए गए अंश उनके पेजों के साथ देखने के लिए **Sources** पर क्लिक करें। जिन अंशों का जवाब में हवाला दिया गया है, वे **Cited** से चिह्नित होते हैं। किसी अंश पर जाने के लिए उस पर क्लिक करें।

आप आगे के प्रश्न भी पूछ सकते हैं। फिर से शुरू करने के लिए **New Conversation** पर क्लिक करें।

> **नोट:** Agent गलतियाँ कर सकता है। किसी भी महत्वपूर्ण बात के लिए स्रोतों की जाँच करें।

## अगर कोई जवाब नहीं बन पाता

अगर आपके Mac पर जवाब बनाने की सुविधा उपलब्ध नहीं है, तो Agent इसके बजाय सबसे अच्छे मेल वाले अंश दिखाता है। [चुनें कि Agent कैसे जवाब दे](agent-engines.md) देखें।

## Agent बंद करें

[Settings](settings.md) में **Use Agent** बंद करें। टैब साइडबार से हट जाता है।
