# PDF से जुड़ी फ़ाइलें

एक PDF अपने अंदर दूसरी फ़ाइलें रख सकता है: किसी रिपोर्ट के साथ एक स्प्रेडशीट, ड्रॉइंग सेट के साथ एक CAD मॉडल, या किसी इलेक्ट्रॉनिक इनवॉइस का डेटा। जब किसी दस्तावेज़ में अटैचमेंट होते हैं, तो साइडबार के ऊपर Attachments टैब (एक पेपरक्लिप) दिखता है। अटैचमेंट वाला एक या दो पेज का दस्तावेज़ Attachments टैब पर खुलता है।

हर अटैचमेंट अपना नाम दिखाता है और, जब PDF में ये शामिल हों, तो अपना विवरण, आकार और वह पेज जिससे वह जुड़ा है। यह देखने के लिए कि फ़ाइल किस तरह की है और उसकी तारीख क्या है, पॉइंटर को उस पर रखें।

| करने के लिए | यह करें |
| --- | --- |
| अटैचमेंट का प्रीव्यू देखें | उस पर डबल-क्लिक करें, या उसे चुनें और स्पेस दबाएँ |
| अगला या पिछला प्रीव्यू देखें | Quick Look खुला होने पर, नीचे या ऊपर तीर कुंजी दबाएँ |
| उसे उसके ऐप में खोलें | उस पर राइट-क्लिक करें और Open चुनें |
| एक कॉपी सहेजें | उस पर राइट-क्लिक करें और Save As… चुनें, या उसे Finder में ड्रैग करें |
| सभी को सहेजें | टैब के ऊपर Save All… पर क्लिक करें, फिर कोई फ़ोल्डर चुनें |
| उसके पेज पर जाएँ | उस पर राइट-क्लिक करें और Show on Page चुनें |

> **चेतावनी:** अटैचमेंट किसी भी तरह की फ़ाइल हो सकता है, जिसमें कोई ऐप या स्क्रिप्ट भी शामिल है। केवल उन्हीं फ़ाइलों को खोलें जिन पर आपको भरोसा हो। VectorPDF किसी PDF से निकाली गई फ़ाइलों को डाउनलोड की गई फ़ाइलों के रूप में चिह्नित करता है, ताकि macOS ऐप और स्क्रिप्ट चलने से पहले उनकी जाँच करे, जैसे वह वेब से आई फ़ाइलों के लिए करता है।

## इलेक्ट्रॉनिक इनवॉइस

ZUGFeRD और Factur-X इनवॉइस अपना डेटा एक XML फ़ाइल में रखते हैं, जिसका नाम आम तौर पर `factur-x.xml` या `zugferd-invoice.xml` होता है। यह दूसरे अटैचमेंट के साथ दिखती है, ताकि आप इसे अपने अकाउंटिंग सॉफ़्टवेयर के लिए सहेज सकें। VectorPDF खुद इनवॉइस का विवरण नहीं दिखाता।
