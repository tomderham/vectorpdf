# प्रिंट करें

File > Print चुनें, या ⌘P दबाएँ।

प्रिंट डायलॉग में ये विकल्प देखने के लिए PDF Options चुनें:

- **Auto Rotate:** कागज़ पर फ़िट करने के लिए पेजों को घुमाता है।
- **Scale to Fit:** हर पेज को कागज़ पर फ़िट करता है।
- **Scale:** आपके दर्ज किए गए प्रतिशत पर प्रिंट करता है।

VectorPDF उसी इंजन से प्रिंट करता है जिसका उपयोग वह स्क्रीन पर करता है, इसलिए प्रिंट वैसा ही आता है जैसा आप देखते हैं।
