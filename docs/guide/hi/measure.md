# लंबाई, क्षेत्रफल और कोण मापें

Measurement टूलबार दिखाने के लिए ⇧⌘M दबाएँ। अगर आपकी ड्रॉइंग स्केल के अनुसार है, तो पहले [स्केल सेट करें](drawing-scale.md)।

सटीकता के लिए मापने से पहले ज़ूम इन करें। Escape दबाने से चल रहा माप रद्द हो जाता है। टूल छोड़ने के लिए फिर से Escape दबाएँ, या चुने हुए टूल पर क्लिक करें।

## माप टूल

| टूल | इसका उपयोग कैसे करें |
| --- | --- |
| Linear Dimension | एक बिंदु से दूसरे बिंदु तक ड्रैग करें। |
| Perimeter | रास्ते के हर बिंदु पर क्लिक करें। समाप्त करने के लिए Return दबाएँ या डबल-क्लिक करें। |
| Polygon Area | हर कोने पर क्लिक करें। आकृति बंद करने के लिए Return दबाएँ, डबल-क्लिक करें, या पहले बिंदु पर क्लिक करें। |
| Vertex Angle | पहली लाइन के किसी बिंदु पर क्लिक करें, फिर कोने पर, फिर दूसरी लाइन के किसी बिंदु पर। |

## सटीक रूप से बनाएँ

- **Ortho Lock** लाइनों को 0°, 45° और 90° पर रखता है। किसी एक लाइन के लिए इसे उलटने के लिए ⇧ दबाए रखें: इसके चालू रहते किसी भी कोण पर मापने के लिए, या बंद रहते लाइन को सीधा रखने के लिए।
- **Vertex Magnetic Snapping** पॉइंटर को ड्रॉइंग के कोनों और अंतिम बिंदुओं पर स्नैप करता है।

## माप बदलें

माप टूल छोड़ने के लिए Escape दबाएँ या चुने हुए टूल पर क्लिक करें, फिर किसी माप को चुनने के लिए उस पर क्लिक करें। उसके बिंदुओं पर हैंडल दिखाई देते हैं।

| यह करने के लिए | यह करें |
| --- | --- |
| एक बिंदु हिलाना | उसका हैंडल खींचें। Ortho Lock और स्नैपिंग वैसे ही काम करते हैं जैसे मापते समय। |
| पूरा माप हिलाना | उसकी रेखा खींचें, या तीर कुंजियाँ दबाएँ (⇧ के साथ यह 10 पॉइंट खिसकता है)। |
| आयाम रेखा को मापी गई चीज़ के पास या उससे दूर ले जाना | उसका लेबल खींचें, या बिंदुओं से हट जाने के बाद आयाम रेखा को ही खींचें। |
| उसका रंग बदलना | Measurement टूलबार के रंग बटन से कोई रंग चुनें। |

खींचते समय मान फिर से निकाला जाता है। किसी माप को पहले जैसा करने के लिए Edit > Undo चुनें। PDF में पहले से सहेजे गए माप भी बदले जा सकते हैं।

किसी क्षेत्रफल को चुनने के लिए उसके किनारे पर क्लिक करें: उसके अंदर क्लिक करने से वहाँ का टेक्स्ट चुना जाता है।

## माप का रूप बदलें

मापने से पहले Measurement टूलबार में रंग बटन और रेखा की मोटाई का उपयोग करें। पहले से बनाए गए माप का रंग बदलने के लिए उसे चुनें, फिर कोई रंग चुनें।

## माप रखें या हटाएँ

माप ऐनोटेशन होते हैं, जो [सहेजने](save.md) पर PDF में संग्रहित होते हैं। किसी माप को हटाने के लिए उस पर राइट-क्लिक करें, फिर Delete Dimension या Delete Area Takeoff जैसा हटाने का कमांड चुनें।

अपने सभी मापों की सूची देखने के लिए [टेकऑफ़ टेबल](takeoff.md) देखें।
