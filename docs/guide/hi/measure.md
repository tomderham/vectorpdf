# लंबाई, क्षेत्रफल और कोण मापें

Measurement टूलबार दिखाने के लिए ⇧⌘M दबाएँ। अगर आपकी ड्रॉइंग स्केल के अनुसार है, तो पहले [स्केल सेट करें](drawing-scale.md)।

सटीकता के लिए मापने से पहले ज़ूम इन करें। Escape दबाने से चल रहा माप रद्द हो जाता है।

## माप टूल

| टूल | इसका उपयोग कैसे करें |
| --- | --- |
| Linear Dimension | एक बिंदु से दूसरे बिंदु तक ड्रैग करें। |
| Perimeter | रास्ते के हर बिंदु पर क्लिक करें। समाप्त करने के लिए Return दबाएँ या डबल-क्लिक करें। |
| Polygon Area | हर कोने पर क्लिक करें। आकृति बंद करने के लिए Return दबाएँ, डबल-क्लिक करें, या पहले बिंदु पर क्लिक करें। |
| Vertex Angle | पहली लाइन के किसी बिंदु पर क्लिक करें, फिर कोने पर, फिर दूसरी लाइन के किसी बिंदु पर। |

## सटीक रूप से बनाएँ

- **Ortho Lock** लाइनों को 0°, 45° और 90° पर रखता है। किसी एक लाइन के लिए ऐसा करने के लिए आप ⇧ भी दबाए रख सकते हैं।
- **Vertex Magnetic Snapping** पॉइंटर को ड्रॉइंग के कोनों और अंतिम बिंदुओं पर स्नैप करता है।

## माप का रूप बदलें

मापने से पहले Measurement टूलबार में रंग बटन और रेखा की मोटाई का उपयोग करें।

## माप रखें या हटाएँ

माप ऐनोटेशन होते हैं, जो [सहेजने](save.md) पर PDF में संग्रहित होते हैं। किसी माप को हटाने के लिए उस पर राइट-क्लिक करें, फिर Delete Dimension या Delete Area Takeoff जैसा हटाने का कमांड चुनें।

अपने सभी मापों की सूची देखने के लिए [टेकऑफ़ टेबल](takeoff.md) देखें।
