# VectorPDF उपयोगकर्ता गाइड

macOS के लिए

VectorPDF तकनीकी शोध-पत्रों, विनिर्देशों, अनुबंधों और ड्रॉइंग के लिए एक तेज़ PDF रीडर है। किसी संदर्भ पर Command दबाए रखें और देखें कि वह कहाँ ले जाता है, वह भी अपना पेज छोड़े बिना। आप PDF पर मार्कअप कर सकते हैं, माप ले सकते हैं, जानकारी रिडैक्ट कर सकते हैं और पेजों को फिर से व्यवस्थित कर सकते हैं, और यह सब आपके Mac पर ही होता है।

> **नोट:** यह गाइड अंग्रेज़ी से मशीन द्वारा अनुवादित है। VectorPDF का इंटरफ़ेस केवल अंग्रेज़ी में है, इसलिए मेनू और बटन के नाम वैसे ही अंग्रेज़ी में दिए गए हैं जैसे वे स्क्रीन पर दिखते हैं।
