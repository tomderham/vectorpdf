# PDF को विभाजित करें

1. File > Split PDF चुनें।
2. Split Method के नीचे इनमें से एक चुनें:
   - **Every N Pages:** तय संख्या के पेजों के बाद एक नई फ़ाइल।
   - **Single Pages:** हर पेज के लिए एक फ़ाइल।
   - **Page Ranges:** अल्पविराम से अलग किए गए पेज नंबर या श्रेणियाँ दर्ज करें, जैसे `1-5, 6-12, 13-20`।
3. Save Location के नीचे कोई फ़ोल्डर चुनने के लिए Choose पर क्लिक करें।
4. File Naming के नीचे कोई उपसर्ग दर्ज करें और एक शैली चुनें: Part Number या Page Range। Output Preview दिखाता है कि कौन-सी फ़ाइलें बनेंगी।
5. Split PDF पर क्लिक करें।

आपका मूल दस्तावेज़ नहीं बदलता। विभाजन पूरा होने पर फ़ाइलें देखने के लिए Reveal in Finder पर क्लिक करें।
