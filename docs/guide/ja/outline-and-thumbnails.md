# アウトラインとサムネール

サイドバー上部の Outline & Thumbnails タブをクリックしてから、**Outline** または **Thumbnails** を選択します。

## アウトライン

アウトラインは、書類に目次がある場合に表示される目次です。読んでいるセクションは、スクロールに合わせてハイライトされます。

- **セクションに移動する:** クリックします。見出しがウインドウの上端近くまでスクロールされます。見出しがすでに表示されている場合は、そのままの位置に留まります。
- **サブセクションを表示または非表示にする:** セクションの横の矢印をクリックします。
- **セクションを探す:** “Search outline” フィールドに入力します。一致するセクションだけが表示されます。
- **セクションをすぐに使えるようにする:** 右クリックして[アンカー](anchors.md)を作成するか、新しいウインドウで開きます。

## アウトラインを編集する {#edit-the-outline}

書類のアウトラインに項目（ほかの App ではブックマークと呼ばれることもあります）を追加したり、名前を変更、移動、削除したりできます。変更は、[保存](save.md)したときにファイルに含まれます。

項目を追加するには、項目の移動先にしたい場所に移動してから、Edit > Add Outline Entry (⌥⌘B) を選択します。テキストを選択している場合、項目はそのテキストに移動し、そのテキストがタイトルとして提案されます。選択していない場合は、読んでいるページの先頭に移動します。タイトルを入力してから、**Add** をクリックします。この方法で追加した項目は、最上位の項目の中にページ順で入ります。そのため、アウトラインのない書類でアウトラインを作り始めるときにもこの方法を使います。

そのほかの操作は、項目を右クリックして行います:

| 目的 | 選択する項目 |
| --- | --- |
| この項目の後、またはこの項目の中に項目を追加する | Add Entry After または Add Entry Inside |
| 名前を変更する | Rename |
| 選択したテキスト、または読んでいるページに移動するようにする | Go Here Instead |
| 同じレベルの項目の中で移動する | Move Up または Move Down |
| 上の項目の中に入れる、または今入っている項目から出す | Indent または Outdent |
| 中の項目とともに削除する | Delete Entry |

項目をドラッグして移動したり、ほかの項目の上にドロップしてその中に入れたりすることもできます。中にある項目も一緒に移動します。“Search outline” フィールドでアウトラインを絞り込んでいる間は項目を移動できないため、Move Up、Move Down、Indent、Outdent はメニューに表示されず、項目をドラッグすることもできません。ほかのコマンドは使えます。Edit > Undo (⌘Z) で、アウトラインへの変更を 1 つずつ取り消せます。

### 見出しからアウトラインを作成する

Edit > Build Outline from Headings を選択すると、書類の見出しからアウトラインを作成できます。このコマンドは、アウトラインの項目の右クリックメニューにもあります。まず、見つかった見出しのリストが開きます。見出しでないもののチェックを外し、タイトルをクリックして変更し、インデントボタンで見出しのレベルを上げ下げします。見出しの横の矢印をクリックすると、ページ上でその見出しを確認できます。次に **Create Outline**、書類にすでにアウトラインがある場合は **Replace Outline** をクリックします。Edit > Undo で元のアウトラインに戻せます。

タグ付き PDF では、タグで示されている見出しが使われます。そのほかの PDF では、VectorPDF は本文と区別されている行（本文より大きい行や、本文が太字でないのに太字の行）を探します。大きいスタイルほど上のレベルになり、同じスタイルの中では 3.2.1 のようなセクション番号でレベルが決まります。柱（ヘッダやフッタ）、図や表のキャプション、目次の行は含まれません。

書類のスタイルから、どの行が見出しなのかが常にわかるとは限らないので、リストを確認してください。スキャンしたページの見出しは、テキストが認識された後でも見つかりません。一部のタグ付き PDF では、セクション番号がテキストの一部にならない形で描かれているため、項目に番号が付きません。

## サムネール

サムネールには、すべてのページが表示されます。クリックすると、そのページに移動します。

複数のページを選択するには ⌘ を、範囲を選択するには ⇧ を押したままにします。その後、新しい位置にドラッグするか、右クリックして回転、複製、抽出、削除を行います。[ページを並べ替える](pages.md)を参照してください。
