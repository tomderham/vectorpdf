# PDF の色を変更する

VectorPDF では、macOS の外観にかかわらず、書類のページの見た目を変更できます。暗い部屋で読むときに便利です。PDF 自体は変更されません。

View > PDF Color を選択するか、[Settings](settings.md) の PDF Color 設定を使用して、次のいずれかを選択します:

- **Follow System:** ページを macOS の外観に合わせます。
- **Light:** 書類で定義されているとおりにページを表示します。
- **Dark:** 色相を保ったままページの色を反転します。図やハイライトは見分けやすいままです。
- **Sepia:** ページを暖かみのある紙の色調にします。

プリントと書き出しでは、書類の元の色が使用されます。
