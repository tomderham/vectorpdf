# 右クリックメニュー

右クリックするか、Control キーを押しながらクリックすると、ポインタの下にある項目のコマンドが表示されます。表示されるメニューは、クリックする場所によって異なります。

## 書類内

| 右クリックする場所 | コマンド |
| --- | --- |
| 選択したテキスト | Copy Text、Look Up、Translate Selection、Start Speaking または Stop Speaking、Highlight、Underline、Strikethrough、Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| 選択した領域 | Copy Extracted Text、Copy Screenshot、Save Screenshot As、Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| リンク | Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| ハイライト、下線、取り消し線 | 対応する Remove コマンド |
| テキストボックスまたは吹き出し | Edit Text Box または Edit Callout Note、および削除コマンド |
| 描画、スタンプ、測定値 | 削除コマンド |
| ページ上のその他の場所 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |

プレーンテキストの参照を右クリックしたときに、関連する書類が別のタブで開いている場合は、メニューに[その参照に移動または検索する](cross-document-references.md)コマンドも表示されます。

## サイドバー内

| 右クリックする場所 | コマンド |
| --- | --- |
| アウトラインの項目 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| サムネール | Rotate Clockwise、Rotate Counterclockwise、Rotate 180°、Duplicate Page、Insert Blank Page、Insert Pages from PDF、Save selected page as a PDF、Move Page Up、Move Page Down、Delete Page。複数のページを選択している場合は、Delete 3 Pages のようにコマンドにページ数が示されます。[ページを並べ替える](pages.md)を参照してください。 |
| 検索結果 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| アンカー | Open in New Window または Close Window、Copy Text、Copy Screenshot、Delete Anchor |

## ウインドウ内

| 右クリックする場所 | コマンド |
| --- | --- |
| 書類のタイトル、またはツールバーの何もない部分 | Favorites への追加または削除、Save All Open Tabs as a Group、Update Group “名前” with Open Tabs、および保存した Tab Groups と Favorites |
| Start 画面の行 | Open、Open in New Tab、Open in New Window、Show in Finder、および Remove または Delete |

コマンドの中には、使用できる場合にのみ表示されるものがあります。たとえば、Save All Open Tabs as a Group には複数のタブが必要です。また、アンカーから開いたウインドウではアンカーのコマンドは使用できません。
