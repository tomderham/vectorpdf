# PDF に添付されたファイル

PDF には、ほかのファイルを含めることができます。たとえば、レポートに付けたスプレッドシート、図面セットに付けた CAD モデル、電子インボイスのデータなどです。書類に添付ファイルがある場合、サイドバーの上部に Attachments タブ（クリップ）が表示されます。添付ファイルのある 1 ページの書類は、サイドバーが表示された状態で開きます。

各添付ファイルには名前と、PDF に含まれている場合は説明、サイズ、添付先のページが表示されます。ポインタを添付ファイルの上に置くと、ファイルの種類と日付が表示されます。

| 目的 | 操作 |
| --- | --- |
| 添付ファイルをプレビューする | ダブルクリックするか、選択してスペースバーを押します |
| 次または前の添付ファイルをプレビューする | Quick Look を開いた状態で、下矢印キーまたは上矢印キーを押します |
| App で開く | 右クリックして Open を選択します |
| コピーを保存する | 右クリックして Save As… を選択するか、Finder にドラッグします |
| すべてを保存する | タブの上部にある Save All… をクリックしてから、フォルダを選択します |
| 添付先のページに移動する | 右クリックして Show on Page を選択します |

> **警告:** 添付ファイルは、App やスクリプトを含め、どのような種類のファイルでもありえます。信頼できるファイルだけを開いてください。VectorPDF は PDF から取り出したファイルをダウンロードしたファイルとしてマークするため、Web からのファイルと同様に、macOS は App やスクリプトを実行する前に確認します。

## 電子インボイス

ZUGFeRD と Factur-X のインボイスは、データを XML ファイルに含めています。ファイル名は通常 `factur-x.xml` または `zugferd-invoice.xml` です。ほかの添付ファイルと一緒に表示されるので、会計ソフトウェア用に保存できます。VectorPDF 自体はインボイスの詳細を表示しません。
