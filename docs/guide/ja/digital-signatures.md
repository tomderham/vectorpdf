# デジタル署名で署名する、確認する

デジタル署名は、誰が書類に署名したか、そしてそれ以降書類が変更されていないことを示します。自分の証明書で [PDF に署名](#sign)できます。署名された PDF を開くと、VectorPDF はその署名を確認し、結果をページの上のバーに表示します:

- **署名は有効です:** 署名以降、書類は変更されておらず、署名者の証明書は Mac が信頼している認証局によって発行されています。
- **署名者の身元はこの Mac では確認されていません:** 書類は変更されていませんが、誰が署名したかを保証するものがありません。[署名者の身元が確認されない場合がある理由](#signer-identity)を参照してください。
- **無効:** 署名後に書類が変更されたか、署名が書類と一致しません。

**Signature Details** をクリックすると、サイドバーの Document タブで各署名を確認できます。バーを隠すには、閉じるボタンをクリックします。

> **注記:** [スタンプ](stamps.md)は署名の画像であり、デジタル署名ではありません。

## 証明書で署名する {#sign}

署名するには、秘密鍵の付いた署名用の証明書が必要です。組織や認証局から、通常はパスワード付きの .p12 または .pfx ファイルとして提供されます。キーチェーン内の証明書はそのまま使用できます。

1. Edit > Sign with Certificate を選択してから、署名を置きたいページの場所に枠をドラッグするか、クリックして通常のサイズの枠を置きます。中止するには Esc キーを押します。書類に空の署名フィールドがある場合は、代わりにそのフィールドをクリックして Sign with Certificate を選択することもできます。
2. 証明書を選択します。署名がどのように表示されるかがプレビューで示されます。ファイルを使うには、**Choose Certificate File** をクリックしてから、そのパスワードを入力します。ファイルはこの署名のためだけに読み込まれ、キーチェーンには追加されません。
3. 必要に応じて、理由（“この書類を承認します” など）と署名する場所を入力します。[スタンプ](stamps.md)を作成している場合は、フィールドに手書きの署名を表示できます。作成していない場合は、名前が表示されます。
4. 必要に応じて、After Signing で次を選択します:
   - **Certify**（まだ誰も署名していない書類の場合）: 今後どの変更なら書類が有効なままかを指定します。フォームへの入力、署名、注釈の追加。フォームへの入力と署名。または変更なし。証明された書類は、確認する誰に対しても証明済みとして表示され、許可されていない後からの変更はあなたの署名を無効にします。
   - **Lock form fields**（フォームの場合）: すべてのフィールド、または選択したフィールドが読み出し専用になり、署名した値が保たれます。
5. **Sign** をクリックします。

署名すると書類が保存されます。そのため、保存していない変更がある場合、VectorPDF はまずそれを保存するかどうかを確認します。保存した変更も署名の対象になります。macOS から、VectorPDF に証明書の鍵の使用を許可するよう求められることがあります。

ロックしたり、より少ない変更しか許可しないよう証明したりしない限り、署名しても書類のほかのフォームフィールドはそのままなので、ほかの人はあなたの署名を無効にすることなく、引き続きフィールドに入力したり、署名したり、注釈を追加したりできます。後から追加される署名も、同じように前の署名の後に追加されます。

この署名は SHA-256 による PKCS #7 署名で、あなたの証明書と、それを発行した認証局の証明書を含みます。Mac の時刻が記録されます。

署名した時刻をタイムスタンプサーバに保証してもらうには、**Add a timestamp** をオンにして、そのアドレスを指定します（組織で運用している場合があります。DigiCert の `http://timestamp.digicert.com` など、無料のものもあります）。タイムスタンプがあると、証明書の有効期限が切れた後でも、署名した時点の状態で署名を確認できます。サーバに送られるのは署名のフィンガープリントだけで、書類の内容は送られません。サーバに接続できない場合は何も署名されず、書類は元のままです。

## VectorPDF が確認する内容

Document タブのリストには、各署名について次のことが表示されます:

- 署名されたファイルの部分が、署名されたときとまったく同じかどうか。
- 署名後にファイルが再保存されたかどうか、およびその変更が署名で許可されているものかどうか。フォームフィールドへの入力、署名の追加、注釈の追加や変更は、通常は許可されています。証明用の署名では、許可される変更が少ない場合があります。署名後に注釈が追加された場合は、リストにそのことが示されます。注釈で署名された内容が隠れる可能性があるためです。
- 証明書に記載された名前による署名者と、証明書の発行者。署名ソフトウェアが書類に書き込んだ名前が異なる場合は、その名前も表示されます。
- 署名された日時。タイムスタンプ局による時刻は、タイムスタンプがこの署名のもので、その局を Mac が信頼している場合に保証されます。そうでない場合は、それが数に入らない理由がリストに示されます。署名者自身のコンピュータの時刻は保証されていません。
- 署名者が指定した理由と場所（ある場合）。

署名をクリックすると、ページ上のその署名に移動します。証明書を見るには、**Show Certificate** をクリックするか、署名を右クリックして Show Certificate を選択します。

VectorPDF は最後に保存された状態のファイルを確認するため、保存していない変更は含まれません。保存するたびに再確認します。

## 署名者の身元が確認されない場合がある理由 {#signer-identity}

誰でも、任意の名前を含む証明書を作成できます。署名が誰によるものかを証明できるのは、その人の身元を確認した認証局が証明書を発行していて、Mac がその認証局を信頼している場合だけです。VectorPDF は、キーチェーンアクセスで Mac が信頼している証明書を使用します。

署名された PDF の多くは、Adobe Acrobat は信頼しているが macOS は信頼していない認証局の証明書を使用しているため、VectorPDF はその署名者を確認されていないと報告します。それでも、書類が署名以降変更されていない場合があります。認証局を信頼するには、その証明書をキーチェーンアクセスに追加して“常に信頼”に設定します。ただし、本物であることが確かな場合に限ります。

VectorPDF は、証明書が失効しているかどうかを確認するためにオンラインにアクセスすることはありません。そのため、あなたが書類を開いたことが誰かに知られることはありません。

## 署名された書類を保存する

署名された書類を保存すると、VectorPDF はファイルの署名された部分の後に変更を追加し、その部分はそのままにします。そのため、変更が許可されている範囲で署名は有効なままです。[墨消し](redact.md)で内容を削除するとファイル全体が書き直されるため、書類の署名は無効になります。

## 確認される署名の種類

VectorPDF は、一般的な PDF 署名である PKCS #7 署名と CAdES（PAdES）署名を確認します。書類のタイムスタンプと古い X.509 RSA 署名はまだ確認しません。これらは **Not checked** と表示されます。
