# プライバシー

VectorPDF には、アカウント、解析、テレメトリ、クラッシュレポートの機能はありません。書類は Mac 上で処理され、書類の内容が開発者に送信されることはありません。

## ネットワークを使用するもの

- **アップデートの確認:** VectorPDF は、1 日に 1 回程度、または Check for Updates を選択したときに、GitHub に最新バージョンを問い合わせます。この要求には、ユーザや書類に関する情報は含まれません。この機能は [Settings](settings.md) でオフにできます。
- **Agent:** On-Device エンジンでは、Mac の外には何も送信されません。[Private Cloud Compute とオンラインモデル](agent-engines.md)は、質問と書類内の該当箇所を、質問したときにのみ送信します。オンラインモデルの設定時にも、モデルの一覧を取得し短いテストを送信するためにキーが使用されます。
- **iCloud:** 読書の状態は、自分の iCloud アカウントに保存されます。保存されるのは、ファイルの場所、最後のページと表示倍率、アンカーの名前、抜粋、ページです。書類、書類の全文、アンカーのサムネールはアップロードされません。
- **クリックしたリンク**は、ブラウザで開きます。
- **Apple のサービス:** Translation、Look Up、音声読み上げ、OCR は macOS によって提供され、Apple から言語ファイルをダウンロードすることがあります。Handoff は、読んでいる書類とページを自分の他のデバイスと共有します。

## Mac に保存されるもの

VectorPDF は、環境設定、お気に入り、タブグループ、読書位置、アンカー、スタンプを保存します。また、Agent で使用した書類のインデックス、アンカーのサムネール、ページ編集や墨消しが保存されていない書類の一時的な作業用コピーも保持します。一時的な作業用コピーは、不要になると削除されます。

オンラインモデルの API キーは、ログインキーチェーンに保存されます。

詳しくは、[GitHub のプライバシーポリシー](https://github.com/tomderham/vectorpdf/blob/main/PRIVACY.md)を参照してください。
