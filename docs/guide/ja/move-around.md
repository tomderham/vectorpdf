# 書類内を移動する

## スクロールとページめくり

トラックパッドまたはマウスでスクロールします。VectorPDF は読んでいる場所の近くのページだけをレイアウトするため、非常に長い書類でも高速に動作します。

キーボードでは次のように操作します:

| キー | 操作 |
| --- | --- |
| Left Arrow、Right Arrow | 前または次のページ |
| Up Arrow、Down Arrow | ウインドウより縦に長いページ内をスクロールしてから、次のページに移動します。ページがウインドウに収まる場合は、1 ページずつ移動します。 |
| Page Up、Page Down | より大きくスクロールしてから、次のページに移動します |
| Space、⇧Space | 前方または後方に移動します。Page Down、Page Up と同じです |
| ⌥Up Arrow、⌥Down Arrow、⌥Left Arrow、⌥Right Arrow | 前または次のページ |
| ⌘Up Arrow、⌘Down Arrow | 最初または最後のページ |

Two-Page Mode では、これらのキーで見開き単位で移動します。

## 指定したページに移動する

ツールバーのページ番号をクリックし、移動先のページを入力して、Return キーを押します。キャンセルするには Escape キーを押します。

文書によっては、前付の `iv` や図面の `A-101` のように、ページに独自の名前が付いています。その場合、VectorPDF はツールバー、ページインジケータ、サムネイルにそのラベルを表示し、`iv (4 of 300)` のようにページの位置も併せて示します。ラベルを入力すると、そのページに移動します。同じラベルが複数ある場合は、そのラベルを持つ次のページに移動します。位置を指定してページに移動するには、`#13` のように `#` と番号を入力します。

Print と Split PDF では、常にファイルの最初のページから数えた位置でページを数えます。

## 元の場所に戻る

リンクをたどったり検索結果に移動したりしたあとは、Go > Back (⌘[) を選択すると元の場所に戻ります。Go > Forward (⌘]) を選択すると、逆方向に移動します。

## 書類の構造を利用する

- [アウトライン](outline-and-thumbnails.md)を使うと、任意のセクションに移動できます。
- [サムネール](outline-and-thumbnails.md)には、すべてのページが表示されます。
- [アンカー](anchors.md)は、あとで戻りたい場所に印を付けます。
- [Link Peek](link-peek.md) を使うと、ページを離れずにリンク先を確認できます。
