# VectorPDF ユーザガイド

macOS 版

VectorPDF は、技術論文、仕様書、契約書、図面のための高速な PDF リーダーです。参照箇所の上で Command キーを押し続けると、今のページを離れずに参照先を確認できます。PDF へのマークアップ、測定、墨消し、ページの整理も、すべて Mac 上で行えます。

> **注記:** このガイドは英語の原文を機械翻訳したものです。VectorPDF の画面はまだ英語のみのため、メニュー名やボタン名は画面の表示と同じ英語のまま記載しています。
