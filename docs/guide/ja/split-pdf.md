# PDF を分割する

1. File > Split PDF を選択します。
2. Split Method で、次のいずれかを選択します:
   - **Every N Pages:** 指定したページ数ごとに新しいファイルを作成します。
   - **Single Pages:** ページごとに 1 つのファイルを作成します。
   - **Page Ranges:** ページ番号または範囲をコンマで区切って入力します。例: `1-5, 6-12, 13-20`
3. Save Location で Choose をクリックして、フォルダを選択します。
4. File Naming で、接頭辞を入力し、スタイルとして Part Number または Page Range を選択します。作成されるファイルは Output Preview に表示されます。
5. Split PDF をクリックします。

元の書類は変更されません。分割が完了したら、Reveal in Finder をクリックするとファイルを確認できます。
