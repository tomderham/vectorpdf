# テキストの選択、コピー、調べる

## テキストを選択する

- テキストの上を**ドラッグ**します。選択範囲は読む順序に従うため、段組みでは 1 つの段に収まり、余白の行番号は飛ばされます。ページをまたいで選択することもできます。
- **ダブルクリック**すると単語を、**トリプルクリック**すると行を選択できます。
- **⌥ を押しながらドラッグ**すると、図や表などの四角い領域を選択できます。

選択を解除するには、Escape キーを押します。

スキャンしたページでは、テキストが[認識](scanned-pages.md)されると選択できるようになります。

## コピーする

⌘C を押すか、選択したテキストを右クリックして Copy Text を選択します。

四角い選択範囲を右クリックすると、さらに次のオプションがあります:

- **Copy Extracted Text** は、領域内のテキストをコピーします。
- **Copy Screenshot** は、領域を画像としてコピーします。
- **Save Screenshot As** は、領域を画像ファイルとして保存します。

## 調べる、翻訳する

選択したテキストを右クリックして、次のいずれかを選択します:

- **Look Up**: 辞書の定義を表示します。
- **Translate Selection**: テキストを翻訳します。

## テキストを読み上げる

テキストを選択してから Edit > Speech > Start Speaking を選択するか、右クリックして Start Speaking を選択します。停止するには、Stop Speaking を選択するか、⌥⌘. (Option + Command + ピリオド) を押します。

## そのほかの操作

選択したテキストを右クリックして表示されるメニューには、テキストの[ハイライト、下線、取り消し線](text-markup.md)、[アンカーの作成](anchors.md)、選択範囲を新しいウインドウで開くコマンドもあります。
