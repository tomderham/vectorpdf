# 書類のプロパティ

File > Document Properties を選択するか、⌘I を押します。上部のタブを選択します:

- **General:** タイトル、作成者、件名、キーワード、日付、作成したアプリケーション、ファイルの場所、ストレージ。
- **Security:** 書類の暗号化と、プリント、コピー、変更、コメント、フォーム入力、アクセシビリティのための抽出、ページの組み立てが許可されているかどうか。
- **Page Geometry:** 任意のページの MediaBox、CropBox、BleedBox、TrimBox、ArtBox。ポイント、インチ、ミリメートルで表示します。
- **Fonts:** 書類内のフォント、その種類とエンコーディング、それぞれが埋め込まれているかどうか。フィルタフィールドを使ってフォントを探せます。
