# 描画、メモ、テキスト、吹き出し

⇧⌘A を押すか、Markup Toolbar ボタンをクリックして、Markup ツールバーを表示します。ツールを選択してから、色とサイズを選択します。色を選ぶには、ツールバーの右寄りにあるカラーボタンをクリックしてから、色をクリックします。ツールの使用を終了するには、Escape キーを押すか、ツールをもう一度クリックするか、ツールバーの最初のツールである Text Selection Mode を選択します。

## フリーハンドで描画する

ペンツールを選択し、線の太さを Thin、Medium、Thick のいずれかに設定して、ページ上をドラッグします。

## 図形を描く

1. Shapes ツールを選択してから、Rectangle、Oval、Line or Arrow、または Revision Cloud を選択します。
2. 線の太さを Thin、Medium、Thick のいずれかに設定します。線の場合は、Line Ending メニューで Open Arrow、Closed Arrow、Diamond などの矢印を選ぶか、矢印のない線にするには None を選びます。
3. ページ上でドラッグします。長方形や楕円は、ドラッグした範囲いっぱいに描かれます。線はドラッグを始めた位置から終えた位置まで引かれ、終点に線の端が付きます。

ドラッグ中に ⇧ を押したままにすると、正方形や円を描いたり、線の角度を 45° の倍数に保ったりできます。

リビジョンクラウドは、変更された箇所や確認が必要な箇所を示します。範囲を囲むようにドラッグすると、描いた輪郭に沿ってクラウドが描かれます。まっすぐ素早くドラッグすると、代わりに楕円形のクラウドになります。

長方形、楕円、クラウドを選択、移動、または右クリックするには、その輪郭を使います。そうすれば、中のテキストも引き続き選択できます。

描いた線を変更するには、どちらかの端をドラッグしてその端だけを動かすか、線を選択してツールバーで別の線の太さや線の端を選びます。右クリックして Line Ending を選ぶこともできます。長方形や楕円の太さを変えるには、選択してから線の太さを選びます。

## テキストボックスを追加する

1. テキストボックスツールを選択し、フォントサイズを 6〜32 ポイントの範囲で設定します。
2. ページ上のテキストを入れたい場所をクリックして、入力します。
3. ボックスの外側をクリックするか、Escape キーを押して終了します。

## 吹き出しを追加する

吹き出しは、ページ上の対象を矢印で指し示すテキストメモです。

1. 吹き出しツールを選択します。
2. 矢印の先を置きたい位置を押したまま、メモを置きたい場所までドラッグします。
3. メモを入力します。

矢印の先とメモは、あとでそれぞれ別にドラッグできます。

線の端を開いた矢印、ひし形、スラッシュなどにするには、描画する前にツールバーの Line Ending メニューを使用します。既存の吹き出しを変更するには、右クリックして Line Ending を選択します。

## 付箋を追加する

付箋は、コメントが入ったページ上の小さなアイコンです。

1. 付箋ツールを選択します。
2. 付箋を置きたい場所をクリックして、入力します。
3. ほかの場所をクリックして終了します。空のままの付箋は削除されます。

付箋を読んだり変更したりするには、ダブルクリックします。

## 注釈に返信する

メモ、ハイライト、描画、図形、クラウド、計測など、どの注釈にも返信を付けられます。注釈をダブルクリックするか、右クリックして Comments… を選ぶと、誰がいつ作成したかが表示されます。ほかの人やほかのアプリの注釈でも同じです。そこから次の操作ができます:

- Reply フィールドに入力して Return キーを押すと、返信を追加できます。
- Status メニューで、Accepted、Rejected、Cancelled、Completed のいずれかに設定できます。
- ゴミ箱ボタンをクリックすると、返信とともに削除できます。

テキストボックスや吹き出しをダブルクリックすると、代わりにテキストを編集します。コメントを表示するには右クリックします。ファイルに元からある線や描画も、右クリックしてください。

注釈に表示される名前は、[設定](settings.md)の Annotation Author で指定します。

## すべての注釈を表示する {#see-all-annotations}

サイドバーの Comments タブをクリックすると、書類内のすべての注釈がページごとに、コメント、ステータス、返信とともに一覧表示されます。このタブは、書類に注釈が 1 つでもあると表示されます。注釈をクリックすると、ページ上のその注釈に移動します。ダブルクリックするとそこでコメントが開き、返信したりステータスを変更したりできます。上部のフィルタボタンを使うと、1 つの種類、作成者、ステータス、日付だけを表示できます。

大きなウインドウで並べ替えや絞り込みができる表を表示するには、Markup ツールバーの右側にある Annotations ボタンをクリックします。注釈を選択して Show on Page をクリックするか、ダブルクリックすると、そのページに移動します。

## 注釈を変更する

| 目的 | 操作 |
| --- | --- |
| テキストを編集する | テキストボックスや吹き出しをダブルクリックするか、選択して Return キーを押すか、右クリックして Edit Text Box または Edit Callout Note を選択します |
| 移動する | ドラッグするか、選択して矢印キーを押します。⇧ を押したままにすると、10 ポイントずつ移動します。 |
| サイズを変更する | 選択してから、角のハンドルをドラッグします。線や矢印の場合は、どちらかの端をドラッグします。 |
| 削除する | 選択して Delete キーを押すか、右クリックして Delete Drawing や Delete Text Box などの削除コマンドを選択します |

Markup ツールバーの Eraser を使うと、注釈をクリックするか、注釈の上をドラッグして削除できます。注釈を削除すると、その返信も削除されます。

### ほかの人やアプリの注釈

ほかのレビュー担当者の図形、メモ、クラウドなど、書類に元からある注釈も同じように変更できます:

- 長方形、楕円、クラウド、線、メモ、スタンプ、テキストボックスをドラッグして移動するか、選択して矢印キーを押します。見た目、作成者、日付、返信はそのまま保たれます。
- 長方形、楕円、クラウドの角のハンドルをドラッグするとサイズが変わり、線の端をドラッグするとその端が動きます。
- 注釈を選択し、Markup ツールバーで色、線の太さ、線の端を選ぶと変更できます。その後、VectorPDF 独自のスタイルで描き直されます。

ファイルに元からあるハイライト、下線、取り消し線、フリーハンドの描画、計測は、自分で作成したものと同じく位置は変わりませんが、削除したり返信したりできます。ほかのアプリで作成されたテキストボックスのテキストは編集できません。

## 変更を取り消す

注釈の追加、移動、スタイル変更、削除を取り消すには、Edit > Undo を選択するか ⌘Z を押します。やり直すには ⇧⌘Z を押します。書類に元からあって削除した注釈や、消しゴムで誤って消した注釈など、どの注釈でも使えます。注釈は返信、作成者、日付とともに元に戻ります。

注釈は、[保存](save.md)すると標準の注釈として PDF に保存されるため、作成者、返信、ステータスとともに、ほかの PDF アプリでも表示されます。注釈をページに焼き付けるには、[フラット化した PDF を書き出します](export.md#flattened-pdf)。
