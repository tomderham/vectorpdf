# ハイライト、下線、取り消し線

## 選択したテキストをマークアップする

テキストを選択してから、次のいずれかの操作を行います:

| マークアップ | メニュー | ショートカット |
| --- | --- | --- |
| ハイライト | Edit > Highlight Selection | ⇧⌘H |
| 下線 | Edit > Underline Selection | ⇧⌘U |
| 取り消し線 | Edit > Strikethrough Selection | ⇧⌘X |

Markup ツールバーのボタンを使うか、選択範囲を右クリックして Highlight、Underline、Strikethrough を選択することもできます。それぞれに色のリストがあります。

## 色を選択する

Markup ツールバー (⇧⌘A) にはカラーボタンがあります。クリックしてから色をクリックします。ショートカットとツールバーのボタンでは、そこで選択した色が使用されます。1 つのマークアップにだけ色を選ぶには、右クリックメニューの色のリスト、または Edit メニューの項目の下にある色のリストを使用します。

## マークアップを削除する

作成したばかりのマークアップを取り消すには、Edit > Undo を選択するか ⌘Z を押します。

マークしたテキストを右クリックし、Remove Highlight、Remove Underline、Remove Strikethrough のいずれかを選択します。または、Markup ツールバーで消しゴムを選択し、削除したいマークアップをクリックするか、その上をドラッグします。誤って削除したマークアップは ⌘Z で元に戻せます。

## マークアップをまとめる

注釈の一覧を取得するには、File > Export Annotations Summary (⇧⌘E) を選択します。Markdown または CSV として保存できます。[他のフォーマットに書き出す](export.md)を参照してください。
