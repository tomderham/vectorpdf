# ハイライト、下線、取り消し線

## 選択したテキストをマークアップする

テキストを選択してから、次のいずれかの操作を行います:

| マークアップ | メニュー | ショートカット |
| --- | --- | --- |
| ハイライト | Edit > Highlight Selection | ⇧⌘H |
| 下線 | Edit > Underline Selection | ⇧⌘U |
| 取り消し線 | Edit > Strikethrough Selection | ⇧⌘X |

Markup ツールバーのボタンを使うか、選択範囲を右クリックして Highlight、Underline、Strikethrough を選択することもできます。それぞれに色のリストがあります。

## 色を選択する

Markup ツールバー (⇧⌘A) にはカラーパレットがあります。ショートカットとツールバーのボタンでは、そこで選択した色が使用されます。1 つのマークアップにだけ色を選ぶには、右クリックメニューの色のリスト、または Edit メニューの項目の下にある色のリストを使用します。

## マークアップを削除する

マークアップしたテキストを右クリックして、Remove Highlight、Remove Underline、Remove Strikethrough のいずれかを選択します。または、Markup ツールバーの Eraser を選択し、削除したいマークアップをクリックするか、その上をドラッグします。

> **注記:** VectorPDF には、マークアップ用の Undo コマンドはありません。不要なマークアップは削除するか、保存せずに書類を閉じて、最後に保存してからの変更をすべて破棄してください。

## マークアップをまとめる

注釈の一覧を取得するには、File > Export Annotations Summary (⇧⌘E) を選択します。Markdown または CSV として保存できます。[他のフォーマットに書き出す](export.md)を参照してください。
