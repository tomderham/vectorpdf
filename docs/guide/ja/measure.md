# 長さ、面積、角度を測定し、数を数える

⇧⌘M を押して Measurement ツールバーを表示します。図面が一定の縮尺で描かれている場合は、先に[縮尺を設定](drawing-scale.md)します。

正確に測定するため、測定の前に拡大してください。測定中に Escape キーを押すと、測定がキャンセルされます。ツールを終了するには、もう一度 Escape キーを押すか、選択中のツールをクリックします。

## 測定ツール

| ツール | 使いかた |
| --- | --- |
| Linear Dimension | 一方の点からもう一方の点までドラッグします。 |
| Perimeter | 経路に沿って各点をクリックします。Return キーを押すかダブルクリックすると終了します。 |
| Polygon Area | 各角をクリックします。Return キーを押すか、ダブルクリックするか、最初の点をクリックすると図形が閉じます。 |
| Rectangle Area | 角から反対側の角までドラッグします。 |
| Circle | 中心から縁までドラッグします。ラベルには面積と直径が表示され、[ステータスバー](rulers-and-inspector.md)には半径と円周も表示されます。 |
| Arc Length | 円弧の始点、円弧上の点、終点を順にクリックします。ラベルには円弧に沿った長さと半径が表示されます。 |
| Vertex Angle | 1 本目の線上の点、角、2 本目の線上の点の順にクリックします。 |
| Count | グループのボックスに数える対象(例: コンセント)を入力してから、1 つずつクリックします。 |

## 図面上のものを数える {#count-things-on-a-drawing}

Count ツールを選び、その横のボックスにグループ名(例: コンセント、タイプ A のドア)を入力するか、ボックスの横のメニューから書類内にあるグループを選びます。クリックするたびに、Measurement ツールバーの色の点のマーカーが置かれ、ツールバーにはそのグループがページ上にいくつあるかが表示されます。ほかのものを数えるにはグループ名を変えます。グループはそれぞれ別に数えられます。ページ上で区別しやすいように、グループごとに色を変えてください。

マーカーを移動するには、Select ツールでドラッグします。削除するには、右クリックして Delete Count Marker を選びます。[拾い出し表](takeoff.md)には、各ページのグループごとの数と合計が表示されます。マーカーは小さな円として PDF に保存されるため、ほかのアプリでも表示されます。

## 正確に描く

- **Ortho Lock** は、線を 0°、45°、90° に保ちます。⇧ を押し続けると、1 本の線に対してだけ切り替わります。オンのときは任意の角度で測定でき、オフのときは線をまっすぐに保てます。
- **Vertex Magnetic Snapping** は、ポインタを図面内の角や端点に吸着させます。
- **ガイドとグリッド:** View > Rulers and Grid > Snap to Guides and Grid がオンのときは、ルーラーから引き出したガイドと、表示中のグリッドに点が吸着します。[ルーラー、ステータスバー、Inspector](rulers-and-inspector.md)を参照してください。
- **ステータスバー**（View > Show Status Bar）には、描画中の計測についてラベルより多くの情報が表示されます。角度と横方向・縦方向の距離、または面積のそれまでの周長です。

## 測定値を変更する

Measurement ツールバーの先頭にある矢印の **Select** を選ぶか、Escape キーを押して測定ツールを終了します。測定値にポインタを合わせると破線の輪郭で示され、クリックすると選択されます。⇧ を押しながらクリックすると複数選択でき、⌥ を押しながらドラッグすることもできます。測定ツールを使っている間は、クリックすると新しく測定されます。

選択した測定値には、その点にハンドルがあります。

| 目的 | 操作 |
| --- | --- |
| 1 つの点を移動する | そのハンドルをドラッグします。Ortho Lock とスナップは、測定するときと同じように機能します。 |
| 測定値全体を移動する | その線をドラッグするか、矢印キーを押します（⇧ を押すと 10 ポイントずつ移動します）。 |
| 寸法線を測定対象に近づける、または離す | そのラベルをドラッグします。点から離れた寸法線は、寸法線そのものをドラッグすることもできます。 |
| 色を変更する | Measurement ツールバーのカラーボタンで色を選択します。 |
| 線の太さを変える | Measurement ツールバーの線の太さのボックスで太さを選ぶか、入力します。 |

値はドラッグ中に計算し直されます。表示より長い測定では、ウインドウの端を越えてドラッグするとスクロールします。測定値を元の状態に戻すには、Edit > Undo を選択します。PDF にすでに保存されている測定値も変更できます。

面積を選択するには、その縁をクリックします。内側をクリックすると、そこにあるテキストが選択されます。

長方形、円、円弧は、変更しても形が保たれます。長方形の角、円の中心または縁、円弧の 3 つの点のいずれかをドラッグします。これらは輪郭に沿った面積または長さとして保存されるため、PDF の測定値を読み取るほかの App でも測定値として表示され、輪郭について独自の値が示されます（円と円弧では VectorPDF の値との差は 0.05% 未満）。

## 測定値の見た目を変更する

計測する前に、Measurement ツールバーのカラーボタンと線の太さのボックスを設定してください。ポイント単位の太さを選ぶか、0.1〜72 ポイントの値を入力します。新しい測定値は、変更するまで灰色で太さ 1.5 ポイントです。選んだ設定は VectorPDF に記憶され、Markup ツールバーは独自の色と太さを保持します。すでに作成した測定値の色や太さを変更するには、その測定値を選択してから、Measurement ツールバーで色や太さを選択します。太さは PDF に保存されます。

## 測定値を残す、または削除する

測定値は注釈であり、[保存](save.md)すると PDF に保存されます。削除するには、右クリックして Delete Dimension、Delete Area Takeoff、Delete Circle Measurement、Delete Count Marker などの削除コマンドを選択します。

すべての測定値を一覧表示するには、[拾い出し表](takeoff.md)を参照してください。
