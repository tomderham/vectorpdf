# 長さ、面積、角度を測定する

⇧⌘M を押して Measurement ツールバーを表示します。図面が一定の縮尺で描かれている場合は、先に[縮尺を設定](drawing-scale.md)します。

正確に測定するため、測定の前に拡大してください。測定中に Escape キーを押すと、測定がキャンセルされます。

## 測定ツール

| ツール | 使いかた |
| --- | --- |
| Linear Dimension | 一方の点からもう一方の点までドラッグします。 |
| Perimeter | 経路に沿って各点をクリックします。Return キーを押すかダブルクリックすると終了します。 |
| Polygon Area | 各角をクリックします。Return キーを押すか、ダブルクリックするか、最初の点をクリックすると図形が閉じます。 |
| Vertex Angle | 1 本目の線上の点、角、2 本目の線上の点の順にクリックします。 |

## 正確に描く

- **Ortho Lock** は、線を 0°、45°、90° に保ちます。⇧ を押し続けると、1 本の線に対して同じことを行えます。
- **Vertex Magnetic Snapping** は、ポインタを図面内の角や端点に吸着させます。

## 測定値の見た目を変更する

測定の前に、Measurement ツールバーのカラーパレットと線の太さを使用します。

## 測定値を残す、または削除する

測定値は注釈であり、[保存](save.md)すると PDF に記録されます。削除するには、測定値を右クリックして、Delete Dimension や Delete Area Takeoff などの削除コマンドを選択します。

すべての測定値を一覧表示するには、[拾い出し表](takeoff.md)を参照してください。
