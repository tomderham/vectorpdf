# 長さ、面積、角度を測定する

⇧⌘M を押して Measurement ツールバーを表示します。図面が一定の縮尺で描かれている場合は、先に[縮尺を設定](drawing-scale.md)します。

正確に測定するため、測定の前に拡大してください。測定中に Escape キーを押すと、測定がキャンセルされます。ツールを終了するには、もう一度 Escape キーを押すか、選択中のツールをクリックします。

## 測定ツール

| ツール | 使いかた |
| --- | --- |
| Linear Dimension | 一方の点からもう一方の点までドラッグします。 |
| Perimeter | 経路に沿って各点をクリックします。Return キーを押すかダブルクリックすると終了します。 |
| Polygon Area | 各角をクリックします。Return キーを押すか、ダブルクリックするか、最初の点をクリックすると図形が閉じます。 |
| Vertex Angle | 1 本目の線上の点、角、2 本目の線上の点の順にクリックします。 |

## 正確に描く

- **Ortho Lock** は、線を 0°、45°、90° に保ちます。⇧ を押し続けると、1 本の線に対してだけ切り替わります。オンのときは任意の角度で測定でき、オフのときは線をまっすぐに保てます。
- **Vertex Magnetic Snapping** は、ポインタを図面内の角や端点に吸着させます。

## 測定値を変更する

Escape キーを押すか、選択中のツールをクリックして測定ツールを終了してから、測定値をクリックして選択します。その点にハンドルが表示されます。

| 目的 | 操作 |
| --- | --- |
| 1 つの点を移動する | そのハンドルをドラッグします。Ortho Lock とスナップは、測定するときと同じように機能します。 |
| 測定値全体を移動する | その線をドラッグするか、矢印キーを押します（⇧ を押すと 10 ポイントずつ移動します）。 |
| 寸法線を測定対象に近づける、または離す | そのラベルをドラッグします。点から離れた寸法線は、寸法線そのものをドラッグすることもできます。 |
| 色を変更する | Measurement ツールバーのカラーボタンで色を選択します。 |

値はドラッグ中に計算し直されます。測定値を元の状態に戻すには、Edit > Undo を選択します。PDF にすでに保存されている測定値も変更できます。

面積を選択するには、その縁をクリックします。内側をクリックすると、そこにあるテキストが選択されます。

## 測定値の見た目を変更する

計測する前に、Measurement ツールバーのカラーボタンと線の太さを設定してください。すでに作成した測定値の色を変更するには、その測定値を選択してから色を選択します。

## 測定値を残す、または削除する

測定値は注釈であり、[保存](save.md)すると PDF に記録されます。削除するには、測定値を右クリックして、Delete Dimension や Delete Area Takeoff などの削除コマンドを選択します。

すべての測定値を一覧表示するには、[拾い出し表](takeoff.md)を参照してください。
