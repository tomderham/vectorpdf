# VectorPDF を使ってみる

VectorPDF を使用するには、Apple シリコン搭載の Mac と macOS 15 以降が必要です。インストールするには、VectorPDF を「アプリケーション」フォルダにドラッグします。

## 最初の PDF を開く

書類を開かずに VectorPDF を起動すると、Start 画面が表示されます。次のいずれかの操作を行います:

- PDF をドロップゾーンにドラッグします。
- ドロップゾーンをクリックして、ファイルを選択します。
- ⌘O を押します。

Finder の [Open With](open-documents.md) から PDF を開くことも、Start 画面の Tab Groups、Favorites、Recent Documents から選択することもできます。

## まず試したい 5 つのこと

1. **Command キーを押したままリンクの上に移動する。** 数式、図、表、引用への参照にポインタを合わせて ⌘ を押し続けると、[参照先をプレビュー](link-peek.md)できます。キーを放すとプレビューは閉じます。
2. **検索する。** ⌘F を押します。[検索結果](search.md)は見つかるたびにサイドバーに表示され、⌘G で順に移動できます。
3. **場所を保存する。** テキストを選択して ⌘B を押すと、あとで戻れる[アンカー](anchors.md)が作成されます。
4. **マークアップする。** テキストを選択して ⇧⌘H を押すと[ハイライト](text-markup.md)できます。⇧⌘A を押すと Markup ツールバーが表示されます。
5. **関連する 2 つの書類をタブで開く。** ⌥⌘O を押して 2 つ目の書類を開き、“Section 4.2 of the Master Agreement” のようなプレーンテキストの参照を右クリックすると、[別のタブで参照先を探せます](cross-document-references.md)。

## 操作を確認する

ほとんどの機能はメニューバー、サイドバー、ツールバーから使用でき、右クリックするとポインタの下にある項目に応じたコマンドが表示されます。概要については [VectorPDF のウインドウ](the-window.md)、各メニューの内容については[右クリックメニュー](right-click-menus.md)、一覧については[キーボードショートカット](keyboard-shortcuts.md)を参照してください。

このガイドを検索するには、サイドバー上部の「このガイドを検索」フィールドを使用します。ウインドウ上部の検索フィールドでは、すべてのアプリのヘルプが検索されます。
