# 書類間の参照

規格書は他の規格を引用し、契約書は別紙を参照しますが、多くの場合、リンクではなくプレーンテキストで書かれています。関連する書類を 1 つのウインドウのタブとして開くと、VectorPDF がこうした参照をたどることができます。

## プレーンテキストの参照をたどる

1. 関連する書類を[同じウインドウのタブ](tabs-and-windows.md)として開きます。
2. “Section 8.8.3 of [HTTP]” や “Clause 4.2 of the Master Agreement” のような参照を右クリックするか、参照を選択して右クリックします。
3. 次のいずれかを選択します:
   - 一致する見出しの **Go to**: 見出しをプレビューします。プレビューからその場所に移動できます。
   - メニューが開いている間に ⌘ を押し続けると、コマンドが **Open** に変わり、プレビューなしで直接移動します。
   - **Find “参照” in Other Tabs**: ほかのタブのテキストを検索します。“参照” はクリックしたテキストです。

VectorPDF は、参照をもう一方の書類のアウトラインと照合します。アウトラインがない場合は、見出しと照合します。同じ見出しが複数のタブにある場合は、プレビューにそれぞれが一覧表示されます。

## 開いている書類への Web リンク

Web 上で互いにリンクしている書類もあります。たとえば、IETF の RFC は rfc-editor.org にリンクしています。Web リンクの指す書類が別のタブで開いている場合は、⌘ を押しながらポインタを合わせるか強めのクリックをすると、ブラウザを開かずに[そのタブの書類がプレビューされます](link-peek.md)。

## 書類のセットをまとめておく

一緒に使う書類を [Tab Group](favorites-and-tab-groups.md) として保存すると、1 回の操作でまとめて開き直すことができます。
