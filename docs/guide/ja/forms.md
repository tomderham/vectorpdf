# フォームに入力する

VectorPDF は、インタラクティブな PDF フォーム (AcroForm) に対応しています。フィールドはページ上に表示され、そのまま使用できます。

- **テキストフィールド:** クリックして入力します。
- **チェックボックスとラジオボタン:** クリックして選択します。
- **ポップアップメニューとリスト:** クリックして項目を選択します。
- **署名フィールド:** **Sign** をクリックしてから、[スタンプ](stamps.md)を作成または選択します。

入力が終わったフォームを[保存](save.md)するには、⌘S を押します。

フォームにリセットボタンがある場合、クリックすると確認を求められたあと、すべてのフィールドが消去されます。

回答を変更できないようにするには、フォームフィールドをフラット化したコピーを保存します。[他のフォーマットに書き出す](export.md#flattened-pdf)を参照してください。

> **注記:** フィールドを使用できるのは、Single Page 表示で回転していない場合のみです。[拡大/縮小、回転、ページレイアウト](zoom-and-layout.md)を参照してください。
