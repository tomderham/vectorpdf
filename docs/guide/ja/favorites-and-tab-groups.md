# お気に入りとタブグループ

## お気に入り

よく使う PDF をお気に入りにしておくと、すぐに開くことができます。

- **現在の PDF を追加または削除する:** Favorites > Add This PDF to Favorites を選択するか、⌘D を押します。もう一度 ⌘D を押すと削除されます。
- **お気に入りを開く:** Favorites メニューで選択してから Open を選択するか、Start 画面でクリックします。

同じコマンドは、書類のタイトルやツールバーの何もない部分を右クリックしたときにも、Favorites と Tab Groups とともに表示されます。

## タブグループ

Tab Group は、1 つのウインドウのタブとしてまとめて開く、名前付きの書類のセットです。プロジェクトの仕様書をまとめる場合などに使用します。

### グループを保存する

1. 書類を 1 つのウインドウのタブとして開きます。
2. Favorites > Save All Open Tabs as a Group を選択します。
3. 名前を入力して、Save をクリックします。

### グループを開く

Favorites メニューでグループを選択してから Open を選択するか、Start 画面でクリックします。

### グループを変更する

グループを開いてタブを追加するか閉じてから、Favorites > Update Group “名前” with Open Tabs を選択します。“名前” はグループの名前です。

### グループを削除する

Favorites メニューでグループを選択してから、Delete Tab Group を選択します。Start 画面でグループを削除したりお気に入りを取り除いたりした場合は、表示されるメッセージの Undo をクリックすると元に戻せます。
