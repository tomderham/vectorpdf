# 2つの書類を比較する

Compare Documents では、1つの書類の2つの版を並べて表示し、変更されたテキストを両方でハイライトします。一方をスクロールすると、版の間でページが追加または削除されていても、もう一方が同じテキストまでスクロールします。

## 比較を開く

1. File > Compare Documents を選択します。
2. 元の書類（Original）と改訂版（Revised）を選択します。それぞれのメニューには開いている書類が表示されます。別の書類を選ぶには Choose File を選択します。最初は手前の書類が元の書類になります。入れ替えるには Swap をクリックします。
3. Compare をクリックします。

書類のタイトル、またはツールバーの何もない部分を右クリックし、Compare With から書類を選択することもできます。手前の書類と選んだ書類が比較されます。

比較は新しいタブで開き、左に元の書類、右に改訂版が表示されます。このタブではどちらも読み出し専用です。編集するには、その書類を専用のタブで開きます。

## 変更を確認する

- 元の書類から削除された単語は、左側で赤くハイライトされます。
- 改訂版で追加された単語は、右側で緑にハイライトされます。
- 一方にだけテキストが追加された箇所では、もう一方の細いバーがその位置を示します。
- 両方で同じでも別の場所にあるテキストは、両側で青い下線が引かれます。たとえば改ページの反対側に回った表や、移動された条項です。連続する 10 語以上が対象です。移動されたテキストは変更として数えられません。Changes タブの上部に、別の場所にある箇所の数が表示されます。

サイドバーの Changes タブには、すべての変更が一覧表示されます。削除された単語は赤の取り消し線付き、追加された単語は緑で、改訂版のページ番号も表示されます。変更をクリックすると、両方の書類でその変更に移動します。

変更を順に確認するには、Changes タブの上部にある上下の矢印をクリックするか、Go > Previous Change または Go > Next Change を選択するか、⌥⌘Up Arrow または ⌥⌘Down Arrow を押します。タブには 3 of 12 のように現在の変更が表示されます。その変更はより強くハイライトされ、リストで選択されます。

比較されるのはテキストだけです。書式、画像、図面の変更は表示されません。柱（ヘッダとフッタ）とページ番号は除外されるため、ページがずれても変更として表示されません。

## セクションや単語を探す

サイドバーの Outline & Thumbnails タブと Search タブは、ほかのタブと同様に改訂版を対象にします。セクションや検索結果に移動すると、元の書類も同じテキストまで移動します。

## 一緒にスクロール、拡大／縮小する

両側の上から約3分の1の位置にある行には、同じテキストが表示されます。一方にしかないテキストがある場合、もう一方はそのテキストを通り過ぎるまで待ちます。どちら側をスクロールしても、もう一方が追従します。

一方を拡大／縮小すると両方が拡大／縮小され、読んでいるテキストはその位置に留まります。ページの幅を超えて拡大している場合、一方を横にスクロールするともう一方も横にスクロールし、両方でページの同じ部分が表示されます。

## 比較のオプション

Changes タブの上部で Ignore Case または Ignore Punctuation を選択すると、大文字と小文字の違いや句読点の違いが除外されます。曲がった引用符とまっすぐな引用符、さまざまな種類のダッシュは、常に同じものとして扱われます。

### 番号の振り直しを無視する

条項、図、表を追加または削除すると、それ以降のすべてに番号が振り直され、それ以降のページ番号もすべて変わります。長い書類では、変更の大半が目次、図の一覧、相互参照の新しい番号になることがあります。最初からオンになっている Ignore Renumbering により、それらが除外されます:

- 目次や図の一覧の項目、または「9.4.2.18 を参照」のような相互参照は、両方のバージョンで同じ場所にリンクしていれば、番号やページ番号が新しくても変更として扱われません。
- リンク先でも、見出しやキャプション自体の番号が同じように変わっていれば、変更として扱われません。たとえば「Figure 9-806」が「Figure 9-809」になった場合です。

何を同じ場所とみなすかは、番号の見た目ではなく書類内のリンクによって決まります。別の場所にリンクするようになった相互参照は引き続き変更として表示されます。リンクの一部ではない番号(たとえば普通のテキストとして入力された「Table 9-12」)も同様です。言い回しが変わった見出しは、目次の項目では表示されなくても、見出し自体では引き続き変更として表示されます。

Ignore Renumbering を使うには、書類内にリンクが必要です。ほとんどのワープロアプリや組版アプリは、目次と相互参照にリンクを作成します。どちらの書類にもリンクがない場合は使用できません。リンクを削除するアプリで保存し直した PDF には、元の書類にあったとしてもリンクはありません。

変更されたすべての番号を表示するには、Ignore Renumbering をオフにします。

## 比較が役に立たない場合

- **書類に比較するテキストがない:** スキャンしたページには、文字認識するまでテキストがありません。[スキャンしたページのテキストを検索、選択する](scanned-pages.md)を参照してください。
- **これらの書類に共通するテキストが少ない:** 同じ書類の版ではない可能性があります。
