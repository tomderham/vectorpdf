# VectorPDF のウインドウ

VectorPDF の各ウインドウには、ツールバー、サイドバー、書類本体があります。1 つのウインドウに複数の書類を[タブ](tabs-and-windows.md)として開くこともできます。

## ツールバー

| コントロール | 機能 |
| --- | --- |
| 書類のタイトル | 書類の名前を表示します。右クリックすると Favorites と Tab Groups のコマンドが表示されます。 |
| Zoom | − と + のボタンで表示倍率を段階的に変更します。パーセント表示をクリックすると値を入力できます。 |
| Rotate Left と Rotate Right | 表示を回転します。保存される PDF は変更されません。 |
| Two-Page Mode | 開いた本のようにページを左右に並べて表示します。 |
| Markup Toolbar | [マークアップツール](text-markup.md)を表示します。 |
| Measurement Toolbar | [測定ツール](measure.md)を表示します。 |
| Page | 矢印で 1 ページずつ移動します。ページ番号をクリックすると、移動先のページを入力できます。 |

これらのコントロールについて詳しくは、[拡大/縮小、回転、ページレイアウト](zoom-and-layout.md)を参照してください。

## サイドバー

サイドバー上部のタブで、次の表示を切り替えます:

- **Outline & Thumbnails:** [目次、または各ページのサムネール](outline-and-thumbnails.md)。
- **Search:** [現在の書類の検索結果](search.md)。
- **Anchors:** [保存した場所](anchors.md)。
- **Layers:** [書類のレイヤーを表示または非表示にする](layers.md)。このタブは、書類にレイヤーがある場合にのみ表示されます。
- **Attachments:** [PDF に添付されたファイル](attachments.md)。このタブは、書類に添付ファイルがある場合にのみ表示されます。
- **Comments:** [すべての注釈と、その返信およびステータス](draw-and-notes.md#see-all-annotations)。
- **Ask About This Document:** [Agent](agent.md)。このタブは macOS 26 以降で表示されます。ただし、Settings で [Use Agent](settings.md) をオフにした場合は表示されません。

サイドバーを表示または非表示にするには、ツールバーのサイドバーボタンを使用します。

## 追加のツールバー

必要に応じて、3 つのツールバーがメインのツールバーの下に表示されます。View メニューから選択します:

- **Markup** (⇧⌘A) には[注釈ツール](text-markup.md)があります。
- **Measurement** (⇧⌘M) には[測定ツール](measure.md)があります。
- **Redact** (⌥⌘R) には[墨消しツール](redact.md)があります。

## 右クリックメニュー

多くのコマンドは、書類、サイドバー、ツールバーを右クリックまたは Control キーを押しながらクリックして表示されるメニューからも使用できます。[右クリックメニュー](right-click-menus.md)を参照してください。

## ページインジケータ

ページを移動すると、前後のページに移動する矢印付きの小さなページインジケータが書類の上に一時的に表示されます。Measurement ツールバーの表示中は、そのページの図面の縮尺も表示されます。

## Start 画面

空のウインドウやタブには Start 画面が表示され、ドロップゾーンのほか、Tab Groups、Favorites、Recent Documents が並びます。行をクリックすると開きます。行にポインタを合わせて ••• ボタンをクリックするか行を右クリックすると、新しいタブやウインドウで開く、Finder に表示する、削除するなどの操作を行えます。

Start 画面に表示されるのは、Tab Groups が最大 3 件、Favorites が最大 5 件です。すべての項目は Favorites メニューで確認できます。
