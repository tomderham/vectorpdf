# プリントする

File > Print を選択するか、⌘P を押します。

プリントダイアログで PDF Options を選択すると、次の項目が表示されます:

- **Auto Rotate:** 用紙に合わせてページを回転します。
- **Scale to Fit:** 各ページを用紙に合わせます。
- **Scale:** 入力したパーセントでプリントします。

VectorPDF は画面表示と同じエンジンでプリントするため、出力は画面で見たとおりになります。
