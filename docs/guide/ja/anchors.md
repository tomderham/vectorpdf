# アンカー

アンカーは、書類内の保存した場所です。文章の一節、ページの領域、リンク先などを保存できます。アンカーは PDF とは別に保存されるため、PDF は変更されません。

## アンカーを作成する

- テキストを選択するか、⌥ を押しながらドラッグして領域を選択し、⌘B を押します。
- 選択範囲、リンク、ページ上の場所を右クリックして、**Create Anchor** を選択します。
- [検索結果](search.md)または[アウトライン](outline-and-thumbnails.md)の項目を右クリックして、**Create Anchor** を選択します。

何も選択していない場合、⌘B を押すと現在のページのアンカーが作成されます。

**Create Anchor and Open in New Window** を選択すると、同じようにアンカーを作成し、その場所を別のウインドウにも表示します。

## アンカーを使う

サイドバーの Anchors タブをクリックすると、アンカーごとのカードが表示されます。Anchors メニューも使用できます。

- **アンカーに移動する:** カードをクリックするか、Anchors メニューで選択します。
- **大きなプレビューを見る:** カードのサムネールにポインタを合わせます。
- **ウインドウ内のすべてのタブのアンカーを見る:** Anchors タブの上部で All Tabs を選択します。アンカーをクリックすると、そのタブに切り替わります。

カードを右クリックすると、新しいウインドウで開く、テキストをコピーする、画像をコピーするなどの操作を行えます。

## アンカーを削除する

- **1 つのアンカー:** カードの × をクリックするか、カードを右クリックして Delete Anchor を選択します。
- **書類内のすべてのアンカー:** Anchors タブの Clear All をクリックするか、Anchors > Clear All Anchors を選択します。

## アンカーとページの変更

アンカーはページ番号を記憶しています。ページの追加、削除、移動によってアンカーが誤った場所を指すようになる場合は、変更の前に VectorPDF が警告します。**Save as Copy** を選択すると、アンカーのないコピーで変更を行います。**Edit Anyway** を選択すると、そのまま変更します。

## 他の Mac のアンカー

オフにしない限り、アンカーは読書位置とともに [iCloud で同期](reading-positions.md)されます。
