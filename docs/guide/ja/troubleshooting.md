# トラブルシューティング

## テキストを選択できない、リンクをたどれない、マークアップツールを使用できない

表示が回転していないこと、Two-Page Mode になっていないことを確認してください。これらの機能は、Single Page 表示で回転していない場合にのみ使用できます。[拡大/縮小、回転、ページレイアウト](zoom-and-layout.md)を参照してください。

また、Markup ツールや Measurement ツールが有効になっていないことも確認してください。Escape キーを押すと、テキスト選択に戻ります。

## 検索しても何も見つからない

- ページがスキャンされたものである可能性があります。[OCR でスキャンしたページを検索する](scanned-pages.md)を参照してください。
- [検索オプション](search.md#search-options)で Match Case と Whole Word がオフになっていること、Smart Search がオンになっていることを確認してください。
- 記号がテキストの途中に入っている場合は、[無視するパターン](search.md#ignore-clutter-in-the-text)を追加してください。

## ⌘ を押し続けてもプレビューが表示されない

Link Peek は、書類内のリンクと、別のタブで開いている書類への Web リンクで機能します。プレーンテキストの参照はリンクではないため、右クリックしてください。[書類間の参照](cross-document-references.md)を参照してください。

VectorPDF のウインドウがアクティブになっている必要もあります。

## 別の書類への参照が見つからない

もう一方の書類を同じウインドウのタブとして開いてください。別のウインドウは検索されません。

## 文書が破損していると表示される

ファイル内にページが見つからない場合、VectorPDF はファイルを開けなかったことを通知します。ファイルが破損しているか不完全であるか、VectorPDF が読み取れない機能を使用している可能性があります。もう一度ダウンロードするか、別の PDF アプリで開いてみてください。

## クラウド上の書類を開けない

接続を確認し、Finder でファイルがダウンロードされることを確認してから、もう一度試してください。

## Agent を使用できない、または該当箇所だけが表示される

Agent には macOS 26 以降が必要です。デバイス上で回答を作成するには、Apple Intelligence がオンになっていて使用できる状態である必要があります。インデックスの作成に失敗した場合は、Ask About This Document タブの Retry をクリックしてください。[Agent の回答方法を選択する](agent-engines.md)を参照してください。

## オンラインモデルが回答しない

[Settings](settings.md) で API キーとモデルを確認し、そのサービスのアカウントにクレジットがあることを確認してください。サービスが機能しない場合は、VectorPDF がデバイス上で回答します。

## 変更が消えた

変更は[保存](save.md)する必要があります。保存していない変更があるときに別のアプリがファイルを変更した場合は、Reload from Disk を選択すると変更が破棄されます。

## ヘルプにこのガイドが表示されない

Tips にこのガイドを表示できるのは、VectorPDF が「アプリケーション」フォルダにある場合のみです。そこに移動してから、もう一度 Help > VectorPDF Help を選択してください。

## さらにヘルプを受ける

問題の報告や質問は [GitHub](https://github.com/tomderham/vectorpdf/issues) で行えます。共有できる場合は、サンプルの PDF があると役立ちます。
