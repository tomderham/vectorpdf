# 拾い出し表

拾い出し表は、書類内のすべての測定値を、ページ、種類、値、縮尺とともに一覧にし、長さと面積の合計を示す表です。

[Measurement ツールバー](measure.md)の **Takeoff Table** をクリックします。

- **Copy Table** は、スプレッドシートに貼り付けられる形で表をコピーします。
- **Export CSV** は、表をファイルとして保存します。

[レイヤー](layers.md)のある書類では、表に各計測のレイヤーも表示され、非表示のレイヤーにある計測は除外されます。そのため、工種ごとに合計できます。

合計では、すべてのページの長さ (寸法と周長) と面積を合算します。各測定値にはそのページの縮尺が使用され、合計は最初の測定値の単位で表示されます。
