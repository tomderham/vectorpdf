# ルーラー、ステータスバー、Inspector

これらは、ページ上のものがどこにあり、何でできているかを示します。読みやすさを保つため、View メニューでオンにするまではオフになっています。

## ステータスバー

View > Show Status Bar（⌘/）を選択すると、ページの下に帯が表示されます。次の情報が表示されます:

- **ポインタの位置**（ページの左上隅から）。[図面の縮尺](drawing-scale.md)が設定されたページでは、その位置を実寸の単位でも表示します。
- ポインタの下にあるページ、または現在のページの**ページサイズ**。A0〜A6、B3〜B5、Letter、Legal、Tabloid、ANSI C〜E、ARCH A〜E のいずれかの用紙サイズに一致する場合は、その名前も表示されます。図面セットではシートのサイズが混在することが多いため、ページを移動すると表示が変わります。
- **描画中の計測:** 長さ、角度、横方向（ΔX）と縦方向（ΔY）の距離。周長のそれまでの長さと最後の線分。面積のそれまでの値と周長。[長さ、面積、角度を計測する](measure.md)を参照してください。
- **テキストの選択範囲の大きさ**（単語数と文字数）。

単位（Millimeters、Inches、Points）は、ステータスバー右端のメニューから選択します。ルーラー、グリッド、Inspector も同じ単位を使います。

## ルーラーとガイド

View > Rulers and Grid > Show Rulers（⌘R）を選択すると、ページの上と左にルーラーが表示されます。ルーラーはポインタの下にあるページを左上隅から測り、各ルーラー上の線がポインタの位置を示します。

| 目的 | 操作 |
| --- | --- |
| ガイドを追加する | ルーラーからページ上にドラッグします |
| ガイドを移動する | ドラッグします |
| ガイドを削除する | ページの外にドラッグします |
| すべてのガイドを削除する | View > Rulers and Grid > Clear Guides を選択します |

ガイドは、配置したページに属します。書類が開いている間は残り、書類には保存されません。

## グリッド

View > Rulers and Grid > Show Grid（⌘'）を選択すると、各ページに左上隅からグリッドが描かれます。間隔は View > Rulers and Grid > Grid Spacing で選択します。5 本ごとの線は濃く表示されます。

View > Rulers and Grid の **Snap to Guides and Grid** がオンのときは、計測の点がポインタ近くのガイドと、表示中のグリッドに吸着します。Vertex Magnetic Snapping で角に吸着するのと同じです。

## Inspector {#the-inspector}

View > Show Inspector（⌃⌘I）を選択すると、ページの横に Inspector が表示されます。ページを右クリックして Inspect を選択することもできます。

- **テキスト、画像、図形:** Inspector を開いた状態で、Select モードでページをクリックします。そこに描かれているものが Inspector に表示され、ページ上で枠で囲まれます:
  - **テキスト:** フォント、サイズ、文字、カラーとカラースペース、フォントがファイルに含まれているかどうか。含まれていないフォントは代替フォントで描かれるため、印刷すると見た目が異なる場合があります。
  - **画像:** ピクセル単位のサイズ、ページ上に配置された状態での解像度、ページ上のサイズ、カラースペース、コンポーネントあたりのビット数。印刷や最適化の前に画像の解像度を確認できます。
  - **図形:** 線の太さとカラー、または図形の塗りつぶしカラー。
- **注釈:** 注釈を選択すると、種類、作成者、日付、レイヤー、不透明度、カラーが表示されます。移動するには、位置（ページの左上隅からの **X** と **Y**）を入力して Return キーを押します。長方形、楕円、テキストボックス、吹き出し、スタンプ、改訂雲形はサイズも変更できます。**Width** と **Height** を入力します。

## ナビゲータ

View > Show Navigator（⌃⌘N）を選択すると、表示中のページのミニチュアがウインドウの隅に表示されます。画面に表示されている部分は枠で囲まれます。枠をドラッグするか、ミニチュアをクリックすると、大きく拡大した状態で大きなシートの中を移動できます。
