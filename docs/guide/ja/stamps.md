# スタンプと署名

スタンプは、署名やイニシャルなどの画像で、任意のページに配置できます。

> **注記:** スタンプは視覚的な印です。暗号化されたデジタル署名ではなく、書類を証明するものでもありません。

## スタンプを作成する

1. VectorPDF > Settings を選択してから、Digital Stamp の Create Stamp をクリックします。Markup ツールバーの Stamp ツールを選択するだけでも、スタンプの作成を求められます。
2. 作成方法を選択します:
   - **Draw:** トラックパッドまたはマウスで署名します。
   - **Type:** 名前またはイニシャルを入力して、フォントを選択します。
   - **Image:** PNG または JPEG ファイルを選択します。**Transparent background** を選択すると、画像の背景からページが透けて見えます。
3. Use をクリックします。

VectorPDF は、次回のためにスタンプをこの Mac に保持します。置き換えたり削除したりするには、[Settings](settings.md) の Modify Stamp または Delete Stamp を使用します。

## スタンプを配置する

1. Markup ツールバー (⇧⌘A) を表示してから、Stamp ツールを選択します。
2. スタンプを配置したい場所をクリックします。

配置後は、ドラッグして移動したり、角をドラッグしてサイズを変更したりできます。削除するには、スタンプを選択して Delete キーを押すか、右クリックして Delete Signature を選択します。

## フォームに署名する

フォームに署名フィールドがある場合は、フィールド内の **Sign** をクリックします。[フォームに入力する](forms.md)を参照してください。
