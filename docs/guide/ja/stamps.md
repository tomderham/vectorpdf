# 書類に署名する

署名には 2 つの方法があり、それぞれ働きが異なります。どちらも、Markup ツールバー（⇧⌘A）にある署名の形をした Sign ボタンにあります。

| | 手書きの署名 | デジタル署名 |
| --- | --- | --- |
| 内容 | ページ上の署名またはイニシャルの画像 | 証明書で作成され、ファイル内に保存される署名 |
| 誰が署名したかを示すか | いいえ: 誰でも画像を貼り付けられます | はい、証明書が読み手の信頼する認証局のものである場合 |
| その後書類が変更されていないことを示すか | いいえ | はい |
| 必要なもの | なし: 描く、入力する、または画像を選択する | 組織または認証局から入手した署名用の証明書 |
| 後から取り除けるか | はい、注釈と同じように | 署名前に保存したコピーに戻した場合のみ |

画像で十分な場合、たとえば形式ばらないフォームなどでは、手書きの署名で足ります。契約、承認、後で誰かが確認する必要がありそうなものには、デジタル署名を使います。デジタル署名の枠に手書きの署名を表示することもできます。

## 手書きの署名を追加する {#add-your-handwritten-signature}

1. Markup ツールバーを表示し（⇧⌘A）、Sign ボタンをクリックしてから、Add Handwritten Signature を選択します。初回は、署名を作成するよう求められます:
   - **Draw:** トラックパッドまたはマウスで署名します。
   - **Type:** 名前またはイニシャルを入力して、フォントを選択します。
   - **Image:** PNG または JPEG ファイルを選択します。**Transparent background** を選択すると、画像の背景からページが透けて見えます。
2. 置きたい場所をクリックします。

配置後は、ドラッグして移動したり、角をドラッグしてサイズを変更したりできます。削除するには、署名を選択して Delete キーを押すか、右クリックして Delete Signature を選択します。

署名は次回のためにこの Mac に保存されます。変更または削除するには、VectorPDF > Settings を選択し、General をクリックしてから、Handwritten Signature の横のボタンを使います。

## 証明書で署名する {#sign}

署名するには、秘密鍵の付いた署名用の証明書が必要です。組織や認証局から、通常はパスワード付きの .p12 または .pfx ファイルとして提供されます。キーチェーン内の証明書はそのまま使用できます。

1. Markup ツールバーの Sign ボタンをクリックして Sign with Certificate を選択するか、Edit > Sign with Certificate を選択します。次に、署名を置きたいページの場所に枠をドラッグするか、クリックして通常のサイズの枠を置きます。中止するには Esc キーを押します。書類に空の署名フィールドがある場合は、代わりにそのフィールドをクリックして Sign with Certificate を選択することもできます。
2. 証明書を選択します。署名がどのように表示されるかがプレビューで示されます。ファイルを使うには、**Choose Certificate File** をクリックしてから、そのパスワードを入力します。ファイルはこの署名のためだけに読み込まれ、キーチェーンには追加されません。
3. 必要に応じて、理由（“この書類を承認します”など）と署名する場所を入力します。[手書きの署名](#add-your-handwritten-signature)を作成してある場合は、フィールドに表示できます。そうでない場合は名前が表示されます。
4. 必要に応じて、After Signing で次を選択します:
   - **Certify**（まだ誰も署名していない書類の場合）: 今後どの変更なら書類が有効なままかを指定します。フォームへの入力、署名、注釈の追加。フォームへの入力と署名。または変更なし。証明された書類は、確認する誰に対しても証明済みとして表示され、許可されていない後からの変更はあなたの署名を無効にします。
   - **Lock form fields**（フォームの場合）: すべてのフィールド、または選択したフィールドが読み出し専用になり、署名した値が保たれます。
5. **Sign** をクリックします。

署名すると書類が保存されます。そのため、保存していない変更がある場合、VectorPDF はまずそれを保存するかどうかを確認します。保存した変更も署名の対象になります。macOS から、VectorPDF に証明書の鍵の使用を許可するよう求められることがあります。

ロックしたり、より少ない変更しか許可しないよう証明したりしない限り、署名しても書類のほかのフォームフィールドはそのままなので、ほかの人はあなたの署名を無効にすることなく、引き続きフィールドに入力したり、署名したり、注釈を追加したりできます。後から追加される署名も、同じように前の署名の後に追加されます。

この署名は SHA-256 による PKCS #7 署名で、あなたの証明書と、それを発行した認証局の証明書を含みます。Mac の時刻が記録されます。

署名した時刻をタイムスタンプサーバに保証してもらうには、**Add a timestamp** をオンにして、そのアドレスを指定します（組織で運用している場合があります。DigiCert の `http://timestamp.digicert.com` など、無料のものもあります）。タイムスタンプがあると、証明書の有効期限が切れた後でも、署名した時点の状態で署名を確認できます。サーバに送られるのは署名のフィンガープリントだけで、書類の内容は送られません。サーバに接続できない場合は何も署名されず、書類は元のままです。

書類の署名を確認するには、[デジタル署名を確認する](digital-signatures.md)を参照してください。

## フォームに署名する

フォームに署名フィールドがある場合は、フィールド内の **Sign** をクリックしてから、Add Handwritten Signature か Sign with Certificate を選択します。[フォームに入力する](forms.md)を参照してください。
