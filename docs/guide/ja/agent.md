# 書類について質問する

Agent は、開いている書類についての質問に回答し、回答の根拠となる箇所を示します。macOS 26 以降が必要です。

## 質問する

1. サイドバーの Ask About This Document タブをクリックします。初回は、VectorPDF が Mac 上で書類のインデックスを作成し、進行状況を表示します。
2. 質問を入力して、Return キーを押すか、Ask をクリックします。改行するには ⇧Return を押します。

回答の下にある **Sources** をクリックすると、回答に使用された箇所とそのページが表示されます。回答で引用された箇所には **Cited** と表示されます。箇所をクリックすると、その場所に移動します。

続けて質問することもできます。最初からやり直すには、**New Conversation** をクリックします。

> **注記:** Agent の回答には誤りが含まれることがあります。重要な内容については、情報源を確認してください。

## 回答を生成できない場合

お使いの Mac で回答を生成できない場合、Agent は代わりに最も一致する箇所を表示します。[Agent の回答方法を選択する](agent-engines.md)を参照してください。

## Agent をオフにする

[Settings](settings.md) で **Use Agent** をオフにします。サイドバーからタブがなくなります。
