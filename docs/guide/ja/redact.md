# 機密情報を墨消しする

墨消しを行うと、PDF から内容が完全に削除されます。VectorPDF は、墨消しした領域の下にあるテキスト、画像のピクセル、線画と、その領域に接する注釈やフォームフィールドをファイルから削除します。単にボックスで覆うのではなく、保存時に以前のリビジョンも残りません。

> **警告:** 墨消しは適用するとすぐに反映され、Undo はありません。元のファイルは保存するまで変更されないため、やり直すには、保存せずに書類を閉じます。元のファイルのコピーを保管し、Save As を使って墨消ししたバージョンを新しい名前で保存してください。

⌥⌘R を押すか、View > Show Redact Toolbar を選択します。

## 領域を墨消しする

1. **Redact Region** を選択します。
2. 墨消しの色として Black または White を選択します。
3. 墨消しする領域をドラッグします。

## 検索して墨消しする

1. **Find & Redact** を選択します。
2. 検索する対象を選択します:
   - **Text / Phrase**: Match Case と Whole Word のオプションがあります。
   - **Custom Regular Expression**: `[A-Z]{3}-\d{5}` など。
   - **Social Security Number (SSN)**、**Credit Card Number**、**Email Address**、**Phone Number**、**Date**: 一般的な形式を自動的に検索します。
3. Find をクリックします。
4. 一致した項目を確認します。項目をクリックするとそのページで確認できます。残したい項目は選択を解除します。
5. 操作を選択します:
   - **Redact** は、内容を削除し、黒または白のボックスを残します。
   - **Remove** は、内容を削除し、ボックスを残しません。
6. **Redact Selected** または **Remove Selected** をクリックします。

> **警告:** 自動検出では、特に一般的でない形式や画像内のテキストを見落とすことがあります。書類を共有する前に確認してください。スキャンしたページのテキストは、Redact Region で墨消しする必要があります。

## 結果を保存する

⇧⌘S を押して、墨消しした書類を新しい名前で保存します。保存すると、削除したテキストが含まれている可能性のある書類の [Agent](agent.md) 検索インデックスも削除されます。
