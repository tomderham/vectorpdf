# スキャンしたページのテキストを検索、選択する

スキャンしたページは、テキストを写した画像です。VectorPDF は光学式文字認識 (OCR) を使って Mac 上でテキストを認識し、検索、選択、マークアップができるようにします。

## 仕組み

書類を開くと、VectorPDF は最初の 50 ページからスキャンしたページを探し、バックグラウンドでテキストを認識します。さらに処理が必要な場合は、Search タブに見つかったスキャンページの数が表示されます。

- **見つかったすべてのスキャンページを認識するには、** Search タブの **Run OCR** をクリックします。
- 検索でもスキャンページが認識されるため、そのまま検索を始めることもできます。

ページがわずかに傾いてスキャンされている場合でも、ハイライトはテキストに沿って表示されます。

## 認識されたテキストを選択する

ページが認識されると、ほかのページと同じように、テキストを[選択してコピー](select-text.md)したり、[ハイライト、下線、取り消し線](text-markup.md)を付けたりできます。認識には少し時間がかかることがあります。また、最初の 50 ページより後のページは、先に Run OCR または検索が必要です。

認識には誤りが含まれることがあるため、正確さが必要なテキストはコピー後に確認してください。選択範囲は単語の端できれいに始まり、終わります。単語の途中では、選択範囲の端はおおよその位置になります。

> **注記:** 認識されたテキストは書類を開いている間に使用され、PDF には保存されません。追加したマークアップは保存されます。ページを墨消しまたは回転すると、そのページのテキストは再度認識されます。
