# スキャンしたページのテキストを検索、選択する

スキャンしたページは、テキストを写した画像です。VectorPDF は光学式文字認識 (OCR) を使って Mac 上でテキストを認識し、検索、選択、マークアップができるようにします。

## 仕組み

書類を開くと、VectorPDF は最初の 50 ページからスキャンしたページを探し、バックグラウンドでテキストを認識します。さらに処理が必要な場合は、Search タブに見つかったスキャンページの数が表示されます。

- **見つかったすべてのスキャンページを認識するには、** Search タブの **Run OCR** をクリックします。
- 検索でもスキャンページが認識されるため、そのまま検索を始めることもできます。

ページがわずかに傾いてスキャンされている場合でも、ハイライトはテキストに沿って表示されます。

テキストは、Mac の「言語と地域」設定にある言語のうち、認識に対応している言語で認識されます。どれにも対応していない場合は英語で認識されます。

## 認識されたテキストを選択する

ページが認識されると、ほかのページと同じように、テキストを[選択してコピー](select-text.md)したり、[ハイライト、下線、取り消し線](text-markup.md)を付けたりできます。認識には少し時間がかかることがあります。また、最初の 50 ページより後のページは、先に Run OCR または検索が必要です。

認識には誤りが含まれることがあるため、正確さが必要なテキストはコピー後に確認してください。選択範囲は単語の端できれいに始まり、終わります。単語の途中では、選択範囲の端はおおよその位置になります。

> **注記:** 認識されたテキストは書類を開いている間に使用され、保存を選択しない限り PDF には保存されません（下記を参照）。追加したマークアップは保存されます。ページを墨消しまたは回転すると、そのページのテキストは再度認識されます。

## 認識されたテキストを PDF に保存する {#save-the-recognized-text-in-the-pdf}

スキャンした PDF をプレビュー、Spotlight、Acrobat などのほかのアプリでも検索できるようにするには、認識されたテキストを PDF に保存します。テキストは、認識された位置に、各スキャンページの下の目に見えないレイヤーとして追加されるため、ページの見た目は変わりません。

- **書類に保存するには、**File > Save with Recognized Text を選択するか、テキストの認識後に Search タブの **Save in PDF** をクリックします。ほかの変更も保存されます。
- **コピーに保存するには、**File > Export Document As > Searchable PDF を選択します。開いている書類は変更されません。

どちらの場合も、VectorPDF はまだ認識していないスキャンページを先に認識し、進行状況を表示します。1 ページごとに少し時間がかかります。Cancel をクリックすると、何も保存されません。

テキストが追加されるのは、独自のテキストがないページだけです。テキストがファイルに入ると、それらのページはスキャンページとして扱われなくなり、VectorPDF はほかのアプリと同じく保存されたテキストを選択・検索します。

> **重要:** 認識には誤りが含まれることがあり、保存したテキストはファイルとともに検索インデックス、コピーされたテキスト、スクリーンリーダーなどあらゆる場所に渡ります。頼る前にテキストが正しいことを確認するか、代わりにコピーを保存してください。また、書類に保存するとファイルから開き直されるため、保存前に行った変更は取り消せなくなります。
