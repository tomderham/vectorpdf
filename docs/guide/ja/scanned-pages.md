# OCR でスキャンしたページを検索する

スキャンしたページは、テキストを写した画像です。VectorPDF は光学式文字認識 (OCR) を使って Mac 上でテキストを認識し、検索できるようにします。

## 仕組み

書類を開くと、VectorPDF は最初の 50 ページからスキャンしたページを探し、バックグラウンドでテキストを認識します。さらに処理が必要な場合は、Search タブに見つかったスキャンページの数が表示されます。

- **見つかったすべてのスキャンページを認識するには、** Search タブの **Run OCR** をクリックします。
- 検索でもスキャンページが認識されるため、そのまま検索を始めることもできます。

ページがわずかに傾いてスキャンされている場合でも、ハイライトはテキストに沿って表示されます。

> **注記:** 認識されたテキストは書類を開いている間に使用され、PDF には保存されません。
