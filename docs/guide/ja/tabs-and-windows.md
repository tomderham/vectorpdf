# タブとウインドウ

## タブ

VectorPDF は、macOS 標準のウインドウタブを使用します。

- **新しいタブ:** ⌘T を押すか、タブバーの + ボタンをクリックします。
- **PDF を新しいタブで開く:** ⌥⌘O を押すか、PDF を開いている書類にドラッグします。
- **新しいウインドウ:** ⌘N を押すと空のウインドウが開き、⌘O を押すと PDF を新しいウインドウで開きます。

開いているタブをグループとして保存するには、書類のタイトルを右クリックして、Save All Open Tabs as a Group を選択します。[お気に入りとタブグループ](favorites-and-tab-groups.md)を参照してください。

関連する書類を 1 つのウインドウのタブとして開いておくと、VectorPDF が[書類間の参照をたどる](cross-document-references.md)こともできます。

## 開いているウインドウを探す

Window メニューと Dock の VectorPDF アイコンには、開いているウインドウと、各ウインドウのタブが一覧表示されます。

## アンカーウインドウ {#anchor-windows}

書類内の任意の場所を専用の小さなウインドウで開いて、読みながら図や定義を表示しておくことができます:

- ⌘ を押しながらリンクをクリックします。
- リンク、選択範囲、ページ上の場所、検索結果、アウトラインの項目を右クリックして、**Open in New Window** を選択します。

これらのウインドウの上部にはバナーがあります。バナーをクリックすると、表示している場所に戻ります。バナーの **Close all Child Windows** をクリックすると、同じ書類から開いたすべてのウインドウが閉じます。元の書類を閉じたときにも閉じます。

VectorPDF は同じ場所を重複して開きません。その場所がすでにウインドウで開いている場合は、そのウインドウが手前に表示されます。
