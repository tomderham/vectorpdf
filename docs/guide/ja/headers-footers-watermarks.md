# ヘッダ、フッタ、ベイツ番号、透かし

ページの上部と下部に、タイトル、ページ番号、ベイツ番号などのテキストを入れたり、ページ全体に“下書き”や“社外秘”などの透かしを入れたりできます。Edit > Headers, Footers and Watermark を選択し、必要な部分に入力してから、**Add** をクリックします。設定の横のプレビューには、読んでいるページが、そのページのページ番号とベイツ番号付きで、仕上がりのとおりに表示されます。下の矢印でほかのページを表示できます。

VectorPDF は選択した内容を書類に保持するため、後からヘッダ、フッタ、透かしを変更したり取り除いたりできます。もう一度 Edit > Headers, Footers and Watermark を選択して変更を加え、**Update** をクリックします。すべて取り除くには、**Remove All** をクリックします。

変更は、[保存](save.md)したときにファイルに含まれます。

## ヘッダとフッタ

6 つのボックス（ヘッダとフッタそれぞれの左、中央、右）のいずれかに入力します。何も入れない場所は、ボックスを空のままにします。

ページ番号など、ページごとに変わる値を追加するには、ボックス内をクリックしてから、**Insert** メニューから選択します:

| Insert | 表示される内容 |
| --- | --- |
| Page Number | 最初に印を付けたページから数えたページの番号。[ページと番号](#pages-and-numbers)を参照してください。 |
| Page Count | 書類のページ数 |
| Bates Number | ページのベイツ番号 |
| Date | 今日の日付 |
| File Name | 書類のファイル名 |

それぞれ、`<<page>>` のように二重山かっこで囲まれた語としてボックスに表示されます。たとえば、Page Number を挿入し、` / ` と入力してから Page Count を挿入すると、“3 / 12”のようになります。

テキストのフォント、サイズ、色と、余白（ヘッダとページ上端、フッタとページ下端、両方とページ左右端との距離）をポイント単位（72 ポイントで 1 インチ）で選択できます。

テキストは、中国語、ヒンディー語、アラビア語など、どの言語でもかまいません。選択したフォントにない文字には、その文字を含む Mac のフォントが使われ、使われた文字は書類に保存されるので、どこでも同じように表示されます。

## 透かし

透かしはテキストか画像です。テキストの場合は入力します。2 行目を入れるには Return キーを押します。ロゴなどの画像の場合は、**Picture** を選択し、**Choose Picture** をクリックしてから、ページの幅に対する割合で画像の幅を設定します。次に以下を選択します:

- **Font** と **Color**。
- **As large as fits the page**、または任意のサイズ。
- **Opacity:** どのくらい濃く表示するか。薄い透かしなら、ページは読みやすいままです。
- **Angle:** 水平、斜め、または垂直。
- **Behind the page's content:** 透かしを、ページのテキストや画像の上ではなく下に描画します。スキャンしたページなど背景があるページでは、背後の透かしは隠れます。

## ページと番号 {#pages-and-numbers}

- **Pages:** すべてのページ、奇数ページまたは偶数ページ、および開始ページから終了ページまで。最初または最後のページにするには、From または To を空にします。
- **First page marked is page:** 最初に印を付けたページに Page Number が付ける番号。番号は、印を付けたページごとに 1 ずつ増えます。
- **Bates numbers:** 事件名や会社名などのプレフィックス、桁数、開始番号、サフィックス。ベイツ番号は印を付けたページごとに 1 ずつ増え、ACME-000001 のようにゼロで桁がそろえられます。表示するには、ヘッダまたはフッタに Bates Number を挿入します。

## 複数のファイルに付ける

ベイツ番号をファイルからファイルへと続けて、一連の書類（訴訟の開示書類など）に番号を付けるには、マークを設定してから **Apply to Other Files** をクリックします。PDF を選択し、次に印を付けたコピーを保存するフォルダを選択します。元のファイルは変更されません。ファイルは名前順に処理されるので、番号を付けたい順に名前を付けておきます。完了すると、使われたベイツ番号と、パスワードが必要なファイルなど処理できなかったファイルが表示されます。

## 知っておくと便利なこと

- ヘッダ、フッタ、透かしは[注釈](draw-and-notes.md)ではなくページの一部なので、印刷され、ほかの App でも表示されます。ページの装飾として印が付けられているため、スクリーンリーダーはそれを読み飛ばすことができます。テキストは検索、選択できます。
- 余白は表示されているページを基準に測られるため、回転したページでもヘッダは上部にあります。
- Adobe Acrobat などほかの App が追加したヘッダ、フッタ、透かしも、その App がそれとして印を付けていれば（ほとんどの App はそうします）取り除けます。VectorPDF が見つけると Pages & Numbers に **Remove them** が表示され、プレビューにはそれらを除いたページが表示されます。いったん取り除くと、保存した書類に戻さない限り元に戻りません。
- [デジタル署名](digital-signatures.md)された書類に追加すると署名された内容が変わるため、書類の署名は無効になります。
