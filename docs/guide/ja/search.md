# 書類を検索する

## テキストを検索する

1. ⌘F を押します。サイドバーに Search タブが表示されます。
2. 検索する語句を入力します。検索結果は、現在のページから順に、見つかるたびに表示されます。

各検索結果にはページと前後のテキストが表示され、一致した箇所はすべて書類内でハイライトされます。

## 検索結果の間を移動する

| 目的 | 操作 |
| --- | --- |
| 次の検索結果に移動する | Return キーまたは ⌘G を押すか、下矢印をクリックします |
| 前の検索結果に移動する | ⇧Return または ⇧⌘G を押すか、上矢印をクリックします |
| 任意の検索結果に移動する | 検索結果をクリックします |
| リストを順に移動する | 検索結果をクリックしてから、矢印キーを押します |

検索結果を右クリックすると、そこから[アンカーを作成](anchors.md)したり、新しいウインドウで開いたりできます。

## 検索オプション {#search-options}

検索フィールドの横にあるオプションボタンをクリックします:

- **Match Case:** 大文字と小文字が同じテキストだけを検索します。
- **Whole Word:** 長い単語の一部には一致しません。
- **Smart Search:** オフにしない限りオンになっています。スペース、ハイフン、ダッシュ、改行が互いに一致するため、“end-to-end” は、行をまたいでいても “end to end” にも一致します。ストレート引用符とカーリー引用符も互いに一致します。

## テキスト内の不要な要素を無視する {#ignore-clutter-in-the-text}

書類によっては、引用番号などの記号が文の途中に入っていて、語句が見つからないことがあります。Smart Search では、こうした記号を読み飛ばすことができます。

1. VectorPDF > Settings を選択します。
2. Ignored Search Patterns の横にある Edit をクリックします。
3. 用意されているパターンか独自の正規表現を追加して、オンにします。

用意されているパターンは、[12] のような数字の引用番号、商標記号、*123 のようなスターページング、IEEE 802.11 のコメントタグに対応しています。

## スキャンした書類

スキャンしたページは、認識されるまで検索できるテキストがありません。[OCR でスキャンしたページを検索する](scanned-pages.md)を参照してください。
