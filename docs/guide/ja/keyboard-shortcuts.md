# キーボードショートカット

これらのコマンドの多くは右クリックメニューからも使用でき、下に記載しています。[右クリックメニュー](right-click-menus.md)を参照してください。

## 書類

| 操作 | ショートカット |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Insert Pages from PDF | ⌥⌘I、またはサムネールを右クリック |
| Duplicate Pages | ⇧⌘D、またはサムネールを右クリック |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Favorites への追加または削除 | ⌘D、または書類のタイトルを右クリック |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## ナビゲーション

| 操作 | ショートカット |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow、⌥Left Arrow、または Left Arrow |
| Next Page | ⌥Down Arrow、⌥Right Arrow、または Right Arrow |
| First Page | ⌘Up Arrow または ⌘Home |
| Last Page | ⌘Down Arrow または ⌘End |
| ページ内を前方または後方へ移動 | Space または ⇧Space |
| Next Tab | ⇧⌘] または ⌃Tab |
| Previous Tab | ⇧⌘[ または ⇧⌃Tab |

## 表示

| 操作 | ショートカット |
| --- | --- |
| Zoom In | ⌘+ |
| Zoom Out | ⌘− |
| Actual Size (100%) | ⌘1 |
| Zoom to Fit Width | ⌘9 |
| Zoom to Fit Window | ⌥⌘0 |
| Two Pages または Single Page | ⌥⌘2 |
| Markup Toolbar の表示/非表示 | ⇧⌘A |
| Measurement Toolbar の表示/非表示 | ⇧⌘M |
| Redact Toolbar の表示/非表示 | ⌥⌘R |

## 検索とテキスト

| 操作 | ショートカット | 右クリック |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G、または検索フィールドで Return | |
| Find Previous | ⇧⌘G、または検索フィールドで ⇧Return | |
| Copy | ⌘C | 選択したテキスト |
| Highlight | ⇧⌘H | 選択したテキスト |
| Underline | ⇧⌘U | 選択したテキスト |
| Strikethrough | ⇧⌘X | 選択したテキスト |
| Stop Speaking | ⌥⌘. | 選択したテキスト |
| Add Anchor | ⌘B | 選択範囲、リンク、ページ (Create Anchor として) |

## マウスとトラックパッド

| 操作 | ジェスチャ |
| --- | --- |
| リンクをプレビューする | リンクの上で ⌘ を押し続ける、または強めのクリック |
| リンクを新しいウインドウで開く | ⌘ を押しながらクリック |
| 単語を選択する | ダブルクリック |
| 行を選択する | トリプルクリック |
| 領域を選択する | ⌥ を押しながらドラッグ |
| 注釈のコメントを開く | ダブルクリック (テキストボックスと吹き出しを除く) |
| 拡大/縮小する | ピンチ |

## 注釈と測定

| 操作 | ショートカット | 右クリック |
| --- | --- | --- |
| 注釈の変更を取り消す/やり直す | ⌘Z または ⇧⌘Z | |
| 選択したテキストボックスまたは吹き出しを編集する | Return | 注釈 |
| 選択した注釈を削除する | Delete | 注釈 |
| 選択した注釈を移動する | Arrow keys、または ⇧Arrow keys で 10 ポイントずつ | |
| 周長または面積の測定を終了する | Return | |
| 1 本の線に対して Ortho Lock（0°、45°、90°）を切り替える | ⇧ を押し続ける | |
| 正方形や円、または 45° の倍数の角度の線を描く | Shapes ツールでドラッグ中に ⇧ を押したままにする | |
| キャンセル、または現在のツールを終了する | Escape | |
