# レイヤーの表示と非表示

CAD やデザインのアプリから書き出された図面では、壁、電気、配管、寸法、リビジョンクラウドなど、シートの各部分がそれぞれ別のレイヤーに分かれていることがよくあります。レイヤーごとに表示と非表示を切り替えられます。

Layers タブは、書類にレイヤーがある場合にのみサイドバー上部に表示されます。書類に最初のレイヤーを追加する方法は、[レイヤーの追加、名前の変更、削除](#add-rename-and-delete-layers)を参照してください。

- **レイヤーを表示または非表示にする:** チェックボックスをクリックします。ページはすぐに描き直されます。
- **グループから 1 つを選ぶ:** シートの言語や縮尺など、一度に 1 つだけ表示されるようにレイヤーをグループ化している書類もあります。これらには丸いボタンがあり、1 つを選ぶとほかは非表示になります。
- **見出し:** その下にあるレイヤーをまとめるもので、見出し自体は非表示にできません。
- **ロックされたレイヤー:** 横に錠前が表示されます。書類の設定により、表示も非表示もできません。

非表示にしたレイヤーは、[プリント](print.md)、[テキストの選択](select-text.md)、[検索](search.md)でも除外されるため、見えているものだけを扱えます。

## 注釈をレイヤーに配置する

注釈もレイヤーに配置でき、そのレイヤーと一緒に表示と非表示が切り替わります。Acrobat や Bluebeam など、レイヤーを読み込むほかのアプリでも同じように表示と非表示が切り替わります。

- **新しい注釈の配置先を選ぶ:** [Markup ツールバー](draw-and-notes.md)または [Measurement ツールバー](measure.md)で、レイヤーメニュー (選ぶまでは **No Layer** と表示されます) をクリックしてレイヤーを選びます。以降に作成するものはすべてそのレイヤーに配置されます。別のレイヤーか **No Layer** を選ぶまで続きます。Layers タブでレイヤーを右クリックして **Put New Annotations Here** を選ぶこともできます。新しい注釈の配置先のレイヤーには鉛筆が表示されます。
- **注釈を別のレイヤーに移動する:** 注釈を右クリックして **Layer** を選び、レイヤーを選ぶか、どのレイヤーからも外すには **None** を選びます。
- **独自のレイヤーを追加する:** [レイヤーの追加、名前の変更、削除](#add-rename-and-delete-layers)を参照してください。

レイヤーメニューは書類にレイヤーがある場合にのみ表示されるため、ほかの書類のツールバーは変わりません。

非表示のレイヤーにある注釈は、ページ、[Comments タブ](draw-and-notes.md#see-all-annotations)、[数量拾い表](takeoff.md)から消え、選択も消去もできなくなります。Annotations の表には、レイヤーとともに引き続き表示されます。

新しい注釈の配置先として非表示のレイヤーを選ぶと、作成したものが消えないように、そのレイヤーが表示されます。Undo を使うと、注釈は元のレイヤーに戻ります。

## レイヤーの追加、名前の変更、削除 {#add-rename-and-delete-layers}

レビュー担当者は、工種ごとやレビューの回ごとなど、自分のマークアップを独自のレイヤーにまとめることがよくあります。レイヤーのない図面でも同様です。以下のコマンドはどれも書類を変更し、Undo で元に戻せます。

- **レイヤーを追加する:** Edit > New Layer… を選び、名前を付けます。どの PDF でも使えるので、書類に最初のレイヤーを追加するときもこの方法を使います。追加すると、Layers タブとレイヤーメニューが表示されます。新しい注釈は新しいレイヤーに配置されます。すでにレイヤーがある書類では、Layers タブ上部の **+** をクリックするか、レイヤーメニューから **New Layer…** を選ぶこともできます。
- **レイヤーの名前を変更する:** Edit > Rename Layer… を選び、レイヤーを選んでから新しい名前を入力します。
- **レイヤーを削除する:** Edit > Delete Layer… を選び、レイヤーを選びます。そのレイヤーの注釈は、どのレイヤーにも属さない状態でページに残ります。削除できるのは注釈だけを含むレイヤーです。図面そのものがあるレイヤーを削除すると、その部分が常に表示されたままになるため、そうしたレイヤーは一覧に表示されません。

## 保存される内容

追加、名前の変更、削除したレイヤーは、注釈が配置されているレイヤーとともに書類に保存されます。

どのレイヤーを表示しているかは書類に保存されません。次に開いたときは、書類自体の設定どおりにレイヤーが表示されます。書類を送った相手にも同じように表示されます。

> **注記:** 1 ページの書類は、サイドバーが非表示の状態で開きます。表示するには、ツールバーのサイドバーボタンを使います。
