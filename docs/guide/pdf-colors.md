# Change PDF colors

VectorPDF can change how a document's pages look, whatever the appearance of macOS. This is useful for reading in a dark room. It doesn't change the PDF.

Choose View > PDF Color, or use the PDF Color setting in [Settings](settings.md), then choose one:

- **Follow System:** pages match the appearance of macOS.
- **Light:** pages appear as the document defines them.
- **Dark:** page colors are inverted, keeping the hues, so diagrams and highlights stay recognizable.
- **Sepia:** pages take on a warm paper tint.

Printing and exporting use the document's original colors.
