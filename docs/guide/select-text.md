# Select, copy and look up text

## Select text

- **Drag** across the text. Selections follow the reading order, so they keep to one column of a multi-column layout and skip margin line numbers. They can run across pages.
- **Double-click** to select a word, or **triple-click** to select a line.
- **Hold ⌥ and drag** to select a rectangular area, such as a figure or table.

Press Escape to clear the selection.

On a scanned page, you can select text once it has been [recognized](scanned-pages.md).

## Copy

Press ⌘C, or right-click selected text and choose Copy Text.

Right-click a rectangular selection for more options:

- **Copy Extracted Text** copies any text in the area.
- **Copy Screenshot** copies the area as an image.
- **Save Screenshot As** saves the area as an image file.

## Look up and translate

Right-click selected text, then choose:

- **Look Up** to see a dictionary definition.
- **Translate Selection** to translate it.

## Have text read aloud

Select text, then choose Edit > Speech > Start Speaking, or right-click and choose Start Speaking. To stop, choose Stop Speaking or press ⌥⌘. (Option-Command-period).

## Other actions

The menu that appears when you right-click selected text also has commands to [highlight, underline or strike through](text-markup.md) the text, to [create an anchor](anchors.md), and to open the selection in a new window.
