# References across documents

Standards cite other standards, and contracts refer to their schedules, usually in plain text rather than with links. If you open the related documents as tabs in one window, VectorPDF can follow those references.

## Follow a plain-text reference

1. Open the related documents as [tabs in the same window](tabs-and-windows.md).
2. Right-click a reference such as “Section 8.8.3 of [HTTP]” or “Clause 4.2 of the Master Agreement”, or select the reference and right-click it.
3. Choose one of these:
   - **Go to** the matching heading, to preview it. From the preview you can go there.
   - Hold ⌘ while the menu is open to change the command to **Open**, which goes straight there without a preview.
   - **Find “reference” in Other Tabs**, where “reference” is the text you clicked, to search the text of your other tabs.

VectorPDF matches references against the other document's outline, or against its headings if it has no outline. If the same heading appears in several tabs, the preview lists each one.

## Web links into an open document

Some documents link to each other on the web. For example, IETF RFCs link to rfc-editor.org. If the document a web link points to is open in another tab, ⌘-hover or Force Click [previews it there](link-peek.md) instead of opening your browser.

## Keep a set of documents together

Save documents you use together as a [Tab Group](favorites-and-tab-groups.md), so you can reopen them in one step.
