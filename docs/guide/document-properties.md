# Document properties

Choose File > Document Properties, or press ⌘I. Choose a tab at the top:

- **General:** the title, author, subject, keywords, dates, the application that created it, the file's location and its storage.
- **Security:** the document's encryption, and whether it allows printing, copying, changes, comments, form filling, accessibility extraction and page assembly.
- **Page Geometry:** the MediaBox, CropBox, BleedBox, TrimBox and ArtBox of any page, in points, inches or millimeters.
- **Fonts:** the fonts in the document, their type and encoding, and whether each is embedded. Use the filter field to find one.
