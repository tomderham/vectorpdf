# Ask about a document

The Agent answers questions about the open document, and shows you the passages its answer comes from. It needs macOS 26 or later.

## Ask a question

1. Click the Ask About This Document tab in the sidebar. The first time, VectorPDF indexes the document on your Mac, and shows its progress.
2. Type a question, then press Return, or click Ask. Press ⇧Return for a new line.

Under the answer, click **Sources** to see the passages it used, with their pages. Passages the answer cites are marked **Cited**. Click a passage to go to it.

You can ask follow-up questions. To start again, click **New Conversation**.

> **Note:** The Agent can make mistakes. Check the sources for anything important.

## If no answer can be generated

If answer generation isn't available on your Mac, the Agent shows the best-matching passages instead. See [Choose how the Agent answers](agent-engines.md).

## Turn the Agent off

Turn off **Use Agent** in [Settings](settings.md). The tab disappears from the sidebar.
