# The VectorPDF window

Each VectorPDF window has a toolbar, a sidebar and the document itself. Windows can hold several documents as [tabs](tabs-and-windows.md).

## Toolbar

| Control | What it does |
| --- | --- |
| Document title | Shows the document's name. Right-click it for Favorites and Tab Groups. |
| Zoom | The − and + buttons step the zoom. Click the percentage to type your own. |
| Rotate Left and Rotate Right | Turn the view. This doesn't change the saved PDF. |
| Two-Page Mode | Shows pages side by side, like an open book. |
| Markup Toolbar | Shows the [markup tools](text-markup.md). |
| Measurement Toolbar | Shows the [measurement tools](measure.md). |
| Page | The arrows move a page at a time. Click the page number to type the page you want. |

See [Zoom, rotate and page layout](zoom-and-layout.md) for more about these controls.

## Sidebar

The tabs at the top of the sidebar switch between:

- **Outline & Thumbnails:** the [table of contents, or a thumbnail of each page](outline-and-thumbnails.md).
- **Search:** [results for the current document](search.md).
- **Anchors:** [the places you've saved](anchors.md).
- **Ask About This Document:** [the Agent](agent.md). This tab appears on macOS 26 or later, unless you've turned off [Use Agent](settings.md) in Settings.

Use the sidebar button in the toolbar to show or hide the sidebar.

## Extra toolbars

Three toolbars appear below the main toolbar when you need them. Choose them from the View menu:

- **Markup** (⇧⌘A) has the [annotation tools](text-markup.md).
- **Measurement** (⇧⌘M) has the [measuring tools](measure.md).
- **Redact** (⌥⌘R) has the [redaction tools](redact.md).

## Right-click menus

Many commands are also in menus that appear when you right-click, or Control-click, the document, the sidebar or the toolbar. See [Right-click menus](right-click-menus.md).

## Page indicator

When you change page, a small page indicator appears over the document for a moment, with arrows for moving to the previous and next page. While the Measurement toolbar is showing, it also shows the page's drawing scale.

## Start screen

An empty window or tab shows the Start screen, with the drop zone, then your Tab Groups, Favorites and Recent Documents. Click a row to open it. Hold the pointer over a row and click the ••• button, or right-click the row, to open it in a new tab or window, show it in the Finder, or remove it.

The Start screen lists up to three Tab Groups and five Favorites. The Favorites menu lists all of them.
