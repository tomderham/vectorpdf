# 询问有关文稿的问题

Agent 可以回答有关当前打开文稿的问题，并向你显示回答所依据的段落。它需要 macOS 26 或更高版本。

## 提问

1. 点按边栏中的 Ask About This Document 标签页。首次使用时，VectorPDF 会在你的 Mac 上为文稿建立索引，并显示进度。
2. 键入问题，然后按下 Return 键或点按 Ask。按下 ⇧Return 可换行。

在带有[图层](layers.md)的文稿中，只有显示的图层会被编入索引。如果你显示或隐藏图层，文稿会重新编入索引。

在回答下方，点按 **Sources** 可查看所用的段落及其所在页面。回答中引用的段落标有 **Cited**。点按某个段落可前往该段落。

你可以继续追问。若要重新开始，请点按 **New Conversation**。

> **注：** Agent 可能会出错。对于重要内容，请核对来源。

## 如果无法生成回答

如果你的 Mac 上无法生成回答，Agent 会改为显示最匹配的段落。请参阅[选择 Agent 的回答方式](agent-engines.md)。

## 关闭 Agent

在 [Settings](settings.md) 中关闭 **Use Agent**。该标签页随即从边栏中消失。
