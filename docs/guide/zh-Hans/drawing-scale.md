# 设置图纸比例

若要从图纸中获得实际尺寸，VectorPDF 需要知道图纸的比例。按下 ⇧⌘M 显示 Measurement 工具栏，然后点按比例按钮以打开 Drawing Scale Calibration。

## 使用标准比例

1. 在 Standard Drawing Scales 下，选取图纸类型：
   - **Metric (ISO)：** 从 1:1 到 1:1000。
   - **Architectural (US)：** 例如 1/4" = 1'-0"。
   - **Civil Engineering (US)**。
2. 选取比例。
3. 在 Area Takeoff 下，选取面积单位。
4. 点按 Apply Scale。

该比例适用于所有页面，并会在你[存储](save.md)时保存在 PDF 中。

## 根据已知长度校准

如果图纸上有你信得过的尺寸或比例尺：

1. 点按 **Calibrate by Measuring Known Line**。
2. 在图纸上点按线条的两端。
3. 输入线条的实际长度并选取单位：Feet & Inches、Decimal Feet、Inches、Millimeters、Centimeters 或 Meters。
4. 点按 Apply Scale。

请尽量使用最长的已知线条，因为距离越长，点按时的微小误差影响就越小。
