# 右键菜单

右键点按或按住 Control 键点按，可查看适用于指针下方内容的命令。出现的菜单取决于你点按的位置。

## 在文稿中

| 右键点按 | 命令 |
| --- | --- |
| 所选文本 | Copy Text、Look Up、Translate Selection、Start Speaking 或 Stop Speaking、Highlight、Underline、Strikethrough、Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| 所选区域 | Copy Extracted Text、Copy Screenshot、Save Screenshot As、Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| 链接 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| 高亮、下划线或删除线 | 相应的 Remove 命令 |
| 文本框或标注框 | Edit Text Box 或 Edit Callout Note，以及删除命令 |
| 绘图、图章或测量结果 | 删除命令 |
| 页面上的其他任何位置 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |

如果你右键点按纯文本引用，并且相关文稿已在其他标签页中打开，菜单还会提供[前往或查找该引用](cross-document-references.md)的命令。

## 在边栏中

| 右键点按 | 命令 |
| --- | --- |
| 大纲条目 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| 缩略图 | Rotate、Duplicate、Insert Blank Page、Insert Pages from PDF、Save selected page as a PDF、Move Page Up 或 Down、Delete。请参阅[重新排列页面](pages.md)。 |
| 搜索结果 | Create Anchor、Create Anchor and Open in New Window、Open in New Window |
| 锚点 | Open in New Window 或 Close Window、Copy Text、Copy Screenshot、Delete Anchor |

## 在窗口中

| 右键点按 | 命令 |
| --- | --- |
| 文稿标题或工具栏的空白部分 | 添加到 Favorites 或从中移除、Save All Open Tabs as a Group、Update Group with Open Tabs，以及你的 Tab Groups 和 Favorites |
| Start 屏幕上的一行 | Open、Open in New Tab、Open in New Window、Show in Finder，以及 Remove 或 Delete |

某些命令仅在适用时才会出现。例如，Save All Open Tabs as a Group 需要有多个标签页，而在从锚点打开的窗口中无法使用锚点命令。
