# 在文稿中移动

## 滚动和翻页

使用触控板或鼠标滚动。VectorPDF 只排布你正在阅读位置附近的页面，因此即使是很长的文稿也能保持流畅。

使用键盘：

| 按键 | 操作 |
| --- | --- |
| Left Arrow、Right Arrow | 上一页或下一页 |
| Up Arrow、Down Arrow | 在高于窗口的页面内滚动，然后移到下一页。如果页面能完整显示在窗口中，则每次移动一页。 |
| Page Up、Page Down | 以较大的幅度滚动，然后移到下一页 |
| Space、⇧Space | 向前或向后，与 Page Down 和 Page Up 相同 |
| ⌥Up Arrow、⌥Down Arrow、⌥Left Arrow、⌥Right Arrow | 上一页或下一页 |
| ⌘Up Arrow、⌘Down Arrow | 第一页或最后一页 |

在 Two-Page Mode 下，这些按键会翻动整个跨页。

## 前往某一页

点按工具栏中的页码，键入要前往的页码，然后按下 Return 键。按下 Escape 键可取消。

有些文档会为页面设置自己的名称，例如前言部分的 `iv` 或图纸的 `A-101`。此时，VectorPDF 会在工具栏、页面指示器和缩略图中显示该标签，并在旁边显示页面的位置，例如 `iv (4 of 300)`。输入标签即可前往该页面。如果某个标签被多次使用，将前往下一个带有该标签的页面。要按位置前往页面，请输入 `#` 和数字，例如 `#13`。

Print 和 Split PDF 始终按位置计算页面，从文件的第一页开始。

## 返回之前的位置

跟随链接或跳到某个结果后，选取 Go > Back (⌘[) 可返回。Go > Forward (⌘]) 则朝相反方向移动。

- [缩略图](outline-and-thumbnails.md)显示每一页。
