# 高亮、下划线和删除线

## 标记所选文本

选择文本，然后执行以下操作之一：

| 标记 | 菜单 | 快捷键 |
| --- | --- | --- |
| 高亮 | Edit > Highlight Selection | ⇧⌘H |
| 下划线 | Edit > Underline Selection | ⇧⌘U |
| 删除线 | Edit > Strikethrough Selection | ⇧⌘X |

你也可以使用 Markup 工具栏中的按钮，或者右键点按所选内容并选取 Highlight、Underline 或 Strikethrough。每一项都有颜色列表。

## 选取颜色

Markup 工具栏 (⇧⌘A) 中有一个颜色按钮。点按它，然后点按一种颜色。快捷键和工具栏按钮会使用在其中选定的颜色。若要为单个标记选取颜色，请使用右键菜单中的颜色列表，或者 Edit 菜单中相应项目下的颜色列表。

## 移除标记

若要撤销刚刚创建的标记，请选取 Edit > Undo 或按下 ⌘Z。

右键点按标记的文本，然后选取 Remove Highlight、Remove Underline 或 Remove Strikethrough。或者在 Markup 工具栏中选取橡皮擦，然后点按或拖过要移除的标记。⌘Z 可恢复误移除的标记。

## 汇总标记

若要获取注释列表，请选取 File > Export Annotations Summary (⇧⌘E)。你可以将其存储为 Markdown 或 CSV 格式。请参阅[导出为其他格式](export.md)。
