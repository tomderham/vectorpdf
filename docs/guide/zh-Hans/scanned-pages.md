# 搜索和选择扫描页面上的文本

扫描页面实际上是文字的图片。VectorPDF 可以在你的 Mac 上使用光学字符识别 (OCR) 来识别其中的文本，以便你进行搜索、选择和标记。

## 工作方式

打开文稿时，VectorPDF 会在前 50 页中查找扫描页面，并在后台识别其中的文本。如果还有更多内容需要处理，Search 标签页会显示找到的扫描页面数量。

- **若要识别已找到的所有扫描页面，**请点按 Search 标签页中的 **Run OCR**。
- 搜索时也会识别这些页面，因此你可以直接开始搜索。

即使页面扫描时略有倾斜，高亮也会贴合文本。

## 选择识别出的文本

页面识别完成后，你可以像在其他页面上一样[选择和拷贝](select-text.md)其中的文本，并为其添加[高亮、下划线或删除线](text-markup.md)。识别可能需要片刻时间，前 50 页之后的页面需要先使用 Run OCR 或进行搜索。

识别可能会出错，因此对于必须准确的内容，请在拷贝后加以检查。所选内容会在单词边缘干净地开始和结束。在单词内部，其端点位置是近似的。

> **注：** 识别出的文本仅在文稿打开期间使用，不会存储到 PDF 中。你添加的标记会被存储。如果你对页面进行涂黑处理或旋转页面，其文本会被重新识别。
