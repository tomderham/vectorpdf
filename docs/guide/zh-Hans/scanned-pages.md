# 使用 OCR 搜索扫描页面

扫描页面实际上是文字的图片。VectorPDF 可以在你的 Mac 上使用光学字符识别 (OCR) 来识别其中的文本，以便你进行搜索。

## 工作方式

打开文稿时，VectorPDF 会在前 50 页中查找扫描页面，并在后台识别其中的文本。如果还有更多内容需要处理，Search 标签页会显示找到的扫描页面数量。

- **若要识别已找到的所有扫描页面，**请点按 Search 标签页中的 **Run OCR**。
- 搜索时也会识别这些页面，因此你可以直接开始搜索。

即使页面扫描时略有倾斜，高亮也会贴合文本。

> **注：** 识别出的文本仅在文稿打开期间使用，不会存储到 PDF 中。
