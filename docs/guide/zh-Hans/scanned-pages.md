# 搜索和选择扫描页面上的文本

扫描页面实际上是文字的图片。VectorPDF 可以在你的 Mac 上使用光学字符识别 (OCR) 来识别其中的文本，以便你进行搜索、选择和标记。

## 工作方式

打开文稿时，VectorPDF 会在前 50 页中查找扫描页面，并在后台识别其中的文本。如果还有更多内容需要处理，Search 标签页会显示找到的扫描页面数量。

- **若要识别已找到的所有扫描页面，**请点按 Search 标签页中的 **Run OCR**。
- 搜索时也会识别这些页面，因此你可以直接开始搜索。

即使页面扫描时略有倾斜，高亮也会贴合文本。

文本会以你的 Mac 的“语言与地区”设置中识别功能支持的语言进行识别；如果都不支持，则以英文识别。

## 选择识别出的文本

页面识别完成后，你可以像在其他页面上一样[选择和拷贝](select-text.md)其中的文本，并为其添加[高亮、下划线或删除线](text-markup.md)。识别可能需要片刻时间，前 50 页之后的页面需要先使用 Run OCR 或进行搜索。

识别可能会出错，因此对于必须准确的内容，请在拷贝后加以检查。所选内容会在单词边缘干净地开始和结束。在单词内部，其端点位置是近似的。

> **注：** 识别出的文本仅在文稿打开期间使用，除非你选择存储（见下文），否则不会存储到 PDF 中。你添加的标记会被存储。如果你对页面进行涂黑处理或旋转页面，其文本会被重新识别。

## 将识别出的文本存储到 PDF 中 {#save-the-recognized-text-in-the-pdf}

若要让扫描的 PDF 在“预览”、Spotlight 和 Acrobat 等其他 App 中也能被搜索，请将识别出的文本存储到其中。文本会作为不可见图层添加到每个扫描页面的下方，位于识别出它的位置，因此页面外观不变。

- **若要存储到文稿中，**请选取 File > Save with Recognized Text，或者在文本识别完成后点按 Search 标签页中的 **Save in PDF**。你的其他更改也会被存储。
- **若要存储到副本中，**请选取 File > Export Document As > Searchable PDF。你打开的文稿不会更改。

无论哪种方式，VectorPDF 都会先识别尚未识别的扫描页面，并显示进度。每个页面都需要一点时间。你可以点按 Cancel，这样不会存储任何内容。

只有本身没有文本的页面才会获得文本。文本存入文件后，这些页面不再被视为扫描页面：VectorPDF 会像其他 App 一样选择和搜索存储的文本。

> **重要：** 识别可能会出错，而存储的文本会随文件去往任何地方：进入搜索索引、拷贝的文本和屏幕阅读器。在依赖这些文本之前，请检查其是否正确，或者改为存储副本。存储到文稿中还会从文件重新打开文稿，因此你无法撤销存储之前所做的更改。
