# 键盘快捷键

其中许多命令也可以在右键菜单中找到，并已在下文注明。请参阅[右键菜单](right-click-menus.md)。

## 文稿

| 操作 | 快捷键 |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Compare Documents | File 菜单，或右键点按文稿标题并选取 Compare With |
| Insert Pages from PDF | ⌥⌘I，或右键点按缩略图 |
| Duplicate Pages | ⇧⌘D，或右键点按缩略图 |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Add to or Remove from Favorites | ⌘D，或右键点按文稿标题 |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## 导航

| 操作 | 快捷键 |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow、⌥Left Arrow 或 Left Arrow |
| Next Page | ⌥Down Arrow、⌥Right Arrow 或 Right Arrow |
| First Page | ⌘Up Arrow 或 ⌘Home |
| Last Page | ⌘Down Arrow 或 ⌘End |
| 上一处或下一处更改（比较文稿时） | ⌥⌘Up Arrow 或 ⌥⌘Down Arrow，或 Changes 标签页中的箭头 |
| 在页面中向前或向后移动 | Space 或 ⇧Space |
| Next Tab | ⇧⌘] 或 ⌃Tab |
| Previous Tab | ⇧⌘[ 或 ⇧⌃Tab |

## 视图

| 操作 | 快捷键 |
| --- | --- |
| Zoom In | ⌘+ |
| Zoom Out | ⌘− |
| Actual Size (100%) | ⌘1 |
| Zoom to Fit Width | ⌘9 |
| Zoom to Fit Window | ⌥⌘0 |
| Two Pages or Single Page | ⌥⌘2 |
| Show or Hide Markup Toolbar | ⇧⌘A |
| Show or Hide Measurement Toolbar | ⇧⌘M |
| Show or Hide Redact Toolbar | ⌥⌘R |

## 搜索和文本

| 操作 | 快捷键 | 右键点按 |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G，或在搜索栏中按下 Return 键 | |
| Find Previous | ⇧⌘G，或在搜索栏中按下 ⇧Return | |
| Copy | ⌘C | 所选文本 |
| Highlight | ⇧⌘H | 所选文本 |
| Underline | ⇧⌘U | 所选文本 |
| Strikethrough | ⇧⌘X | 所选文本 |
| Stop Speaking | ⌥⌘. | 所选文本 |
| Add Anchor | ⌘B | 所选内容、链接或页面，显示为 Create Anchor |

## 鼠标和触控板

| 操作 | 手势 |
| --- | --- |
| 预览链接 | 将指针放在链接上并按住 ⌘，或者用力点按 |
| 在新窗口中打开链接 | 按住 ⌘ 点按 |
| 选择一个单词 | 连按两下 |
| 选择一行 | 连按三下 |
| 选择一个区域 | 按住 ⌥ 拖移 |
| 打开注释的评论 | 连按两下（文本框和标注框除外） |
| 缩放 | 双指张开或捏合 |

## 注释和测量

| 操作 | 快捷键 | 右键点按 |
| --- | --- | --- |
| 撤销或重做对注释的更改 | ⌘Z 或 ⇧⌘Z | |
| 编辑所选文本框或标注框 | Return | 该注释 |
| 删除所选注释 | Delete | 该注释 |
| 移动所选注释 | Arrow keys，或使用 ⇧Arrow keys 每次移动 10 点 | |
| 完成周长或面积测量 | Return | |
| 针对单条线切换 Ortho Lock（0°、45° 或 90°） | 按住 ⇧ | |
| 绘制正方形或圆形，或角度为 45° 倍数的线条 | 使用 Shapes 工具拖移时按住 ⇧ | |
| 取消或退出当前工具 | Escape | |
