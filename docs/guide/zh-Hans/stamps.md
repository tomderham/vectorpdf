# 图章和签名

图章是一张图像（例如你的签名或姓名首字母），你可以将它放在任意页面上。

> **注：** 图章只是一种视觉标记。它不是加密数字签名，也不能证明文稿的真实性。

## 创建图章

1. 选取 VectorPDF > Settings，然后点按 Digital Stamp 下的 Create Stamp。你也可以直接选取 Markup 工具栏中的 Stamp 工具，VectorPDF 会要求你创建一个图章。
2. 选取创建方式：
   - **Draw：** 使用触控板或鼠标签名。
   - **Type：** 输入你的姓名或姓名首字母，然后选取字体。
   - **Image：** 选取 PNG 或 JPEG 文件。如果你选取 **Transparent background**，页面内容会透过图像的背景显示出来。
3. 点按 Use。

VectorPDF 会将图章保留在这台 Mac 上，供下次使用。若要替换或移除它，请使用 [Settings](settings.md) 中的 Modify Stamp 或 Delete Stamp。

## 放置图章

1. 显示 Markup 工具栏 (⇧⌘A)，然后选取 Stamp 工具。
2. 点按要放置图章的位置。

然后，拖移图章可移动它，拖移角可调整其大小。若要移除图章，请选择它并按下 Delete 键，或者右键点按它并选取 Delete Signature。

## 签署表单

如果表单有签名栏，请点按栏中的 **Sign**。请参阅[填写表单](forms.md)。
