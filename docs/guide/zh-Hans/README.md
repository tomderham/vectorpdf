# VectorPDF 使用手册

适用于 macOS

VectorPDF 是一款快速的 PDF 阅读器，适合阅读技术论文、规范、合同和图纸。将指针放在引用上并按住 Command 键，即可查看它指向的内容，而不会离开当前页面。你还可以在 Mac 上为 PDF 添加标记、进行测量、涂黑内容和重新整理页面。

> **注：** 本手册由英文原文机器翻译而成。VectorPDF 的界面仅提供英文版，因此菜单和按钮名称均按屏幕上显示的英文给出。
