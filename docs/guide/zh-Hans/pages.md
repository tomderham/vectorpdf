# 重新排列页面

页面更改在边栏的 [Thumbnails](outline-and-thumbnails.md) 视图中进行。这些更改会在你[存储](save.md)时写入文件。

## 选择页面

点按缩略图。按住 ⌘ 可逐个添加页面，按住 ⇧ 可选择一个范围。

## 移动页面

将所选缩略图拖移到新位置。一条线会显示它们将放置的位置。你也可以右键点按页面，然后选取 Move Page Up 或 Move Page Down。

## 其他页面命令

右键点按一个或多个所选缩略图，然后选取：

- **Rotate Clockwise、Rotate Counterclockwise 或 Rotate 180°：** 旋转 PDF 本身的页面，这与[工具栏中的 Rotate 按钮](zoom-and-layout.md#rotate-the-view)不同。
- **Duplicate Page：** 紧接在所选页面之后添加副本。你也可以选取 File > Duplicate Pages (⇧⌘D)；如果所选缩略图包含你当前所在的页面，此命令会复制所选缩略图，否则会复制当前页面。
- **Insert Blank Page**。
- **Insert Pages from PDF：** 添加另一个 PDF 中的页面。你也可以选取 File > Insert Pages from PDF (⌥⌘I)。
- **Save selected page as a PDF：** 将页面提取到新文件中。
- **Delete Page**。

## 如果你创建了锚点

添加、删除或移动页面可能会使[锚点](anchors.md)指向错误的位置。VectorPDF 会发出警告，并提供改为在副本中进行更改的选项。
