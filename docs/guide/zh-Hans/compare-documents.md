# 比较两份文稿

Compare Documents 会并排显示一份文稿的两个版本，并在两边高亮显示发生更改的文本。滚动其中一个时，另一个会滚动到相同的文本，即使两个版本之间增加或删除了页面也是如此。

## 打开比较

1. 选取 File > Compare Documents。
2. 选取原始文稿（Original）和修订版（Revised）。每个菜单都会列出你打开的文稿；若要选择其他文稿，请选取 Choose File。前面的文稿起初作为原始文稿。点按 Swap 可交换二者。
3. 点按 Compare。

你也可以右键点按文稿标题或工具栏的空白部分，然后从 Compare With 中选取一份文稿。这会将前面的文稿与你选取的文稿进行比较。

比较会在新标签页中打开，左侧是原始文稿，右侧是修订版。两者在其中都是只读的。若要编辑其中一份，请在它自己的标签页中打开。

## 查看更改

- 从原始文稿中删除的单词在左侧以红色高亮显示。
- 修订版中新增的单词在右侧以绿色高亮显示。
- 如果只有一边新增了文本，另一边会用一条细条标出它应在的位置。

边栏中的 Changes 标签页会列出每一处更改：删除的单词以红色删除线显示，新增的单词以绿色显示，并附有修订版中的页码。点按一处更改即可在两份文稿中前往该处。

若要逐个查看更改，请点按 Changes 标签页顶部的上箭头或下箭头，选取 Go > Previous Change 或 Go > Next Change，或者按下 ⌥⌘Up Arrow 或 ⌥⌘Down Arrow。标签页会显示你所在的更改，例如 3 of 12。这处更改会以更醒目的方式高亮显示，并在列表中被选中。

只比较文本。格式、图像或图纸的更改不会显示。页眉、页脚和页码会被排除，因此页面移动时它们不会显示为更改。

## 查找章节或字词

边栏中的 Outline & Thumbnails 和 Search 标签页作用于修订版，与在任何标签页中一样。前往某个章节或搜索结果时，原始文稿会跟随到相同的文本。

## 一起滚动和缩放

两边从上往下约三分之一处的那一行显示相同的文本。如果一边有另一边没有的文本，另一边会等你滚动过这段文本。你可以滚动任意一边，另一边会跟随。

若要分别滚动两边，请在 Changes 标签页顶部关闭 Scroll Together。再次打开即可重新对齐。

缩放一边会同时缩放两边，并且你正在阅读的文本会保持在原处。放大到超过页面宽度时，横向滚动一边也会横向滚动另一边，使两边显示页面的同一部分。

## 比较选项

在 Changes 标签页顶部，选取 Ignore Case 或 Ignore Punctuation 可忽略大小写或标点符号的差异。弯引号和直引号，以及不同种类的破折号，始终视为相同。

## 如果比较没有帮助

- **文稿没有可比较的文本：**扫描的页面在识别文本之前没有文本。请参阅[搜索和选择扫描页面上的文本](scanned-pages.md)。
- **这些文稿的共同文本很少：**它们可能不是同一份文稿的不同版本。
