# 个人收藏和标签页组

## 个人收藏

个人收藏让你最常用的 PDF 触手可及。

- **添加或移除当前 PDF：** 选取 Favorites > Add This PDF to Favorites，或者按下 ⌘D。再次按下 ⌘D 可将其移除。
- **打开收藏项：** 在 Favorites 菜单中选取它，然后选取 Open，或者在 Start 屏幕上点按它。

右键点按文稿标题或工具栏的空白部分时，也会出现相同的命令，以及你的 Favorites 和 Tab Groups。

## 标签页组

标签页组是一组具有名称的文稿，它们作为同一窗口的标签页一起打开，例如某个项目的规范文件。

### 存储组

1. 将文稿作为标签页在同一窗口中打开。
2. 选取 Favorites > Save All Open Tabs as a Group。
3. 输入名称，然后点按 Save。

### 打开组

在 Favorites 菜单中选取该组，然后选取 Open，或者在 Start 屏幕上点按它。

### 更改组

打开该组，添加或关闭标签页，然后选取 Favorites > Update Group with Open Tabs。

### 删除组

在 Favorites 菜单中选取该组，然后选取 Delete Tab Group。如果你删除了某个组，或者从 Start 屏幕移除了某个收藏项，可以点按随后出现的信息中的 Undo。
