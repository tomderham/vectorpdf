# 更改 PDF 颜色

无论 macOS 的外观如何，VectorPDF 都可以更改文稿页面的显示方式。这在暗室中阅读时很有用。此操作不会更改 PDF。

选取 View > PDF Color，或者使用 [Settings](settings.md) 中的 PDF Color 设置，然后选取以下选项之一：

- **Follow System：** 页面与 macOS 的外观保持一致。
- **Light：** 页面按文稿定义的样式显示。
- **Dark：** 反转页面颜色并保留色相，因此图表和高亮内容仍然清晰可辨。
- **Sepia：** 页面呈现温暖的纸张色调。

打印和导出时使用文稿的原始颜色。
