# 文稿属性

选取 File > Document Properties，或者按下 ⌘I。然后在顶部选取一个标签页：

- **General：** 标题、作者、主题、关键词、日期、创建文稿的应用程序、文件位置及其存储信息。
- **Security：** 文稿的加密情况，以及是否允许打印、拷贝、更改、注释、填写表单、辅助功能提取和页面组合。
- **Page Geometry：** 任一页面的 MediaBox、CropBox、BleedBox、TrimBox 和 ArtBox，单位可以是 Points、Inches 或 Millimeters。
- **Fonts：** 文稿中的字体及其类型和编码，以及每种字体是否已嵌入。可使用过滤栏查找字体。
