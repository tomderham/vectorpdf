# 选择、拷贝和查询文本

## 选择文本

- **拖移**划过文本。所选内容遵循阅读顺序，因此在多栏布局中会保持在同一栏内，并跳过页边的行号。所选内容可以跨页。
- **连按两下**可选择一个单词，**连按三下**可选择一行。
- **按住 ⌥ 并拖移**可选择一个矩形区域，例如图或表。

按下 Escape 键可清除所选内容。

在扫描页面上，文本[识别](scanned-pages.md)完成后即可选择。

## 拷贝

按下 ⌘C，或者右键点按所选文本并选取 Copy Text。

右键点按矩形所选内容可获得更多选项：

- **Copy Extracted Text** 拷贝该区域内的所有文本。
- **Copy Screenshot** 将该区域拷贝为图像。
- **Save Screenshot As** 将该区域存储为图像文件。

## 查询和翻译

右键点按所选文本，然后选取：

- **Look Up** 查看词典释义。
- **Translate Selection** 进行翻译。

## 朗读文本

选择文本，然后选取 Edit > Speech > Start Speaking，或者右键点按并选取 Start Speaking。若要停止，请选取 Stop Speaking 或按下 ⌥⌘.（Option-Command-句点）。

## 其他操作

右键点按所选文本时出现的菜单还包含用于[高亮、添加下划线或删除线](text-markup.md)、[创建锚点](anchors.md)以及在新窗口中打开所选内容的命令。
