# 使用 Link Peek 预览链接

技术文稿中到处都是引用：“see Equation 3”、“as shown in Figure 2”、“[14]”。Link Peek 让你就地查看目标内容，不会失去当前的阅读位置。

## 预览链接

- 将指针停放在链接上，然后**按住 ⌘**。松开即可关闭预览。
- 或者在力度触控板上**用力点按**链接。松开后预览随即关闭。

预览会根据目标类型显示有用的内容：公式显示几行，章节显示开头一段，表或图显示顶部。

## 跟随链接

点按链接可前往其目标。选取 Go > Back (⌘[) 可返回。

网页链接会在浏览器中打开。你可以通过 [Open Links In](settings.md) 设置选择使用哪个浏览器。

## 在新窗口中打开目标

若要将目标保留在屏幕上，显示在当前页面旁边：

- **按住 ⌘ 点按**链接。
- 或者右键点按链接，然后选取 **Open in New Window**。

你也可以右键点按文本或页面上的某个位置，在新窗口中打开该位置。请参阅[标签页和窗口](tabs-and-windows.md#anchor-windows)。

## 保留目标

右键点按链接，然后选取 **Create Anchor** 将其目标存储为[锚点](anchors.md)，或者选取 **Create Anchor and Open in New Window** 同时完成这两项操作。
