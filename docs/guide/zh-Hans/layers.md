# 显示和隐藏图层

从 CAD 和设计程序导出的图纸，通常会把图纸的每个部分放在各自的图层上：墙体、电气、给排水、尺寸、修订云等。你可以分别显示或隐藏每个图层。

只有当文稿带有图层时，边栏顶部才会出现 Layers 标签页。若要为文稿添加第一个图层，请参阅[添加、重命名和删除图层](#add-rename-and-delete-layers)。

- **显示或隐藏图层：** 点按其复选框。页面会立即重新绘制。
- **从一组中选取一个：** 有些文稿会将图层分组，一次只显示其中一个，例如图纸的不同语言或比例。这些图层带有圆形按钮；选取一个会隐藏其他图层。
- **标题：** 用于将列在其下方的图层归为一组，标题本身不能隐藏。
- **锁定的图层：** 旁边带有锁形图标。文稿不允许显示或隐藏它们。

你隐藏的图层在[打印](print.md)、[选择文本](select-text.md)或[搜索](search.md)时也会被排除，因此你只会处理所看到的内容。

## 将注释放在图层上

注释也可以放在图层上，这样它们会随该图层一起显示和隐藏。其他能读取图层的 App（例如 Acrobat 和 Bluebeam）也会以同样的方式显示和隐藏它们。

- **选取新注释放在哪里：** 在 [Markup 工具栏](draw-and-notes.md)或 [Measurement 工具栏](measure.md)中，点按图层菜单（在你选取之前显示为 **No Layer**），然后选取一个图层。此后你创建的所有内容都会放在该图层上，直到你选取另一个图层或 **No Layer**。你也可以在 Layers 标签页中右键点按一个图层，然后选取 **Put New Annotations Here**。新注释所在的图层旁边带有铅笔图标。
- **将注释移到另一个图层：** 右键点按注释，选取 **Layer**，然后选取一个图层；或选取 **None**，使其不在任何图层上。
- **添加你自己的图层：** 请参阅[添加、重命名和删除图层](#add-rename-and-delete-layers)。

只有当文稿带有图层时才会出现图层菜单，因此其他文稿的工具栏不会改变。

隐藏图层上的注释会从页面、[Comments 标签页](draw-and-notes.md#see-all-annotations)和[工程量表](takeoff.md)中消失，并且无法被选择或擦除。Annotations 表格仍会列出它们及其所在图层。

如果你为新注释选取了一个隐藏的图层，该图层会被显示出来，这样你创建的内容就不会消失。Undo 会将注释放回它原来所在的图层。

## 添加、重命名和删除图层 {#add-rename-and-delete-layers}

审阅者常常把自己的标记放在专门的图层上，例如每个专业或每轮审阅各用一个图层，即使图纸本来没有图层也是如此。以下每个命令都会更改文稿，Undo 可以撤销它们。

- **添加图层：** 选取 Edit > New Layer…，然后为它命名。这适用于任何 PDF，因此文稿的第一个图层就是这样添加的；之后会出现 Layers 标签页和图层菜单。新注释会放在新图层上。在已有图层的文稿中，你也可以点按 Layers 标签页顶部的 **+**，或从图层菜单中选取 **New Layer…**。
- **重命名图层：** 选取 Edit > Rename Layer…，选取图层，然后输入新名称。
- **删除图层：** 选取 Edit > Delete Layer…，然后选取图层。其上的注释会保留在页面上，不属于任何图层。只有仅包含注释的图层才能删除：如果删除图纸本身所在的图层，图纸的那一部分将始终显示，因此这些图层不会列出。

## 会存储哪些内容

你添加、重命名或删除的图层会随文稿一起存储，注释所在的图层也是如此。

显示哪些图层不会随文稿存储。下次打开文稿时，其图层会按照文稿本身的设置显示，你发送文稿的对象看到的也一样。

> **注：** 单页文稿打开时边栏处于隐藏状态。使用工具栏中的边栏按钮可显示边栏。
