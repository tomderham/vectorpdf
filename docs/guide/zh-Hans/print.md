# 打印

选取 File > Print，或者按下 ⌘P。

在打印对话框中，选取 PDF Options 可看到以下选项：

- **Auto Rotate：** 旋转页面以适合纸张。
- **Scale to Fit：** 使每个页面适合纸张。
- **Scale：** 按你输入的百分比打印。

VectorPDF 打印时使用与屏幕显示相同的引擎，因此打印结果与你所见的一致。
