# 开始使用 VectorPDF

VectorPDF 需要搭载 Apple 芯片并运行 macOS 15 或更高版本的 Mac。将它拖移到“应用程序”文件夹即可安装。

初次使用 VectorPDF？请选取 Help > Take the Tour，或在空白的 Start 屏幕上点按 New here? Take the Tour。这会打开一份简短的示例文档，你可以在其中试用这些功能并添加标记。

## 打开第一个 PDF

如果 VectorPDF 启动时没有打开文稿，会显示 Start 屏幕。请执行以下任一操作：

- 将 PDF 拖移到拖放区域。
- 点按拖放区域，然后选取文件。
- 按下 ⌘O。

你也可以在访达 (Finder) 中使用 [Open With](open-documents.md) 打开 PDF，或者从 Start 屏幕上的 Tab Groups、Favorites 或 Recent Documents 中选取一个。

## 五件值得尝试的事

1. **按住 Command 键并将指针放在链接上。** 将指针移到对公式、图、表或文献的引用上，然后按住 ⌘ 即可[预览其目标](link-peek.md)。松开后，预览随即关闭。
2. **搜索。** 按下 ⌘F。[结果](search.md)一经找到就会显示在边栏中，按下 ⌘G 可逐个查看。
3. **保存当前位置。** 选择一些文本并按下 ⌘B，创建一个之后可以跳回的[锚点](anchors.md)。
4. **添加标记。** 选择文本并按下 ⇧⌘H 将其[高亮显示](text-markup.md)，或者按下 ⇧⌘A 显示 Markup 工具栏。
5. **将两份相关文稿作为标签页打开。** 按下 ⌥⌘O 打开第二份文稿，然后右键点按“Section 4.2 of the Master Agreement”这样的纯文本引用，即可[在另一个标签页中找到它](cross-document-references.md)。

## 熟悉界面

菜单栏、边栏和工具栏涵盖了大部分功能，右键点按则会提供适用于指针下方内容的命令。若要大致了解界面，请参阅 [VectorPDF 窗口](the-window.md)；若要了解每个菜单中的内容，请参阅[右键菜单](right-click-menus.md)；若要查看完整列表，请参阅[键盘快捷键](keyboard-shortcuts.md)。

若要搜索本手册，请使用边栏顶部的“搜索本手册”栏。此窗口顶部的搜索栏会搜索你所有应用的帮助。
