# 工程量表

工程量表是文稿中所有测量结果的明细表，列出每项测量的页面、类型、数值和比例，以及长度和面积的合计。

点按 [Measurement 工具栏](measure.md)中的 **Takeoff Table**。

- **Copy Table** 拷贝该表，可直接粘贴到电子表格中。
- **Export CSV** 将其存储为文件。

合计会将所有页面的长度（尺寸和周长）和面积相加。每项测量使用其所在页面的比例，合计以第一项测量的单位显示。
