# 填写表单

VectorPDF 支持交互式 PDF 表单 (AcroForms)。栏位会直接显示在页面上，随时可以使用。

- **文本栏：** 点按并键入。
- **复选框和单选按钮：** 点按以选择。
- **弹出式菜单和列表：** 点按并选取一项。
- **签名栏：** 点按 **Sign**，然后创建或选取[图章](stamps.md)。

按下 ⌘S [存储](save.md)填写好的表单。

如果表单有重置按钮，点按该按钮时会要求你确认，然后清除所有栏位。

若要防止他人更改答案，请存储一份拼合了表单栏位的副本。请参阅[导出为其他格式](export.md#flattened-pdf)。

> **注：** 栏位仅在未旋转的 Single Page 视图中可用。请参阅[缩放、旋转和页面布局](zoom-and-layout.md)。
