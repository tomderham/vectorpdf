# 缩放、旋转和页面布局

## 缩放

| 若要 | 请执行以下操作 |
| --- | --- |
| 放大或缩小 | 按下 ⌘+ 或 ⌘−，点按工具栏中的 + 或 −，或者在触控板上双指张开或捏合 |
| 设置精确的缩放比例 | 点按工具栏中的百分比，键入 10 到 1000 之间的值，然后按下 Return 键 |
| 以实际大小查看页面 | 选取 View > Actual Size (100%)，或者按下 ⌘1 |
| 适合页面宽度 | 选取 View > Zoom to Fit Width，或者按下 ⌘9 |
| 适合整个页面 | 选取 View > Zoom to Fit Window，或者按下 ⌥⌘0 |

Zoom In 和 Zoom Out 命令的范围为 25% 到 400%。若要超出此范围，请键入百分比。

VectorPDF 会在任何缩放比例下保持页面清晰，因为它会重新绘制页面，而不是放大图像。

## 100% 的含义

选取 View > Define 100% Scale As，然后选取以下选项之一：

- **Size on Screen Equals Size on Printout：** 比例为 100% 时，页面显示的大小约等于打印大小。
- **1 Point Equals 1 Screen Point：** 一个 PDF 点占用显示器上的一个点。

## 旋转视图 {#rotate-the-view}

点按工具栏中的 Rotate Left 或 Rotate Right。这只会更改文稿在屏幕上的显示方式，不会被存储。若要旋转 PDF 本身的页面，请参阅[重新排列页面](pages.md)。

## Two-Page Mode

点按工具栏中的 Two-Page Mode，或者选取 View > Two Pages (⌥⌘2)。页面会像翻开的书一样成对显示，封面单独显示，并且跨页会缩放以适合窗口。若要返回，请再次点按该按钮，或者选取 View > Single Page。

> **注：** 视图处于旋转状态或 Two-Page Mode 时，也可以选择文本、跟随链接、搜索、使用标记和测量工具以及填写表单。你添加的内容位于页面本身，因此将视图转回后仍会留在原处。
