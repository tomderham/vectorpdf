# 进行数字签名和检查数字签名

数字签名表明谁签署了文稿，以及文稿自签署后未被更改。你可以用自己的证书[签署 PDF](#sign)。打开已签名的 PDF 时，VectorPDF 会检查其签名，并在页面上方的栏中显示检查结果：

- **签名有效：**文稿自签署后未被更改，签名人的证书由你的 Mac 信任的机构颁发。
- **签名人的身份未在这台 Mac 上得到验证：**文稿未被更改，但没有任何东西能担保是谁签的名。请参阅[签名人的身份为何可能未得到验证](#signer-identity)。
- **无效：**文稿在签署后被更改，或签名与文稿不符。

点按 **Signature Details**，即可在边栏的 Document 标签页中查看每个签名。若要隐藏此栏，请点按它的关闭按钮。

> **注：** [图章](stamps.md)是签名的图像，不是数字签名。

## 使用证书签名 {#sign}

若要签名，你需要一个带有私钥的签名证书。你的组织或证书颁发机构可以为你提供，通常是带密码的 .p12 或 .pfx 文件。钥匙串中的证书可以直接使用。

1. 选取 Edit > Sign with Certificate，然后点按页面上要放置签名的位置。按下 Esc 键可停止。如果文稿有空的签名栏位，你也可以点按该栏位并选取 Sign with Certificate。
2. 选取你的证书。若要使用文件，请点按 **Choose Certificate File**，然后输入它的密码。该文件只为这次签名读取，不会添加到你的钥匙串。
3. 如有需要，输入原因（例如“我批准此文稿”）和签名地点。如果你创建了[图章](stamps.md)，可以在栏位中显示你的手写签名。否则会显示你的姓名。
4. 点按 **Sign**。

签名会存储文稿，因此如果文稿有未存储的更改，VectorPDF 会先询问是否存储。这些更改会成为你所签内容的一部分。macOS 可能会要求你允许 VectorPDF 使用证书的密钥。

签名不会改变文稿中的其他表单栏位，因此其他人仍可填写它们、同样进行签名或添加注释，而不会使你的签名失效。之后的每个签名也会以同样方式添加在之前的签名之后。

该签名是使用 SHA-256 的 PKCS #7 签名，包含你的证书以及颁发它的机构的证书。它记录你的 Mac 上的时间。目前还不包含时间戳机构提供的时间戳。

## VectorPDF 检查的内容

对于每个签名，Document 标签页中的列表会显示：

- 它所签署的文件部分是否与签署时完全一致。
- 文件在签署后是否再次存储过，以及这些更改是否属于签名允许的更改。填写表单栏位、添加签名以及添加或更改注释通常是允许的。认证签名可能允许较少的更改。如果签署后添加了注释，列表会注明：注释可能会遮盖已签署的内容。
- 签名人（按其证书中的姓名）以及证书的颁发者。如果签名软件写入文稿的姓名与之不同，也会一并显示。
- 签署时间。来自时间戳机构的时间是有担保的，来自签名人自己电脑的时间则没有。
- 签名人填写的原因和地点（如有）。

点按签名可前往它在页面上的位置。若要查看其证书，请点按 **Show Certificate**，或右键点按签名并选取 Show Certificate。

VectorPDF 检查的是上次存储时的文件，因此不包括未存储的更改。每次存储时它都会重新检查。

## 签名人的身份为何可能未得到验证 {#signer-identity}

任何人都可以制作包含任意姓名的证书。只有当证书由核实过签名人身份的机构颁发，并且你的 Mac 信任该机构时，签名才能证明是谁签的名。VectorPDF 使用你的 Mac 在“钥匙串访问”中信任的证书。

许多已签名的 PDF 使用的证书来自 Adobe Acrobat 信任而 macOS 不信任的机构，因此 VectorPDF 会报告其签名人未得到验证。尽管如此，文稿可能自签署后并未更改。若要信任某个机构，请将它的证书添加到“钥匙串访问”并设为“始终信任”，但前提是你确信它是真的。

VectorPDF 不会联网检查证书是否已被吊销。这样，就不会有人知道你打开了文稿。

## 存储已签名的文稿

存储已签名的文稿时，VectorPDF 会把你的更改添加在文件已签名部分之后，并保持该部分不变，因此在更改被允许的范围内，签名仍然有效。用[涂黑](redact.md)删除内容会重写整个文件，因此文稿的签名会失效。

## 检查的签名类型

VectorPDF 检查常见的 PDF 签名：PKCS #7 和 CAdES (PAdES) 签名。它目前还不检查文稿时间戳和较旧的 X.509 RSA 签名。它们会被列为 **Not checked**。
