# 锚点

锚点是文稿中保存下来的位置，可以是一段文本、页面上的一个区域或链接的目标。锚点与 PDF 分开保存，不会更改 PDF。

## 创建锚点

- 选择文本，或者按住 ⌥ 并拖移以选择一个区域，然后按下 ⌘B。
- 右键点按所选内容、链接或页面上的某个位置，然后选取 **Create Anchor**。
- 右键点按[搜索结果](search.md)或[大纲](outline-and-thumbnails.md)条目，然后选取 **Create Anchor**。

如果未选择任何内容，按下 ⌘B 会为当前页面创建锚点。

**Create Anchor and Open in New Window** 的作用相同，并且还会在单独的窗口中显示该位置。

## 使用锚点

点按边栏中的 Anchors 标签页可查看每个锚点的卡片，你也可以使用 Anchors 菜单。

- **跳到锚点：** 点按其卡片，或者从 Anchors 菜单中选取它。
- **查看较大的预览：** 将指针停放在卡片的缩略图上。
- **查看窗口中所有标签页的锚点：** 在 Anchors 标签页顶部选取 All Tabs。点按其中一个锚点可切换到相应的标签页。

右键点按卡片可在新窗口中打开它、拷贝其文本或拷贝其图像。

## 删除锚点

- **单个锚点：** 点按其卡片上的 ×，或者右键点按它并选取 Delete Anchor。
- **文稿中的所有锚点：** 点按 Anchors 标签页中的 Clear All，或者选取 Anchors > Clear All Anchors。

## 锚点和页面更改

锚点会记住页码。如果添加、删除或移动页面会导致锚点指向错误的位置，VectorPDF 会先发出警告。你可以选取 **Save as Copy** 在副本中进行更改（副本不包含锚点），也可以选取 **Edit Anyway**。

## 你其他 Mac 上的锚点

除非你将其关闭，否则锚点会与阅读位置一起[通过 iCloud 同步](reading-positions.md)。
