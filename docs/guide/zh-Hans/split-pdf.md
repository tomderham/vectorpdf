# 拆分 PDF

1. 选取 File > Split PDF。
2. 在 Split Method 下，选取以下方式之一：
   - **Every N Pages：** 每隔指定页数生成一个新文件。
   - **Single Pages：** 每页一个文件。
   - **Page Ranges：** 输入以逗号分隔的页码或页面范围，例如 `1-5, 6-12, 13-20`。
3. 在 Save Location 下，点按 Choose 以选取文件夹。
4. 在 File Naming 下，输入前缀并选取样式：Part Number 或 Page Range。Output Preview 会显示将要创建的文件。
5. 点按 Split PDF。

原始文稿不会更改。拆分完成后，点按 Reveal in Finder 可查看这些文件。
