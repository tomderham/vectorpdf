# 打开文稿

## 打开 PDF

- **在新窗口中打开：** 选取 File > Open PDF，或者按下 ⌘O。
- **在新标签页中打开：** 选取 File > Open PDF in New Tab，或者按下 ⌥⌘O。
- **从访达 (Finder) 打开：** 右键点按 PDF，然后选取 Open With > VectorPDF（“打开方式”）。若要用 VectorPDF 打开所有 PDF，请选择一个 PDF，在访达中选取 File > Get Info（“文件”>“显示简介”），更改“Open with”（“打开方式”），然后点按 Change All（“全部更改”）。
- **通过拖移打开：** 将 PDF 拖移到 Start 屏幕可在该屏幕上打开，拖移到已打开的文稿上则会在新标签页中打开。
- **从列表打开：** 选取 File > Open Recent，或者使用 [Favorites](favorites-and-tab-groups.md) 菜单。在 Start 屏幕上，右键点按文稿可在新标签页或新窗口中打开它。

## 受密码保护的 PDF

打开受保护的 PDF 时，VectorPDF 会要求你输入密码。请参阅[密码和加密](passwords.md)。

## 云存储中的 PDF

VectorPDF 能识别 iCloud 云盘、Google Drive、Dropbox、OneDrive 和 Box 中的文件。如果文件尚未下载到你的 Mac，VectorPDF 会先下载再打开，并显示进度。如果下载未完成，你会看到一条信息，可以在连接网络后重试。

## 文件发生更改时

VectorPDF 会监视每个打开的文件。如果其他应用更改了文件，文稿会自动重新载入。如果你正在用 LaTeX 或其他工具生成 PDF 并希望保持打开，这会很有用。

如果你有未存储的更改，VectorPDF 会询问是选择 **Reload from Disk**（这会丢失你的更改），还是选择 **Keep My Changes**。

如果你在访达中移动文件或给文件重新命名，打开的文稿会随之更新。

## 关闭文稿

像平常一样关闭标签页或窗口。如果有未存储的更改，VectorPDF 会询问是否存储。VectorPDF 会记住[你阅读到的位置](reading-positions.md)，方便下次继续。
