# 绘图、添加文本和标注框

按下 ⇧⌘A 或点按 Markup Toolbar 按钮，以显示 Markup 工具栏。选取一个工具，然后选取颜色和大小。若要结束使用工具，请按下 Escape 键，或者选取工具栏中的第一个工具 Text Selection Mode。

## 手绘

选取钢笔工具，将线宽设为 Thin、Medium 或 Thick，然后在页面上拖移。

## 添加文本框

1. 选取文本框工具，并设置 6 到 32 点的字体大小。
2. 在页面上要放置文本的位置点按，然后键入内容。
3. 点按文本框外部或按下 Escape 键以完成。

## 添加标注框

标注框是一段带箭头的文本注解，箭头指向页面上的某个内容。

1. 选取标注框工具。
2. 在希望箭头指向的位置按住，然后拖移到要放置注解的位置。
3. 键入注解。

之后，你可以分别拖移箭头的目标和注解。

## 更改注释

| 若要 | 请执行以下操作 |
| --- | --- |
| 编辑文本 | 连按两下文本框或标注框，或者选择它并按下 Return 键，或者右键点按它并选取 Edit Text Box 或 Edit Callout Note |
| 移动 | 拖移它，或者选择它并按下箭头键。按住 ⇧ 可每次移动 10 点。 |
| 调整大小 | 选择它，然后拖移角上的控制柄 |
| 删除 | 选择它并按下 Delete 键，或者右键点按它并选取相应的删除命令，例如 Delete Drawing 或 Delete Text Box |

使用 Markup 工具栏中的 Eraser，可通过点按或拖移划过注释来删除它们。

[存储](save.md)时，你的注释会以标准注释的形式保存在 PDF 中，因此也会显示在其他 PDF 应用中。若要将它们固定到页面上，请[导出拼合的 PDF](export.md#flattened-pdf)。
