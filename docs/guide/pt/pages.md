# Reorganizar páginas

As alterações de páginas são feitas na visualização [Thumbnails](outline-and-thumbnails.md) da barra lateral. Elas passam a fazer parte do arquivo quando você [salva](save.md).

## Selecionar páginas

Clique em uma miniatura. Mantenha ⌘ pressionada para adicionar páginas uma a uma, ou ⇧ para selecionar um intervalo.

## Mover páginas

Arraste as miniaturas selecionadas para uma nova posição. Uma linha mostra para onde elas irão. Você também pode clicar em uma página com o botão direito e escolher Move Page Up ou Move Page Down.

## Outros comandos de páginas

Clique com o botão direito em uma miniatura ou em uma seleção de miniaturas e escolha:

- **Rotate Clockwise, Rotate Counterclockwise ou Rotate 180°:** gira as páginas no próprio PDF, ao contrário dos [botões de rotação na barra de ferramentas](zoom-and-layout.md#rotate-the-view).
- **Duplicate Page:** adiciona cópias logo após as páginas selecionadas. Você também pode escolher File > Duplicate Pages (⇧⌘D), que copia as miniaturas selecionadas se elas incluírem a página em que você está; caso contrário, copia essa página.
- **Insert Blank Page.**
- **Insert Pages from PDF:** adiciona páginas de outro PDF. Você também pode escolher File > Insert Pages from PDF (⌥⌘I).
- **Save selected page as a PDF:** extrai páginas para um novo arquivo.
- **Delete Page.**

## Se você criou âncoras

Adicionar, apagar ou mover páginas pode fazer uma [âncora](anchors.md) apontar para o lugar errado. O VectorPDF avisa você e oferece a opção de fazer a alteração em uma cópia.
