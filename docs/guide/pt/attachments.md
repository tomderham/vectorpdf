# Arquivos anexados a um PDF

Um PDF pode levar outros arquivos dentro dele: uma planilha junto com um relatório, um modelo CAD junto com um conjunto de desenhos ou os dados de uma fatura eletrônica. Quando um documento tem anexos, a aba Attachments (um clipe) aparece na parte superior da barra lateral. Um documento de uma página com anexos abre com a barra lateral visível.

Cada anexo mostra o nome e, quando o PDF os inclui, a descrição, o tamanho e a página à qual está anexado. Mantenha o ponteiro sobre um anexo para ver o tipo de arquivo e a data.

| Para | Faça isto |
| --- | --- |
| Pré-visualizar um anexo | Clique duas vezes nele, ou selecione-o e pressione a barra de espaço |
| Pré-visualizar o próximo ou o anterior | Com o Quick Look aberto, pressione a tecla Seta para Baixo ou Seta para Cima |
| Abri-lo no app dele | Clique nele com o botão direito e escolha Open |
| Salvar uma cópia | Clique nele com o botão direito e escolha Save As…, ou arraste-o para o Finder |
| Salvar todos | Clique em Save All… na parte superior da aba e escolha uma pasta |
| Ir para a página dele | Clique nele com o botão direito e escolha Show on Page |

> **Aviso:** Um anexo pode ser qualquer tipo de arquivo, inclusive um app ou um script. Abra somente arquivos em que você confia. O VectorPDF marca como baixados os arquivos que tira de um PDF, para que o macOS verifique apps e scripts antes de executá-los, como faz com arquivos da internet.

## Faturas eletrônicas

As faturas ZUGFeRD e Factur-X levam seus dados em um arquivo XML, geralmente chamado `factur-x.xml` ou `zugferd-invoice.xml`. Ele aparece com os outros anexos, para que você possa salvá-lo para o seu software de contabilidade. O VectorPDF não mostra os detalhes da fatura por conta própria.
