# Propriedades do documento

Escolha File > Document Properties ou pressione ⌘I. Escolha uma aba na parte superior:

- **General:** o título, o autor, o assunto, as palavras-chave, as datas, o aplicativo que criou o documento, a localização do arquivo e seu armazenamento.
- **Security:** a criptografia do documento e se ele permite impressão, cópia, alterações, comentários, preenchimento de formulários, extração para acessibilidade e montagem de páginas.
- **Page Geometry:** a MediaBox, a CropBox, a BleedBox, a TrimBox e a ArtBox de qualquer página, em pontos, polegadas ou milímetros.
- **Fonts:** as fontes do documento, seu tipo e codificação, e se cada uma está incorporada. Use o campo de filtro para encontrar uma fonte.
