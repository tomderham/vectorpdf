# Alterar as cores do PDF

O VectorPDF pode alterar a aparência das páginas de um documento, seja qual for a aparência do macOS. Isso é útil para ler em um ambiente escuro. O PDF não é alterado.

Escolha View > PDF Color, ou use o ajuste PDF Color em [Ajustes](settings.md), e escolha uma opção:

- **Follow System:** as páginas acompanham a aparência do macOS.
- **Light:** as páginas aparecem como o documento as define.
- **Dark:** as cores da página são invertidas, mantendo os matizes, para que diagramas e realces continuem reconhecíveis.
- **Sepia:** as páginas ganham um tom quente de papel.

A impressão e a exportação usam as cores originais do documento.
