# Navegar por um documento

## Rolar e virar páginas

Role com o trackpad ou o mouse. O VectorPDF prepara apenas as páginas próximas de onde você está lendo, por isso documentos muito longos continuam rápidos.

Pelo teclado:

| Teclas | Ação |
| --- | --- |
| Left Arrow, Right Arrow | Página anterior ou seguinte |
| Up Arrow, Down Arrow | Rolar dentro de uma página mais alta que a janela e depois passar à página seguinte. Se a página couber na janela, mover uma página por vez. |
| Page Up, Page Down | Rolar um trecho maior e depois passar à página seguinte |
| Space, ⇧Space | Avançar ou voltar, como Page Down e Page Up |
| ⌥Up Arrow, ⌥Down Arrow, ⌥Left Arrow, ⌥Right Arrow | Página anterior ou seguinte |
| ⌘Up Arrow, ⌘Down Arrow | Primeira ou última página |

Em Two-Page Mode, essas teclas viram um par de páginas inteiro.

## Ir para uma página

Clique no número da página na barra de ferramentas, digite a página desejada e pressione Return. Pressione Escape para cancelar.

## Voltar para onde você estava

Depois de seguir um link ou ir até um resultado, escolha Go > Back (⌘[) para voltar. Go > Forward (⌘]) faz o caminho inverso.

## Usar a estrutura do documento

- [O sumário](outline-and-thumbnails.md) leva a qualquer seção.
- [As miniaturas](outline-and-thumbnails.md) mostram todas as páginas.
- [As âncoras](anchors.md) marcam os locais aos quais você deseja voltar.
- [O Link Peek](link-peek.md) mostra o destino de um link sem sair da sua página.
