# Começar a usar o VectorPDF

O VectorPDF requer o macOS 15 ou posterior em um Mac com Apple Silicon. Para instalá-lo, arraste-o para a pasta Aplicativos.

## Abrir seu primeiro PDF

Quando o VectorPDF é iniciado sem um documento, ele mostra a tela Start. Faça uma destas ações:

- Arraste um PDF para a área de soltar.
- Clique na área de soltar e escolha um arquivo.
- Pressione ⌘O.

Você também pode abrir um PDF no Finder com [Open With](open-documents.md) ou escolher um em Tab Groups, Favorites ou Recent Documents na tela Start.

## Cinco coisas para experimentar

1. **Mantenha a tecla Command pressionada sobre um link.** Mova o cursor sobre uma referência a uma equação, figura, tabela ou citação e mantenha ⌘ pressionada para [pré-visualizar o destino](link-peek.md). Solte a tecla e a pré-visualização se fecha.
2. **Busque.** Pressione ⌘F. Os [resultados](search.md) aparecem na barra lateral à medida que são encontrados, e ⌘G percorre cada um deles.
3. **Salve o local em que está.** Selecione um texto e pressione ⌘B para criar uma [âncora](anchors.md) à qual você pode voltar.
4. **Faça marcações.** Selecione um texto e pressione ⇧⌘H para [realçá-lo](text-markup.md), ou pressione ⇧⌘A para mostrar a barra de ferramentas Markup.
5. **Abra dois documentos relacionados como abas.** Pressione ⌥⌘O para abrir o segundo e clique com o botão direito em uma referência em texto simples, como “Section 4.2 of the Master Agreement”, para [encontrá-la na outra aba](cross-document-references.md).

## Conhecer o app

A barra de menus, a barra lateral e as barras de ferramentas reúnem a maioria dos recursos, e clicar com o botão direito mostra os comandos adequados ao que está sob o cursor. Consulte [A janela do VectorPDF](the-window.md) para fazer um tour, [Menus do botão direito](right-click-menus.md) para saber o que há em cada menu e [Atalhos de teclado](keyboard-shortcuts.md) para ver a lista completa.

Para buscar neste manual, use o campo Buscar neste manual na parte superior da barra lateral. O campo de busca na parte superior desta janela busca na ajuda de todos os seus apps.
