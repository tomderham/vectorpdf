# Senhas e criptografia

## Abrir um PDF protegido

O VectorPDF pede a senha quando você abre um PDF protegido. Se você clicar em Cancel, o documento permanecerá fechado.

## Criptografar uma cópia

1. Escolha File > Save Encrypted with Password (⌥⌘S).
2. Escolha um nome e uma localização.
3. Digite a senha duas vezes e clique em Encrypt & Save.

A cópia é criptografada com AES-256 e precisa da senha para ser aberta.

> **Aviso:** Guarde a senha em um lugar seguro. Se você a perder, não haverá como recuperar o PDF criptografado.

## Ver as permissões de um documento

Para ver o que o autor de um documento permite, como imprimir ou copiar, escolha File > Document Properties (⌘I) e clique em Security. Consulte [Propriedades do documento](document-properties.md).
