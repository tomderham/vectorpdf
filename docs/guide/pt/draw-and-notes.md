# Desenhar, adicionar notas, texto e textos explicativos

Pressione ⇧⌘A ou clique no botão Markup Toolbar para mostrar a barra de ferramentas Markup. Escolha uma ferramenta e, depois, uma cor e um tamanho. Para escolher uma cor, clique no botão de cor perto da direita da barra e, depois, em uma cor. Para terminar de usar uma ferramenta, pressione Escape ou escolha Text Selection Mode, a primeira ferramenta da barra.

## Desenhar à mão livre

Escolha a ferramenta de caneta, defina a espessura da linha como Thin, Medium ou Thick e arraste na página.

## Desenhar uma forma

1. Escolha a ferramenta Shapes e, depois, Rectangle, Oval, Line or Arrow ou Revision Cloud.
2. Defina a espessura da linha como Thin, Medium ou Thick. Para uma linha, use o menu Line Ending para escolher uma ponta de seta, como Open Arrow, Closed Arrow ou Diamond, ou None para uma linha simples.
3. Arraste na página. Um retângulo ou oval preenche a área sobre a qual você arrasta. Uma linha vai de onde você começa até onde para, com a terminação no fim.

Mantenha ⇧ pressionada enquanto arrasta para desenhar um quadrado ou círculo, ou para manter uma linha em um múltiplo de 45°.

Uma nuvem de revisão marca uma área que mudou ou precisa de revisão. Arraste ao redor da área, e a nuvem segue o contorno que você desenha. Um arraste rápido em linha reta cria uma nuvem oval.

Para selecionar, mover ou clicar com o botão direito em um retângulo, oval ou nuvem, use o contorno; assim você ainda pode selecionar o texto dentro dele.

Para alterar uma linha depois de desenhá-la, arraste uma das extremidades para mover só essa extremidade, ou selecione-a e escolha outra espessura ou terminação de linha na barra. Você também pode clicar nela com o botão direito e escolher Line Ending. Selecione um retângulo ou oval e escolha uma espessura de linha para alterar sua espessura.

## Adicionar uma caixa de texto

1. Escolha a ferramenta de caixa de texto e defina um tamanho de fonte de 6 a 32 pontos.
2. Clique na página onde deseja colocar o texto e digite.
3. Clique fora da caixa ou pressione Escape para terminar.

## Adicionar um texto explicativo

Um texto explicativo é uma nota com uma seta que aponta para algo na página.

1. Escolha a ferramenta de texto explicativo.
2. Pressione o ponto que a seta deve tocar e arraste até onde deseja colocar a nota.
3. Digite sua nota.

Depois, você pode arrastar separadamente o alvo da seta e a nota.

Para escolher como a linha termina, por exemplo com uma seta aberta, um losango ou uma barra, use o menu Line Ending na barra de ferramentas antes de desenhar. Para alterar um texto explicativo existente, clique nele com o botão direito e escolha Line Ending.

## Adicionar uma nota adesiva

Uma nota é um pequeno ícone na página com um comentário associado.

1. Escolha a ferramenta de nota adesiva.
2. Clique onde deseja colocar a nota e digite.
3. Clique em outro lugar para terminar. Uma nota deixada vazia é removida.

Clique duas vezes em uma nota para lê-la ou alterá-la.

## Responder a uma anotação

Qualquer anotação pode ter respostas: uma nota, um realce, um desenho, uma forma, uma nuvem ou uma medição. Clique duas vezes nela, ou clique nela com o botão direito e escolha Comments…, para ver quem a criou e quando. Você também pode fazer isso com anotações de outras pessoas e de outros apps. A partir daí, você pode:

- Digitar no campo Reply e pressionar Return para adicionar uma resposta.
- Usar o menu Status para marcá-la como Accepted, Rejected, Cancelled ou Completed.
- Clicar no botão da lixeira para apagá-la com suas respostas.

Clicar duas vezes em uma caixa de texto ou texto explicativo edita o texto; clique nele com o botão direito para chegar aos comentários. Para uma linha ou desenho que veio no arquivo, clique com o botão direito também.

Seu nome nas anotações vem de Annotation Author em [Ajustes](settings.md).

## Ver todas as anotações {#see-all-annotations}

Clique na aba Comments da barra lateral para listar todas as anotações do documento por página, com comentário, status e respostas. A aba aparece quando o documento tem alguma anotação. Clique em uma para ir até ela na página. Clique duas vezes para abrir os comentários ali, responder ou alterar o status. Use o botão de filtro na parte superior para mostrar só um tipo, autor, status ou data.

Para uma tabela que você pode ordenar e filtrar em uma janela maior, clique no botão Annotations, à direita da barra de ferramentas Markup. Selecione uma e clique em Show on Page, ou clique duas vezes nela, para ir à página dela.

## Alterar uma anotação

| Para | Faça o seguinte |
| --- | --- |
| Editar o texto | Clique duas vezes em uma caixa de texto ou texto explicativo, selecione-o e pressione Return, ou clique nele com o botão direito e escolha Edit Text Box ou Edit Callout Note |
| Mover | Arraste-a, ou selecione-a e pressione as teclas de seta. Mantenha ⇧ pressionada para mover 10 pontos por vez. |
| Redimensionar | Selecione-a e arraste uma alça de canto. Para uma linha ou seta, arraste uma das extremidades. |
| Apagar | Selecione-a e pressione Delete, ou clique nela com o botão direito e escolha o comando de apagar, como Delete Drawing ou Delete Text Box |

Use a Eraser na barra de ferramentas Markup para apagar anotações clicando nelas ou arrastando sobre elas. Apagar uma anotação também apaga as respostas dela.

### Anotações de outras pessoas e apps

Você pode alterar da mesma forma as anotações que já estavam no documento, como as formas, notas e nuvens de outro revisor:

- Arraste um retângulo, oval, nuvem, linha, nota, carimbo ou caixa de texto para movê-lo, ou selecione-o e pressione as teclas de seta. Ele mantém a aparência, o autor, a data e as respostas.
- Arraste uma alça de canto de um retângulo, oval ou nuvem para redimensioná-lo, ou uma das extremidades de uma linha para mover essa extremidade.
- Selecione uma e escolha uma cor, espessura ou terminação de linha na barra de ferramentas Markup para alterá-la. O VectorPDF a desenha de novo no próprio estilo.

Realces, sublinhados, tachados, desenhos à mão livre e medições do arquivo ficam onde estão, como os seus, mas você pode apagá-los ou respondê-los. Não é possível editar o texto de uma caixa de texto criada em outro app.

## Desfazer uma alteração

Escolha Edit > Undo, ou pressione ⌘Z, para desfazer a adição, o movimento, a mudança de estilo ou a exclusão de uma anotação. Pressione ⇧⌘Z para refazer. Isso funciona com qualquer anotação, inclusive uma que já estava no documento e que você apagou, ou removeu por engano com a borracha. Ela volta com as respostas, o autor e a data.

Suas anotações são armazenadas no PDF como anotações padrão quando você [salva](save.md), por isso aparecem em outros apps de PDF, com seus autores, respostas e status. Para fixá-las na página, [exporte um Flattened PDF](export.md#flattened-pdf).
