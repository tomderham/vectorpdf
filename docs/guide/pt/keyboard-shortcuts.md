# Atalhos de teclado

Muitos destes comandos também estão em um menu do botão direito, conforme indicado abaixo. Consulte [Menus do botão direito](right-click-menus.md).

## Documentos

| Ação | Atalho |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Insert Pages from PDF | ⌥⌘I, ou clique com o botão direito em uma miniatura |
| Duplicate Pages | ⇧⌘D, ou clique com o botão direito em uma miniatura |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Add to or Remove from Favorites | ⌘D, ou clique com o botão direito no título do documento |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## Navegação

| Ação | Atalho |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow ou Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow ou Right Arrow |
| First Page | ⌘Up Arrow ou ⌘Home |
| Last Page | ⌘Down Arrow ou ⌘End |
| Avançar ou voltar pela página | Space ou ⇧Space |
| Next Tab | ⇧⌘] ou ⌃Tab |
| Previous Tab | ⇧⌘[ ou ⇧⌃Tab |

| Zoom Out | ⌘− |

| Zoom to Fit Width | ⌘9 |

| Show or Hide Measurement Toolbar | ⇧⌘M |
| Show or Hide Redact Toolbar | ⌥⌘R |

## Busca e texto

| Ação | Atalho | Botão direito |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G, ou Return no campo de busca | |
| Find Previous | ⇧⌘G, ou ⇧Return no campo de busca | |
| Copy | ⌘C | Texto selecionado |
| Highlight | ⇧⌘H | Texto selecionado |
| Underline | ⇧⌘U | Texto selecionado |
| Strikethrough | ⇧⌘X | Texto selecionado |
| Stop Speaking | ⌥⌘. | Texto selecionado |
| Add Anchor | ⌘B | Seleção, link ou página, como Create Anchor |

## Mouse e trackpad

| Ação | Gesto |
| --- | --- |
| Pré-visualizar um link | Mantenha ⌘ pressionada sobre ele ou use o clique forte |
| Abrir um link em uma nova janela | Clique com ⌘ pressionada |
| Selecionar uma palavra | Clique duas vezes |
| Selecionar uma linha | Clique três vezes |
| Selecionar uma área | Arraste com ⌥ pressionada |
| Abrir os comentários de uma anotação | Clicar duas vezes nela, exceto em uma caixa de texto ou texto explicativo |
| Zoom | Faça o gesto de pinça |

## Anotações e medições

| Ação | Atalho | Botão direito |
| --- | --- | --- |
| Desfazer ou refazer uma alteração em uma anotação | ⌘Z ou ⇧⌘Z | |
| Editar a caixa de texto ou o texto explicativo selecionado | Return | A anotação |
| Apagar a anotação selecionada | Delete | A anotação |
| Mover a anotação selecionada | Arrow keys, ou ⇧Arrow keys para mover 10 pontos | |
| Terminar o perímetro ou a área | Return | |
| Inverter Ortho Lock (0°, 45° ou 90°) em uma linha | Mantenha ⇧ pressionada | |
| Desenhar um quadrado ou círculo, ou uma linha em um múltiplo de 45° | Manter ⇧ pressionada ao arrastar com a ferramenta Shapes | |
| Cancelar ou sair da ferramenta atual | Escape | |
