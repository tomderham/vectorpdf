# Dividir um PDF

1. Escolha File > Split PDF.
2. Em Split Method, escolha uma opção:
   - **Every N Pages:** um novo arquivo a cada determinado número de páginas.
   - **Single Pages:** um arquivo para cada página.
   - **Page Ranges:** digite números de página ou intervalos separados por vírgulas, como `1-5, 6-12, 13-20`.
3. Em Save Location, clique em Choose para selecionar uma pasta.
4. Em File Naming, digite um prefixo e escolha um estilo: Part Number ou Page Range. Output Preview mostra os arquivos que serão criados.
5. Clique em Split PDF.

O documento original não é alterado. Quando a divisão terminar, clique em Reveal in Finder para ver os arquivos.
