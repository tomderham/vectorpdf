# Abas e janelas

## Abas

O VectorPDF usa as abas de janela padrão do macOS.

- **Nova aba:** pressione ⌘T ou clique no botão + na barra de abas.
- **Abrir um PDF em uma nova aba:** pressione ⌥⌘O ou arraste-o para um documento aberto.
- **Nova janela:** pressione ⌘N para abrir uma janela vazia ou ⌘O para abrir um PDF em uma nova janela.
- **Alternar entre abas:** pressione ⇧⌘] para a próxima aba e ⇧⌘[ para a anterior (Go > Next Tab e Go > Previous Tab). ⌃Tab e ⇧⌃Tab também funcionam.

Para salvar as abas abertas como um grupo, clique no título do documento com o botão direito e escolha Save All Open Tabs as a Group. Consulte [Favoritos e Grupos de Abas](favorites-and-tab-groups.md).

Manter documentos relacionados como abas de uma mesma janela também permite que o VectorPDF [siga as referências entre eles](cross-document-references.md).

## Encontrar uma janela aberta

O menu Window e o ícone do VectorPDF no Dock listam as janelas abertas, com as abas de cada uma.

## Janelas de âncora {#anchor-windows}

Você pode abrir qualquer local de um documento em uma pequena janela própria, para manter uma figura ou definição à vista enquanto lê:

- Clique em um link com ⌘ pressionada.
- Clique com o botão direito em um link, uma seleção, um local da página, um resultado de busca ou uma entrada do sumário e escolha **Open in New Window**.

Essas janelas têm uma faixa na parte superior. Clique nela para voltar ao local que ela mostra. Clique em **Close all Child Windows** na faixa para fechar todas as janelas abertas a partir do mesmo documento. Elas também se fecham quando você fecha o documento de origem.

O VectorPDF não abre duplicatas: se o local já estiver aberto em uma janela, ele traz essa janela para a frente.
