# Selecionar, copiar e pesquisar texto

## Selecionar texto

- **Arraste** sobre o texto. As seleções seguem a ordem de leitura, por isso ficam em uma coluna de um layout com várias colunas e ignoram os números de linha nas margens. Elas podem se estender por várias páginas.
- **Clique duas vezes** para selecionar uma palavra ou **clique três vezes** para selecionar uma linha.
- **Mantenha ⌥ pressionada e arraste** para selecionar uma área retangular, como uma figura ou tabela.

Pressione Escape para limpar a seleção.

## Copiar

Pressione ⌘C, ou clique no texto selecionado com o botão direito e escolha Copy Text.

Clique em uma seleção retangular com o botão direito para ver mais opções:

- **Copy Extracted Text** copia o texto que houver na área.
- **Copy Screenshot** copia a área como imagem.
- **Save Screenshot As** salva a área como um arquivo de imagem.

## Pesquisar e traduzir

Clique no texto selecionado com o botão direito e escolha:

- **Look Up** para ver uma definição do dicionário.
- **Translate Selection** para traduzi-lo.

## Ouvir o texto em voz alta

Selecione o texto e escolha Edit > Speech > Start Speaking, ou clique com o botão direito e escolha Start Speaking. Para parar, escolha Stop Speaking ou pressione ⌥⌘. (Option-Command-ponto).

## Outras ações

O menu que aparece ao clicar com o botão direito no texto selecionado também tem comandos para [realçar, sublinhar ou tachar](text-markup.md) o texto, [criar uma âncora](anchors.md) e abrir a seleção em uma nova janela.
