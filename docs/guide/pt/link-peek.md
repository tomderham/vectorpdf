# Pré-visualizar links com o Link Peek

Documentos técnicos são cheios de referências: “see Equation 3”, “as shown in Figure 2”, “[14]”. O Link Peek mostra o destino ali mesmo, para que você não perca seu lugar.

## Espiar um link

- Mantenha o cursor sobre um link e **mantenha ⌘ pressionada**. Solte a tecla para fechar a pré-visualização.
- Ou use o **clique forte** no link em um trackpad Force Touch. A pré-visualização se fecha quando você solta.

A pré-visualização mostra o que é útil para cada tipo de destino: algumas linhas de uma equação, o parágrafo inicial de uma seção e a parte superior de uma tabela ou figura.

## Seguir um link

Clique em um link para ir até o destino. Escolha Go > Back (⌘[) para voltar.

Os links da web são abertos no navegador. Você pode escolher qual navegador com o ajuste [Open Links In](settings.md).

## Abrir o destino em uma nova janela

Para manter o destino na tela ao lado da sua página:

- **Clique com ⌘ pressionada** no link.
- Ou clique no link com o botão direito e escolha **Open in New Window**.

Você também pode clicar com o botão direito em um texto ou em um local da página para abrir esse local em uma nova janela. Consulte [Abas e janelas](tabs-and-windows.md#anchor-windows).

## Manter o destino

Clique em um link com o botão direito e escolha **Create Anchor** para salvar o destino como uma [âncora](anchors.md), ou **Create Anchor and Open in New Window** para fazer as duas coisas.
