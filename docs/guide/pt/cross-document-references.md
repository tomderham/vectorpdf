# Referências entre documentos

Normas citam outras normas e contratos mencionam seus anexos, geralmente em texto simples, e não com links. Se você abrir os documentos relacionados como abas em uma mesma janela, o VectorPDF poderá seguir essas referências.

## Seguir uma referência em texto simples

1. Abra os documentos relacionados como [abas na mesma janela](tabs-and-windows.md).
2. Clique com o botão direito em uma referência como “Section 8.8.3 of [HTTP]” ou “Clause 4.2 of the Master Agreement”, ou selecione a referência e clique nela com o botão direito.
3. Escolha uma destas opções:
   - **Go to** o título correspondente, para pré-visualizá-lo. Na pré-visualização, você pode ir até lá.
   - Mantenha ⌘ pressionada com o menu aberto para mudar o comando para **Open**, que vai direto para o local, sem pré-visualização.
   - **Find in Other Tabs**, para buscar no texto das suas outras abas.

O VectorPDF compara as referências com o sumário do outro documento ou, se ele não tiver sumário, com seus títulos. Se o mesmo título aparecer em várias abas, a pré-visualização listará cada uma delas.

## Links da web para um documento aberto

Alguns documentos têm links entre si na web. Por exemplo, as RFCs da IETF têm links para rfc-editor.org. Se o documento indicado por um link da web estiver aberto em outra aba, manter ⌘ pressionada sobre o link ou usar o clique forte [o pré-visualiza nessa aba](link-peek.md), em vez de abrir o navegador.

## Manter um conjunto de documentos reunido

Salve os documentos que você usa juntos como um [Grupo de Abas](favorites-and-tab-groups.md) para poder reabri-los de uma só vez.
