# Preencher formulários

O VectorPDF funciona com formulários PDF interativos (AcroForms). Os campos aparecem na página, prontos para uso.

- **Campos de texto:** clique e digite.
- **Caixas de seleção e botões de opção:** clique para escolher.
- **Menus pop-up e listas:** clique e escolha um item.
- **Campos de assinatura:** clique em **Sign** e crie ou escolha um [carimbo](stamps.md).

Pressione ⌘S para [salvar](save.md) o formulário preenchido.

Se um formulário tiver um botão de redefinição, ao clicar nele será solicitada uma confirmação e, em seguida, todos os campos serão limpos.

Para impedir que alguém altere as respostas, salve uma cópia com os campos de formulário nivelados. Consulte [Exportar para outros formatos](export.md#flattened-pdf).

> **Nota:** Os campos só ficam disponíveis na visualização Single Page, sem rotação. Consulte [Zoom, rotação e layout de página](zoom-and-layout.md).
