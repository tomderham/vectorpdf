# A janela do VectorPDF

Cada janela do VectorPDF tem uma barra de ferramentas, uma barra lateral e o próprio documento. As janelas podem conter vários documentos como [abas](tabs-and-windows.md).

## Barra de ferramentas

| Controle | O que faz |
| --- | --- |
| Título do documento | Mostra o nome do documento. Clique nele com o botão direito para ver Favorites e Tab Groups. |
| Zoom | Os botões − e + alteram o zoom em etapas. Clique na porcentagem para digitar um valor. |
| Rotate Left e Rotate Right | Giram a visualização. Isso não altera o PDF salvo. |
| Two-Page Mode | Mostra as páginas lado a lado, como um livro aberto. |
| Markup Toolbar | Mostra as [ferramentas de marcação](text-markup.md). |
| Measurement Toolbar | Mostra as [ferramentas de medição](measure.md). |
| Página | As setas avançam ou voltam uma página por vez. Clique no número da página para digitar a página desejada. |

Consulte [Zoom, rotação e layout de página](zoom-and-layout.md) para saber mais sobre esses controles.

## Barra lateral

As abas na parte superior da barra lateral alternam entre:

- **Outline & Thumbnails:** o [índice ou uma miniatura de cada página](outline-and-thumbnails.md).
- **Search:** os [resultados do documento atual](search.md).
- **Anchors:** [os locais que você salvou](anchors.md).
- **Layers:** [mostrar ou ocultar as camadas do documento](layers.md). Esta aba aparece somente quando o documento tem camadas.
- **Attachments:** [arquivos anexados ao PDF](attachments.md). Esta aba só aparece quando o documento tem anexos.
- **Comments:** [todas as anotações, com as respostas e o status](draw-and-notes.md#see-all-annotations).
- **Ask About This Document:** [o Agent](agent.md). Esta aba aparece no macOS 26 ou posterior, a menos que você tenha desativado [Use Agent](settings.md) em Settings.

Use o botão da barra lateral na barra de ferramentas para mostrá-la ou ocultá-la.

## Barras de ferramentas adicionais

Três barras de ferramentas aparecem abaixo da barra principal quando você precisa delas. Escolha-as no menu View:

- **Markup** (⇧⌘A) tem as [ferramentas de anotação](text-markup.md).
- **Measurement** (⇧⌘M) tem as [ferramentas de medição](measure.md).
- **Redact** (⌥⌘R) tem as [ferramentas de tarjamento](redact.md).

## Menus do botão direito

Muitos comandos também estão em menus que aparecem quando você clica com o botão direito, ou clica com a tecla Control pressionada, no documento, na barra lateral ou na barra de ferramentas. Consulte [Menus do botão direito](right-click-menus.md).

## Indicador de página

Quando você muda de página, um pequeno indicador de página aparece sobre o documento por um momento, com setas para ir à página anterior e à seguinte. Enquanto a barra de ferramentas Measurement estiver visível, ele também mostra a escala de desenho da página.

## Tela Start

Uma janela ou aba vazia mostra a tela Start, com a área de soltar e, em seguida, Tab Groups, Favorites e Recent Documents. Clique em uma linha para abrir o item. Mantenha o cursor sobre uma linha e clique no botão •••, ou clique na linha com o botão direito, para abri-la em uma nova aba ou janela, mostrá-la no Finder ou removê-la.

A tela Start lista até três Grupos de Abas e cinco favoritos. O menu Favorites lista todos eles.
