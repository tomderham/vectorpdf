# Fazer perguntas sobre um documento

O Agent responde a perguntas sobre o documento aberto e mostra os trechos em que a resposta se baseia. Ele requer o macOS 26 ou posterior.

## Fazer uma pergunta

1. Clique na aba Ask About This Document na barra lateral. Na primeira vez, o VectorPDF indexa o documento no seu Mac e mostra o progresso.
2. Digite uma pergunta e pressione Return ou clique em Ask. Pressione ⇧Return para inserir uma nova linha.

Em um documento com [camadas](layers.md), só as camadas mostradas são indexadas. Se você mostrar ou ocultar camadas, o documento é indexado de novo.

Abaixo da resposta, clique em **Sources** para ver os trechos usados, com suas páginas. Os trechos citados na resposta aparecem marcados como **Cited**. Clique em um trecho para ir até ele.

Você pode fazer outras perguntas na sequência. Para recomeçar, clique em **New Conversation**.

> **Nota:** O Agent pode cometer erros. Confira as fontes de tudo o que for importante.

## Se não for possível gerar uma resposta

Se a geração de respostas não estiver disponível no seu Mac, o Agent mostra os trechos mais relevantes. Consulte [Escolher como o Agent responde](agent-engines.md).

## Desativar o Agent

Desative **Use Agent** em [Ajustes](settings.md). A aba desaparece da barra lateral.
