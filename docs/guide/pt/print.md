# Imprimir

Escolha File > Print ou pressione ⌘P.

Na caixa de diálogo de impressão, escolha PDF Options para ver:

- **Auto Rotate:** gira as páginas para se ajustarem ao papel.
- **Scale to Fit:** ajusta cada página ao papel.
- **Scale:** imprime na porcentagem que você digitar.

O VectorPDF imprime com o mesmo mecanismo que usa na tela, portanto o resultado corresponde ao que você vê.
