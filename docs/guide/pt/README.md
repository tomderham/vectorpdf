# Manual do Usuário do VectorPDF

para macOS

O VectorPDF é um leitor de PDF rápido para artigos técnicos, especificações, contratos e desenhos. Mantenha a tecla Command pressionada sobre uma referência para ver o que ela indica, sem perder sua página. Você também pode fazer marcações, medir, tarjar e reorganizar PDFs, tudo no seu Mac.

> **Nota:** Este manual foi traduzido automaticamente do inglês. A interface do VectorPDF está disponível somente em inglês, por isso os nomes de menus e botões aparecem em inglês, exatamente como na tela.
