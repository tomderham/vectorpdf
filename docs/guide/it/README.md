# Manuale utente di VectorPDF

per macOS

VectorPDF è un lettore PDF veloce per articoli tecnici, specifiche, contratti e disegni. Tieni premuto il tasto Comando su un riferimento per vedere a cosa rimanda, senza perdere la pagina. Puoi anche aggiungere annotazioni, misurare, oscurare contenuti e riorganizzare i PDF, il tutto sul tuo Mac.

> **Nota:** questo manuale è stato tradotto automaticamente dall'inglese. L'interfaccia di VectorPDF è disponibile solo in inglese, quindi i nomi dei menu e dei pulsanti sono riportati in inglese, così come appaiono sullo schermo.
