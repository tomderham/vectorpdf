# Dividere un PDF

1. Scegli File > Split PDF.
2. In Split Method, scegli un'opzione:
   - **Every N Pages:** un nuovo file ogni determinato numero di pagine.
   - **Single Pages:** un file per ogni pagina.
   - **Page Ranges:** inserisci numeri di pagina o intervalli separati da virgole, ad esempio `1-5, 6-12, 13-20`.
3. In Save Location, fai clic su Choose per selezionare una cartella.
4. In File Naming, inserisci un prefisso e scegli uno stile: Part Number o Page Range. Output Preview mostra i file che verranno creati.
5. Fai clic su Split PDF.

Il documento originale non cambia. Al termine della divisione, fai clic su Reveal in Finder per vedere i file.
