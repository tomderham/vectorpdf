# Stampare

Scegli File > Print oppure premi ⌘P.

Nella finestra di stampa, scegli PDF Options per vedere:

- **Auto Rotate:** ruota le pagine per adattarle alla carta.
- **Scale to Fit:** adatta ogni pagina alla carta.
- **Scale:** stampa alla percentuale inserita.

VectorPDF stampa con lo stesso motore che usa sullo schermo, quindi il risultato corrisponde a ciò che vedi.
