# Abbreviazioni da tastiera

Molti di questi comandi sono disponibili anche in un menu di scelta rapida, come indicato di seguito. Consulta [Menu di scelta rapida](right-click-menus.md).

## Documenti

| Azione | Abbreviazione |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Insert Pages from PDF | ⌥⌘I, oppure clic con il tasto destro su una miniatura |
| Duplicate Pages | ⇧⌘D, oppure clic con il tasto destro su una miniatura |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Add to or Remove from Favorites | ⌘D, oppure clic con il tasto destro sul titolo del documento |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## Navigazione

| Azione | Abbreviazione |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow o Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow o Right Arrow |
| First Page | ⌘Up Arrow o ⌘Home |
| Last Page | ⌘Down Arrow o ⌘End |
| Avanti o indietro nella pagina | Space o ⇧Space |
| Next Tab | ⇧⌘] o ⌃Tab |
| Previous Tab | ⇧⌘[ o ⇧⌃Tab |

| --- | --- | --- |

| Eliminare l'annotazione selezionata | Delete | L'annotazione |

| Terminare un perimetro o un'area | Return | |
| Invertire Ortho Lock (0°, 45° o 90°) per una linea | Tieni premuto ⇧ | |
