# Zoom, rotazione e layout di pagina

## Zoom

| Per | Esegui questa operazione |
| --- | --- |
| Ingrandire o ridurre | Premi ⌘+ o ⌘−, fai clic su + o − nella barra degli strumenti oppure pizzica sul trackpad |
| Impostare uno zoom esatto | Fai clic sulla percentuale nella barra degli strumenti, digita un valore da 10 a 1000, quindi premi Return |
| Vedere la pagina alle dimensioni reali | Scegli View > Actual Size (100%) oppure premi ⌘1 |
| Adattare la larghezza della pagina | Scegli View > Zoom to Fit Width oppure premi ⌘9 |
| Adattare l'intera pagina | Scegli View > Zoom to Fit Window oppure premi ⌥⌘0 |

I comandi Zoom In e Zoom Out funzionano tra il 25% e il 400%. Digita una percentuale per superare questi limiti.

VectorPDF mantiene le pagine nitide a qualsiasi livello di zoom, perché le ridisegna anziché ingrandire un'immagine.

## Cosa significa 100%

Scegli View > Define 100% Scale As, quindi scegli un'opzione:

- **Size on Screen Equals Size on Printout:** una pagina al 100% appare all'incirca alle sue dimensioni di stampa.
- **1 Point Equals 1 Screen Point:** un punto PDF occupa un punto sul display.

## Ruotare la vista {#rotate-the-view}

Fai clic su Rotate Left o Rotate Right nella barra degli strumenti. Questa operazione cambia solo il modo in cui vedi il documento sullo schermo e non viene salvata. Per ruotare le pagine nel PDF stesso, consulta [Riordinare le pagine](pages.md).

## Two-Page Mode

Fai clic su Two-Page Mode nella barra degli strumenti, oppure scegli View > Two Pages (⌥⌘2). Le pagine appaiono a coppie, con la copertina da sola, come in un libro aperto, e la doppia pagina viene adattata alla finestra. Per tornare indietro, fai di nuovo clic sul pulsante oppure scegli View > Single Page.

> **Nota:** mentre la vista è ruotata o in Two-Page Mode, non puoi selezionare il testo, seguire i link, usare gli strumenti di annotazione e misurazione né compilare moduli. Torna a Single Page senza rotazione per usarli.
