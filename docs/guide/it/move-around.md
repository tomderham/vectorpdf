# Spostarsi in un documento

## Scorrere e sfogliare le pagine

Scorri con il trackpad o il mouse. VectorPDF impagina solo le pagine vicine al punto in cui stai leggendo, così anche i documenti molto lunghi restano veloci.

Dalla tastiera:

| Tasti | Azione |
| --- | --- |
| Left Arrow, Right Arrow | Pagina precedente o successiva |
| Up Arrow, Down Arrow | Scorre all'interno di una pagina più alta della finestra, quindi passa alla pagina successiva. Se la pagina è contenuta nella finestra, si sposta di una pagina alla volta. |
| Page Up, Page Down | Scorre di un passo più ampio, quindi passa alla pagina successiva |
| Space, ⇧Space | Avanti o indietro, come Page Down e Page Up |
| ⌥Up Arrow, ⌥Down Arrow, ⌥Left Arrow, ⌥Right Arrow | Pagina precedente o successiva |
| ⌘Up Arrow, ⌘Down Arrow | Prima o ultima pagina |

In Two-Page Mode, questi tasti sfogliano un'intera doppia pagina.

## Andare a una pagina

Fai clic sul numero di pagina nella barra degli strumenti, digita la pagina desiderata, quindi premi Return. Premi Escape per annullare.

## Tornare al punto precedente

Dopo aver seguito un link o aver raggiunto un risultato, scegli Go > Back (⌘[) per tornare indietro. Go > Forward (⌘]) ti porta nella direzione opposta.
