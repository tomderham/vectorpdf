# Menu di scelta rapida

Fai clic con il tasto destro, o fai clic tenendo premuto Ctrl, per vedere i comandi per ciò che si trova sotto il puntatore. Il menu che ottieni dipende da dove fai clic. In qualsiasi punto di una pagina, il menu termina con Inspect, che apre l’[Inspector](rulers-and-inspector.md#the-inspector) su ciò che è disegnato lì.

## Nel documento

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Testo selezionato | Copy Text, Look Up, Translate Selection, Start Speaking o Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un'area selezionata | Highlight Area, Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un link | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un'evidenziazione, una sottolineatura o una barratura | Comments… e il comando Remove corrispondente |
| Una casella di testo | Comments…, Edit Text Box e il comando di eliminazione |
| Un richiamo | Comments…, Edit Callout Note, Line Ending e il comando di eliminazione |
| Una nota, o il contorno di un rettangolo, di un ovale o di una nuvola di revisione | Comments… e il comando di eliminazione |
| Una linea o una freccia | Comments…, Line Ending e il comando di eliminazione |
| Un disegno, un timbro o una misurazione | Comments… e il comando di eliminazione |
| Una di più annotazioni selezionate | Align (bordi e centri; Distribute con tre o più), Delete con quante sono |
| Una forma, una nuvola, una linea, una nota, un timbro o una casella di testo salvati in precedenza nel documento, o creati in un'altra app | Comments…, Line Ending per una linea, e il comando di eliminazione |
| Un'evidenziazione, un disegno o una misura salvati in precedenza nel documento, o creati in un'altra app | Comments… e i comandi validi in qualsiasi altro punto della pagina |
| Qualsiasi altro punto della pagina | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

Se fai clic con il tasto destro su un riferimento in testo semplice e in altri pannelli sono aperti documenti correlati, il menu include anche i comandi per [raggiungerlo o trovarlo](cross-document-references.md).

In un PDF creato da LaTeX con SyncTeX attivo, ogni menu del documento inizia con **Show in Editor**, che apre la [riga del sorgente](latex.md) del punto in cui hai fatto clic.

In un documento con [livelli](layers.md), il menu di un'annotazione contiene anche **Layer**, per spostarla su un altro livello o su nessuno.

## Nella barra laterale

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Una voce della struttura | Create Anchor, Create Anchor and Open in New Window, Open in New Window, Add Entry After, Add Entry Inside, Rename, Go Here Instead, Move Up, Move Down, Indent, Outdent, Delete Entry, Build Outline from Headings. Consulta [Modificare la struttura](outline-and-thumbnails.md#edit-the-outline). |
| Una miniatura | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Export Page as Image, Move Page Up, Move Page Down, Delete Page. Con più pagine selezionate, i comandi ne indicano il numero, ad esempio Delete 3 Pages. Consulta [Riordinare le pagine](pages.md). |
| Un risultato di ricerca | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un ancoraggio | Open in New Window o Close Window, Copy Text, Copy Screenshot, Delete Anchor |
| Un'annotazione nel pannello Comments | Show on Page, Comments…, Delete |
| Un livello nel pannello Document | Put New Annotations Here oppure Stop Putting New Annotations Here. Consulta [Mostrare e nascondere i livelli](layers.md). |
| Un allegato nel pannello Document | Quick Look, Open, Save As… e, per un file allegato a una pagina, Show on Page. Consulta [File allegati a un PDF](attachments.md). |
| Un campo modulo nel pannello Document | Show on Page, Copy Name, Copy Value. Consulta [Campi modulo, firme, link e destinazioni](document-tab.md). |
| Una firma nel pannello Document | Show on Page, Show Certificate. Consulta [Firmare e verificare le firme digitali](digital-signatures.md). |
| Un link nel pannello Document | Show on Page, Go to Destination oppure Open Link e, per un link web, Copy Address |
| Una destinazione nel pannello Document | Copy Name |

## Nella finestra

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Il titolo del documento o una parte vuota della barra degli strumenti | Aggiunta o rimozione dai preferiti, Save All Open Tabs as a Group, Update Group “nome” with Open Tabs, Compare With (vedi [Confrontare due documenti](compare-documents.md)), e i tuoi Tab Groups e Favorites |
| Una riga nella schermata Start | Open, Open in New Tab, Open in New Window, Show in Finder, e Remove o Delete |

Alcuni comandi compaiono solo quando sono applicabili. Ad esempio, Save All Open Tabs as a Group richiede più di un pannello, e i comandi degli ancoraggi non sono disponibili in una finestra aperta da un ancoraggio.
