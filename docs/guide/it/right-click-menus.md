# Menu di scelta rapida

Fai clic con il tasto destro, oppure fai clic tenendo premuto il tasto Control, per vedere i comandi relativi all'elemento sotto il puntatore. Il menu visualizzato dipende dal punto in cui fai clic.

## Nel documento

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Testo selezionato | Copy Text, Look Up, Translate Selection, Start Speaking o Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un'area selezionata | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un link | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un'evidenziazione, una sottolineatura o una barratura | Comments… e il comando Remove corrispondente |
| Una casella di testo | Comments…, Edit Text Box e il comando di eliminazione |
| Un richiamo | Comments…, Edit Callout Note, Line Ending e il comando di eliminazione |
| Una nota, o il contorno di un rettangolo, di un ovale o di una nuvola di revisione | Comments… e il comando di eliminazione |
| Una linea o una freccia | Comments…, Line Ending e il comando di eliminazione |
| Un disegno, un timbro o una misurazione | Comments… e il comando di eliminazione |
| Una forma, una nuvola, una linea, una nota, un timbro o una casella di testo salvati in precedenza nel documento, o creati in un'altra app | Comments…, Line Ending per una linea, e il comando di eliminazione |
| Un'evidenziazione, un disegno o una misura salvati in precedenza nel documento, o creati in un'altra app | Comments… e i comandi validi in qualsiasi altro punto della pagina |
| Qualsiasi altro punto della pagina | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

Se fai clic con il tasto destro su un riferimento in testo semplice e in altri pannelli sono aperti documenti correlati, il menu include anche i comandi per [raggiungerlo o trovarlo](cross-document-references.md).

In un documento con [livelli](layers.md), il menu di un'annotazione contiene anche **Layer**, per spostarla su un altro livello o su nessuno.

## Nella barra laterale

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Una voce della struttura | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Una miniatura | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up, Move Page Down, Delete Page. Con più pagine selezionate, i comandi ne indicano il numero, ad esempio Delete 3 Pages. Consulta [Riordinare le pagine](pages.md). |
| Un risultato di ricerca | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un ancoraggio | Open in New Window o Close Window, Copy Text, Copy Screenshot, Delete Anchor |
| Un'annotazione nel pannello Comments | Show on Page, Comments…, Delete |
| Un livello nel pannello Layers | Put New Annotations Here oppure Stop Putting New Annotations Here. Consulta [Mostrare e nascondere i livelli](layers.md). |

## Nella finestra

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Il titolo del documento o una parte vuota della barra degli strumenti | Aggiunta o rimozione dai preferiti, Save All Open Tabs as a Group, Update Group “nome” with Open Tabs, e i tuoi Tab Groups e Favorites |
| Una riga nella schermata Start | Open, Open in New Tab, Open in New Window, Show in Finder, e Remove o Delete |

Alcuni comandi compaiono solo quando sono applicabili. Ad esempio, Save All Open Tabs as a Group richiede più di un pannello, e i comandi degli ancoraggi non sono disponibili in una finestra aperta da un ancoraggio.
