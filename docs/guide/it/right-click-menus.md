# Menu di scelta rapida

Fai clic con il tasto destro, oppure fai clic tenendo premuto il tasto Control, per vedere i comandi relativi all'elemento sotto il puntatore. Il menu visualizzato dipende dal punto in cui fai clic.

## Nel documento

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Testo selezionato | Copy Text, Look Up, Translate Selection, Start Speaking o Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un'area selezionata | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un link | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un'evidenziazione, una sottolineatura o una barratura | Il comando Remove corrispondente |
| Una casella di testo o un richiamo | Edit Text Box o Edit Callout Note, e il comando di eliminazione |
| Un disegno, un timbro o una misurazione | Il comando di eliminazione |
| Qualsiasi altro punto della pagina | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

Se fai clic con il tasto destro su un riferimento in testo semplice e in altri pannelli sono aperti documenti correlati, il menu include anche i comandi per [raggiungerlo o trovarlo](cross-document-references.md).

## Nella barra laterale

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Una voce della struttura | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Una miniatura | Rotate, Duplicate, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up o Move Page Down, Delete. Consulta [Riordinare le pagine](pages.md). |
| Un risultato di ricerca | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un ancoraggio | Open in New Window o Close Window, Copy Text, Copy Screenshot, Delete Anchor |

## Nella finestra

| Clic con il tasto destro su | Comandi |
| --- | --- |
| Il titolo del documento o una parte vuota della barra degli strumenti | Aggiunta o rimozione dai preferiti, Save All Open Tabs as a Group, Update Group with Open Tabs, e i tuoi Tab Groups e Favorites |
| Una riga nella schermata Start | Open, Open in New Tab, Open in New Window, Show in Finder, e Remove o Delete |

Alcuni comandi compaiono solo quando sono applicabili. Ad esempio, Save All Open Tabs as a Group richiede più di un pannello, e i comandi degli ancoraggi non sono disponibili in una finestra aperta da un ancoraggio.
