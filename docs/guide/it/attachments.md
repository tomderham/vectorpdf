# File allegati a un PDF

Un PDF può contenere altri file: un foglio di calcolo insieme a un report, un modello CAD insieme a una serie di disegni o i dati di una fattura elettronica. Quando un documento contiene allegati, nella parte superiore della barra laterale appare il pannello Attachments (una graffetta). Un documento di una o due pagine con allegati si apre sul pannello Attachments.

Ogni allegato mostra il suo nome e, quando il PDF li include, la descrizione, le dimensioni e la pagina a cui è allegato. Tieni il puntatore su un allegato per vedere che tipo di file è e la sua data.

| Per | Procedi così |
| --- | --- |
| Visualizzare l'anteprima di un allegato | Fai doppio clic su di esso, oppure selezionalo e premi la barra spaziatrice |
| Visualizzare l'anteprima del successivo o del precedente | Con Quick Look aperto, premi il tasto Freccia giù o Freccia su |
| Aprirlo nella sua app | Fai clic con il tasto destro su di esso e scegli Open |
| Salvarne una copia | Fai clic con il tasto destro su di esso e scegli Save As…, oppure trascinalo nel Finder |
| Salvarli tutti | Fai clic su Save All… nella parte superiore del pannello, quindi scegli una cartella |
| Andare alla sua pagina | Fai clic con il tasto destro su di esso e scegli Show on Page |

> **Attenzione:** un allegato può essere qualsiasi tipo di file, comprese un'app o uno script. Apri solo file di cui ti fidi. VectorPDF contrassegna come scaricati i file che estrae da un PDF, così macOS controlla app e script prima che vengano eseguiti, come fa con i file provenienti dal web.

## Fatture elettroniche

Le fatture ZUGFeRD e Factur-X contengono i loro dati in un file XML, di solito chiamato `factur-x.xml` o `zugferd-invoice.xml`. Viene elencato insieme agli altri allegati, così puoi salvarlo per il tuo software di contabilità. VectorPDF non mostra direttamente i dettagli della fattura.
