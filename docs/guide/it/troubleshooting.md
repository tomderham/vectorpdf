# Risoluzione dei problemi

## Non riesco a selezionare il testo, seguire i link o usare gli strumenti di annotazione

Verifica che non sia attivo uno strumento Markup o Measurement. Premi Escape, o fai di nuovo clic sullo strumento selezionato, per tornare alla selezione del testo.

## Una ricerca non trova nulla

- Le pagine potrebbero essere scansionate. Consulta [Cercare e selezionare il testo nelle pagine scansionate](scanned-pages.md).
- Verifica che Match Case e Whole Word siano disattivate nelle [opzioni di ricerca](search.md#search-options) e che Smart Search sia attiva.
- Se degli indicatori interrompono il testo, aggiungi uno [schema ignorato](search.md#ignore-clutter-in-the-text).

## Tenendo premuto ⌘ non viene mostrata un'anteprima

Link Peek funziona con i link del documento e con i link web a documenti aperti in un altro pannello. I riferimenti in testo semplice non sono link, quindi fai clic su di essi con il tasto destro. Consulta [Riferimenti tra documenti](cross-document-references.md).

Inoltre, la finestra di VectorPDF deve essere la finestra attiva.

## Un riferimento a un altro documento non viene trovato

Apri l'altro documento come pannello nella stessa finestra. La ricerca non viene eseguita nelle finestre separate.

## Un documento risulta danneggiato

Se VectorPDF non trova pagine in un file, segnala che il file non può essere aperto. Il file potrebbe essere danneggiato o incompleto, oppure usare funzioni che VectorPDF non è in grado di leggere. Prova a scaricarlo di nuovo o ad aprirlo in un’altra app per PDF.

## Un documento nel cloud non si apre

Controlla la connessione e verifica che il file venga scaricato nel Finder, quindi riprova.

## L'Agent non è disponibile o mostra solo i passaggi

L'Agent richiede macOS 26 o versioni successive e, per scrivere le risposte sul dispositivo, Apple Intelligence deve essere attivata e pronta. Se l'indicizzazione non riesce, fai clic su Retry nel pannello Ask About This Document. Consulta [Scegliere come risponde l'Agent](agent-engines.md).

## Un modello online non risponde

Controlla la chiave API e il modello in [Settings](settings.md), e verifica che il tuo account del servizio abbia credito disponibile. Se il servizio non funziona, VectorPDF risponde sul dispositivo.

## Le mie modifiche sono scomparse

Le modifiche devono essere [salvate](save.md). Se un'altra app ha modificato il file mentre avevi modifiche non salvate, scegliendo Reload from Disk le perdi.

## L'aiuto non mostra questo manuale

Tips può mostrare questo manuale solo quando VectorPDF si trova nella cartella Applicazioni. Spostalo lì, quindi scegli di nuovo Help > VectorPDF Help.

## Ottenere ulteriore assistenza

Segnala un problema o fai una domanda su [GitHub](https://github.com/tomderham/vectorpdf/issues). Un PDF di esempio è utile, se puoi condividerlo.
