# Proprietà del documento

Scegli File > Document Properties oppure premi ⌘I. Scegli un pannello in alto:

- **General:** il titolo, l'autore, l'oggetto, le parole chiave, le date, l'applicazione con cui è stato creato, la posizione del file e il suo spazio di archiviazione.
- **Security:** la codifica del documento e se consente la stampa, la copia, le modifiche, i commenti, la compilazione di moduli, l'estrazione per l'accessibilità e l'assemblaggio delle pagine.
- **Page Geometry:** MediaBox, CropBox, BleedBox, TrimBox e ArtBox di qualsiasi pagina, in punti, pollici o millimetri.
- **Fonts:** i font del documento, il loro tipo e la loro codifica e se ciascuno è incorporato. Usa il campo di filtro per trovarne uno.
