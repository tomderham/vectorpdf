# Password e codifica

## Aprire un PDF protetto

VectorPDF chiede la password quando apri un PDF protetto. Se fai clic su Cancel, il documento rimane chiuso.

## Codificare una copia

1. Scegli File > Save Encrypted with Password (⌥⌘S).
2. Scegli un nome e una posizione.
3. Inserisci la password due volte, quindi fai clic su Encrypt & Save.

La copia viene codificata con AES-256 e per aprirla è necessaria la password.

> **Attenzione:** conserva la password in un luogo sicuro. Se la perdi, non c'è modo di recuperare un PDF codificato.

## Vedere le autorizzazioni di un documento

Per vedere cosa consente l'autore di un documento, ad esempio la stampa o la copia, scegli File > Document Properties (⌘I), quindi fai clic su Security. Consulta [Proprietà del documento](document-properties.md).
