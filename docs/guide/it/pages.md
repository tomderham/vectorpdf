# Riordinare le pagine

Le modifiche alle pagine si effettuano nella vista [Thumbnails](outline-and-thumbnails.md) della barra laterale. Diventano parte del file quando [salvi](save.md).

## Selezionare le pagine

Fai clic su una miniatura. Tieni premuto ⌘ per aggiungere le pagine una alla volta, oppure ⇧ per selezionare un intervallo.

## Spostare le pagine

Trascina le miniature selezionate in una nuova posizione. Una linea indica dove verranno inserite. Puoi anche fare clic con il tasto destro su una pagina, quindi scegliere Move Page Up o Move Page Down.

## Altri comandi per le pagine

Fai clic con il tasto destro su una miniatura o su una selezione di miniature, quindi scegli:

- **Rotate Clockwise, Rotate Counterclockwise o Rotate 180°:** ruota le pagine nel PDF stesso, a differenza dei [pulsanti di rotazione nella barra degli strumenti](zoom-and-layout.md#rotate-the-view).
- **Duplicate Page:** aggiunge delle copie subito dopo le pagine selezionate. Puoi anche scegliere File > Duplicate Pages (⇧⌘D), che copia le miniature selezionate se includono la pagina in cui ti trovi, altrimenti copia quella pagina.
- **Insert Blank Page.**
- **Insert Pages from PDF:** aggiunge pagine da un altro PDF. Puoi anche scegliere File > Insert Pages from PDF (⌥⌘I).
- **Save selected page as a PDF:** estrae le pagine in un nuovo file.
- **Delete Page.**

## Se hai creato degli ancoraggi

Aggiungere, eliminare o spostare pagine può far puntare un [ancoraggio](anchors.md) alla posizione sbagliata. VectorPDF ti avvisa e ti propone di apportare la modifica in una copia.
