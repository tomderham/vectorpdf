# Aprire documenti

## Aprire un PDF

- **In una nuova finestra:** scegli File > Open PDF oppure premi ⌘O.
- **In un nuovo pannello:** scegli File > Open PDF in New Tab oppure premi ⌥⌘O.
- **Dal Finder:** fai clic con il tasto destro su un PDF, quindi scegli Open With > VectorPDF. Per aprire tutti i PDF in VectorPDF, seleziona un PDF, scegli File > Get Info nel Finder, modifica “Open with”, quindi fai clic su Change All.
- **Trascinando:** trascina un PDF sulla schermata Start per aprirlo lì, oppure su un documento aperto per aprirlo in un nuovo pannello.
- **Da un elenco:** scegli File > Open Recent oppure usa il menu [Favorites](favorites-and-tab-groups.md). Nella schermata Start, fai clic con il tasto destro su un documento per aprirlo in un nuovo pannello o in una nuova finestra.

## Ebook, fumetti e documenti XPS

VectorPDF apre anche ebook EPUB e FictionBook (FB2), archivi di fumetti CBZ e documenti XPS, negli stessi modi di un PDF. Un ebook viene impaginato per la lettura.

Puoi leggere questi documenti, seguirne l'indice, cercarvi, selezionarne e copiarne il testo e aggiungere [ancore](anchors.md). Si aprono in sola lettura: VectorPDF non può salvarli, quindi annotazione, misurazione, oscuramento e modifica delle pagine non sono disponibili e Save è disattivato.

## PDF protetti da password

VectorPDF chiede la password quando apri un PDF protetto. Consulta [Password e codifica](passwords.md).

## PDF nell'archiviazione cloud

VectorPDF riconosce i file in iCloud Drive, Google Drive, Dropbox, OneDrive e Box. Se un file non è ancora sul Mac, VectorPDF lo scarica prima di aprirlo e ti mostra l'avanzamento. Se il download non viene completato, viene visualizzato un messaggio e puoi riprovare quando sei connesso.

## Quando un file cambia

VectorPDF tiene sotto controllo ogni file aperto. Se un'altra app modifica il file, il documento si ricarica automaticamente. Questa funzione è utile se generi un PDF da LaTeX o da un altro strumento e vuoi tenerlo aperto. Il ricaricamento mantiene la posizione, lo zoom, la rotazione e il layout delle pagine, e attende che un file ancora in scrittura sia completo. Per LaTeX, vedi anche [Passare dal sorgente LaTeX al PDF](latex.md).

Se ci sono modifiche non salvate, VectorPDF ti chiede se vuoi scegliere **Reload from Disk**, che comporta la perdita delle modifiche, oppure **Keep My Changes**.

Se sposti o rinomini un file nel Finder, il documento aperto lo segue.

## Chiudere un documento

Chiudi un pannello o una finestra come di consueto. Se ci sono modifiche non salvate, VectorPDF chiede se vuoi salvarle. VectorPDF ricorda [il punto in cui eri](reading-positions.md) per la volta successiva.
