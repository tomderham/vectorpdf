# Right-click menus

Right-click, or Control-click, to see commands for what's under the pointer. The menu you get depends on where you click.

## In the document

| Right-click | Commands |
| --- | --- |
| Selected text | Copy Text, Look Up, Translate Selection, Start Speaking or Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| A selected area | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| A link | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| A highlight, underline or strikethrough | Comments…, and the matching Remove command |
| A text box | Comments…, Edit Text Box, and the delete command |
| A callout | Comments…, Edit Callout Note, Line Ending, and the delete command |
| A note, or the outline of a rectangle, oval or revision cloud | Comments…, and the delete command |
| A line or arrow | Comments…, Line Ending, and the delete command |
| A drawing, stamp or measurement | Comments…, and the delete command |
| A shape, cloud, line, note, stamp or text box saved in the document earlier, or made in another app | Comments…, Line Ending for a line, and the delete command |
| A highlight, drawing or measurement saved in the document earlier, or made in another app | Comments…, and the commands for anywhere else on the page |
| Anywhere else on the page | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

If you right-click a plain-text reference and related documents are open in other tabs, the menu also has commands to [go to it or find it](cross-document-references.md).

In a document with [layers](layers.md), the menu for an annotation also has **Layer**, to move it to another layer or to none.

## In the sidebar

| Right-click | Commands |
| --- | --- |
| An outline entry | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| A thumbnail | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up, Move Page Down, Delete Page. With several pages selected, the commands name how many, such as Delete 3 Pages. See [Rearrange pages](pages.md). |
| A search result | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| An anchor | Open in New Window or Close Window, Copy Text, Copy Screenshot, Delete Anchor |
| An annotation in the Comments tab | Show on Page, Comments…, Delete |
| A layer in the Layers tab | Put New Annotations Here, or Stop Putting New Annotations Here. See [Show and hide layers](layers.md). |
| An attachment in the Attachments tab | Quick Look, Open, Save As…, and Show on Page for a file attached to a page. See [Files attached to a PDF](attachments.md). |

## In the window

| Right-click | Commands |
| --- | --- |
| The document's title, or an empty part of the toolbar | Add to or remove from Favorites, Save All Open Tabs as a Group, Update Group “name” with Open Tabs, Compare With (see [Compare two documents](compare-documents.md)), and your Tab Groups and Favorites |
| A row on the Start screen | Open, Open in New Tab, Open in New Window, Show in Finder, and Remove or Delete |

Some commands appear only when they apply. For example, Save All Open Tabs as a Group needs more than one tab, and anchor commands aren't available in a window opened from an anchor.
