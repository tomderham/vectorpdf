# Split a PDF

1. Choose File > Split PDF.
2. Under Split Method, choose one:
   - **Every N Pages:** a new file every so many pages.
   - **Single Pages:** one file for each page.
   - **Page Ranges:** enter page numbers or ranges separated by commas, such as `1-5, 6-12, 13-20`.
3. Under Save Location, click Choose to pick a folder.
4. Under File Naming, enter a prefix and choose a style: Part Number or Page Range. Output Preview shows the files that will be created.
5. Click Split PDF.

Your original document doesn't change. When the split finishes, click Reveal in Finder to see the files.
