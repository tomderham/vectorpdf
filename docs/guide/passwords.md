# Passwords and encryption

## Open a protected PDF

VectorPDF asks for the password when you open a protected PDF. If you click Cancel, the document stays closed.

## Encrypt a copy

1. Choose File > Save Encrypted with Password (⌥⌘S).
2. Choose a name and location.
3. Enter the password twice, then click Encrypt & Save.

The copy is encrypted with AES-256, and needs the password to open.

> **Warning:** Keep the password safe. There's no way to recover an encrypted PDF if you lose it.

## See a document's permissions

To see what a document's author allows, such as printing or copying, choose File > Document Properties (⌘I), then click Security. See [Document properties](document-properties.md).
