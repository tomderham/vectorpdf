# Zeichnungsmaßstab festlegen

Um aus einer Zeichnung reale Maße zu erhalten, muss VectorPDF ihren Maßstab kennen. Drücke ⇧⌘M, um die Symbolleiste „Measurement“ einzublenden, und klicke dann auf die Maßstabstaste, um „Drawing Scale Calibration“ zu öffnen.

## Einen Standardmaßstab verwenden

1. Wähle unter „Standard Drawing Scales“ den Zeichnungstyp aus:
   - **Metric (ISO):** von 1:1 bis 1:1000.
   - **Architectural (US):** zum Beispiel 1/4" = 1'-0".
   - **Civil Engineering (US).**
2. Wähle den Maßstab aus.
3. Wähle unter „Area Takeoff“ die Einheit für Flächen aus.
4. Klicke auf „Apply Scale“.

Der Maßstab gilt für alle Seiten und wird beim [Sichern](save.md) im PDF gespeichert.

## Anhand einer bekannten Länge kalibrieren

Wenn die Zeichnung ein Maß enthält, auf das du dich verlassen kannst, oder eine Maßstabsleiste:

1. Klicke auf **Calibrate by Measuring Known Line**.
2. Klicke auf die beiden Enden der Linie in der Zeichnung.
3. Gib die reale Länge der Linie ein und wähle ihre Einheit aus: Fuß und Zoll, Dezimalfuß, Zoll, Millimeter, Zentimeter oder Meter.
4. Klicke auf „Apply Scale“.

Verwende die längste bekannte Linie, die du finden kannst, denn kleine Ungenauigkeiten beim Klicken fallen über eine lange Strecke weniger ins Gewicht.
