# Fragen zu einem Dokument stellen

Der Agent beantwortet Fragen zum geöffneten Dokument und zeigt dir die Textstellen, auf denen seine Antwort beruht. Dafür ist macOS 26 oder neuer erforderlich.

## Eine Frage stellen

1. Klicke in der Seitenleiste auf den Tab „Ask About This Document“. Beim ersten Mal indexiert VectorPDF das Dokument auf deinem Mac und zeigt den Fortschritt an.
2. Gib eine Frage ein und drücke dann die Return-Taste oder klicke auf „Ask“. Drücke ⇧Return für eine neue Zeile.

Klicke unter der Antwort auf **Sources**, um die verwendeten Textstellen mit ihren Seiten zu sehen. Textstellen, die in der Antwort zitiert werden, sind mit **Cited** gekennzeichnet. Klicke auf eine Textstelle, um zu ihr zu springen.

Du kannst Folgefragen stellen. Um neu zu beginnen, klicke auf **New Conversation**.

> **Hinweis:** Der Agent kann Fehler machen. Prüfe bei allem Wichtigen die Quellen.

## Wenn keine Antwort erstellt werden kann

Wenn die Antworterstellung auf deinem Mac nicht verfügbar ist, zeigt der Agent stattdessen die am besten passenden Textstellen an. Weitere Informationen findest du unter [Festlegen, wie der Agent antwortet](agent-engines.md).

## Den Agenten deaktivieren

Deaktiviere **Use Agent** in [Settings](settings.md). Der Tab wird dann nicht mehr in der Seitenleiste angezeigt.
