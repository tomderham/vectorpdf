# Kontextmenüs

Klicke mit der rechten Maustaste oder bei gedrückter Taste „ctrl“, um Befehle für das Objekt unter dem Zeiger zu sehen. Welches Menü angezeigt wird, hängt davon ab, wohin du klickst.

## Im Dokument

| Rechtsklick auf | Befehle |
| --- | --- |
| Ausgewählter Text | Copy Text, Look Up, Translate Selection, Start Speaking oder Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Ein ausgewählter Bereich | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Ein Link | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Eine Hervorhebung, Unterstreichung oder Durchstreichung | Der passende Befehl „Remove“ |
| Ein Textfeld oder eine Legende | Edit Text Box oder Edit Callout Note und der Löschbefehl |
| Eine Zeichnung, ein Stempel oder eine Messung | Der Löschbefehl |
| Eine andere Stelle auf der Seite | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

Wenn du mit der rechten Maustaste auf einen Verweis im Text klickst und zugehörige Dokumente in anderen Tabs geöffnet sind, enthält das Menü außerdem Befehle, um [zu ihm zu gehen oder ihn zu finden](cross-document-references.md).

## In der Seitenleiste

| Rechtsklick auf | Befehle |
| --- | --- |
| Ein Eintrag der Gliederung | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Eine Miniatur | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up, Move Page Down, Delete Page. Wenn mehrere Seiten ausgewählt sind, nennen die Befehle deren Anzahl, z. B. Delete 3 Pages. Weitere Informationen findest du unter [Seiten neu anordnen](pages.md). |
| Ein Suchergebnis | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Ein Anker | Open in New Window oder Close Window, Copy Text, Copy Screenshot, Delete Anchor |

## Im Fenster

| Rechtsklick auf | Befehle |
| --- | --- |
| Den Titel des Dokuments oder einen leeren Bereich der Symbolleiste | Zu Favorites hinzufügen oder daraus entfernen, Save All Open Tabs as a Group, Update Group “Name” with Open Tabs sowie deine Tabgruppen und Favoriten |
| Eine Zeile auf dem Start-Bildschirm | Open, Open in New Tab, Open in New Window, Show in Finder und Remove oder Delete |

Manche Befehle werden nur angezeigt, wenn sie zutreffen. So erfordert „Save All Open Tabs as a Group“ mehr als einen Tab, und in einem aus einem Anker geöffneten Fenster sind keine Ankerbefehle verfügbar.
