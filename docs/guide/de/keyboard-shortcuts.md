# Tastaturkurzbefehle

Viele dieser Befehle sind auch in einem Kontextmenü verfügbar. Das ist unten vermerkt. Weitere Informationen findest du unter [Kontextmenüs](right-click-menus.md).

## Dokumente

| Aktion | Kurzbefehl |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Insert Pages from PDF | ⌥⌘I oder Rechtsklick auf eine Miniatur |
| Duplicate Pages | ⇧⌘D oder Rechtsklick auf eine Miniatur |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Zu Favorites hinzufügen oder daraus entfernen | ⌘D oder Rechtsklick auf den Titel des Dokuments |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## Navigation

| Aktion | Kurzbefehl |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow oder Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow oder Right Arrow |
| First Page | ⌘Up Arrow oder ⌘Home |
| Last Page | ⌘Down Arrow oder ⌘End |
| Durch die Seite vor- oder zurückblättern | Space oder ⇧Space |
| Next Tab | ⇧⌘] oder ⌃Tab |
| Previous Tab | ⇧⌘[ oder ⇧⌃Tab |

| Zoom Out | ⌘− |

## Suche und Text

| Aktion | Kurzbefehl | Rechtsklick |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G oder Return im Suchfeld | |
| Find Previous | ⇧⌘G oder ⇧Return im Suchfeld | |

## Maus und Trackpad

| Aktion | Geste |
| --- | --- |
| Vorschau eines Links anzeigen | ⌘ darüber gedrückt halten oder kräftig klicken |
| Link in einem neuen Fenster öffnen | Bei gedrückter ⌘-Taste klicken |
| Ein Wort auswählen | Doppelklicken |
| Eine Zeile auswählen | Dreimal klicken |
| Einen Bereich auswählen | Bei gedrückter ⌥-Taste ziehen |
| Kommentare einer Anmerkung öffnen | Doppelklicken, außer bei einem Textfeld oder einer Legende |
| Zoomen | Zwei Finger zusammen- oder auseinanderziehen |

## Anmerkungen und Messungen

| Aktion | Kurzbefehl | Rechtsklick |
| --- | --- | --- |
| Änderung an einer Anmerkung widerrufen oder wiederholen | ⌘Z oder ⇧⌘Z | |
| Ausgewähltes Textfeld oder ausgewählte Legende bearbeiten | Return | Die Anmerkung |
| Ausgewählte Anmerkung löschen | Delete | Die Anmerkung |
| Ausgewählte Anmerkung bewegen | Arrow keys oder ⇧Arrow keys für 10 Punkt | |
| Umfang oder Fläche abschließen | Return | |
| „Ortho Lock“ (0°, 45° oder 90°) für eine Linie umschalten | ⇧ gedrückt halten | |
| Quadrat oder Kreis zeichnen oder eine Linie in einem Vielfachen von 45° | Beim Ziehen mit dem Werkzeug „Shapes“ ⇧ gedrückt halten | |
| Abbrechen oder aktuelles Werkzeug verlassen | Escape | |
