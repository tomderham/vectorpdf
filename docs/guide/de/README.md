# VectorPDF-Benutzerhandbuch

für macOS

VectorPDF ist ein schneller PDF-Reader für Fachartikel, Spezifikationen, Verträge und Zeichnungen. Halte die Befehlstaste über einem Verweis gedrückt, um sein Ziel zu sehen, ohne deine Seite zu verlassen. Du kannst PDFs außerdem markieren, vermessen, schwärzen und neu ordnen – alles auf deinem Mac.

> **Hinweis:** Dieses Handbuch wurde maschinell aus dem Englischen übersetzt. Die Oberfläche von VectorPDF ist nur auf Englisch verfügbar. Menü- und Tastennamen sind deshalb auf Englisch angegeben, so wie sie auf dem Bildschirm erscheinen.
