# Seiten neu anordnen

Seitenänderungen nimmst du in der Ansicht [Thumbnails](outline-and-thumbnails.md) der Seitenleiste vor. Sie werden beim [Sichern](save.md) Teil der Datei.

## Seiten auswählen

Klicke auf eine Miniatur. Halte ⌘ gedrückt, um einzelne Seiten hinzuzufügen, oder ⇧, um einen Bereich auszuwählen.

## Seiten bewegen

Ziehe ausgewählte Miniaturen an eine neue Position. Eine Linie zeigt, wo sie eingefügt werden. Du kannst auch mit der rechten Maustaste auf eine Seite klicken und dann „Move Page Up“ oder „Move Page Down“ wählen.

## Weitere Seitenbefehle

Klicke mit der rechten Maustaste auf eine Miniatur oder eine Auswahl von Miniaturen und wähle dann:

- **Rotate Clockwise, Rotate Counterclockwise oder Rotate 180°:** Dreht die Seiten im PDF selbst, anders als die [Tasten zum Drehen in der Symbolleiste](zoom-and-layout.md#rotate-the-view).
- **Duplicate Page:** Fügt Kopien direkt nach den ausgewählten Seiten ein. Du kannst auch File > Duplicate Pages (⇧⌘D) wählen. Dieser Befehl kopiert die ausgewählten Miniaturen, wenn sie die aktuelle Seite enthalten, andernfalls die aktuelle Seite.
- **Insert Blank Page.**
- **Insert Pages from PDF:** Fügt Seiten aus einem anderen PDF hinzu. Du kannst auch File > Insert Pages from PDF (⌥⌘I) wählen.
- **Save selected page as a PDF:** Extrahiert Seiten in eine neue Datei.
- **Delete Page.**

## Wenn du Anker erstellt hast

Durch das Hinzufügen, Löschen oder Bewegen von Seiten kann ein [Anker](anchors.md) auf die falsche Stelle zeigen. VectorPDF warnt dich und bietet an, die Änderung stattdessen in einer Kopie vorzunehmen.
