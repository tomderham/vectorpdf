# Ein PDF teilen

1. Wähle File > Split PDF.
2. Wähle unter „Split Method“ eine Option aus:
   - **Every N Pages:** Eine neue Datei nach jeweils einer bestimmten Anzahl von Seiten.
   - **Single Pages:** Eine Datei für jede Seite.
   - **Page Ranges:** Gib durch Kommas getrennte Seitenzahlen oder Bereiche ein, zum Beispiel `1-5, 6-12, 13-20`.
3. Klicke unter „Save Location“ auf „Choose“, um einen Ordner auszuwählen.
4. Gib unter „File Naming“ ein Präfix ein und wähle einen Stil aus: „Part Number“ oder „Page Range“. „Output Preview“ zeigt die Dateien, die erstellt werden.
5. Klicke auf „Split PDF“.

Dein Originaldokument ändert sich nicht. Wenn das Teilen abgeschlossen ist, klicke auf „Reveal in Finder“, um die Dateien zu sehen.
