# Passwörter und Verschlüsselung

## Ein geschütztes PDF öffnen

VectorPDF fragt nach dem Passwort, wenn du ein geschütztes PDF öffnest. Wenn du auf „Cancel“ klickst, bleibt das Dokument geschlossen.

## Eine Kopie verschlüsseln

1. Wähle File > Save Encrypted with Password (⌥⌘S).
2. Wähle einen Namen und einen Speicherort aus.
3. Gib das Passwort zweimal ein und klicke dann auf „Encrypt & Save“.

Die Kopie wird mit AES-256 verschlüsselt und kann nur mit dem Passwort geöffnet werden.

> **Warnung:** Bewahre das Passwort sicher auf. Wenn du es verlierst, gibt es keine Möglichkeit, das verschlüsselte PDF wiederherzustellen.

## Die Berechtigungen eines Dokuments ansehen

Um zu sehen, was der Autor eines Dokuments erlaubt, zum Beispiel Drucken oder Kopieren, wähle File > Document Properties (⌘I) und klicke dann auf „Security“. Weitere Informationen findest du unter [Dokumenteigenschaften](document-properties.md).
