# Favoriten und Tabgruppen

## Favoriten

Mit Favoriten hast du die PDFs, die du am häufigsten verwendest, immer griffbereit.

- **Aktuelles PDF hinzufügen oder entfernen:** Wähle Favorites > Add This PDF to Favorites oder drücke ⌘D. Drücke ⌘D erneut, um es zu entfernen.
- **Einen Favoriten öffnen:** Wähle ihn im Menü „Favorites“ aus und wähle dann „Open“, oder klicke auf dem Start-Bildschirm darauf.

Dieselben Befehle werden zusammen mit deinen Favoriten und Tabgruppen angezeigt, wenn du mit der rechten Maustaste auf den Titel des Dokuments oder einen leeren Bereich der Symbolleiste klickst.

## Tabgruppen

Eine Tabgruppe ist eine benannte Zusammenstellung von Dokumenten, die gemeinsam als Tabs eines Fensters geöffnet werden, zum Beispiel die Spezifikationen für ein Projekt.

### Eine Gruppe sichern

1. Öffne die Dokumente als Tabs in einem Fenster.
2. Wähle Favorites > Save All Open Tabs as a Group.
3. Gib einen Namen ein und klicke dann auf „Save“.

### Eine Gruppe öffnen

Wähle die Gruppe im Menü „Favorites“ aus und wähle dann „Open“, oder klicke auf dem Start-Bildschirm darauf.

### Eine Gruppe ändern

Öffne die Gruppe, füge Tabs hinzu oder schließe welche und wähle dann Favorites > Update Group with Open Tabs.

### Eine Gruppe löschen

Wähle die Gruppe im Menü „Favorites“ aus und wähle dann „Delete Tab Group“. Wenn du auf dem Start-Bildschirm eine Gruppe löschst oder einen Favoriten entfernst, kannst du in der angezeigten Meldung auf „Undo“ klicken.
