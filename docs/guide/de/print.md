# Drucken

Wähle File > Print oder drücke ⌘P.

Wähle im Dialogfenster zum Drucken „PDF Options“, um Folgendes zu sehen:

- **Auto Rotate:** Dreht die Seiten passend zum Papier.
- **Scale to Fit:** Passt jede Seite an das Papier an.
- **Scale:** Druckt mit dem eingegebenen Prozentwert.

VectorPDF druckt mit derselben Engine, die auch die Bildschirmdarstellung erzeugt, sodass die Ausgabe dem entspricht, was du siehst.
