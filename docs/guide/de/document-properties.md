# Dokumenteigenschaften

Wähle File > Document Properties oder drücke ⌘I. Wähle oben einen Tab aus:

- **General:** Titel, Autor, Thema, Schlüsselwörter, Daten, das Programm, mit dem das Dokument erstellt wurde, sowie Speicherort und Speicherplatz der Datei.
- **Security:** die Verschlüsselung des Dokuments und ob es Drucken, Kopieren, Änderungen, Kommentare, das Ausfüllen von Formularen, die Textextraktion für Bedienungshilfen und das Zusammenstellen von Seiten erlaubt.
- **Page Geometry:** MediaBox, CropBox, BleedBox, TrimBox und ArtBox jeder Seite in Punkt, Zoll oder Millimetern.
- **Fonts:** die Schriften im Dokument, ihr Typ und ihre Codierung sowie die Angabe, ob sie jeweils eingebettet sind. Verwende das Filterfeld, um eine Schrift zu finden.
