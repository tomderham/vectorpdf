# Zoomen, Drehen und Seitenlayout

## Zoomen

| Aktion | Vorgehensweise |
| --- | --- |
| Vergrößern oder verkleinern | Drücke ⌘+ oder ⌘−, klicke in der Symbolleiste auf „+“ oder „−“ oder ziehe zwei Finger auf dem Trackpad auseinander oder zusammen |
| Genaue Zoomstufe festlegen | Klicke in der Symbolleiste auf den Prozentwert, gib einen Wert von 10 bis 1000 ein und drücke dann die Return-Taste |
| Seite in tatsächlicher Größe ansehen | Wähle View > Actual Size (100%) oder drücke ⌘1 |
| An die Seitenbreite anpassen | Wähle View > Zoom to Fit Width oder drücke ⌘9 |
| Ganze Seite einpassen | Wähle View > Zoom to Fit Window oder drücke ⌥⌘0 |

Die Befehle „Zoom In“ und „Zoom Out“ funktionieren zwischen 25 % und 400 %. Gib einen Prozentwert ein, um über diese Grenzen hinauszugehen.

VectorPDF hält Seiten bei jeder Zoomstufe scharf, weil es sie neu zeichnet, statt ein Bild zu vergrößern.

## Was 100 % bedeutet

Wähle View > Define 100% Scale As und dann eine Option:

- **Size on Screen Equals Size on Printout:** Eine Seite wird bei 100 % ungefähr in ihrer Druckgröße angezeigt.
- **1 Point Equals 1 Screen Point:** Ein PDF-Punkt nimmt einen Punkt auf deinem Display ein.

## Die Ansicht drehen {#rotate-the-view}

Klicke in der Symbolleiste auf „Rotate Left“ oder „Rotate Right“. Das ändert nur, wie du das Dokument auf dem Bildschirm siehst, und wird nicht gesichert. Informationen zum Drehen von Seiten im PDF selbst findest du unter [Seiten neu anordnen](pages.md).

## Two-Page Mode

Klicke in der Symbolleiste auf „Two-Page Mode“ oder wähle View > Two Pages (⌥⌘2). Die Seiten werden paarweise angezeigt, mit dem Deckblatt allein, wie in einem aufgeschlagenen Buch, und die Doppelseite wird an das Fenster angepasst. Um zurückzukehren, klicke erneut auf die Taste oder wähle View > Single Page.

> **Hinweis:** Solange die Ansicht gedreht ist oder sich im Two-Page Mode befindet, kannst du keinen Text auswählen, keinen Links folgen, keine Markierungs- und Messwerkzeuge verwenden und keine Formulare ausfüllen. Kehre zu „Single Page“ ohne Drehung zurück, um sie zu verwenden.
