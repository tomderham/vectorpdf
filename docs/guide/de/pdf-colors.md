# PDF-Farben ändern

VectorPDF kann das Aussehen der Seiten eines Dokuments ändern, unabhängig vom Erscheinungsbild von macOS. Das ist beim Lesen in einem dunklen Raum praktisch. Das PDF selbst wird dabei nicht verändert.

Wähle View > PDF Color oder verwende die Einstellung „PDF Color“ in [Settings](settings.md) und wähle dann eine Option aus:

- **Follow System:** Die Seiten passen sich dem Erscheinungsbild von macOS an.
- **Light:** Die Seiten werden so angezeigt, wie das Dokument sie festlegt.
- **Dark:** Die Seitenfarben werden invertiert, wobei die Farbtöne erhalten bleiben, sodass Diagramme und Hervorhebungen erkennbar bleiben.
- **Sepia:** Die Seiten erhalten den warmen Farbton von Papier.

Beim Drucken und Exportieren werden die Originalfarben des Dokuments verwendet.
