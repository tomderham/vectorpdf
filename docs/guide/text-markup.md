# Highlight, underline and strike through

## Mark up selected text

Select text, then do one of these:

| Markup | Menu | Shortcut |
| --- | --- | --- |
| Highlight | Edit > Highlight Selection | ⇧⌘H |
| Underline | Edit > Underline Selection | ⇧⌘U |
| Strikethrough | Edit > Strikethrough Selection | ⇧⌘X |

You can also use the buttons in the Markup toolbar, or right-click the selection and choose Highlight, Underline or Strikethrough. Each has a list of colors.

## Choose a color

The Markup toolbar (⇧⌘A) has a palette of colors. The shortcuts and toolbar buttons use the color selected there. To pick a color for one markup, use the color list in the right-click menu, or under the item in the Edit menu.

## Remove a markup

Right-click the marked text, then choose Remove Highlight, Remove Underline or Remove Strikethrough. Or choose the Eraser in the Markup toolbar, then click or drag across the markups you want to remove.

> **Note:** VectorPDF doesn't have an Undo command for markups. Remove a markup you don't want, or close the document without saving to discard all your changes since the last save.

## Summarize your markups

To get a list of your annotations, choose File > Export Annotations Summary (⇧⌘E). You can save it as Markdown or CSV. See [Export to other formats](export.md).
