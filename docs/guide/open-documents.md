# Open documents

## Open a PDF

- **In a new window:** choose File > Open PDF, or press ⌘O.
- **In a new tab:** choose File > Open PDF in New Tab, or press ⌥⌘O.
- **From the Finder:** right-click a PDF, then choose Open With > VectorPDF. To open all PDFs in VectorPDF, select a PDF, choose File > Get Info in the Finder, change “Open with”, then click Change All.
- **By dragging:** drag a PDF onto the Start screen to open it there, or onto an open document to open it in a new tab.
- **From a list:** choose File > Open Recent, or use the [Favorites](favorites-and-tab-groups.md) menu. On the Start screen, right-click a document to open it in a new tab or window.

## E-books, comics and XPS documents

VectorPDF also opens EPUB and FictionBook (FB2) e-books, CBZ comic archives and XPS documents, the same ways as a PDF. An e-book is laid out into pages for reading.

You can read these documents, follow their table of contents, search them, select and copy their text, and add [anchors](anchors.md). They open for reading only: VectorPDF can't save them, so markup, measurement, redaction and page editing aren't available, and Save is dimmed.

## Password-protected PDFs

VectorPDF asks for the password when you open a protected PDF. See [Passwords and encryption](passwords.md).

## PDFs in cloud storage

VectorPDF recognizes files in iCloud Drive, Google Drive, Dropbox, OneDrive and Box. If a file isn't on your Mac yet, VectorPDF downloads it before opening it, and shows you the progress. If the download doesn't finish, you'll see a message, and you can try again when you're connected.

## When a file changes

VectorPDF watches each open file. If another app changes the file, the document reloads by itself. This is useful if you're generating a PDF from LaTeX or another tool and want to keep it open.

If you have unsaved changes, VectorPDF asks whether to **Reload from Disk**, which loses your changes, or **Keep My Changes**.

If you move or rename a file in the Finder, the open document follows it.

## Close a document

Close a tab or window as usual. If there are unsaved changes, VectorPDF asks whether to save them. VectorPDF remembers [where you were](reading-positions.md) for next time.
