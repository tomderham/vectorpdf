# Keyboard shortcuts

Many of these commands are also on a right-click menu, noted below. See [Right-click menus](right-click-menus.md).

## Documents

| Action | Shortcut |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Insert Pages from PDF | ⌥⌘I, or right-click a thumbnail |
| Duplicate Pages | ⇧⌘D, or right-click a thumbnail |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Add to or Remove from Favorites | ⌘D, or right-click the document's title |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## Navigation

| Action | Shortcut |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow or Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow or Right Arrow |
| First Page | ⌘Up Arrow or ⌘Home |
| Last Page | ⌘Down Arrow or ⌘End |
| Forward or backward through the page | Space or ⇧Space |
| Next Tab | ⇧⌘] or ⌃Tab |
| Previous Tab | ⇧⌘[ or ⇧⌃Tab |

## View

| Action | Shortcut |
| --- | --- |
| Zoom In | ⌘+ |
| Zoom Out | ⌘− |
| Actual Size (100%) | ⌘1 |
| Zoom to Fit Width | ⌘9 |
| Zoom to Fit Window | ⌥⌘0 |
| Two Pages or Single Page | ⌥⌘2 |
| Show or Hide Markup Toolbar | ⇧⌘A |
| Show or Hide Measurement Toolbar | ⇧⌘M |
| Show or Hide Redact Toolbar | ⌥⌘R |

## Search and text

| Action | Shortcut | Right-click |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G, or Return in the search field | |
| Find Previous | ⇧⌘G, or ⇧Return in the search field | |
| Copy | ⌘C | Selected text |
| Highlight | ⇧⌘H | Selected text |
| Underline | ⇧⌘U | Selected text |
| Strikethrough | ⇧⌘X | Selected text |
| Stop Speaking | ⌥⌘. | Selected text |
| Add Anchor | ⌘B | Selection, link or page, as Create Anchor |

## Mouse and trackpad

| Action | Gesture |
| --- | --- |
| Preview a link | Hold ⌘ over it, or Force Click |
| Open a link in a new window | ⌘-click |
| Select a word | Double-click |
| Select a line | Triple-click |
| Select an area | ⌥-drag |
| Open an annotation's comments | Double-click it, except a text box or callout |
| Zoom | Pinch |

## Annotations and measurements

| Action | Shortcut | Right-click |
| --- | --- | --- |
| Undo or redo an annotation change | ⌘Z or ⇧⌘Z | |
| Edit selected text box or callout | Return | The annotation |
| Delete selected annotation | Delete | The annotation |
| Move selected annotation | Arrow keys, or ⇧Arrow keys for 10 points | |
| Finish perimeter or area | Return | |
| Switch Ortho Lock (0°, 45° or 90°) for one line | Hold ⇧ | |
| Draw a square or circle, or a line at a multiple of 45° | Hold ⇧ while dragging with the Shapes tool | |
| Cancel, or leave the current tool | Escape | |
