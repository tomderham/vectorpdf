# Sélectionner, copier et consulter du texte

## Sélectionner du texte

- **Faites glisser** le pointeur sur le texte. Les sélections suivent l’ordre de lecture : elles restent dans une seule colonne d’une mise en page à plusieurs colonnes et ignorent les numéros de ligne en marge. Elles peuvent s’étendre sur plusieurs pages.
- **Double-cliquez** pour sélectionner un mot, ou **cliquez trois fois** pour sélectionner une ligne.
- **Maintenez la touche ⌥ enfoncée et faites glisser** pour sélectionner une zone rectangulaire, par exemple une figure ou un tableau.

Appuyez sur Escape pour effacer la sélection.

Sur une page numérisée, vous pouvez sélectionner le texte une fois qu’il a été [reconnu](scanned-pages.md).

## Copier

Appuyez sur ⌘C, ou cliquez avec le bouton droit sur le texte sélectionné et choisissez Copy Text.

Cliquez avec le bouton droit sur une sélection rectangulaire pour obtenir plus d’options :

- **Copy Extracted Text** copie le texte éventuel de la zone.
- **Copy Screenshot** copie la zone sous forme d’image.
- **Save Screenshot As** enregistre la zone dans un fichier image.

## Consulter et traduire

Cliquez avec le bouton droit sur le texte sélectionné, puis choisissez :

- **Look Up** pour voir une définition du dictionnaire.
- **Translate Selection** pour le traduire.

## Faire lire le texte à voix haute

Sélectionnez du texte, puis choisissez Edit > Speech > Start Speaking, ou cliquez avec le bouton droit et choisissez Start Speaking. Pour arrêter, choisissez Stop Speaking ou appuyez sur ⌥⌘. (Option-Commande-point).

## Autres actions

Le menu qui s’affiche lorsque vous cliquez avec le bouton droit sur du texte sélectionné propose aussi des commandes pour [surligner, souligner ou barrer](text-markup.md) le texte, [créer une ancre](anchors.md) et ouvrir la sélection dans une nouvelle fenêtre.
