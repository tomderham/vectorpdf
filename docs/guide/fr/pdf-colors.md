# Modifier les couleurs du PDF

VectorPDF peut changer l’aspect des pages d’un document, quelle que soit l’apparence de macOS. C’est utile pour lire dans une pièce sombre. Le PDF n’est pas modifié.

Choisissez View > PDF Color, ou utilisez le réglage PDF Color dans [Settings](settings.md), puis choisissez une option :

- **Follow System :** les pages suivent l’apparence de macOS.
- **Light :** les pages s’affichent telles que le document les définit.
- **Dark :** les couleurs des pages sont inversées en conservant les teintes, afin que les schémas et les surlignages restent reconnaissables.
- **Sepia :** les pages prennent une teinte chaude de papier ancien.

L’impression et l’exportation utilisent les couleurs d’origine du document.
