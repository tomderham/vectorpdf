# Poser une question sur un document

L’Agent répond aux questions sur le document ouvert et vous montre les passages sur lesquels sa réponse s’appuie. Il nécessite macOS 26 ou une version ultérieure.

## Poser une question

1. Cliquez sur l’onglet Ask About This Document dans la barre latérale. La première fois, VectorPDF indexe le document sur votre Mac et affiche la progression.
2. Saisissez une question, puis appuyez sur Return ou cliquez sur Ask. Appuyez sur ⇧Return pour aller à la ligne.

Sous la réponse, cliquez sur **Sources** pour voir les passages utilisés, avec leurs pages. Les passages cités dans la réponse sont marqués **Cited**. Cliquez sur un passage pour y accéder.

Vous pouvez poser des questions complémentaires. Pour recommencer, cliquez sur **New Conversation**.

> **Remarque :** L’Agent peut se tromper. Vérifiez les sources pour tout ce qui est important.

## Si aucune réponse ne peut être générée

Si la génération de réponses n’est pas disponible sur votre Mac, l’Agent affiche à la place les passages les plus pertinents. Consultez [Choisir comment l’Agent répond](agent-engines.md).

## Désactiver l’Agent

Désactivez **Use Agent** dans [Settings](settings.md). L’onglet disparaît de la barre latérale.
