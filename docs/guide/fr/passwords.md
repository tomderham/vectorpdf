# Mots de passe et chiffrement

## Ouvrir un PDF protégé

VectorPDF demande le mot de passe lorsque vous ouvrez un PDF protégé. Si vous cliquez sur Cancel, le document reste fermé.

## Chiffrer une copie

1. Choisissez File > Save Encrypted with Password (⌥⌘S).
2. Choisissez un nom et un emplacement.
3. Saisissez deux fois le mot de passe, puis cliquez sur Encrypt & Save.

La copie est chiffrée avec AES-256 et ne peut être ouverte qu’avec le mot de passe.

> **Attention :** Conservez le mot de passe en lieu sûr. Si vous le perdez, il n’existe aucun moyen de récupérer le PDF chiffré.

## Voir les autorisations d’un document

Pour voir ce que l’auteur d’un document autorise, comme l’impression ou la copie, choisissez File > Document Properties (⌘I), puis cliquez sur Security. Consultez [Propriétés du document](document-properties.md).
