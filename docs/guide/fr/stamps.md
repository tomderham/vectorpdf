# Tampons et signatures

Un tampon est une image, par exemple votre signature ou vos initiales, que vous pouvez placer sur n’importe quelle page.

> **Remarque :** Un tampon est une marque visuelle. Ce n’est pas une signature numérique cryptographique, et il ne certifie pas le document.

## Créer votre tampon

1. Choisissez VectorPDF > Settings, puis cliquez sur Create Stamp sous Digital Stamp. Vous pouvez aussi choisir directement l’outil Stamp dans la barre d’outils Markup : VectorPDF vous propose alors d’en créer un.
2. Choisissez comment le créer :
   - **Draw :** signez avec votre trackpad ou votre souris.
   - **Type :** saisissez votre nom ou vos initiales et choisissez une police.
   - **Image :** choisissez un fichier PNG ou JPEG. Si vous choisissez **Transparent background**, la page apparaît à travers l’arrière-plan de l’image.
3. Cliquez sur Use.

VectorPDF conserve votre tampon sur ce Mac pour la prochaine fois. Pour le remplacer ou le supprimer, utilisez Modify Stamp ou Delete Stamp dans [Settings](settings.md).

## Placer un tampon

1. Affichez la barre d’outils Markup (⇧⌘A), puis choisissez l’outil Stamp.
2. Cliquez à l’endroit où vous voulez placer le tampon.

Faites-le ensuite glisser pour le déplacer, ou faites glisser un angle pour le redimensionner. Pour le retirer, sélectionnez-le et appuyez sur Delete, ou cliquez dessus avec le bouton droit et choisissez Delete Signature.

## Signer un formulaire

Si un formulaire comporte un champ de signature, cliquez sur **Sign** dans ce champ. Consultez [Remplir des formulaires](forms.md).
