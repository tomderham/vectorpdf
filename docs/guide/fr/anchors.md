# Ancres

Une ancre est un endroit enregistré dans un document : un passage de texte, une zone de page ou la cible d’un lien. Les ancres sont conservées séparément du PDF et ne le modifient pas.

## Créer une ancre

- Sélectionnez du texte, ou maintenez la touche ⌥ enfoncée et faites glisser le pointeur pour sélectionner une zone, puis appuyez sur ⌘B ou choisissez Anchors > Add Anchor.
- Cliquez avec le bouton droit sur une sélection, un lien ou un endroit de la page, puis choisissez **Create Anchor**.
- Cliquez avec le bouton droit sur un [résultat de recherche](search.md) ou une entrée du [plan](outline-and-thumbnails.md), puis choisissez **Create Anchor**.

Si rien n’est sélectionné, ⌘B crée une ancre pour la page active.

**Create Anchor and Open in New Window** fait la même chose et affiche en plus l’endroit dans sa propre fenêtre.

## Utiliser vos ancres

Cliquez sur l’onglet Anchors dans la barre latérale pour voir une carte par ancre, ou utilisez le menu Anchors.

- **Accéder à une ancre :** cliquez sur sa carte ou choisissez-la dans le menu Anchors.
- **Voir un aperçu plus grand :** maintenez le pointeur sur la vignette de la carte.
- **Voir les ancres de tous les onglets de la fenêtre :** si la fenêtre a plusieurs onglets, l’onglet Anchors affiche les ancres de chacun, regroupées par onglet. Cliquez sur une ancre pour passer à son onglet, ou choisissez This Document en haut pour ne voir que celles de ce document.

Cliquez avec le bouton droit sur une carte pour l’ouvrir dans une nouvelle fenêtre, copier son texte ou copier son image.

## Supprimer des ancres

- **Une ancre :** cliquez sur le × de sa carte, ou cliquez dessus avec le bouton droit et choisissez Delete Anchor.
- **Toutes les ancres d’un document :** cliquez sur Clear All dans l’onglet Anchors, ou choisissez Anchors > Clear All Anchors. Si plusieurs onglets sont ouverts, choisissez d’abord This Document en haut.

## Ancres et modifications de pages

Une ancre retient un numéro de page. Si vous ajoutez, supprimez ou déplacez des pages et qu’une ancre risque de pointer au mauvais endroit, VectorPDF vous prévient d’abord. Vous pouvez choisir **Save as Copy** pour effectuer la modification dans une copie, qui démarre sans ancres, ou **Edit Anyway**.

## Ancres sur vos autres Mac

Les ancres se [synchronisent via iCloud](reading-positions.md) avec votre position de lecture, sauf si vous désactivez cette option.
