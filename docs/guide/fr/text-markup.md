# Surligner, souligner et barrer

## Annoter le texte sélectionné

Sélectionnez du texte, puis utilisez l’une de ces méthodes :

| Annotation | Menu | Raccourci |
| --- | --- | --- |
| Surlignage | Edit > Highlight Selection | ⇧⌘H |
| Soulignement | Edit > Underline Selection | ⇧⌘U |
| Texte barré | Edit > Strikethrough Selection | ⇧⌘X |

Vous pouvez aussi utiliser les boutons de la barre d’outils Markup, ou cliquer avec le bouton droit sur la sélection et choisir Highlight, Underline ou Strikethrough. Chacun propose une liste de couleurs.

## Choisir une couleur

La barre d’outils Markup (⇧⌘A) comporte une palette de couleurs. Les raccourcis et les boutons de la barre d’outils utilisent la couleur qui y est sélectionnée. Pour choisir une couleur pour une seule annotation, utilisez la liste de couleurs du menu du clic droit, ou celle située sous l’élément dans le menu Edit.

## Retirer une annotation

Cliquez avec le bouton droit sur le texte annoté, puis choisissez Remove Highlight, Remove Underline ou Remove Strikethrough. Ou choisissez l’outil Eraser dans la barre d’outils Markup, puis cliquez ou faites glisser le pointeur sur les annotations à retirer.

> **Remarque :** VectorPDF ne dispose pas d’une commande Undo pour les annotations. Retirez l’annotation dont vous ne voulez pas, ou fermez le document sans l’enregistrer pour annuler toutes vos modifications depuis le dernier enregistrement.

## Résumer vos annotations

Pour obtenir la liste de vos annotations, choisissez File > Export Annotations Summary (⇧⌘E). Vous pouvez l’enregistrer au format Markdown ou CSV. Consultez [Exporter vers d’autres formats](export.md).
