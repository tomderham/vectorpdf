# Surligner, souligner et barrer

## Annoter le texte sélectionné

Sélectionnez du texte, puis utilisez l’une de ces méthodes :

| Annotation | Menu | Raccourci |
| --- | --- | --- |
| Surlignage | Edit > Highlight Selection | ⇧⌘H |
| Soulignement | Edit > Underline Selection | ⇧⌘U |
| Texte barré | Edit > Strikethrough Selection | ⇧⌘X |

Vous pouvez aussi utiliser les boutons de la barre d’outils Markup, ou cliquer avec le bouton droit sur la sélection et choisir Highlight, Underline ou Strikethrough. Chacun propose une liste de couleurs.

## Choisir une couleur

La barre d’outils Markup (⇧⌘A) comporte un bouton de couleur. Cliquez dessus, puis sur une couleur. Les raccourcis et les boutons de la barre utilisent la couleur qui y est sélectionnée. Pour choisir la couleur d’une seule annotation, utilisez la liste de couleurs du menu contextuel ou celle située sous l’élément dans le menu Edit.

## Retirer une annotation

Pour annuler une annotation que vous venez de créer, choisissez Edit > Undo ou appuyez sur ⌘Z.

Cliquez avec le bouton droit sur le texte annoté, puis choisissez Remove Highlight, Remove Underline ou Remove Strikethrough. Vous pouvez aussi choisir la gomme dans la barre d’outils Markup, puis cliquer ou faire glisser sur les annotations à supprimer. ⌘Z rétablit une annotation supprimée par erreur.

## Résumer vos annotations

Pour obtenir la liste de vos annotations, choisissez File > Export Annotations Summary (⇧⌘E). Vous pouvez l’enregistrer au format Markdown ou CSV. Consultez [Exporter vers d’autres formats](export.md).
