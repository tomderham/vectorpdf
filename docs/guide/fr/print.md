# Imprimer

Choisissez File > Print, ou appuyez sur ⌘P.

Dans la zone de dialogue d’impression, choisissez PDF Options pour afficher :

- **Auto Rotate :** fait pivoter les pages pour les adapter au papier.
- **Scale to Fit :** adapte chaque page au papier.
- **Scale :** imprime au pourcentage que vous saisissez.

VectorPDF imprime avec le même moteur que celui qu’il utilise à l’écran : le résultat correspond donc à ce que vous voyez.
