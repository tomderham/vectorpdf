# Références entre documents

Les normes citent d’autres normes et les contrats renvoient à leurs annexes, le plus souvent en texte brut plutôt qu’avec des liens. Si vous ouvrez les documents liés dans des onglets d’une même fenêtre, VectorPDF peut suivre ces références.

## Suivre une référence en texte brut

1. Ouvrez les documents liés dans des [onglets de la même fenêtre](tabs-and-windows.md).
2. Cliquez avec le bouton droit sur une référence telle que « Section 8.8.3 of [HTTP] » ou « Clause 4.2 of the Master Agreement », ou sélectionnez la référence et cliquez dessus avec le bouton droit.
3. Choisissez l’une de ces options :
   - **Go to** suivi du titre correspondant, pour le prévisualiser. Depuis l’aperçu, vous pouvez vous y rendre.
   - Maintenez la touche ⌘ enfoncée pendant que le menu est ouvert pour changer la commande en **Open**, qui s’y rend directement sans aperçu.
   - **Find in Other Tabs**, pour rechercher dans le texte de vos autres onglets.

VectorPDF compare les références au plan de l’autre document, ou à ses titres s’il n’a pas de plan. Si le même titre figure dans plusieurs onglets, l’aperçu les liste tous.

## Liens web vers un document ouvert

Certains documents sont liés entre eux sur le web. Par exemple, les RFC de l’IETF renvoient à rfc-editor.org. Si le document visé par un lien web est ouvert dans un autre onglet, le survol avec ⌘ ou le clic forcé [le prévisualise dans cet onglet](link-peek.md) au lieu d’ouvrir votre navigateur.

## Conserver un ensemble de documents

Enregistrez les documents que vous utilisez ensemble sous forme de [Tab Group](favorites-and-tab-groups.md), afin de pouvoir les rouvrir en une seule étape.
