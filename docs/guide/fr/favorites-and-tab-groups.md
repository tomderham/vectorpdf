# Favorites et Tab Groups

## Favorites

Les favoris gardent à portée de main les PDF que vous utilisez le plus.

- **Ajouter ou retirer le PDF actif :** choisissez Favorites > Add This PDF to Favorites, ou appuyez sur ⌘D. Appuyez à nouveau sur ⌘D pour le retirer.
- **Ouvrir un favori :** choisissez-le dans le menu Favorites, puis choisissez Open, ou cliquez dessus dans l’écran Start.

Les mêmes commandes apparaissent, avec vos Favorites et Tab Groups, lorsque vous cliquez avec le bouton droit sur le titre du document ou sur une partie vide de la barre d’outils.

## Tab Groups

Un Tab Group est un ensemble nommé de documents qui s’ouvrent ensemble dans les onglets d’une même fenêtre, par exemple les spécifications d’un projet.

### Enregistrer un groupe

1. Ouvrez les documents dans des onglets d’une même fenêtre.
2. Choisissez Favorites > Save All Open Tabs as a Group.
3. Saisissez un nom, puis cliquez sur Save.

### Ouvrir un groupe

Choisissez le groupe dans le menu Favorites, puis choisissez Open, ou cliquez dessus dans l’écran Start.

### Modifier un groupe

Ouvrez le groupe, ajoutez ou fermez des onglets (ou faites glisser des onglets depuis d’autres fenêtres), puis choisissez Favorites > Update Group “nom” with Open Tabs, où “nom” est le nom du groupe. Un onglet que vous faites glisser hors de la fenêtre du groupe ne fait plus partie du groupe.

### Supprimer un groupe

Choisissez le groupe dans le menu Favorites, puis choisissez Delete Tab Group. Si vous supprimez un groupe ou retirez un favori depuis l’écran Start, vous pouvez cliquer sur Undo dans le message qui s’affiche.
