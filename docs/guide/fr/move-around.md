# Se déplacer dans un document

## Faire défiler et tourner les pages

Faites défiler avec votre trackpad ou votre souris. VectorPDF ne met en page que les pages proches de votre position de lecture : les très longs documents restent donc rapides.

Au clavier :

| Touches | Action |
| --- | --- |
| Left Arrow, Right Arrow | Page précédente ou suivante |
| Up Arrow, Down Arrow | Fait défiler une page plus haute que la fenêtre, puis passe à la page suivante. Si la page tient dans la fenêtre, avance d’une page à la fois. |
| Page Up, Page Down | Fait défiler d’un pas plus grand, puis passe à la page suivante |
| Space, ⇧Space | Avance ou recule, comme Page Down et Page Up |
| ⌥Up Arrow, ⌥Down Arrow, ⌥Left Arrow, ⌥Right Arrow | Page précédente ou suivante |
| ⌘Up Arrow, ⌘Down Arrow | Première ou dernière page |

En Two-Page Mode, ces touches tournent une double page entière.

## Accéder à une page

Cliquez sur le numéro de page dans la barre d’outils, saisissez la page souhaitée, puis appuyez sur Return. Appuyez sur Escape pour annuler.

Certains documents nomment eux-mêmes leurs pages, par exemple `iv` pour les pages liminaires ou `A-101` pour un plan. VectorPDF affiche alors cette étiquette dans la barre d’outils, l’indicateur de page et les vignettes, avec la position de la page à côté, comme dans `iv (4 of 300)`. Saisissez une étiquette pour accéder à cette page. Si une étiquette est utilisée plusieurs fois, vous accédez à la page suivante qui la porte. Pour accéder à une page par sa position, saisissez `#` suivi du numéro, par exemple `#13`.

Print et Split PDF comptent toujours les pages selon leur position, à partir de la première page du fichier.

## Revenir à l’endroit précédent

Après avoir suivi un lien ou accédé à un résultat, choisissez Go > Back (⌘[) pour revenir. Go > Forward (⌘]) vous ramène dans l’autre sens.

## Utiliser la structure du document

- [Le plan](outline-and-thumbnails.md) permet d’accéder à n’importe quelle section.
- [Les vignettes](outline-and-thumbnails.md) montrent toutes les pages.
- [Les ancres](anchors.md) marquent les endroits auxquels vous voulez revenir.
- [Link Peek](link-peek.md) vous montre la cible d’un lien sans quitter votre page.
