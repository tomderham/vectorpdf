# Raccourcis clavier

Bon nombre de ces commandes figurent aussi dans un menu du clic droit, comme indiqué ci-dessous. Consultez [Menus du clic droit](right-click-menus.md).

## Documents

| Action | Raccourci |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Compare Documents | Menu File, ou cliquez avec le bouton droit sur le titre du document et choisissez Compare With |
| Insert Pages from PDF | ⌥⌘I, ou clic droit sur une vignette |
| Duplicate Pages | ⇧⌘D, ou clic droit sur une vignette |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Add to or Remove from Favorites | ⌘D, ou clic droit sur le titre du document |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## Navigation

| Action | Raccourci |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow ou Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow ou Right Arrow |
| First Page | ⌘Up Arrow ou ⌘Home |
| Last Page | ⌘Down Arrow ou ⌘End |
| Modification précédente ou suivante, en comparant des documents | ⌥⌘Up Arrow ou ⌥⌘Down Arrow, ou les flèches de l’onglet Changes |
| Avancer ou reculer dans la page | Space ou ⇧Space |
| Next Tab | ⇧⌘] ou ⌃Tab |
| Previous Tab | ⇧⌘[ ou ⇧⌃Tab |

## Recherche et texte

| --- | --- | --- |
| Find | ⌘F | |

## Souris et trackpad

| Action | Geste |
| --- | --- |
| Prévisualiser un lien | Maintenir la touche ⌘ enfoncée sur le lien, ou clic forcé |

## Annotations et mesures

| Action | Raccourci | Clic droit |
| --- | --- | --- |
| Annuler ou rétablir une modification d’annotation | ⌘Z ou ⇧⌘Z | |
| Modifier la zone de texte ou la bulle sélectionnée | Return | L’annotation |
| Supprimer l’annotation sélectionnée | Delete | L’annotation |
| Déplacer l’annotation sélectionnée | Touches fléchées, ou ⇧Arrow keys pour 10 points | |
| Terminer un périmètre ou une surface | Return | |
| Inverser Ortho Lock (0°, 45° ou 90°) pour une ligne | Maintenir la touche ⇧ enfoncée | |
| Dessiner un carré ou un cercle, ou une ligne à un multiple de 45° | Maintenir ⇧ en faisant glisser avec l’outil Shapes | |
| Annuler, ou quitter l’outil actif | Escape | |
