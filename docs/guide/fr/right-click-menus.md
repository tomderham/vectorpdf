# Menus du clic droit

Cliquez avec le bouton droit, ou en maintenant la touche Contrôle enfoncée, pour voir les commandes liées à ce qui se trouve sous le pointeur. Le menu affiché dépend de l’endroit où vous cliquez.

## Dans le document

| Clic droit sur | Commandes |
| --- | --- |
| Du texte sélectionné | Copy Text, Look Up, Translate Selection, Start Speaking ou Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Une zone sélectionnée | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un lien | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Un surlignage, un soulignement ou un texte barré | Comments… et la commande Remove correspondante |
| Une zone de texte | Comments…, Edit Text Box et la commande de suppression |
| Une bulle | Comments…, Edit Callout Note, Line Ending et la commande de suppression |
| Une note, ou le contour d’un rectangle, d’un ovale ou d’un nuage de révision | Comments… et la commande de suppression |
| Une ligne ou une flèche | Comments…, Line Ending et la commande de suppression |
| Un dessin, un tampon ou une mesure | Comments… et la commande de suppression |
| Une forme, un nuage, une ligne, une note, un tampon ou une zone de texte enregistré plus tôt dans le document, ou créé dans une autre app | Comments…, Line Ending pour une ligne, et la commande de suppression |
| Un surlignage, un dessin ou une mesure enregistré plus tôt dans le document, ou créé dans une autre app | Comments… et les commandes valables partout ailleurs sur la page |
| Partout ailleurs sur la page | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

Si vous cliquez avec le bouton droit sur une référence en texte brut alors que des documents liés sont ouverts dans d’autres onglets, le menu propose aussi des commandes pour [y accéder ou la trouver](cross-document-references.md).

Dans un document avec des [calques](layers.md), le menu d’une annotation propose aussi **Layer**, pour la déplacer vers un autre calque ou vers aucun.

## Dans la barre latérale

| Clic droit sur | Commandes |
| --- | --- |
| Une entrée du plan | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Une vignette | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up, Move Page Down, Delete Page. Lorsque plusieurs pages sont sélectionnées, les commandes indiquent leur nombre, par exemple Delete 3 Pages. Consultez [Réorganiser les pages](pages.md). |
| Un résultat de recherche | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| Une ancre | Open in New Window ou Close Window, Copy Text, Copy Screenshot, Delete Anchor |
| Une annotation dans l’onglet Comments | Show on Page, Comments…, Delete |
| Un calque dans l’onglet Layers | Put New Annotations Here, ou Stop Putting New Annotations Here. Voir [Afficher et masquer les calques](layers.md). |
| Une pièce jointe dans l’onglet Attachments | Quick Look, Open, Save As…, et Show on Page pour un fichier joint à une page. Voir [Fichiers joints à un PDF](attachments.md). |

## Dans la fenêtre

| Clic droit sur | Commandes |
| --- | --- |
| Le titre du document ou une partie vide de la barre d’outils | Ajout à Favorites ou retrait de Favorites, Save All Open Tabs as a Group, Update Group “nom” with Open Tabs, Compare With (voir [Comparer deux documents](compare-documents.md)), ainsi que vos Tab Groups et Favorites |
| Une ligne de l’écran Start | Open, Open in New Tab, Open in New Window, Show in Finder, et Remove ou Delete |

Certaines commandes n’apparaissent que lorsqu’elles s’appliquent. Par exemple, Save All Open Tabs as a Group nécessite plus d’un onglet, et les commandes d’ancre ne sont pas disponibles dans une fenêtre ouverte depuis une ancre.
