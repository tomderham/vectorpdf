# Définir l’échelle d’un plan

Pour obtenir des mesures réelles à partir d’un plan, VectorPDF doit connaître son échelle. Appuyez sur ⇧⌘M pour afficher la barre d’outils Measurement, puis cliquez sur le bouton d’échelle pour ouvrir Drawing Scale Calibration.

## Utiliser une échelle standard

1. Sous Standard Drawing Scales, choisissez le type de plan :
   - **Metric (ISO) :** de 1:1 à 1:1000.
   - **Architectural (US) :** par exemple 1/4" = 1'-0".
   - **Civil Engineering (US).**
2. Choisissez l’échelle.
3. Sous Area Takeoff, choisissez l’unité des surfaces.
4. Cliquez sur Apply Scale.

L’échelle s’applique à toutes les pages et est stockée dans le PDF lorsque vous [enregistrez](save.md).

## Étalonner à partir d’une longueur connue

Si le plan comporte une cote fiable ou une échelle graphique :

1. Cliquez sur **Calibrate by Measuring Known Line**.
2. Cliquez sur les deux extrémités de la ligne sur le plan.
3. Saisissez la longueur réelle de la ligne et choisissez son unité : pieds et pouces, pieds décimaux, pouces, millimètres, centimètres ou mètres.
4. Cliquez sur Apply Scale.

Utilisez la ligne connue la plus longue possible : les petites erreurs de clic comptent moins sur une grande distance.
