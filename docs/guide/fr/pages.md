# Réorganiser les pages

Les modifications de pages s’effectuent dans la présentation [Thumbnails](outline-and-thumbnails.md) de la barre latérale. Elles sont intégrées au fichier lorsque vous [enregistrez](save.md).

## Sélectionner des pages

Cliquez sur une vignette. Maintenez la touche ⌘ enfoncée pour ajouter des pages une à une, ou la touche ⇧ pour sélectionner une plage.

## Déplacer des pages

Faites glisser les vignettes sélectionnées vers un nouvel emplacement. Une ligne indique où elles iront. Vous pouvez aussi cliquer avec le bouton droit sur une page, puis choisir Move Page Up ou Move Page Down.

## Autres commandes de page

Cliquez avec le bouton droit sur une vignette ou une sélection de vignettes, puis choisissez :

- **Rotate Clockwise, Rotate Counterclockwise ou Rotate 180° :** fait pivoter les pages dans le PDF lui-même, contrairement aux [boutons Rotate de la barre d’outils](zoom-and-layout.md#rotate-the-view).
- **Duplicate Page :** ajoute des copies juste après les pages sélectionnées. Vous pouvez aussi choisir File > Duplicate Pages (⇧⌘D), qui copie les vignettes sélectionnées si elles incluent la page où vous êtes, ou cette page dans le cas contraire.
- **Insert Blank Page.**
- **Insert Pages from PDF :** ajoute des pages d’un autre PDF. Vous pouvez aussi choisir File > Insert Pages from PDF (⌥⌘I).
- **Save selected page as a PDF :** extrait des pages dans un nouveau fichier.
- **Delete Page.**

## Si vous avez créé des ancres

L’ajout, la suppression ou le déplacement de pages peut faire pointer une [ancre](anchors.md) au mauvais endroit. VectorPDF vous prévient et propose d’effectuer plutôt la modification dans une copie.
