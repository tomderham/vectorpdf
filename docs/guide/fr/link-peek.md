# Prévisualiser des liens avec Link Peek

Les documents techniques regorgent de références : « see Equation 3 », « as shown in Figure 2 », « [14] ». Link Peek vous montre la cible là où vous êtes, pour que vous ne perdiez pas votre page.

## Jeter un coup d'œil à un lien

- Placez le pointeur sur un lien, puis **maintenez la touche ⌘ enfoncée**. Relâchez-la pour fermer l’aperçu.
- Ou effectuez un **clic forcé** sur le lien avec un trackpad Force Touch. L’aperçu se ferme lorsque vous relâchez.

L’aperçu montre ce qui est utile selon le type de cible : quelques lignes pour une équation, le premier paragraphe pour une section, le haut d’un tableau ou d’une figure.

## Suivre un lien

Cliquez sur un lien pour accéder à sa cible. Choisissez Go > Back (⌘[) pour revenir.

Les liens web s’ouvrent dans votre navigateur. Vous pouvez choisir lequel avec le réglage [Open Links In](settings.md).

## Ouvrir la cible dans une nouvelle fenêtre

Pour garder la cible à l’écran à côté de votre page :

- **⌘-cliquez** sur le lien.
- Ou cliquez avec le bouton droit sur le lien, puis choisissez **Open in New Window**.

Vous pouvez aussi cliquer avec le bouton droit sur du texte ou un endroit de la page pour ouvrir cet emplacement dans une nouvelle fenêtre. Consultez [Onglets et fenêtres](tabs-and-windows.md#anchor-windows).

## Conserver la cible

Cliquez avec le bouton droit sur un lien, puis choisissez **Create Anchor** pour enregistrer sa cible comme [ancre](anchors.md), ou **Create Anchor and Open in New Window** pour faire les deux.
