# Onglets et fenêtres

## Onglets

VectorPDF utilise les onglets de fenêtre standard de macOS.

- **Nouvel onglet :** appuyez sur ⌘T, ou cliquez sur le bouton + de la barre d’onglets.
- **Ouvrir un PDF dans un nouvel onglet :** appuyez sur ⌥⌘O, ou faites-le glisser sur un document ouvert.
- **Nouvelle fenêtre :** appuyez sur ⌘N pour ouvrir une fenêtre vide, ou sur ⌘O pour ouvrir un PDF dans une nouvelle fenêtre.
- **Changer d’onglet :** appuyez sur ⇧⌘] pour l’onglet suivant et sur ⇧⌘[ pour le précédent (Go > Next Tab et Go > Previous Tab). ⌃Tab et ⇧⌃Tab fonctionnent aussi.

Pour enregistrer les onglets ouverts sous forme de groupe, cliquez avec le bouton droit sur le titre du document, puis choisissez Save All Open Tabs as a Group. Consultez [Favorites et Tab Groups](favorites-and-tab-groups.md).

Regrouper des documents liés dans les onglets d’une même fenêtre permet aussi à VectorPDF de [suivre les références entre eux](cross-document-references.md).

## Trouver une fenêtre ouverte

Le menu Window et l’icône de VectorPDF dans le Dock listent vos fenêtres ouvertes, avec les onglets de chacune.

## Fenêtres d’ancre {#anchor-windows}

Vous pouvez ouvrir n’importe quel endroit d’un document dans sa propre petite fenêtre, pour garder une figure ou une définition sous les yeux pendant votre lecture :

- ⌘-cliquez sur un lien.
- Cliquez avec le bouton droit sur un lien, une sélection, un endroit de la page, un résultat de recherche ou une entrée du plan, puis choisissez **Open in New Window**.

Ces fenêtres comportent une bannière en haut. Cliquez dessus pour revenir à l’endroit affiché. Cliquez sur **Close all Child Windows** dans la bannière pour fermer toutes les fenêtres ouvertes depuis le même document. Elles se ferment aussi lorsque vous fermez le document dont elles proviennent.

VectorPDF n’ouvre pas de doublon : si l’endroit est déjà ouvert dans une fenêtre, cette fenêtre passe au premier plan.
