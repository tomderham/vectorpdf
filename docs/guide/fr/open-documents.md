# Ouvrir des documents

## Ouvrir un PDF

- **Dans une nouvelle fenêtre :** choisissez File > Open PDF, ou appuyez sur ⌘O.
- **Dans un nouvel onglet :** choisissez File > Open PDF in New Tab, ou appuyez sur ⌥⌘O.
- **Depuis le Finder :** cliquez avec le bouton droit sur un PDF, puis choisissez Open With > VectorPDF (Ouvrir avec dans un Finder en français). Pour ouvrir tous les PDF dans VectorPDF, sélectionnez un PDF, choisissez File > Get Info dans le Finder (Fichier > Lire les informations en français), modifiez « Open with » (Ouvrir avec), puis cliquez sur Change All (Tout modifier).
- **Par glissement :** faites glisser un PDF sur l’écran Start pour l’y ouvrir, ou sur un document ouvert pour l’ouvrir dans un nouvel onglet.
- **Depuis une liste :** choisissez File > Open Recent, ou utilisez le menu [Favorites](favorites-and-tab-groups.md). Dans l’écran Start, cliquez avec le bouton droit sur un document pour l’ouvrir dans un nouvel onglet ou une nouvelle fenêtre.

## PDF protégés par mot de passe

VectorPDF demande le mot de passe lorsque vous ouvrez un PDF protégé. Consultez [Mots de passe et chiffrement](passwords.md).

## PDF dans le stockage en ligne

VectorPDF reconnaît les fichiers dans iCloud Drive, Google Drive, Dropbox, OneDrive et Box. Si un fichier n’est pas encore sur votre Mac, VectorPDF le télécharge avant de l’ouvrir et affiche la progression. Si le téléchargement n’aboutit pas, un message s’affiche et vous pouvez réessayer une fois connecté.

## Lorsqu’un fichier change

VectorPDF surveille chaque fichier ouvert. Si une autre app modifie le fichier, le document se recharge tout seul. C’est utile si vous générez un PDF depuis LaTeX ou un autre outil et que vous voulez le garder ouvert.

Si vous avez des modifications non enregistrées, VectorPDF vous demande si vous voulez choisir **Reload from Disk**, qui perd vos modifications, ou **Keep My Changes**.

Si vous déplacez ou renommez un fichier dans le Finder, le document ouvert le suit.

## Fermer un document

Fermez un onglet ou une fenêtre comme d’habitude. S’il y a des modifications non enregistrées, VectorPDF vous demande s’il faut les enregistrer. VectorPDF retient [où vous en étiez](reading-positions.md) pour la prochaine fois.
