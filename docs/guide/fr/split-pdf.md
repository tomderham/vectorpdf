# Scinder un PDF

1. Choisissez File > Split PDF.
2. Sous Split Method, choisissez une option :
   - **Every N Pages :** un nouveau fichier toutes les N pages.
   - **Single Pages :** un fichier par page.
   - **Page Ranges :** saisissez des numéros ou des plages de pages séparés par des virgules, par exemple `1-5, 6-12, 13-20`.
3. Sous Save Location, cliquez sur Choose pour sélectionner un dossier.
4. Sous File Naming, saisissez un préfixe et choisissez un style : Part Number ou Page Range. Output Preview montre les fichiers qui seront créés.
5. Cliquez sur Split PDF.

Votre document d’origine n’est pas modifié. Une fois la scission terminée, cliquez sur Reveal in Finder pour voir les fichiers.
