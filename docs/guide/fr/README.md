# Guide d’utilisation de VectorPDF

pour macOS

VectorPDF est un lecteur de PDF rapide, conçu pour les articles techniques, les spécifications, les contrats et les plans. Maintenez la touche Commande sur une référence pour voir ce vers quoi elle pointe, sans perdre votre page. Vous pouvez aussi annoter, mesurer, caviarder et réorganiser vos PDF, le tout sur votre Mac.

> **Remarque :** Ce guide a été traduit automatiquement de l’anglais. L’interface de VectorPDF n’existe qu’en anglais : les noms des menus et des boutons sont donc indiqués en anglais, tels qu’ils apparaissent à l’écran.
