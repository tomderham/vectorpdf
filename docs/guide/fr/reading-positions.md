# Positions de lecture, iCloud et Handoff

## Reprendre là où vous vous étiez arrêté

VectorPDF retient la dernière page et le dernier zoom de chaque document, et les rétablit lorsque vous le rouvrez.

## Synchroniser avec vos autres Mac

Si vous êtes connecté à iCloud, votre position de lecture et vos [ancres](anchors.md) vous suivent sur vos autres Mac utilisant le même compte Apple. Cela fonctionne pour les fichiers dans iCloud Drive et les dossiers de stockage en ligne, même si le dossier se trouve à un emplacement différent sur chaque Mac.

Vos documents et leur texte ne sont pas téléversés. Pour garder ces informations sur votre Mac, désactivez **Sync reading positions with iCloud** dans [Settings](settings.md). Cela supprime aussi les entrées de VectorPDF dans iCloud.

> **Remarque :** La synchronisation iCloud dépend de la façon dont une copie de VectorPDF a été compilée : elle peut donc ne pas être disponible si vous avez compilé VectorPDF vous-même.

## Handoff

Lorsque Handoff est activé, vous pouvez poursuivre votre lecture sur un autre Mac. VectorPDF propose le document et la page où vous êtes, et les ouvre si le fichier est disponible sur ce Mac.

Pour activer ou désactiver Handoff, consultez les réglages AirDrop et Handoff dans Réglages Système.
