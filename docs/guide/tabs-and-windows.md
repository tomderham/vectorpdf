# Tabs and windows

## Tabs

VectorPDF uses standard macOS window tabs.

- **New tab:** press ⌘T, or click the + button in the tab bar.
- **Open a PDF in a new tab:** press ⌥⌘O, or drag it onto an open document.
- **Open a document in another window:** ⌘N opens a new window.

To save the open tabs as a group, right-click the document's title, then choose Save All Open Tabs as a Group. See [Favorites and Tab Groups](favorites-and-tab-groups.md).

Keeping related documents as tabs of one window also lets VectorPDF [follow references between them](cross-document-references.md).

## Find an open window

The Window menu and the VectorPDF icon in the Dock list your open windows, with the tabs of each one.

## Anchor windows

You can open any place in a document in a small window of its own, to keep a figure or definition in view while you read:

- ⌘-click a link.
- Right-click a link, selection, place on the page, search result or outline entry, then choose **Open in New Window**.

These windows have a banner at the top. Click it to jump back to the place it shows. Click **Close all Child Windows** in the banner to close every window opened from the same document. They also close when you close the document they came from.

VectorPDF doesn't open a duplicate: if the place is already open in a window, it brings that window forward.
