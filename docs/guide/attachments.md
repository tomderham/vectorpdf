# Files attached to a PDF

A PDF can carry other files inside it: a spreadsheet with a report, a CAD model with a drawing set, or the data of an electronic invoice. When a document has attachments, the Attachments tab (a paperclip) appears at the top of the sidebar. A document of one or two pages with attachments opens on the Attachments tab.

Each attachment shows its name and, when the PDF includes them, its description, size and the page it's attached to. Hold the pointer over one to see what kind of file it is and its date.

| To | Do this |
| --- | --- |
| Preview an attachment | Double-click it, or select it and press Space |
| Preview the next or previous one | While Quick Look is open, press the Down Arrow or Up Arrow key |
| Open it in its app | Right-click it and choose Open |
| Save a copy | Right-click it and choose Save As…, or drag it to the Finder |
| Save them all | Click Save All… at the top of the tab, then choose a folder |
| Go to its page | Right-click it and choose Show on Page |

> **Warning:** An attachment can be any kind of file, including an app or a script. Open only files you trust. VectorPDF marks the files it takes out of a PDF as downloaded, so macOS checks apps and scripts before they run, as it does for files from the web.

## Electronic invoices

ZUGFeRD and Factur-X invoices carry their data in an XML file, usually named `factur-x.xml` or `zugferd-invoice.xml`. It's listed with the other attachments, so you can save it for your accounting software. VectorPDF doesn't show the invoice's details itself.
