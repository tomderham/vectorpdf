# VectorPDF 사용 설명서

macOS용

VectorPDF는 기술 논문, 사양서, 계약서, 도면을 위한 빠른 PDF 리더입니다. 참조 위에서 Command 키를 길게 누르면 지금 보고 있는 페이지를 벗어나지 않고 참조 대상을 확인할 수 있습니다. PDF에 마크업하고, 측정하고, 내용을 가리고, 페이지를 재구성하는 작업도 모두 Mac에서 할 수 있습니다.

> **참고:** 이 설명서는 영어 원문을 기계 번역한 것입니다. VectorPDF의 인터페이스는 영어로만 제공되므로 메뉴와 버튼 이름은 화면에 표시되는 그대로 영어로 표기했습니다.
