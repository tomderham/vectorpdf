# 페이지 재배열하기

페이지 변경은 사이드바의 [축소판](outline-and-thumbnails.md) 보기에서 합니다. 변경 사항은 [저장](save.md)할 때 파일에 반영됩니다.

## 페이지 선택하기

축소판을 클릭합니다. 페이지를 하나씩 추가하려면 ⌘ 키를, 범위를 선택하려면 ⇧ 키를 길게 누릅니다.

## 페이지 이동하기

선택한 축소판을 새로운 위치로 드래그합니다. 페이지가 들어갈 위치에 선이 표시됩니다. 페이지를 오른쪽 클릭한 다음 Move Page Up 또는 Move Page Down을 선택할 수도 있습니다.

## 기타 페이지 명령

축소판 또는 선택한 축소판을 오른쪽 클릭한 다음 선택합니다.

- **Rotate Clockwise, Rotate Counterclockwise 또는 Rotate 180°:** PDF 자체의 페이지를 회전합니다. [도구 막대의 Rotate 버튼](zoom-and-layout.md#rotate-the-view)과는 다릅니다.
- **Duplicate Page:** 선택한 페이지 바로 뒤에 사본을 추가합니다. File > Duplicate Pages(⇧⌘D)를 선택할 수도 있습니다. 이 명령은 선택한 축소판에 현재 페이지가 포함되어 있으면 선택한 축소판을 복사하고, 그렇지 않으면 현재 페이지를 복사합니다.
- **Insert Blank Page.**
- **Insert Pages from PDF:** 다른 PDF의 페이지를 추가합니다. File > Insert Pages from PDF(⌥⌘I)를 선택할 수도 있습니다.
- **Save selected page as a PDF:** 페이지를 새로운 파일로 추출합니다.
- **Delete Page.**

## 앵커를 만든 경우

페이지를 추가, 삭제 또는 이동하면 [앵커](anchors.md)가 잘못된 위치를 가리키게 될 수 있습니다. VectorPDF는 경고를 표시하고 대신 사본에서 변경하도록 제안합니다.
