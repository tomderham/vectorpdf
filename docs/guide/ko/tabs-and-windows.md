# 탭과 윈도우

## 탭

VectorPDF는 macOS의 표준 윈도우 탭을 사용합니다.

- **새로운 탭:** ⌘T 키를 누르거나 탭 막대의 + 버튼을 클릭합니다.
- **새로운 탭에서 PDF 열기:** ⌥⌘O 키를 누르거나 PDF를 열려 있는 문서 위로 드래그합니다.
- **새로운 윈도우:** ⌘N 키를 누르면 빈 윈도우가 열리고, ⌘O 키를 누르면 새로운 윈도우에서 PDF가 열립니다.

열려 있는 탭을 그룹으로 저장하려면 문서 제목을 오른쪽 클릭한 다음 Save All Open Tabs as a Group을 선택합니다. [즐겨찾기와 탭 그룹](favorites-and-tab-groups.md)을 참조하십시오.

관련 문서를 윈도우 하나의 탭으로 열어 두면 VectorPDF가 [문서 간 참조를 따라갈 수 있습니다](cross-document-references.md).

## 열려 있는 윈도우 찾기

Window 메뉴와 Dock의 VectorPDF 아이콘에 열려 있는 윈도우가 각 윈도우의 탭과 함께 나열됩니다.

## 앵커 윈도우 {#anchor-windows}

문서의 어느 위치든 별도의 작은 윈도우로 열어, 읽는 동안 그림이나 정의를 계속 볼 수 있습니다.

- 링크를 ⌘-클릭합니다.
- 링크, 선택 영역, 페이지의 특정 위치, 검색 결과 또는 개요 항목을 오른쪽 클릭한 다음 **Open in New Window**를 선택합니다.

이러한 윈도우의 상단에는 배너가 있습니다. 배너를 클릭하면 표시된 위치로 돌아갑니다. 배너에서 **Close all Child Windows**를 클릭하면 같은 문서에서 연 윈도우가 모두 닫힙니다. 원본 문서를 닫을 때도 함께 닫힙니다.

VectorPDF는 중복된 윈도우를 열지 않습니다. 해당 위치가 이미 윈도우에 열려 있으면 그 윈도우를 앞으로 가져옵니다.
