# 프린트하기

File > Print를 선택하거나 ⌘P 키를 누릅니다.

프린트 대화상자에서 PDF Options를 선택하면 다음 항목이 표시됩니다.

- **Auto Rotate:** 용지에 맞게 페이지를 회전합니다.
- **Scale to Fit:** 각 페이지를 용지에 맞춥니다.
- **Scale:** 입력한 비율로 프린트합니다.

VectorPDF는 화면 표시에 사용하는 것과 같은 엔진으로 프린트하므로 출력물이 화면에 보이는 것과 일치합니다.
