# 물량 산출표

물량 산출표는 문서의 모든 측정을 페이지, 유형, 값, 축척과 함께 나열하고 길이와 면적의 합계를 보여 주는 표입니다.

[Measurement 도구 막대](measure.md)에서 **Takeoff Table**을 클릭합니다.

- **Copy Table**은 스프레드시트에 바로 붙여 넣을 수 있도록 표를 복사합니다.
- **Export CSV**는 표를 파일로 저장합니다.

[레이어](layers.md)가 있는 문서에서는 표에 각 측정의 레이어도 표시되고, 가려진 레이어의 측정은 제외됩니다. 따라서 공종별로 하나씩 합계를 낼 수 있습니다.

합계는 모든 페이지의 길이(치수 및 둘레)와 면적을 더한 값입니다. 각 측정에는 해당 페이지의 축척이 사용되며, 합계는 첫 번째 측정의 단위로 표시됩니다.
