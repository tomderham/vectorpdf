# 오른쪽 클릭 메뉴

오른쪽 클릭하거나 Control-클릭하면 포인터 아래에 있는 항목에 대한 명령이 표시됩니다. 클릭하는 위치에 따라 표시되는 메뉴가 달라집니다.

## 문서에서

| 오른쪽 클릭 대상 | 명령 |
| --- | --- |
| 선택한 텍스트 | Copy Text, Look Up, Translate Selection, Start Speaking 또는 Stop Speaking, Highlight, Underline, Strikethrough, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| 선택한 영역 | Copy Extracted Text, Copy Screenshot, Save Screenshot As, Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| 링크 | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| 하이라이트, 밑줄 또는 취소선 | Comments… 및 해당하는 Remove 명령 |
| 텍스트 상자 | Comments…, Edit Text Box 및 삭제 명령 |
| 설명선 | Comments…, Edit Callout Note, Line Ending 및 삭제 명령 |
| 메모 또는 리비전 클라우드의 윤곽선 | Comments… 및 삭제 명령 |
| 그린 항목, 스탬프 또는 측정 | Comments… 및 삭제 명령 |
| 이전에 문서에 저장되었거나 다른 앱에서 만든 주석 | Comments… 및 페이지의 다른 위치에 대한 명령 |
| 페이지의 기타 위치 | Create Anchor, Create Anchor and Open in New Window, Open in New Window |

일반 텍스트 참조를 오른쪽 클릭했을 때 다른 탭에 관련 문서가 열려 있으면 메뉴에 [참조 대상으로 이동하거나 찾는](cross-document-references.md) 명령도 표시됩니다.

## 사이드바에서

| 오른쪽 클릭 대상 | 명령 |
| --- | --- |
| 개요 항목 | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| 축소판 | Rotate Clockwise, Rotate Counterclockwise, Rotate 180°, Duplicate Page, Insert Blank Page, Insert Pages from PDF, Save selected page as a PDF, Move Page Up, Move Page Down, Delete Page. 여러 페이지를 선택하면 Delete 3 Pages와 같이 명령에 페이지 수가 표시됩니다. [페이지 재배열하기](pages.md)를 참조하십시오. |
| 검색 결과 | Create Anchor, Create Anchor and Open in New Window, Open in New Window |
| 앵커 | Open in New Window 또는 Close Window, Copy Text, Copy Screenshot, Delete Anchor |

## 윈도우에서

| 오른쪽 클릭 대상 | 명령 |
| --- | --- |
| 문서 제목 또는 도구 막대의 빈 부분 | Favorites에 추가 또는 제거, Save All Open Tabs as a Group, Update Group “이름” with Open Tabs, 내 Tab Groups 및 Favorites |
| Start 화면의 행 | Open, Open in New Tab, Open in New Window, Show in Finder, Remove 또는 Delete |

일부 명령은 해당하는 경우에만 나타납니다. 예를 들어 Save All Open Tabs as a Group을 사용하려면 탭이 두 개 이상 있어야 하며, 앵커에서 연 윈도우에서는 앵커 명령을 사용할 수 없습니다.
