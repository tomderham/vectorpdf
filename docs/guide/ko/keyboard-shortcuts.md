# 키보드 단축키

이러한 명령 중 다수는 오른쪽 클릭 메뉴에서도 사용할 수 있으며, 아래에 표시되어 있습니다. [오른쪽 클릭 메뉴](right-click-menus.md)를 참조하십시오.

## 문서

| 동작 | 단축키 |
| --- | --- |
| New Window | ⌘N |
| New Tab | ⌘T |
| Open PDF | ⌘O |
| Open PDF in New Tab | ⌥⌘O |
| Compare Documents | File 메뉴, 또는 문서 제목을 오른쪽 클릭하고 Compare With 선택 |
| Insert Pages from PDF | ⌥⌘I 또는 축소판을 오른쪽 클릭 |
| Duplicate Pages | ⇧⌘D 또는 축소판을 오른쪽 클릭 |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Save Encrypted with Password | ⌥⌘S |
| Export Annotations Summary | ⇧⌘E |
| Show in Finder | ⇧⌘R |
| Print | ⌘P |
| Document Properties | ⌘I |
| Add to or Remove from Favorites | ⌘D 또는 문서 제목을 오른쪽 클릭 |
| Settings | ⌘, |
| VectorPDF Help | ⇧⌘? |

## 탐색

| 동작 | 단축키 |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Previous Page | ⌥Up Arrow, ⌥Left Arrow 또는 Left Arrow |
| Next Page | ⌥Down Arrow, ⌥Right Arrow 또는 Right Arrow |
| First Page | ⌘Up Arrow 또는 ⌘Home |
| Last Page | ⌘Down Arrow 또는 ⌘End |
| 이전 또는 다음 변경 사항(문서 비교 중) | ⌥⌘Up Arrow 또는 ⌥⌘Down Arrow, 또는 Changes 탭의 화살표 |
| 페이지 단위로 앞으로 또는 뒤로 이동 | Space 또는 ⇧Space |
| Next Tab | ⇧⌘] 또는 ⌃Tab |
| Previous Tab | ⇧⌘[ 또는 ⇧⌃Tab |

## 보기

| 동작 | 단축키 |
| --- | --- |
| Zoom In | ⌘+ |
| Zoom Out | ⌘− |
| Actual Size (100%) | ⌘1 |
| Zoom to Fit Width | ⌘9 |
| Zoom to Fit Window | ⌥⌘0 |
| Two Pages 또는 Single Page | ⌥⌘2 |
| Show or Hide Markup Toolbar | ⇧⌘A |
| Show or Hide Measurement Toolbar | ⇧⌘M |
| Show or Hide Redact Toolbar | ⌥⌘R |

## 검색 및 텍스트

| 동작 | 단축키 | 오른쪽 클릭 |
| --- | --- | --- |
| Find | ⌘F | |
| Find Next | ⌘G 또는 검색 필드에서 Return | |
| Find Previous | ⇧⌘G 또는 검색 필드에서 ⇧Return | |
| Copy | ⌘C | 선택한 텍스트 |
| Highlight | ⇧⌘H | 선택한 텍스트 |
| Underline | ⇧⌘U | 선택한 텍스트 |
| Strikethrough | ⇧⌘X | 선택한 텍스트 |
| Stop Speaking | ⌥⌘. | 선택한 텍스트 |
| Add Anchor | ⌘B | 선택 영역, 링크 또는 페이지, Create Anchor로 표시 |

## 마우스 및 트랙패드

| 동작 | 제스처 |
| --- | --- |
| 링크 미리 보기 | 링크 위에서 ⌘ 키를 길게 누르기 또는 강한 클릭 |
| 새로운 윈도우에서 링크 열기 | ⌘-클릭 |
| PDF의 특정 위치에 해당하는 LaTeX 소스 열기 | ⇧⌘을 누른 채 클릭([SyncTeX 파일](latex.md)이 있는 PDF에서) |
| 단어 선택하기 | 이중 클릭 |
| 줄 선택하기 | 세 번 클릭 |
| 영역 선택하기 | ⌥-드래그 |
| 주석의 코멘트 열기 | 이중 클릭(텍스트 상자와 설명선 제외) |
| 확대/축소 | 손가락 오므리기/벌리기 |

## 주석 및 측정

| 동작 | 단축키 | 오른쪽 클릭 |
| --- | --- | --- |
| 주석 변경 실행 취소 또는 다시 실행 | ⌘Z 또는 ⇧⌘Z | |
| 선택한 텍스트 상자 또는 설명선 편집하기 | Return | 해당 주석 |
| 선택한 주석 삭제하기 | Delete | 해당 주석 |
| 선택한 주석 이동하기 | Arrow keys, 또는 10포인트씩 이동하려면 ⇧Arrow keys | |
| 둘레 또는 면적 측정 완료하기 | Return | |
| 선 하나에 대해 Ortho Lock(0°, 45° 또는 90°) 전환하기 | ⇧ 키를 길게 누르기 | |
| 정사각형이나 원, 또는 45° 배수 각도의 선 그리기 | Shapes 도구로 드래그하는 동안 ⇧ 키 누르기 | |
| 취소 또는 현재 도구 종료하기 | Escape | |
