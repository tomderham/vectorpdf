# 문서에 관해 질문하기

Agent는 열려 있는 문서에 관한 질문에 답하고, 답변의 근거가 된 구절을 보여 줍니다. macOS 26 이상이 필요합니다.

## 질문하기

1. 사이드바에서 Ask About This Document 탭을 클릭합니다. 처음에는 VectorPDF가 Mac에서 문서를 색인하고 진행 상황을 표시합니다.
2. 질문을 입력한 다음 Return 키를 누르거나 Ask를 클릭합니다. 줄을 바꾸려면 ⇧Return 키를 누릅니다.

답변 아래에서 **Sources**를 클릭하면 답변에 사용된 구절을 페이지와 함께 볼 수 있습니다. 답변에서 인용한 구절에는 **Cited**가 표시됩니다. 구절을 클릭하면 해당 위치로 이동합니다.

후속 질문을 할 수 있습니다. 처음부터 다시 시작하려면 **New Conversation**을 클릭합니다.

> **참고:** Agent는 실수할 수 있습니다. 중요한 내용은 출처를 확인하십시오.

## 답변을 생성할 수 없는 경우

Mac에서 답변 생성을 사용할 수 없으면 Agent는 대신 가장 일치하는 구절을 보여 줍니다. [Agent의 답변 방식 선택하기](agent-engines.md)를 참조하십시오.

## Agent 끄기

[Settings](settings.md)에서 **Use Agent**를 끕니다. 사이드바에서 해당 탭이 사라집니다.
