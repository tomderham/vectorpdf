# 문서 열기

## PDF 열기

- **새로운 윈도우에서 열기:** File > Open PDF를 선택하거나 ⌘O 키를 누릅니다.
- **새로운 탭에서 열기:** File > Open PDF in New Tab을 선택하거나 ⌥⌘O 키를 누릅니다.
- **Finder에서 열기:** PDF를 오른쪽 클릭한 다음 Open With > VectorPDF(다음으로 열기)를 선택합니다. 모든 PDF를 VectorPDF로 열려면 PDF를 선택하고 Finder에서 File > Get Info(파일 > 정보 가져오기)를 선택하고 “Open with”(다음으로 열기)를 변경한 다음 Change All(모두 변경)을 클릭합니다.
- **드래그하여 열기:** PDF를 Start 화면으로 드래그하면 그 자리에서 열리고, 열려 있는 문서 위로 드래그하면 새로운 탭에서 열립니다.
- **목록에서 열기:** File > Open Recent를 선택하거나 [Favorites](favorites-and-tab-groups.md) 메뉴를 사용합니다. Start 화면에서 문서를 오른쪽 클릭하면 새로운 탭이나 윈도우에서 열 수 있습니다.

## 전자책, 만화 및 XPS 문서

VectorPDF는 EPUB 및 FictionBook(FB2) 전자책, CBZ 만화 아카이브, XPS 문서도 PDF와 같은 방법으로 엽니다. 전자책은 읽기 좋게 페이지로 배치됩니다.

이러한 문서는 읽고, 목차를 따라가고, 검색하고, 텍스트를 선택하여 복사하고, [앵커](anchors.md)를 추가할 수 있습니다. 읽기 전용으로 열리므로 VectorPDF에서 저장할 수 없습니다. 따라서 마크업, 측정, 가리기, 페이지 편집은 사용할 수 없으며 Save는 흐리게 표시됩니다.

## 암호로 보호된 PDF

보호된 PDF를 열면 VectorPDF에서 암호를 묻습니다. [암호 및 암호화](passwords.md)를 참조하십시오.

## 클라우드 저장 공간의 PDF

VectorPDF는 iCloud Drive, Google Drive, Dropbox, OneDrive 및 Box에 있는 파일을 인식합니다. 파일이 아직 Mac에 없으면 VectorPDF가 파일을 다운로드한 후 열며, 진행 상황을 보여 줍니다. 다운로드가 완료되지 않으면 메시지가 표시되며, 연결되면 다시 시도할 수 있습니다.

## 파일이 변경된 경우

VectorPDF는 열려 있는 각 파일을 감시합니다. 다른 앱에서 파일을 변경하면 문서가 자동으로 다시 로드됩니다. LaTeX나 다른 도구로 PDF를 생성하면서 문서를 계속 열어 두려는 경우에 유용합니다.

저장하지 않은 변경 사항이 있으면 VectorPDF에서 변경 사항을 잃게 되는 **Reload from Disk**를 선택할지 **Keep My Changes**를 선택할지 묻습니다.

Finder에서 파일을 이동하거나 이름을 변경하면 열려 있는 문서도 이를 따라갑니다.

## 문서 닫기

평소와 같이 탭이나 윈도우를 닫습니다. 저장하지 않은 변경 사항이 있으면 VectorPDF에서 저장할지 묻습니다. VectorPDF는 다음에 사용할 수 있도록 [읽던 위치](reading-positions.md)를 기억합니다.
