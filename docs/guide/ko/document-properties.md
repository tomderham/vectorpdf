# 문서 속성

File > Document Properties를 선택하거나 ⌘I 키를 누릅니다. 상단에서 탭을 선택합니다.

- **General:** 제목, 작성자, 주제, 키워드, 날짜, 문서를 만든 응용 프로그램, 파일 위치 및 저장 공간.
- **Security:** 문서의 암호화 및 프린트, 복사, 변경, 주석, 양식 작성, 손쉬운 사용을 위한 추출, 페이지 조합의 허용 여부.
- **Page Geometry:** 모든 페이지의 MediaBox, CropBox, BleedBox, TrimBox, ArtBox(points, inches 또는 millimeters 단위).
- **Fonts:** 문서의 서체, 서체 유형 및 인코딩, 포함 여부. 서체를 찾으려면 필터 필드를 사용합니다.
