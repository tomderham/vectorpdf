# 문제 해결

## 텍스트를 선택하거나, 링크를 따라가거나, 마크업 도구를 사용할 수 없는 경우

보기가 회전되어 있거나 Two-Page Mode가 아닌지 확인합니다. 이러한 기능은 회전 없는 Single Page 보기에서만 작동합니다. [확대/축소, 회전 및 페이지 레이아웃](zoom-and-layout.md)을 참조하십시오.

Markup 또는 Measurement 도구가 활성화되어 있지 않은지도 확인합니다. 텍스트 선택으로 돌아가려면 Escape 키를 누릅니다.

## 검색 결과가 없는 경우

- 스캔한 페이지일 수 있습니다. [OCR로 스캔한 페이지 검색하기](scanned-pages.md)를 참조하십시오.
- [검색 옵션](search.md#search-options)에서 Match Case와 Whole Word가 꺼져 있고 Smart Search가 켜져 있는지 확인합니다.
- 표시가 텍스트 중간에 끼어 있으면 [무시할 패턴](search.md#ignore-clutter-in-the-text)을 추가합니다.

## ⌘ 키를 길게 눌러도 미리보기가 표시되지 않는 경우

Link Peek은 문서의 링크와, 다른 탭에 열려 있는 문서로 연결되는 웹 링크에서 작동합니다. 일반 텍스트 참조는 링크가 아니므로 대신 오른쪽 클릭합니다. [문서 간 참조](cross-document-references.md)를 참조하십시오.

VectorPDF 윈도우가 활성 윈도우여야 합니다.

## 다른 문서에 대한 참조를 찾을 수 없는 경우

다른 문서를 같은 윈도우의 탭으로 엽니다. 별도의 윈도우는 검색되지 않습니다.

## 클라우드 문서가 열리지 않는 경우

인터넷 연결을 확인하고 Finder에서 파일이 다운로드되는지 확인한 다음 다시 시도합니다.

## Agent를 사용할 수 없거나 구절만 표시되는 경우

Agent를 사용하려면 macOS 26 이상이 필요하며, 기기 내에서 답변을 작성하려면 Apple Intelligence가 켜져 있고 준비되어 있어야 합니다. 색인 생성에 실패하면 Ask About This Document 탭에서 Retry를 클릭합니다. [Agent의 답변 방식 선택하기](agent-engines.md)를 참조하십시오.

## 온라인 모델이 응답하지 않는 경우

[Settings](settings.md)에서 API 키와 모델을 확인하고, 해당 서비스 계정에 크레딧이 있는지 확인합니다. 서비스에 문제가 있으면 VectorPDF가 기기 내에서 답변합니다.

## 변경 사항이 사라진 경우

변경 사항은 [저장](save.md)해야 합니다. 저장하지 않은 변경 사항이 있는 동안 다른 앱에서 파일을 변경한 경우 Reload from Disk를 선택하면 변경 사항이 버려집니다.

## 도움말에 이 설명서가 표시되지 않는 경우

Tips는 VectorPDF가 응용 프로그램 폴더에 있을 때만 이 설명서를 표시할 수 있습니다. VectorPDF를 해당 폴더로 옮긴 다음 Help > VectorPDF Help를 다시 선택합니다.

## 추가 도움 받기

[GitHub](https://github.com/tomderham/vectorpdf/issues)에서 문제를 보고하거나 질문합니다. 공유할 수 있다면 샘플 PDF를 함께 첨부하면 도움이 됩니다.
