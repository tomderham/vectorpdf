# 텍스트 선택, 복사 및 찾아보기

## 텍스트 선택하기

- 텍스트 위로 **드래그**합니다. 선택 영역은 읽는 순서를 따르므로 다단 레이아웃에서는 한 단 안에 머물고 여백의 줄 번호는 건너뜁니다. 여러 페이지에 걸쳐 선택할 수도 있습니다.
- **이중 클릭**하면 단어가 선택되고, **세 번 클릭**하면 줄이 선택됩니다.
- **⌥ 키를 누른 채 드래그**하면 그림이나 표와 같은 사각형 영역이 선택됩니다.

선택을 해제하려면 Escape 키를 누릅니다.

## 복사하기

⌘C 키를 누르거나, 선택한 텍스트를 오른쪽 클릭하고 Copy Text를 선택합니다.

사각형 선택 영역을 오른쪽 클릭하면 더 많은 옵션을 사용할 수 있습니다.

- **Copy Extracted Text**는 영역 안의 텍스트를 복사합니다.
- **Copy Screenshot**은 영역을 이미지로 복사합니다.
- **Save Screenshot As**는 영역을 이미지 파일로 저장합니다.

## 찾아보기 및 번역하기

선택한 텍스트를 오른쪽 클릭한 다음 선택합니다.

- **Look Up**: 사전 정의를 봅니다.
- **Translate Selection**: 선택한 텍스트를 번역합니다.

## 텍스트 소리 내어 읽기

텍스트를 선택한 다음 Edit > Speech > Start Speaking을 선택하거나, 오른쪽 클릭하고 Start Speaking을 선택합니다. 중단하려면 Stop Speaking을 선택하거나 ⌥⌘. (Option-Command-마침표) 키를 누릅니다.

## 기타 동작

선택한 텍스트를 오른쪽 클릭할 때 나타나는 메뉴에는 텍스트를 [하이라이트, 밑줄 또는 취소선으로 표시](text-markup.md)하거나, [앵커를 생성](anchors.md)하거나, 선택 영역을 새로운 윈도우에서 여는 명령도 있습니다.
