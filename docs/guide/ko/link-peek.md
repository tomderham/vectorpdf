# Link Peek으로 링크 미리 보기

기술 문서에는 “see Equation 3”, “as shown in Figure 2”, “[14]”와 같은 참조가 가득합니다. Link Peek은 현재 위치에서 대상을 보여 주므로 읽던 곳을 놓치지 않습니다.

## 링크 미리 보기

- 링크 위에 포인터를 올려놓은 다음 **⌘ 키를 길게 누릅니다**. 키에서 손을 떼면 미리보기가 닫힙니다.
- 또는 Force Touch 트랙패드에서 링크를 **강한 클릭**합니다. 손을 떼면 미리보기가 닫힙니다.

미리보기에는 대상의 종류에 따라 유용한 내용이 표시됩니다. 수식은 몇 줄, 섹션은 첫 단락, 표나 그림은 윗부분이 표시됩니다.

## 링크 따라가기

링크를 클릭하면 대상으로 이동합니다. 돌아가려면 Go > Back(⌘[)을 선택합니다.

웹 링크는 브라우저에서 열립니다. [Open Links In](settings.md) 설정에서 사용할 브라우저를 선택할 수 있습니다.

## 새로운 윈도우에서 대상 열기

대상을 현재 페이지 옆 화면에 띄워 두려면 다음과 같이 합니다.

- 링크를 **⌘-클릭**합니다.
- 또는 링크를 오른쪽 클릭한 다음 **Open in New Window**를 선택합니다.

텍스트나 페이지의 특정 위치를 오른쪽 클릭하여 해당 위치를 새로운 윈도우에서 열 수도 있습니다. [탭과 윈도우](tabs-and-windows.md#anchor-windows)를 참조하십시오.

## 대상 보관하기

링크를 오른쪽 클릭한 다음 **Create Anchor**를 선택하면 대상이 [앵커](anchors.md)로 저장되고, **Create Anchor and Open in New Window**를 선택하면 앵커를 저장하고 새로운 윈도우에서도 엽니다.
