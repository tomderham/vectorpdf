# 그리기, 메모, 텍스트 및 설명선 추가하기

⇧⌘A 키를 누르거나 Markup Toolbar 버튼을 클릭하여 Markup 도구 막대를 표시합니다. 도구를 선택한 다음 색상과 크기를 선택합니다. 색상을 고르려면 도구 막대 오른쪽 근처의 색상 버튼을 클릭한 다음 색상을 클릭합니다. 도구 사용을 마치려면 Escape 키를 누르거나 도구 막대의 첫 번째 도구인 Text Selection Mode를 선택합니다.

## 자유롭게 그리기

펜 도구를 선택하고 선 두께를 Thin, Medium 또는 Thick으로 설정한 다음 페이지에서 드래그합니다.

## 도형 그리기

1. Shapes 도구를 선택한 다음 Rectangle, Oval, Line or Arrow 또는 Revision Cloud를 선택합니다.
2. 선 굵기를 Thin, Medium 또는 Thick으로 설정합니다. 선의 경우 Line Ending 메뉴에서 Open Arrow, Closed Arrow, Diamond 같은 화살촉을 선택하거나, 일반 선으로 그리려면 None을 선택합니다.
3. 페이지에서 드래그합니다. 사각형이나 타원은 드래그한 영역을 채웁니다. 선은 드래그를 시작한 곳에서 멈춘 곳까지 이어지며, 끝점에 선 끝 모양이 붙습니다.

드래그하는 동안 ⇧ 키를 누르고 있으면 정사각형이나 원을 그리거나, 선을 45°의 배수 각도로 유지할 수 있습니다.

수정 구름은 변경되었거나 검토가 필요한 영역을 표시합니다. 영역 주위를 드래그하면 그린 윤곽을 따라 구름이 그려집니다. 가로질러 빠르게 직선으로 드래그하면 대신 타원형 구름이 만들어집니다.

사각형, 타원 또는 구름을 선택하거나 이동하거나 오른쪽 클릭하려면 윤곽선을 사용합니다. 그러면 안쪽의 텍스트도 계속 선택할 수 있습니다.

선을 그린 후 변경하려면 한쪽 끝을 드래그하여 그 끝만 이동하거나, 선을 선택하고 도구 막대에서 다른 선 굵기나 선 끝을 선택합니다. 오른쪽 클릭하고 Line Ending을 선택할 수도 있습니다. 사각형이나 타원의 굵기를 바꾸려면 선택한 다음 선 굵기를 선택합니다.

## 텍스트 상자 추가하기

1. 텍스트 상자 도구를 선택하고 서체 크기를 6~32포인트로 설정합니다.
2. 페이지에서 텍스트를 넣을 위치를 클릭한 다음 입력합니다.
3. 입력을 마치려면 상자 바깥쪽을 클릭하거나 Escape 키를 누릅니다.

## 설명선 추가하기

설명선은 페이지의 특정 대상을 화살표로 가리키는 텍스트 메모입니다.

1. 설명선 도구를 선택합니다.
2. 화살표가 닿을 지점을 누른 다음 메모를 놓을 위치로 드래그합니다.
3. 메모를 입력합니다.

나중에 화살표가 가리키는 지점과 메모를 각각 드래그할 수 있습니다.

열린 화살표, 마름모, 슬래시 등 선의 끝 모양을 선택하려면 그리기 전에 도구 막대의 Line Ending 메뉴를 사용합니다. 기존 설명선을 변경하려면 오른쪽 클릭하고 Line Ending을 선택합니다.

## 스티커 메모 추가하기

스티커 메모는 코멘트가 담긴 페이지의 작은 아이콘입니다.

1. 스티커 메모 도구를 선택합니다.
2. 메모를 놓을 위치를 클릭한 다음 입력합니다.
3. 다른 곳을 클릭하여 마칩니다. 비어 있는 메모는 제거됩니다.

메모를 읽거나 변경하려면 이중 클릭합니다.

## 주석에 답글 달기

메모, 하이라이트, 드로잉, 도형, 구름, 측정 등 모든 주석에는 답글을 달 수 있습니다. 주석을 이중 클릭하거나, 오른쪽 클릭하고 Comments…를 선택하면 누가 언제 만들었는지 볼 수 있습니다. 다른 사람이나 다른 앱의 주석에서도 마찬가지입니다. 여기에서 다음을 할 수 있습니다.

- Reply 필드에 입력하고 Return 키를 눌러 답글을 추가합니다.
- Status 메뉴를 사용하여 Accepted, Rejected, Cancelled 또는 Completed로 표시합니다.
- 휴지통 버튼을 클릭하여 답글과 함께 삭제합니다.

텍스트 상자나 설명선을 이중 클릭하면 대신 텍스트를 편집합니다. 코멘트를 보려면 오른쪽 클릭합니다. 파일에 원래 있던 선이나 드로잉도 오른쪽 클릭합니다.

주석에 표시되는 이름은 [설정](settings.md)의 Annotation Author에서 가져옵니다.

## 모든 주석 보기 {#see-all-annotations}

사이드바의 Comments 탭을 클릭하면 문서의 모든 주석이 페이지별로 코멘트, 상태, 답글과 함께 나열됩니다. 이 탭은 문서에 주석이 생기면 나타납니다. 주석을 클릭하면 페이지에서 해당 주석으로 이동합니다. 이중 클릭하면 그 자리에서 코멘트가 열려 답글을 달거나 상태를 바꿀 수 있습니다. 상단의 필터 버튼을 사용하면 한 가지 유형, 작성자, 상태 또는 날짜만 표시할 수 있습니다.

더 큰 윈도우에서 정렬하고 필터링할 수 있는 표를 보려면 Markup 도구 막대 오른쪽의 Annotations 버튼을 클릭합니다. 주석을 선택하고 Show on Page를 클릭하거나 이중 클릭하면 해당 페이지로 이동합니다.

## 주석 변경하기

| 원하는 작업 | 방법 |
| --- | --- |
| 텍스트 편집하기 | 텍스트 상자나 설명선을 이중 클릭하거나, 선택하고 Return 키를 누르거나, 오른쪽 클릭하고 Edit Text Box 또는 Edit Callout Note를 선택합니다. |
| 이동하기 | 드래그하거나, 선택하고 화살표 키를 누릅니다. ⇧ 키를 길게 누르면 10포인트씩 이동합니다. |
| 크기 조절 | 선택한 다음 모서리 핸들을 드래그합니다. 선이나 화살표는 한쪽 끝을 드래그합니다. |
| 삭제하기 | 선택하고 Delete 키를 누르거나, 오른쪽 클릭하고 Delete Drawing 또는 Delete Text Box와 같은 삭제 명령을 선택합니다. |

Markup 도구 막대의 Eraser를 사용하면 주석을 클릭하거나 그 위로 드래그하여 삭제할 수 있습니다. 주석을 삭제하면 답글도 함께 삭제됩니다.

### 다른 사람과 다른 앱의 주석

다른 검토자의 도형, 메모, 구름처럼 문서에 이미 있던 주석도 같은 방법으로 변경할 수 있습니다.

- 사각형, 타원, 구름, 선, 메모, 스탬프 또는 텍스트 상자를 드래그하여 이동하거나, 선택하고 화살표 키를 누릅니다. 모양, 작성자, 날짜, 답글은 그대로 유지됩니다.
- 사각형, 타원 또는 구름의 모서리 핸들을 드래그하면 크기가 바뀌고, 선의 한쪽 끝을 드래그하면 그 끝이 이동합니다.
- 주석을 선택하고 Markup 도구 막대에서 색상, 선 굵기 또는 선 끝을 선택하면 변경됩니다. 그러면 VectorPDF가 자체 스타일로 다시 그립니다.

파일에 있던 하이라이트, 밑줄, 취소선, 자유형 드로잉, 측정은 직접 만든 것처럼 제자리에 있지만, 삭제하거나 답글을 달 수는 있습니다. 다른 앱에서 만든 텍스트 상자의 텍스트는 편집할 수 없습니다.

## 변경 사항 실행 취소하기

주석의 추가, 이동, 스타일 변경 또는 삭제를 되돌리려면 Edit > Undo를 선택하거나 ⌘Z 키를 누릅니다. 다시 실행하려면 ⇧⌘Z 키를 누릅니다. 문서에 원래 있다가 삭제한 주석이나 지우개로 실수로 지운 주석을 포함해 모든 주석에서 작동합니다. 주석은 답글, 작성자, 날짜와 함께 돌아옵니다.

주석은 [저장](save.md)할 때 표준 주석으로 PDF에 저장되므로 작성자, 답글 및 상태와 함께 다른 PDF 앱에서도 나타납니다. 주석을 페이지에 고정하려면 [평면화된 PDF를 내보냅니다](export.md#flattened-pdf).
