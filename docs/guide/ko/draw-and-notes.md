# 그리기, 텍스트 및 설명선 추가하기

⇧⌘A 키를 누르거나 Markup Toolbar 버튼을 클릭하여 Markup 도구 막대를 표시합니다. 도구를 선택한 다음 색상과 크기를 선택합니다. 도구 사용을 마치려면 Escape 키를 누르거나 도구 막대의 첫 번째 도구인 Text Selection Mode를 선택합니다.

## 자유롭게 그리기

펜 도구를 선택하고 선 두께를 Thin, Medium 또는 Thick으로 설정한 다음 페이지에서 드래그합니다.

## 텍스트 상자 추가하기

1. 텍스트 상자 도구를 선택하고 서체 크기를 6~32포인트로 설정합니다.
2. 페이지에서 텍스트를 넣을 위치를 클릭한 다음 입력합니다.
3. 입력을 마치려면 상자 바깥쪽을 클릭하거나 Escape 키를 누릅니다.

## 설명선 추가하기

설명선은 페이지의 특정 대상을 화살표로 가리키는 텍스트 메모입니다.

1. 설명선 도구를 선택합니다.
2. 화살표가 닿을 지점을 누른 다음 메모를 놓을 위치로 드래그합니다.
3. 메모를 입력합니다.

나중에 화살표가 가리키는 지점과 메모를 각각 드래그할 수 있습니다.

## 주석 변경하기

| 원하는 작업 | 방법 |
| --- | --- |
| 텍스트 편집하기 | 텍스트 상자나 설명선을 이중 클릭하거나, 선택하고 Return 키를 누르거나, 오른쪽 클릭하고 Edit Text Box 또는 Edit Callout Note를 선택합니다. |
| 이동하기 | 드래그하거나, 선택하고 화살표 키를 누릅니다. ⇧ 키를 길게 누르면 10포인트씩 이동합니다. |
| 크기 조절하기 | 선택한 다음 모서리 핸들을 드래그합니다. |
| 삭제하기 | 선택하고 Delete 키를 누르거나, 오른쪽 클릭하고 Delete Drawing 또는 Delete Text Box와 같은 삭제 명령을 선택합니다. |

Markup 도구 막대의 Eraser를 사용하면 주석을 클릭하거나 그 위로 드래그하여 삭제할 수 있습니다.

주석은 [저장](save.md)할 때 표준 주석으로 PDF에 저장되므로 다른 PDF 앱에서도 나타납니다. 주석을 페이지에 고정하려면 [평면화된 PDF를 내보냅니다](export.md#flattened-pdf).
