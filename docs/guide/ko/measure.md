# 길이, 면적 및 각도 측정하기

⇧⌘M 키를 눌러 Measurement 도구 막대를 표시합니다. 도면이 축척에 맞게 그려져 있다면 먼저 [축척을 설정](drawing-scale.md)합니다.

측정하기 전에 확대하면 더 정확합니다. 측정 도중 Escape 키를 누르면 측정이 취소됩니다. 도구를 내려놓으려면 Escape 키를 다시 누르거나 선택된 도구를 클릭합니다.

## 측정 도구

| 도구 | 사용 방법 |
| --- | --- |
| Linear Dimension | 한 지점에서 다른 지점으로 드래그합니다. |
| Perimeter | 경로를 따라 각 지점을 클릭합니다. 완료하려면 Return 키를 누르거나 이중 클릭합니다. |
| Polygon Area | 각 모서리를 클릭합니다. 도형을 닫으려면 Return 키를 누르거나, 이중 클릭하거나, 첫 번째 지점을 클릭합니다. |
| Vertex Angle | 첫 번째 선의 한 지점, 꼭짓점, 두 번째 선의 한 지점을 차례로 클릭합니다. |

## 정확하게 그리기

- **Ortho Lock**은 선을 0°, 45°, 90°로 유지합니다. 선 하나에 대해 반대로 전환하려면 ⇧ 키를 길게 누릅니다. 켜져 있을 때는 어떤 각도로든 측정할 수 있고, 꺼져 있을 때는 선을 곧게 유지할 수 있습니다.
- **Vertex Magnetic Snapping**은 포인터를 도면의 모서리와 끝점에 맞춥니다.

## 측정 변경하기

Escape 키를 누르거나 선택된 도구를 클릭하여 측정 도구를 내려놓은 다음, 측정을 클릭하여 선택합니다. 측정의 점에 핸들이 나타납니다.

| 원하는 작업 | 방법 |
| --- | --- |
| 점 하나 이동하기 | 해당 핸들을 드래그합니다. Ortho Lock과 스냅은 측정할 때와 같이 작동합니다. |
| 측정 전체 이동하기 | 선을 드래그하거나 화살표 키를 누릅니다(⇧ 키를 함께 누르면 10포인트씩 이동). |
| 치수선을 측정 대상에 더 가깝게 또는 더 멀리 옮기기 | 레이블을 드래그하거나, 치수선이 점에서 떨어진 후에는 치수선 자체를 드래그합니다. |
| 색상 변경하기 | Measurement 도구 막대의 색상 버튼으로 색상을 선택합니다. |

드래그하는 동안 값이 다시 계산됩니다. 측정을 원래대로 되돌리려면 Edit > Undo를 선택합니다. PDF에 이미 저장된 측정도 변경할 수 있습니다.

면적을 선택하려면 가장자리를 클릭합니다. 안쪽을 클릭하면 그곳의 텍스트가 선택됩니다.

## 측정 표시 모양 변경하기

측정하기 전에 Measurement 도구 막대의 색상 버튼과 선 굵기를 사용합니다. 이미 만든 측정의 색상을 변경하려면 측정을 선택한 다음 색상을 선택합니다.

## 측정 유지 또는 제거하기

측정은 주석이며 [저장](save.md)할 때 PDF에 저장됩니다. 측정을 삭제하려면 해당 측정을 오른쪽 클릭한 다음 Delete Dimension 또는 Delete Area Takeoff와 같은 삭제 명령을 선택합니다.

모든 측정을 목록으로 보려면 [물량 산출표](takeoff.md)를 참조하십시오.
