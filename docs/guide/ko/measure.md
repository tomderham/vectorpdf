# 길이, 면적 및 각도 측정하기

⇧⌘M 키를 눌러 Measurement 도구 막대를 표시합니다. 도면이 축척에 맞게 그려져 있다면 먼저 [축척을 설정](drawing-scale.md)합니다.

측정하기 전에 확대하면 더 정확합니다. 측정 도중 Escape 키를 누르면 측정이 취소됩니다.

## 측정 도구

| 도구 | 사용 방법 |
| --- | --- |
| Linear Dimension | 한 지점에서 다른 지점으로 드래그합니다. |
| Perimeter | 경로를 따라 각 지점을 클릭합니다. 완료하려면 Return 키를 누르거나 이중 클릭합니다. |
| Polygon Area | 각 모서리를 클릭합니다. 도형을 닫으려면 Return 키를 누르거나, 이중 클릭하거나, 첫 번째 지점을 클릭합니다. |
| Vertex Angle | 첫 번째 선의 한 지점, 꼭짓점, 두 번째 선의 한 지점을 차례로 클릭합니다. |

## 정확하게 그리기

- **Ortho Lock**은 선을 0°, 45°, 90°로 유지합니다. 선 하나에만 적용하려면 ⇧ 키를 길게 누릅니다.
- **Vertex Magnetic Snapping**은 포인터를 도면의 모서리와 끝점에 맞춥니다.

## 측정 표시 모양 변경하기

측정하기 전에 Measurement 도구 막대의 색상 팔레트와 선 두께를 사용합니다.

## 측정 유지 또는 제거하기

측정은 주석이며 [저장](save.md)할 때 PDF에 저장됩니다. 측정을 삭제하려면 해당 측정을 오른쪽 클릭한 다음 Delete Dimension 또는 Delete Area Takeoff와 같은 삭제 명령을 선택합니다.

모든 측정을 목록으로 보려면 [물량 산출표](takeoff.md)를 참조하십시오.
