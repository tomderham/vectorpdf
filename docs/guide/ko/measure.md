# 길이, 면적 및 각도 측정하기 및 개수 세기

⇧⌘M 키를 눌러 Measurement 도구 막대를 표시합니다. 도면이 축척에 맞게 그려져 있다면 먼저 [축척을 설정](drawing-scale.md)합니다.

측정하기 전에 확대하면 더 정확합니다. 측정 도중 Escape 키를 누르면 측정이 취소됩니다. 도구를 내려놓으려면 Escape 키를 다시 누르거나 선택된 도구를 클릭합니다.

## 측정 도구

| 도구 | 사용 방법 |
| --- | --- |
| Linear Dimension | 한 지점에서 다른 지점으로 드래그합니다. |
| Perimeter | 경로를 따라 각 지점을 클릭합니다. 완료하려면 Return 키를 누르거나 이중 클릭합니다. |
| Polygon Area | 각 모서리를 클릭합니다. 도형을 닫으려면 Return 키를 누르거나, 이중 클릭하거나, 첫 번째 지점을 클릭합니다. |
| Vertex Angle | 첫 번째 선의 한 지점, 꼭짓점, 두 번째 선의 한 지점을 차례로 클릭합니다. |
| Count | 그룹 상자에 셀 대상(예: 콘센트)을 입력한 다음 하나씩 클릭합니다. |

## 도면에서 개수 세기 {#count-things-on-a-drawing}

Count 도구를 선택한 다음 옆 상자에 그룹 이름(예: 콘센트, A형 문)을 입력하거나, 상자 옆 메뉴에서 문서에 이미 있는 그룹을 선택합니다. 클릭할 때마다 Measurement 도구 막대 색상의 점인 마커가 놓이고, 도구 막대에 그 그룹이 페이지에 몇 개 있는지 표시됩니다. 다른 것을 세려면 그룹 이름을 바꿉니다. 그룹마다 따로 셉니다. 페이지에서 구분할 수 있도록 그룹마다 다른 색상을 사용합니다.

마커를 이동하려면 Select 도구로 드래그합니다. 마커를 제거하려면 오른쪽 클릭하고 Delete Count Marker를 선택합니다. [물량 산출표](takeoff.md)에는 각 페이지의 그룹별 개수와 합계가 표시됩니다. 마커는 PDF에 작은 원으로 저장되므로 다른 앱에서도 표시됩니다.

## 정확하게 그리기

- **Ortho Lock**은 선을 0°, 45°, 90°로 유지합니다. 선 하나에 대해 반대로 전환하려면 ⇧ 키를 길게 누릅니다. 켜져 있을 때는 어떤 각도로든 측정할 수 있고, 꺼져 있을 때는 선을 곧게 유지할 수 있습니다.
- **Vertex Magnetic Snapping**은 포인터를 도면의 모서리와 끝점에 맞춥니다.
- **안내선과 격자:** View > Rulers and Grid > Snap to Guides and Grid가 켜져 있으면 점이 눈금자에서 끌어온 안내선과, 격자가 표시되어 있는 동안에는 격자에 맞춰집니다. [눈금자, 상태 막대 및 Inspector](rulers-and-inspector.md)를 참고하십시오.
- **상태 막대**(View > Show Status Bar)는 그리는 중인 측정에 대해 레이블보다 많은 정보를 보여 줍니다. 각도와 가로 및 세로로 얼마나 뻗어 있는지, 또는 지금까지의 면적 둘레입니다.

## 측정 변경하기

Measurement 도구 막대 맨 앞에 있는 화살표인 **Select**를 선택하거나 Escape 키를 눌러 측정 도구를 내려놓습니다. 측정에 포인터를 올리면 점선 윤곽선으로 표시되고, 클릭하면 선택됩니다. ⇧-클릭하면 여러 개를 선택할 수 있고, ⌥ 키를 누른 채 그 위로 드래그할 수도 있습니다. 측정 도구를 사용하는 동안에는 클릭하면 다시 측정합니다.

선택한 측정의 점에는 핸들이 있습니다.

| 원하는 작업 | 방법 |
| --- | --- |
| 점 하나 이동하기 | 해당 핸들을 드래그합니다. Ortho Lock과 스냅은 측정할 때와 같이 작동합니다. |
| 측정 전체 이동하기 | 선을 드래그하거나 화살표 키를 누릅니다(⇧ 키를 함께 누르면 10포인트씩 이동). |
| 치수선을 측정 대상에 더 가깝게 또는 더 멀리 옮기기 | 레이블을 드래그하거나, 치수선이 점에서 떨어진 후에는 치수선 자체를 드래그합니다. |
| 색상 변경하기 | Measurement 도구 막대의 색상 버튼으로 색상을 선택합니다. |
| 선 굵기 변경하기 | Measurement 도구 막대의 선 굵기 상자에서 굵기를 선택하거나 입력합니다. |

드래그하는 동안 값이 다시 계산됩니다. 측정이 보기보다 길면 윈도우 가장자리 밖으로 드래그하여 스크롤합니다. 측정을 원래대로 되돌리려면 Edit > Undo를 선택합니다. PDF에 이미 저장된 측정도 변경할 수 있습니다.

면적을 선택하려면 가장자리를 클릭합니다. 안쪽을 클릭하면 그곳의 텍스트가 선택됩니다.

## 측정 표시 모양 변경하기

측정하기 전에 Measurement 도구 막대의 색상 버튼과 선 굵기 상자를 사용합니다. 포인트 단위의 굵기를 선택하거나 0.1~72포인트 사이의 값을 입력합니다. 새 측정은 다른 값을 선택할 때까지 회색, 1.5포인트 굵기입니다. VectorPDF는 선택한 값을 기억하며, Markup 도구 막대는 별도의 색상과 굵기를 유지합니다. 이미 만든 측정의 색상이나 굵기를 변경하려면 측정을 선택한 다음 Measurement 도구 막대에서 색상이나 굵기를 선택합니다. 굵기는 PDF에 저장됩니다.

## 측정 유지 또는 제거하기

측정은 주석이며 [저장](save.md)할 때 PDF에 저장됩니다. 측정을 삭제하려면 해당 측정을 오른쪽 클릭한 다음 Delete Dimension, Delete Area Takeoff 또는 Delete Count Marker와 같은 삭제 명령을 선택합니다.

모든 측정을 목록으로 보려면 [물량 산출표](takeoff.md)를 참조하십시오.
