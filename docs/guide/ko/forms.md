# 양식 작성하기

VectorPDF는 대화형 PDF 양식(AcroForms)을 지원합니다. 필드가 페이지에 나타나며 바로 사용할 수 있습니다.

- **텍스트 필드:** 클릭하여 입력합니다.
- **체크상자 및 라디오 버튼:** 클릭하여 선택합니다.
- **팝업 메뉴 및 목록:** 클릭하여 항목을 선택합니다.
- **서명 필드:** **Sign**을 클릭한 다음 [스탬프](stamps.md)를 만들거나 선택합니다.

작성한 양식을 [저장](save.md)하려면 ⌘S 키를 누릅니다.

양식에 재설정 버튼이 있으면 버튼을 클릭할 때 확인을 요청한 다음 모든 필드를 지웁니다.

다른 사람이 답변을 변경하지 못하게 하려면 양식 필드를 평면화한 사본을 저장합니다. [다른 포맷으로 내보내기](export.md#flattened-pdf)를 참조하십시오.
