# 두 문서 비교하기

Compare Documents는 한 문서의 두 버전을 나란히 보여 주며, 바뀐 텍스트를 양쪽 모두에서 하이라이트합니다. 한쪽을 스크롤하면 버전 사이에 페이지가 추가되거나 삭제된 곳에서도 다른 쪽이 같은 텍스트로 스크롤됩니다.

## 비교 열기

1. File > Compare Documents를 선택합니다.
2. 원본(Original)과 개정판(Revised)을 선택합니다. 각 메뉴에는 열려 있는 문서가 표시되며, 다른 문서를 고르려면 Choose File을 선택합니다. 처음에는 앞에 있는 문서가 원본이 됩니다. 서로 바꾸려면 Swap을 클릭합니다.
3. Compare를 클릭합니다.

문서 제목이나 도구 막대의 빈 부분을 오른쪽 클릭하고 Compare With에서 문서를 선택할 수도 있습니다. 그러면 앞에 있는 문서와 선택한 문서가 비교됩니다.

비교는 새 탭에서 열리며, 왼쪽에 원본, 오른쪽에 개정판이 표시됩니다. 이 탭에서는 둘 다 읽기 전용입니다. 하나를 편집하려면 해당 문서를 별도의 탭에서 엽니다.

## 변경 사항 읽기

- 원본에서 삭제된 단어는 왼쪽에 빨간색으로 하이라이트됩니다.
- 개정판에서 추가된 단어는 오른쪽에 초록색으로 하이라이트됩니다.
- 한쪽에만 텍스트가 추가된 곳에서는 다른 쪽의 가는 막대가 그 텍스트가 들어갈 위치를 표시합니다.

사이드바의 Changes 탭에는 모든 변경 사항이 나열됩니다. 삭제된 단어는 빨간색 취소선으로, 추가된 단어는 초록색으로 표시되며 개정판의 페이지 번호도 함께 나옵니다. 변경 사항을 클릭하면 두 문서 모두에서 해당 위치로 이동합니다.

변경 사항을 차례로 보려면 Changes 탭 위쪽의 위쪽 또는 아래쪽 화살표를 클릭하거나, Go > Previous Change 또는 Go > Next Change를 선택하거나, ⌥⌘Up Arrow 또는 ⌥⌘Down Arrow를 누릅니다. 탭에는 3 of 12처럼 현재 변경 사항이 표시됩니다. 그 변경 사항은 더 진하게 하이라이트되고 목록에서 선택됩니다.

텍스트만 비교됩니다. 서식, 이미지 또는 도면의 변경 사항은 표시되지 않습니다. 머리글, 바닥글과 페이지 번호는 제외되므로 페이지가 밀려도 변경 사항으로 나타나지 않습니다.

## 섹션이나 단어 찾기

사이드바의 Outline & Thumbnails 탭과 Search 탭은 다른 탭에서와 마찬가지로 개정판에 적용됩니다. 섹션이나 검색 결과로 이동하면 원본도 같은 텍스트로 따라갑니다.

## 함께 스크롤하고 확대/축소하기

양쪽에서 위에서 약 3분의 1 지점에 있는 줄에는 같은 텍스트가 표시됩니다. 한쪽에만 있는 텍스트가 있으면, 다른 쪽은 그 텍스트를 지나갈 때까지 기다립니다. 어느 쪽을 스크롤해도 다른 쪽이 따라갑니다.

두 쪽을 따로 스크롤하려면 Changes 탭 위쪽에서 Scroll Together를 끕니다. 다시 켜면 다시 맞춰집니다.

한쪽을 확대/축소하면 양쪽이 모두 확대/축소되며, 읽고 있던 텍스트는 그 자리에 머뭅니다. 페이지 너비보다 크게 확대한 상태에서 한쪽을 가로로 스크롤하면 다른 쪽도 가로로 스크롤되어, 양쪽에 페이지의 같은 부분이 표시됩니다.

## 비교 옵션

Changes 탭 위쪽에서 Ignore Case 또는 Ignore Punctuation을 선택하면 대소문자나 문장 부호의 차이를 제외합니다. 둥근 따옴표와 곧은 따옴표, 여러 종류의 대시는 항상 같은 것으로 취급됩니다.

## 비교가 도움이 되지 않을 때

- **문서에 비교할 텍스트가 없음:** 스캔한 페이지는 텍스트를 인식하기 전까지는 텍스트가 없습니다. [스캔한 페이지에서 텍스트 검색 및 선택하기](scanned-pages.md)를 참조하십시오.
- **두 문서에 공통된 텍스트가 거의 없음:** 같은 문서의 버전이 아닐 수 있습니다.
