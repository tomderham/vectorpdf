# 민감한 내용 가리기

가림 처리는 PDF에서 내용을 영구적으로 제거합니다. VectorPDF는 가림 처리된 영역 아래의 텍스트, 이미지 픽셀, 선화를 해당 영역에 닿는 주석 및 양식 필드와 함께 파일에서 삭제합니다. 단순히 상자로 덮는 것이 아니며, 저장할 때 이전 버전도 보관되지 않습니다.

문서에서 처음으로 가림 처리를 하면 그 밖에 무엇이 변경되는지 알림으로 설명합니다.

- **문서 전체에서 제거되는 항목:** 제목과 작성자 같은 메타데이터, 첨부 파일, 페이지 썸네일, 손쉬운 사용을 위한 대체 텍스트, XFA 양식 데이터. 이를 유지하려면 사본에서 가림 처리합니다.
- **책갈피는 유지되며,** 제목에 있는 가림 처리된 단어는 각각 [Redacted]로 바뀝니다. 이미지와 스캔의 텍스트는 대조할 수 없으므로, 이를 가림 처리한 후에는 책갈피를 직접 확인합니다.
- **제거되지 않는 항목:** 이름이 지정된 대상, 페이지 레이블, 레이어 이름, JavaScript. 여기에는 해당 텍스트가 남아 있을 수 있습니다.

> **경고:** 가림 처리는 적용하는 즉시 효력이 발생하며 Undo가 없습니다. 저장하기 전까지 원본 파일은 변경되지 않으므로 다시 시작하려면 문서를 저장하지 않고 닫습니다. 원본의 사본을 보관하고, Save As를 사용하여 가림 처리된 버전을 새로운 이름으로 저장합니다.

⌥⌘R 키를 누르거나 View > Show Redact Toolbar를 선택합니다.

## 영역 가리기

1. **Redact Region**을 선택합니다.
2. 가림 색상으로 Black 또는 White를 선택합니다.
3. 가리려는 영역 위로 드래그합니다.

## 찾아서 가리기

1. **Find & Redact**를 선택합니다.
2. 찾을 대상을 선택합니다.
   - **Text / Phrase**: Match Case 및 Whole Word 옵션을 사용할 수 있습니다.
   - **Custom Regular Expression**: 예를 들어 `[A-Z]{3}-\d{5}`와 같습니다.
   - **Social Security Number (SSN)**, **Credit Card Number**, **Email Address**, **Phone Number** 또는 **Date**: 일반적인 형식을 자동으로 찾습니다.
3. Find를 클릭합니다.
4. 일치 항목을 확인합니다. 항목을 클릭하면 해당 페이지에서 볼 수 있으며, 유지하려는 항목은 선택을 해제합니다.
5. 동작을 선택합니다.
   - **Redact**: 내용을 제거하고 검은색 또는 흰색 상자를 남깁니다.
   - **Remove**: 내용을 제거하고 상자를 남기지 않습니다.
6. **Redact Selected** 또는 **Remove Selected**를 클릭합니다.

> **경고:** 자동 감지는 특히 특이한 형식이나 이미지 속 텍스트를 놓칠 수 있습니다. 문서를 공유하기 전에 확인하십시오. 스캔한 페이지의 텍스트는 Redact Region으로 가림 처리해야 합니다.

## 결과 저장하기

⇧⌘S 키를 눌러 가림 처리된 문서를 새로운 이름으로 저장합니다. 저장하면 문서의 [Agent](agent.md) 검색 색인도 삭제됩니다. 이 색인에는 제거한 텍스트가 포함되어 있을 수 있기 때문입니다.
