# 암호 및 암호화

## 보호된 PDF 열기

보호된 PDF를 열면 VectorPDF에서 암호를 묻습니다. Cancel을 클릭하면 문서가 열리지 않습니다.

## 암호화된 사본 만들기

1. File > Save Encrypted with Password(⌥⌘S)를 선택합니다.
2. 이름과 위치를 선택합니다.
3. 암호를 두 번 입력한 다음 Encrypt & Save를 클릭합니다.

사본은 AES-256으로 암호화되며, 열려면 암호가 필요합니다.

> **경고:** 암호를 안전하게 보관하십시오. 암호를 잊어버리면 암호화된 PDF를 복구할 방법이 없습니다.

## 문서의 권한 확인하기

프린트나 복사처럼 문서 작성자가 허용한 작업을 확인하려면 File > Document Properties(⌘I)를 선택한 다음 Security를 클릭합니다. [문서 속성](document-properties.md)을 참조하십시오.
