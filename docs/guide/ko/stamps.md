# 문서에 서명하기

서명하는 방법은 두 가지이며, 하는 일이 서로 다릅니다. 두 방법 모두 Markup 도구 막대(⇧⌘A)에 있는 서명 모양의 Sign 버튼에 있습니다.

| | 손글씨 서명 | 디지털 서명 |
| --- | --- | --- |
| 무엇인가 | 페이지에 놓인 서명이나 이니셜의 그림 | 인증서로 만들어 파일에 보관되는 서명 |
| 누가 서명했는지 보여 줌 | 아니요: 누구나 그림을 붙여 넣을 수 있음 | 예, 인증서가 읽는 사람이 신뢰하는 기관에서 발급된 경우 |
| 그 후 문서가 변경되지 않았음을 보여 줌 | 아니요 | 예 |
| 필요한 것 | 없음: 그리거나, 입력하거나, 이미지를 선택 | 조직이나 인증 기관에서 받은 서명용 인증서 |
| 나중에 제거할 수 있음 | 예, 주석처럼 | 서명 전에 저장한 사본으로 되돌려야만 가능 |

비공식 양식처럼 그림으로 충분한 경우에는 손글씨 서명이면 됩니다. 계약, 승인, 그리고 나중에 누군가 확인해야 할 수 있는 모든 것에는 디지털 서명을 사용하십시오. 디지털 서명의 상자에 손글씨 서명을 함께 표시할 수도 있습니다.

## 손글씨 서명 추가하기 {#add-your-handwritten-signature}

1. Markup 도구 막대를 표시하고(⇧⌘A) Sign 버튼을 클릭한 다음 Add Handwritten Signature를 선택합니다. 처음에는 VectorPDF에서 서명을 만들라고 안내합니다.
   - **Draw:** 트랙패드나 마우스로 서명합니다.
   - **Type:** 이름이나 이니셜을 입력하고 서체를 선택합니다.
   - **Image:** PNG 또는 JPEG 파일을 선택합니다. **Transparent background**를 선택하면 이미지의 배경으로 페이지가 비쳐 보입니다.
2. 원하는 위치를 클릭합니다.

그런 다음 서명을 드래그하여 이동하거나 모서리를 드래그하여 크기를 조절합니다. 제거하려면 서명을 선택하고 Delete 키를 누르거나, 오른쪽 클릭하고 Delete Signature를 선택합니다.

VectorPDF는 다음에 사용할 수 있도록 서명을 이 Mac에 보관합니다. 변경하거나 삭제하려면 VectorPDF > Settings를 선택하고 General을 클릭한 다음 Handwritten Signature 옆의 버튼을 사용합니다.

## 인증서로 서명하기 {#sign}

서명하려면 개인 키가 있는 서명용 인증서가 필요합니다. 조직이나 인증 기관에서 보통 암호가 있는 .p12 또는 .pfx 파일로 제공합니다. 키체인에 있는 인증서는 바로 사용할 수 있습니다.

1. Markup 도구 막대에서 Sign 버튼을 클릭하고 Sign with Certificate를 선택하거나, Edit > Sign with Certificate를 선택합니다. 그런 다음 서명을 넣을 페이지 위치에 상자를 드래그하거나, 클릭하여 일반 크기의 상자를 놓습니다. 중단하려면 Esc 키를 누릅니다. 문서에 빈 서명 필드가 있으면 대신 그 필드를 클릭하고 Sign with Certificate를 선택할 수 있습니다.
2. 인증서를 선택합니다. 미리 보기에 서명이 어떻게 보일지 표시됩니다. 파일을 사용하려면 **Choose Certificate File**을 클릭한 다음 파일의 암호를 입력합니다. 파일은 이번 서명에만 읽히며 키체인에 추가되지 않습니다.
3. 원하는 경우 사유(예: "이 문서를 승인합니다")와 서명하는 장소를 입력합니다. [손글씨 서명](#add-your-handwritten-signature)을 만들어 두었다면 필드에 표시할 수 있습니다. 그렇지 않으면 이름이 표시됩니다.
4. 원하는 경우 After Signing에서 다음을 선택합니다.
   - **Certify**(아직 아무도 서명하지 않은 문서의 경우): 앞으로 어떤 변경이 문서를 유효하게 두는지 정합니다. 양식 채우기, 서명 및 주석 추가, 양식 채우기 및 서명, 또는 변경 없음 중에서 고릅니다. 인증된 문서는 확인하는 모든 사람에게 인증된 것으로 표시되며, 허용하지 않는 이후의 변경은 사용자의 서명을 무효로 만듭니다.
   - **Lock form fields**(양식의 경우): 모든 필드 또는 선택한 필드가 읽기 전용이 되어 서명한 값을 유지합니다.
5. **Sign**을 클릭합니다.

서명하면 문서가 저장되므로, 저장하지 않은 변경 사항이 있으면 VectorPDF가 먼저 저장할지 묻습니다. 그 변경 사항도 서명 대상에 포함됩니다. macOS에서 VectorPDF가 인증서의 키를 사용하도록 허용할지 물을 수 있습니다.

필드를 잠그거나 더 적은 변경만 허용하도록 인증하지 않는 한, 서명은 문서의 다른 양식 필드를 그대로 두므로 다른 사람이 서명을 무효화하지 않고도 계속 필드를 채우거나 함께 서명하거나 주석을 추가할 수 있습니다. 이후의 각 서명도 같은 방식으로 이전 서명 뒤에 추가됩니다.

이 서명은 SHA-256을 사용하는 PKCS #7 서명이며, 사용자의 인증서와 이를 발급한 기관의 인증서를 포함합니다. Mac의 시각이 기록됩니다.

타임스탬프 서버가 서명한 시각을 보증하게 하려면 **Add a timestamp**를 켜고 서버 주소를 입력합니다(조직에서 운영하는 서버가 있을 수 있으며, DigiCert의 `http://timestamp.digicert.com`처럼 무료 서버도 있습니다). 타임스탬프가 있으면 인증서가 만료된 후에도 서명한 시점의 상태로 서명을 확인할 수 있습니다. 서버에는 서명의 지문만 전송되며 문서 내용은 전송되지 않습니다. 서버에 연결할 수 없으면 아무것도 서명되지 않고 문서는 그대로 유지됩니다.

문서의 서명을 확인하려면 [디지털 서명 확인하기](digital-signatures.md)를 참조하십시오.

## 양식에 서명하기

양식에 서명 필드가 있으면 필드에서 **Sign**을 클릭한 다음 Add Handwritten Signature 또는 Sign with Certificate를 선택합니다. [양식 작성하기](forms.md)를 참조하십시오.
