# 스탬프와 서명

스탬프는 서명이나 이니셜과 같은 이미지로, 어느 페이지에나 넣을 수 있습니다.

> **참고:** 스탬프는 시각적인 표시입니다. 암호화 디지털 서명이 아니며 문서를 인증하지 않습니다.

## 스탬프 만들기

1. VectorPDF > Settings를 선택한 다음 Digital Stamp 아래에서 Create Stamp를 클릭합니다. Markup 도구 막대에서 Stamp 도구를 선택해도 VectorPDF에서 스탬프를 만들라고 안내합니다.
2. 만드는 방법을 선택합니다.
   - **Draw:** 트랙패드나 마우스로 서명합니다.
   - **Type:** 이름이나 이니셜을 입력하고 서체를 선택합니다.
   - **Image:** PNG 또는 JPEG 파일을 선택합니다. **Transparent background**를 선택하면 이미지의 배경으로 페이지가 비쳐 보입니다.
3. Use를 클릭합니다.

VectorPDF는 다음에 사용할 수 있도록 스탬프를 이 Mac에 보관합니다. 스탬프를 교체하거나 제거하려면 [Settings](settings.md)에서 Modify Stamp 또는 Delete Stamp를 사용합니다.

## 스탬프 넣기

1. Markup 도구 막대(⇧⌘A)를 표시한 다음 Stamp 도구를 선택합니다.
2. 스탬프를 넣을 위치를 클릭합니다.

그런 다음 스탬프를 드래그하여 이동하거나 모서리를 드래그하여 크기를 조절합니다. 제거하려면 스탬프를 선택하고 Delete 키를 누르거나, 오른쪽 클릭하고 Delete Signature를 선택합니다.

## 양식에 서명하기

양식에 서명 필드가 있으면 필드에서 **Sign**을 클릭합니다. [양식 작성하기](forms.md)를 참조하십시오.
