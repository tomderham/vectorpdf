# 앵커

앵커는 문서에 저장한 위치로, 텍스트 구절, 페이지의 영역 또는 링크의 대상이 될 수 있습니다. 앵커는 PDF와 별도로 보관되며 PDF를 변경하지 않습니다.

## 앵커 생성하기

- 텍스트를 선택하거나 ⌥ 키를 누른 채 드래그하여 영역을 선택한 다음 ⌘B 키를 누릅니다.
- 선택 영역, 링크 또는 페이지의 특정 위치를 오른쪽 클릭한 다음 **Create Anchor**를 선택합니다.
- [검색 결과](search.md)나 [개요](outline-and-thumbnails.md) 항목을 오른쪽 클릭한 다음 **Create Anchor**를 선택합니다.

아무것도 선택되어 있지 않으면 ⌘B 키를 눌러 현재 페이지의 앵커를 생성합니다.

**Create Anchor and Open in New Window**는 앵커를 생성하고 해당 위치를 별도의 윈도우에서도 표시합니다.

## 앵커 사용하기

사이드바에서 Anchors 탭을 클릭하면 앵커별 카드가 표시됩니다. Anchors 메뉴를 사용할 수도 있습니다.

- **앵커로 이동하기:** 카드를 클릭하거나 Anchors 메뉴에서 해당 앵커를 선택합니다.
- **더 큰 미리보기 보기:** 카드의 축소판 위에 포인터를 올려놓습니다.
- **윈도우의 모든 탭에 있는 앵커 보기:** Anchors 탭 상단에서 All Tabs를 선택합니다. 앵커를 클릭하면 해당 탭으로 전환됩니다.

카드를 오른쪽 클릭하면 새로운 윈도우에서 열거나, 텍스트를 복사하거나, 이미지를 복사할 수 있습니다.

## 앵커 삭제하기

- **앵커 하나:** 카드의 ×를 클릭하거나, 카드를 오른쪽 클릭하고 Delete Anchor를 선택합니다.
- **문서의 모든 앵커:** Anchors 탭에서 Clear All을 클릭하거나 Anchors > Clear All Anchors를 선택합니다.

## 앵커와 페이지 변경

앵커는 페이지 번호를 기억합니다. 페이지를 추가, 삭제 또는 이동하여 앵커가 잘못된 위치를 가리키게 되는 경우 VectorPDF에서 먼저 경고합니다. **Save as Copy**를 선택하면 앵커가 없는 사본에서 변경하고, **Edit Anyway**를 선택하면 그대로 변경합니다.

## 다른 Mac의 앵커

끄지 않는 한 앵커는 읽던 위치와 함께 [iCloud를 통해 동기화](reading-positions.md)됩니다.
