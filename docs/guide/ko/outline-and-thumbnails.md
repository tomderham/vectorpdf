# 개요 및 축소판

사이드바 상단의 Outline & Thumbnails 탭을 클릭한 다음 **Outline** 또는 **Thumbnails**를 선택합니다.

## 개요

개요는 문서의 목차입니다(문서에 목차가 있는 경우). 스크롤하면 읽고 있는 섹션이 하이라이트됩니다.

- **섹션으로 이동하기:** 섹션을 클릭합니다.
- **하위 섹션 표시 또는 숨기기:** 섹션 옆의 화살표를 클릭합니다.
- **섹션 찾기:** “Search outline” 필드에 입력합니다. 일치하는 섹션만 표시됩니다.
- **섹션을 가까이 두기:** 섹션을 오른쪽 클릭하여 [앵커](anchors.md)를 생성하거나 새로운 윈도우에서 엽니다.

## 축소판

축소판에는 모든 페이지가 표시됩니다. 축소판을 클릭하면 해당 페이지로 이동합니다.

여러 페이지를 선택하려면 ⌘ 키를, 범위를 선택하려면 ⇧ 키를 길게 누릅니다. 그런 다음 새로운 위치로 드래그하거나, 오른쪽 클릭하여 회전, 복제, 추출 또는 삭제합니다. [페이지 재배열하기](pages.md)를 참조하십시오.
