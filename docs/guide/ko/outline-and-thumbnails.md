# 개요 및 축소판

사이드바 상단의 Outline & Thumbnails 탭을 클릭한 다음 **Outline** 또는 **Thumbnails**를 선택합니다.

## 개요

개요는 문서의 목차입니다(문서에 목차가 있는 경우). 스크롤하면 읽고 있는 섹션이 하이라이트됩니다.

- **섹션으로 이동하기:** 섹션을 클릭합니다. 제목이 윈도우 위쪽 근처로 스크롤되며, 이미 보이는 경우에는 그 자리에 그대로 있습니다.
- **하위 섹션 표시 또는 숨기기:** 섹션 옆의 화살표를 클릭합니다.
- **섹션 찾기:** “Search outline” 필드에 입력합니다. 일치하는 섹션만 표시됩니다.
- **섹션을 가까이 두기:** 섹션을 오른쪽 클릭하여 [앵커](anchors.md)를 생성하거나 새로운 윈도우에서 엽니다.

## 개요 편집하기 {#edit-the-outline}

문서의 개요에 항목(다른 앱에서는 책갈피라고 부르기도 함)을 추가하고, 이름을 변경하고, 이동하고, 삭제할 수 있습니다. 변경 사항은 [저장](save.md)할 때 파일에 포함됩니다.

항목을 추가하려면 항목이 가리킬 위치로 이동한 다음 Edit > Add Outline Entry(⌥⌘B)를 선택합니다. 텍스트를 선택한 경우 항목은 그 텍스트로 이동하며, 그 텍스트가 제목으로 제안됩니다. 그렇지 않으면 읽고 있는 페이지의 맨 위로 이동합니다. 제목을 입력한 다음 **Add**를 클릭합니다. 이렇게 추가한 항목은 최상위 항목 사이에 페이지 순서대로 들어가므로, 개요가 없는 문서에서 개요를 시작하는 방법이기도 합니다.

나머지 작업은 항목을 오른쪽 클릭하여 수행합니다.

| 하려는 작업 | 선택할 항목 |
| --- | --- |
| 이 항목 다음이나 안에 항목 추가하기 | Add Entry After 또는 Add Entry Inside |
| 이름 변경하기 | Rename |
| 선택한 텍스트나 읽고 있는 페이지로 이동하도록 하기 | Go Here Instead |
| 같은 수준의 항목 사이에서 이동하기 | Move Up 또는 Move Down |
| 위의 항목 안에 넣거나, 들어 있는 항목에서 빼기 | Indent 또는 Outdent |
| 안의 항목과 함께 삭제하기 | Delete Entry |

항목을 드래그하여 이동하거나, 다른 항목 위에 놓아 그 안에 넣을 수도 있습니다. 안에 있는 항목도 함께 이동합니다. “Search outline” 필드로 개요를 필터링하는 동안에는 항목을 이동할 수 없으므로 Move Up, Move Down, Indent, Outdent가 메뉴에 없고 항목을 드래그할 수 없습니다. 다른 명령은 사용할 수 있습니다. Edit > Undo(⌘Z)로 개요 변경 사항을 하나씩 되돌릴 수 있습니다.

### 제목으로 개요 만들기

Edit > Build Outline from Headings를 선택하면 문서의 제목으로 개요를 만들 수 있습니다. 이 명령은 개요 항목의 오른쪽 클릭 메뉴에도 있습니다. 먼저 찾은 제목 목록이 열립니다. 제목이 아닌 것은 선택을 해제하고, 제목을 클릭하여 바꾸고, 들여쓰기 버튼으로 제목의 수준을 올리거나 내립니다. 제목 옆의 화살표를 클릭하면 페이지에서 제목을 볼 수 있습니다. 그런 다음 **Create Outline**을, 문서에 이미 개요가 있으면 **Replace Outline**을 클릭합니다. Edit > Undo로 이전 개요를 되돌릴 수 있습니다.

태그가 있는 PDF에서는 태그로 표시된 제목이 사용됩니다. 다른 PDF에서는 VectorPDF가 본문과 구별되는 줄, 즉 본문보다 크거나 본문이 굵지 않은데 굵게 된 줄을 찾습니다. 큰 스타일이 작은 스타일보다 높은 수준이 되며, 같은 스타일 안에서는 3.2.1과 같은 섹션 번호로 수준이 정해집니다. 반복되는 머리말과 꼬리말, 그림과 표의 캡션, 목차의 줄은 제외됩니다.

문서의 스타일만으로 어떤 줄이 제목인지 항상 알 수 있는 것은 아니므로 목록을 확인하십시오. 스캔한 페이지의 제목은 텍스트가 인식된 후에도 찾지 못합니다. 일부 태그가 있는 PDF에서는 섹션 번호가 텍스트의 일부가 아닌 방식으로 그려져 있어, 항목에 번호가 붙지 않습니다.

## 축소판

축소판에는 모든 페이지가 표시됩니다. 축소판을 클릭하면 해당 페이지로 이동합니다.

여러 페이지를 선택하려면 ⌘ 키를, 범위를 선택하려면 ⇧ 키를 길게 누릅니다. 그런 다음 새로운 위치로 드래그하거나, 오른쪽 클릭하여 회전, 복제, 추출 또는 삭제합니다. [페이지 재배열하기](pages.md)를 참조하십시오.
