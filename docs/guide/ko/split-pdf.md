# PDF 분할하기

1. File > Split PDF를 선택합니다.
2. Split Method 아래에서 하나를 선택합니다.
   - **Every N Pages:** 지정한 페이지 수마다 새로운 파일을 만듭니다.
   - **Single Pages:** 페이지마다 파일을 하나씩 만듭니다.
   - **Page Ranges:** `1-5, 6-12, 13-20`과 같이 페이지 번호나 범위를 쉼표로 구분하여 입력합니다.
3. Save Location 아래에서 Choose를 클릭하여 폴더를 선택합니다.
4. File Naming 아래에서 접두어를 입력하고 스타일로 Part Number 또는 Page Range를 선택합니다. Output Preview에 생성될 파일이 표시됩니다.
5. Split PDF를 클릭합니다.

원본 문서는 변경되지 않습니다. 분할이 끝나면 Reveal in Finder를 클릭하여 파일을 확인합니다.
