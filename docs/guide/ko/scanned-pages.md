# OCR로 스캔한 페이지 검색하기

스캔한 페이지는 텍스트를 찍은 그림입니다. VectorPDF는 광학 문자 인식(OCR)을 사용하여 Mac에서 텍스트를 인식하므로 해당 페이지를 검색할 수 있습니다.

## 작동 방식

문서를 열면 VectorPDF는 처음 50페이지에서 스캔한 페이지를 찾아 백그라운드에서 텍스트를 인식합니다. 처리할 내용이 더 남아 있으면 Search 탭에 찾은 스캔 페이지 수가 표시됩니다.

- **찾은 스캔 페이지를 모두 인식하려면** Search 탭에서 **Run OCR**을 클릭합니다.
- 검색을 해도 인식이 진행되므로 바로 검색을 시작해도 됩니다.

페이지가 약간 비스듬하게 스캔된 경우에도 하이라이트가 텍스트를 따라갑니다.

> **참고:** 인식된 텍스트는 문서가 열려 있는 동안 사용되며 PDF에 저장되지 않습니다.
