# 스캔한 페이지에서 텍스트 검색 및 선택하기

스캔한 페이지는 텍스트를 찍은 그림입니다. VectorPDF는 광학 문자 인식(OCR)을 사용하여 Mac에서 텍스트를 인식하므로 해당 페이지를 검색하고, 텍스트를 선택하고, 마크업을 추가할 수 있습니다.

## 작동 방식

문서를 열면 VectorPDF는 처음 50페이지에서 스캔한 페이지를 찾아 백그라운드에서 텍스트를 인식합니다. 처리할 내용이 더 남아 있으면 Search 탭에 찾은 스캔 페이지 수가 표시됩니다.

- **찾은 스캔 페이지를 모두 인식하려면** Search 탭에서 **Run OCR**을 클릭합니다.
- 검색을 해도 인식이 진행되므로 바로 검색을 시작해도 됩니다.

페이지가 약간 비스듬하게 스캔된 경우에도 하이라이트가 텍스트를 따라갑니다.

텍스트는 Mac의 언어 및 지역 설정에 있는 언어 중 인식이 지원하는 언어로 인식되며, 지원하는 언어가 없으면 영어로 인식됩니다.

## 인식된 텍스트 선택하기

페이지가 인식되면 다른 페이지에서와 마찬가지로 텍스트를 [선택하고 복사](select-text.md)할 수 있으며 [하이라이트, 밑줄 또는 취소선](text-markup.md)을 적용할 수 있습니다. 인식에는 잠시 시간이 걸릴 수 있으며, 처음 50페이지 이후의 페이지는 먼저 Run OCR 또는 검색이 필요합니다.

인식에는 오류가 있을 수 있으므로 정확해야 하는 내용은 복사한 후 확인하십시오. 선택 영역은 단어 경계에서 깔끔하게 시작하고 끝납니다. 단어 안에서는 선택 영역의 끝이 대략적인 위치입니다.

> **참고:** 인식된 텍스트는 문서가 열려 있는 동안 사용되며, 저장하도록 선택하지 않는 한 PDF에 저장되지 않습니다(아래 참고). 추가한 마크업은 저장됩니다. 페이지를 가림 처리하거나 회전하면 해당 페이지의 텍스트가 다시 인식됩니다.

## 인식된 텍스트를 PDF에 저장하기 {#save-the-recognized-text-in-the-pdf}

스캔한 PDF를 미리보기, Spotlight, Acrobat 같은 다른 앱에서도 검색할 수 있게 하려면 인식된 텍스트를 PDF에 저장합니다. 텍스트는 인식된 위치에 각 스캔 페이지 아래의 보이지 않는 레이어로 추가되므로 페이지 모양은 그대로입니다.

- **문서에 저장하려면** File > Save with Recognized Text를 선택하거나, 텍스트가 인식된 후 Search 탭에서 **Save in PDF**를 클릭합니다. 다른 변경 사항도 함께 저장됩니다.
- **사본에 저장하려면** File > Export Document As > Searchable PDF를 선택합니다. 열려 있는 문서는 변경되지 않습니다.

어느 쪽이든 VectorPDF는 아직 인식하지 않은 스캔 페이지를 먼저 인식하며 진행 상황을 표시합니다. 페이지마다 잠시 시간이 걸립니다. Cancel을 클릭하면 아무것도 저장되지 않습니다.

자체 텍스트가 없는 페이지에만 텍스트가 추가됩니다. 텍스트가 파일에 들어가면 해당 페이지는 더 이상 스캔 페이지로 취급되지 않으며, VectorPDF는 다른 앱처럼 저장된 텍스트를 선택하고 검색합니다.

> **중요:** 인식에는 오류가 있을 수 있으며, 저장된 텍스트는 파일이 가는 곳 어디든 함께 갑니다. 검색 색인, 복사한 텍스트, 화면 읽기 프로그램 등으로 전달됩니다. 텍스트를 신뢰하기 전에 올바른지 확인하거나, 대신 사본을 저장하십시오. 또한 문서에 저장하면 파일에서 다시 열리므로, 저장 전에 한 변경 사항은 실행 취소할 수 없습니다.
