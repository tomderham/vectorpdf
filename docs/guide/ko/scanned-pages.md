# 스캔한 페이지에서 텍스트 검색 및 선택하기

스캔한 페이지는 텍스트를 찍은 그림입니다. VectorPDF는 광학 문자 인식(OCR)을 사용하여 Mac에서 텍스트를 인식하므로 해당 페이지를 검색하고, 텍스트를 선택하고, 마크업을 추가할 수 있습니다.

## 작동 방식

문서를 열면 VectorPDF는 처음 50페이지에서 스캔한 페이지를 찾아 백그라운드에서 텍스트를 인식합니다. 처리할 내용이 더 남아 있으면 Search 탭에 찾은 스캔 페이지 수가 표시됩니다.

- **찾은 스캔 페이지를 모두 인식하려면** Search 탭에서 **Run OCR**을 클릭합니다.
- 검색을 해도 인식이 진행되므로 바로 검색을 시작해도 됩니다.

페이지가 약간 비스듬하게 스캔된 경우에도 하이라이트가 텍스트를 따라갑니다.

## 인식된 텍스트 선택하기

페이지가 인식되면 다른 페이지에서와 마찬가지로 텍스트를 [선택하고 복사](select-text.md)할 수 있으며 [하이라이트, 밑줄 또는 취소선](text-markup.md)을 적용할 수 있습니다. 인식에는 잠시 시간이 걸릴 수 있으며, 처음 50페이지 이후의 페이지는 먼저 Run OCR 또는 검색이 필요합니다.

인식에는 오류가 있을 수 있으므로 정확해야 하는 내용은 복사한 후 확인하십시오. 선택 영역은 단어 경계에서 깔끔하게 시작하고 끝납니다. 단어 안에서는 선택 영역의 끝이 대략적인 위치입니다.

> **참고:** 인식된 텍스트는 문서가 열려 있는 동안 사용되며 PDF에 저장되지 않습니다. 추가한 마크업은 저장됩니다. 페이지를 가림 처리하거나 회전하면 해당 페이지의 텍스트가 다시 인식됩니다.
