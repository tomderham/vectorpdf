# 도면 축척 설정하기

도면에서 실제 치수를 측정하려면 VectorPDF가 도면의 축척을 알아야 합니다. ⇧⌘M 키를 눌러 Measurement 도구 막대를 표시한 다음 축척 버튼을 클릭하여 Drawing Scale Calibration을 엽니다.

## 표준 축척 사용하기

1. Standard Drawing Scales 아래에서 도면 유형을 선택합니다.
   - **Metric (ISO):** 1:1부터 1:1000까지.
   - **Architectural (US):** 예: 1/4" = 1'-0".
   - **Civil Engineering (US).**
2. 축척을 선택합니다.
3. Area Takeoff 아래에서 면적 단위를 선택합니다.
4. Apply Scale을 클릭합니다.

축척은 모든 페이지에 적용되며 [저장](save.md)할 때 PDF에 저장됩니다.

## 알고 있는 길이로 보정하기

도면에 신뢰할 수 있는 치수나 축척 막대가 있는 경우:

1. **Calibrate by Measuring Known Line**을 클릭합니다.
2. 도면에서 선의 양 끝을 클릭합니다.
3. 선의 실제 길이를 입력하고 단위를 선택합니다. 단위는 feet and inches, decimal feet, inches, millimeters, centimeters 또는 meters 중에서 선택할 수 있습니다.
4. Apply Scale을 클릭합니다.

클릭할 때 생기는 작은 오차는 거리가 길수록 영향이 줄어들므로 알고 있는 선 중 가장 긴 선을 사용합니다.
