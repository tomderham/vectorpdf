# 문서 검색하기

## 텍스트 찾기

1. ⌘F 키를 누릅니다. VectorPDF의 사이드바에 Search 탭이 표시됩니다.
2. 찾으려는 내용을 입력합니다. 현재 페이지부터 시작하여 찾는 대로 결과가 나타납니다.

각 결과에는 해당 페이지와 주변 텍스트가 표시되며, 일치하는 모든 항목이 문서에서 하이라이트됩니다.

## 결과 사이를 이동하기

| 원하는 작업 | 방법 |
| --- | --- |
| 다음 결과로 이동하기 | Return 또는 ⌘G 키를 누르거나 아래쪽 화살표를 클릭합니다. |
| 이전 결과로 이동하기 | ⇧Return 또는 ⇧⌘G 키를 누르거나 위쪽 화살표를 클릭합니다. |
| 원하는 결과로 이동하기 | 해당 결과를 클릭합니다. |
| 목록을 차례로 이동하기 | 결과를 클릭한 다음 화살표 키를 누릅니다. |

결과를 오른쪽 클릭하면 해당 결과로 [앵커를 생성](anchors.md)하거나 새로운 윈도우에서 열 수 있습니다.

## 이전에 검색한 내용 다시 검색하기

각 문서는 결과로 이동했던 최근 검색 10개를 기억합니다. 다시 검색하려면:

- 검색 필드의 돋보기를 클릭하고 선택하거나,
- 검색 필드가 비어 있을 때 필드 아래 Recent Searches 목록에서 클릭합니다.

VectorPDF는 가장 가까운 결과로 이동합니다. 문서의 검색 기록을 지우려면 돋보기에서 Clear Recent Searches를 선택하거나 목록 위의 Clear를 클릭합니다. 문서에 가리기를 적용해도 최근 검색이 지워집니다.

## 검색 옵션 {#search-options}

검색 필드 옆의 옵션 버튼을 클릭합니다.

- **Match Case:** 대소문자가 같은 텍스트만 찾습니다.
- **Whole Word:** 더 긴 단어의 일부와는 일치시키지 않습니다.
- **Smart Search:** 끄지 않는 한 켜져 있습니다. 공백, 하이픈, 대시, 줄 바꿈이 서로 일치하므로 “end-to-end”를 검색하면 줄이 바뀐 경우를 포함하여 “end to end”도 찾습니다. 곧은따옴표와 둥근따옴표도 서로 일치합니다.

## 텍스트 속 불필요한 요소 무시하기 {#ignore-clutter-in-the-text}

일부 문서에는 인용 번호와 같은 표시가 문장 중간에 들어 있어서 구문을 찾지 못하는 경우가 있습니다. Smart Search는 이러한 표시를 건너뛸 수 있습니다.

1. VectorPDF > Settings를 선택합니다.
2. Ignored Search Patterns 옆의 Edit를 클릭합니다.
3. 미리 만들어진 패턴을 추가하거나 직접 작성한 정규 표현식을 추가한 다음 켭니다.

미리 만들어진 패턴에는 [12]와 같은 숫자 인용, 상표 기호, *123과 같은 스타 페이징, IEEE 802.11 주석 태그가 포함되어 있습니다.

## 스캔한 문서

스캔한 페이지는 텍스트가 인식되기 전까지 검색할 수 있는 텍스트가 없습니다. [스캔한 페이지에서 텍스트 검색 및 선택하기](scanned-pages.md)를 참조하십시오.
