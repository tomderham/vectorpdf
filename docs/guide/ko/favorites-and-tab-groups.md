# 즐겨찾기와 탭 그룹

## 즐겨찾기

즐겨찾기를 사용하면 자주 사용하는 PDF를 손쉽게 열 수 있습니다.

- **현재 PDF 추가 또는 제거하기:** Favorites > Add This PDF to Favorites를 선택하거나 ⌘D 키를 누릅니다. ⌘D 키를 다시 누르면 제거됩니다.
- **즐겨찾기 열기:** Favorites 메뉴에서 해당 항목을 선택한 다음 Open을 선택하거나, Start 화면에서 해당 항목을 클릭합니다.

문서 제목이나 도구 막대의 빈 부분을 오른쪽 클릭해도 같은 명령이 즐겨찾기 및 탭 그룹과 함께 나타납니다.

## 탭 그룹

탭 그룹은 프로젝트의 사양서처럼 윈도우 하나에 탭으로 함께 열리는, 이름이 지정된 문서 세트입니다.

### 그룹 저장하기

1. 문서를 윈도우 하나에 탭으로 엽니다.
2. Favorites > Save All Open Tabs as a Group을 선택합니다.
3. 이름을 입력한 다음 Save를 클릭합니다.

### 그룹 열기

Favorites 메뉴에서 그룹을 선택한 다음 Open을 선택하거나, Start 화면에서 그룹을 클릭합니다.

### 그룹 변경하기

그룹을 열고 탭을 추가하거나 닫은 다음 Favorites > Update Group “이름” with Open Tabs를 선택합니다. “이름”은 그룹의 이름입니다.

### 그룹 삭제하기

Favorites 메뉴에서 그룹을 선택한 다음 Delete Tab Group을 선택합니다. Start 화면에서 그룹을 삭제하거나 즐겨찾기를 제거한 경우 나타나는 메시지에서 Undo를 클릭하면 취소할 수 있습니다.
