# PDF 색상 변경하기

VectorPDF는 macOS의 화면 모드와 관계없이 문서 페이지가 표시되는 방식을 변경할 수 있습니다. 어두운 방에서 읽을 때 유용합니다. PDF 자체는 변경되지 않습니다.

View > PDF Color를 선택하거나 [Settings](settings.md)의 PDF Color 설정을 사용한 다음 하나를 선택합니다.

- **Follow System:** 페이지가 macOS의 화면 모드를 따릅니다.
- **Light:** 페이지가 문서에 정의된 대로 표시됩니다.
- **Dark:** 색조를 유지한 채 페이지 색상을 반전하므로 도표와 하이라이트를 계속 알아볼 수 있습니다.
- **Sepia:** 페이지가 따뜻한 종이 색조로 표시됩니다.

프린트하거나 내보낼 때는 문서의 원래 색상이 사용됩니다.
