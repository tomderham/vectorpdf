# 하이라이트, 밑줄 및 취소선

## 선택한 텍스트 마크업하기

텍스트를 선택한 다음 다음 중 하나를 수행합니다.

| 마크업 | 메뉴 | 단축키 |
| --- | --- | --- |
| Highlight | Edit > Highlight Selection | ⇧⌘H |
| Underline | Edit > Underline Selection | ⇧⌘U |
| Strikethrough | Edit > Strikethrough Selection | ⇧⌘X |

Markup 도구 막대의 버튼을 사용하거나, 선택 영역을 오른쪽 클릭하고 Highlight, Underline 또는 Strikethrough를 선택할 수도 있습니다. 각 항목에는 색상 목록이 있습니다.

## 색상 선택하기

Markup 도구 막대(⇧⌘A)에는 색상 버튼이 있습니다. 버튼을 클릭한 다음 색상을 클릭합니다. 단축키와 도구 막대 버튼은 여기에서 선택한 색상을 사용합니다. 특정 마크업에만 색상을 지정하려면 오른쪽 클릭 메뉴의 색상 목록이나 Edit 메뉴의 해당 항목 아래에 있는 색상 목록을 사용합니다.

## 마크업 제거하기

방금 만든 마크업을 되돌리려면 Edit > Undo를 선택하거나 ⌘Z 키를 누릅니다.

표시한 텍스트를 오른쪽 클릭한 다음 Remove Highlight, Remove Underline 또는 Remove Strikethrough를 선택합니다. 또는 Markup 도구 막대에서 지우개를 선택한 다음 제거할 마크업을 클릭하거나 그 위로 드래그합니다. 실수로 제거한 마크업은 ⌘Z 키로 되돌릴 수 있습니다.

## 마크업 요약하기

주석 목록을 얻으려면 File > Export Annotations Summary(⇧⌘E)를 선택합니다. Markdown 또는 CSV로 저장할 수 있습니다. [다른 포맷으로 내보내기](export.md)를 참조하십시오.
