# 확대/축소, 회전 및 페이지 레이아웃

## 확대/축소

| 원하는 작업 | 방법 |
| --- | --- |
| 확대 또는 축소하기 | ⌘+ 또는 ⌘− 키를 누르거나, 도구 막대에서 + 또는 −를 클릭하거나, 트랙패드에서 손가락을 오므리거나 벌립니다. |
| 정확한 비율 설정하기 | 도구 막대에서 퍼센트 값을 클릭하고 10에서 1000 사이의 값을 입력한 다음 Return 키를 누릅니다. |
| 페이지를 실제 크기로 보기 | View > Actual Size (100%)를 선택하거나 ⌘1 키를 누릅니다. |
| 페이지 너비에 맞추기 | View > Zoom to Fit Width를 선택하거나 ⌘9 키를 누릅니다. |
| 페이지 전체를 맞추기 | View > Zoom to Fit Window를 선택하거나 ⌥⌘0 키를 누릅니다. |

Zoom In 및 Zoom Out 명령은 25%에서 400% 사이에서 작동합니다. 이 범위를 벗어나려면 퍼센트 값을 입력합니다.

VectorPDF는 이미지를 확대하는 대신 페이지를 다시 그리므로 어떤 배율에서도 페이지가 선명하게 유지됩니다.

## 100%의 의미

View > Define 100% Scale As를 선택한 다음 하나를 선택합니다.

- **Size on Screen Equals Size on Printout:** 100%로 표시한 페이지가 프린트했을 때와 거의 같은 크기로 나타납니다.
- **1 Point Equals 1 Screen Point:** PDF의 1포인트가 디스플레이의 1포인트를 차지합니다.

## 보기 회전하기 {#rotate-the-view}

도구 막대에서 Rotate Left 또는 Rotate Right를 클릭합니다. 이 작업은 화면에서 문서가 보이는 방식만 변경하며 저장되지 않습니다. PDF 자체의 페이지를 회전하려면 [페이지 재배열하기](pages.md)를 참조하십시오.

## Two-Page Mode

도구 막대에서 Two-Page Mode를 클릭하거나 View > Two Pages(⌥⌘2)를 선택합니다. 펼친 책처럼 표지는 한 페이지로, 나머지 페이지는 두 페이지씩 나타나며, 펼침면이 윈도우에 맞게 확대/축소됩니다. 되돌리려면 버튼을 다시 클릭하거나 View > Single Page를 선택합니다.

> **참고:** 보기가 회전되어 있거나 Two-Page Mode일 때는 텍스트를 선택하거나, 링크를 따라가거나, 마크업 및 측정 도구를 사용하거나, 양식을 작성할 수 없습니다. 이러한 기능을 사용하려면 회전을 해제하고 Single Page로 돌아갑니다.
