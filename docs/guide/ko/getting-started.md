# VectorPDF 시작하기

VectorPDF를 사용하려면 Apple 실리콘이 탑재된 Mac과 macOS 15 이상이 필요합니다. 설치하려면 VectorPDF를 응용 프로그램 폴더로 드래그합니다.

## 첫 번째 PDF 열기

문서 없이 VectorPDF를 시작하면 Start 화면이 나타납니다. 다음 중 하나를 수행합니다.

- PDF를 드롭 영역으로 드래그합니다.
- 드롭 영역을 클릭한 다음 파일을 선택합니다.
- ⌘O 키를 누릅니다.

Finder에서 [Open With](open-documents.md)(다음으로 열기)로 PDF를 열거나 Start 화면의 Tab Groups, Favorites 또는 Recent Documents에서 PDF를 선택할 수도 있습니다.

## 먼저 해 볼 만한 다섯 가지

1. **링크 위에서 Command 키를 길게 누르기.** 수식, 그림, 표 또는 인용 참조 위로 포인터를 이동한 다음 ⌘ 키를 길게 누르면 [대상을 미리 볼 수 있습니다](link-peek.md). 키에서 손을 떼면 미리보기가 닫힙니다.
2. **검색하기.** ⌘F 키를 누릅니다. [검색 결과](search.md)는 찾는 대로 사이드바에 나타나며, ⌘G 키를 누르면 결과를 차례로 이동할 수 있습니다.
3. **위치 저장하기.** 텍스트를 선택하고 ⌘B 키를 누르면 나중에 바로 돌아올 수 있는 [앵커](anchors.md)가 생성됩니다.
4. **마크업하기.** 텍스트를 선택하고 ⇧⌘H 키를 눌러 [하이라이트](text-markup.md)하거나, ⇧⌘A 키를 눌러 Markup 도구 막대를 표시합니다.
5. **관련 문서 두 개를 탭으로 열기.** ⌥⌘O 키를 눌러 두 번째 문서를 연 다음, “Section 4.2 of the Master Agreement”와 같은 일반 텍스트 참조를 오른쪽 클릭하면 [다른 탭에서 참조 대상을 찾을 수 있습니다](cross-document-references.md).

## 둘러보기

메뉴 막대, 사이드바, 도구 막대에서 대부분의 기능을 사용할 수 있으며, 오른쪽 클릭하면 포인터 아래에 있는 항목에 맞는 명령을 사용할 수 있습니다. 전체적인 안내는 [VectorPDF 윈도우](the-window.md), 각 메뉴의 내용은 [오른쪽 클릭 메뉴](right-click-menus.md), 전체 목록은 [키보드 단축키](keyboard-shortcuts.md)를 참조하십시오.

이 설명서를 검색하려면 사이드바 상단의 ‘이 설명서 검색’ 필드를 사용합니다. 이 윈도우 상단의 검색 필드는 모든 앱의 도움말을 검색합니다.
