# Move around a document

## Scroll and turn pages

Scroll with your trackpad or mouse. VectorPDF lays out only the pages near where you're reading, so very long documents stay fast.

From the keyboard:

| Keys | Action |
| --- | --- |
| Left Arrow, Right Arrow | Previous or next page |
| Up Arrow, Down Arrow | Scroll within a page that's taller than the window, then move to the next page. If the page fits in the window, move a page at a time. |
| Page Up, Page Down | Scroll a larger step, then move to the next page |
| Space, ⇧Space | Forward or backward, the same as Page Down and Page Up |
| ⌥Up Arrow, ⌥Down Arrow, ⌥Left Arrow, ⌥Right Arrow | Previous or next page |
| ⌘Up Arrow, ⌘Down Arrow | First or last page |

In Two-Page Mode, these keys turn a whole spread.

## Go to a page

Click the page number in the toolbar, type the page you want, then press Return. Press Escape to cancel.

Some documents name their own pages, such as `iv` for front matter or `A-101` for a drawing sheet. VectorPDF then shows that label in the toolbar, the page indicator and the thumbnails, with the page's position beside it, as in `iv (4 of 300)`. Type a label to go to that page. If a label is used more than once, you go to the next page that has it. To go to a page by its position, type `#` and the number, such as `#13`.

Print and Split PDF always count pages by position, from the first page of the file.

## Go back to where you were

After following a link or jumping to a result, choose Go > Back (⌘[) to return. Go > Forward (⌘]) takes you the other way.
