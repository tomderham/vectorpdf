# VectorPDF User Guide

for macOS

VectorPDF is a fast PDF reader for technical papers, specifications, contracts and drawings. Hold Command over a reference to see what it points to, without losing your page. You can also mark up, measure, redact and reorganize PDFs, all on your Mac.
